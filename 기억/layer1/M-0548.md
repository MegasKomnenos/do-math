B132가 역할 입력의 생성 메타데이터를 닫은 뒤, DOC-RETURN-ROLE 가운데 restore_continuation의 결과·반려 응답·이전 출력 파일을 한 독립 문맥에서 구현했다. 기존 multihop 시험은 stage의 result_source와 최신·유지 출력 파일을 실제로 복원했지만 rejected_response를 만들지는 않았다. 기존 정상 호출과 활동 경계·순환 거부 단언을 그대로 두고, 같은 함수에 repair.raw_output_ref를 주는 호출을 추가해 반려 원 응답을 실제 파일로 복원했다. 큰 _context나 문서 구조 검사에서 엔진을 새로 실행할 필요는 없었다.

수정 전에는 기존 구조 시험의 field_schemas/scoped_field_issues만 사용해 실제 결과 없는 세 소유자를 거부해야 한다는 단언을 넣었다. 직접 경로와 줄 안 별칭의 여섯 하위단언이 ValueError not raised로 실패했고, import나 새 인자 오류는 아니었다. red는 시험 한 개, 1.8초, 실제 종료 코드 1이었다. 이어 restore_continuation의 네 AST 추출과 previous_file 조립을 제거했다. 실제 결과가 없으면 기본 거부하며, 다른 경계 시험은 자신이 제공하지 않는 소유자만 명시적으로 보류한다.

실제 continuation_history의 결과와 반려 응답, previous_output_files의 공통 키를 소유자별로 따로 구한다. 한 단계나 한 출력 항목의 local_path만 지워도 나머지 항목·다른 소유자의 키로 보완되지 않는다. doc_code.documents()의 전체 원문을 검사했고, 공통-실행의 31·45·49행과 지식-저작과-재사용의 25행이 설명하는 경로를 이 결과에 연결했다. 정상 별칭, 필드 삭제, 빈 출력 목록, 반려 응답이 없는 정상 분기, 결과가 없는 선택 분기, 키 차용과 배열 오용을 확인했다. 범용 재귀 스키마나 새 AST 데이터흐름 추론기는 만들지 않았다.

local_path가 가리키는 실제 임시파일을 읽어 원래 바이트·sha256·길이·snapshot을 대조하고 최신 lemma와 유지 keep 파일의 execution_id·artifact_ref를 확인했다. 기존 stage 순서·체크포인트·바이트 단언과 owner activity 불일치·계보 순환 거부도 유지했다. 이 시험의 저장 읽기는 snapshot에 귀속된 archive callback 대역이다. 실제 임시파일 복원을 입증하지만 실제 Git 게시나 과거 결과의 수학적 완결을 검증한 것은 아니다. stored_file과 materialized_output_files 등 _context의 살아 있는 다른 결속은 바꾸지 않았다.

최종 관련 검증은 구조 18개·단위 6개·CLI 경계 4개, 모두 28개가 304.2초에 통과했고 실제 종료 코드는 0이다. complete/successful은 true이고 changed_during_run은 비어 있다. 소프트 시간 기준을 넘은 시험 10개를 보존하며 중단·범위 축소·전체 재실행으로 처리하지 않았다. 원보고는 추적되는 docs/do-math/시험-재편-2026-09-29/검증/2026-10-06-복원-실제반환의 red.json·green.json에 바이트 그대로 보존했다. .skill-workspace 아래 원보고와 렌더러는 로컬 보관이며 정리로 사라질 수 있다. 보고서 해시와 원경로는 작업판 JSON의 current_work.continuation_document_binding에서 확인한다.

이번에 닫은 것은 result_source·rejected_response·previous_output_files 세 소유자다. DOC-RETURN-ROLE은 partial_complete로 유지했고, profile_selection 역할 본문과 CoreEngineMixin._context는 남겼다. 다음 단위는 공통-실행의 profile_selection.allowed_profiles와 기존 candidate population 시험의 prepare_role_input 반환을 먼저 대조하는 한정 작업이다. 관련 28개 통과를 전체 일반·T3·13-C·ROLE 전체 완료로 확대하지 않는다.
