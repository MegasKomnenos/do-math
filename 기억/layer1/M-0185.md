Semantic Scholar의 문헌 이름·링크·식별자, 공개 PDF 조건, 원 BibTeX와 범위별 참고·피인용 조회를 보완했다. 공통 검사 171개가 통과했다. 신규 실서비스 흐름은 첫 검색의 호출 제한으로 미완료이며 대역 검사 통과와 구별한다.

공식 API 문서는 정적 본문이 짧았지만 redoc의 spec-url이 /graph/v1/swagger.json을 가리켰다. 그 명세에서 openAccessPdf가 값을 받지 않는 존재 필터임을 확인했다. 기존 false 전달도 필터를 켤 수 있었으므로 true일 때만 전달하고 false/null은 뺀다. 이름 조회는 공식 plain-text 검색의 하이픈 제약에 맞춰 공백으로 바꾸되 원 이름도 남긴다. 사용자가 작성한 명시적 search query는 그대로 전달한다.

문헌 URL과 DOI·ARXIV·PMID·CorpusId 별칭은 응답 ID와 대조한다. 기본 문헌 조회에 전체 참고·피인용 배열을 붙이지 않고, 나가는 참고문헌은 supplementary로 요청할 때 회수한다. 참고·피인용의 임의 범위는 search의 kind로 고른다. 원 offset과 next를 확인하고 null paperId를 가진 인용 항목도 보존한다. 후속 페이지가 제한되면 이전 참조·원 count·실패·재개 위치를 유지한다. 피인용 전체를 기본 문헌 조회에서 자동 수집하지 않는다.

원 citationStyles.bibtex의 문자열을 보존하고 한 문헌으로 파싱되는지와 제공되는 DOI를 대조한다. 공식 명세의 예시에도 일반 BibTeX 형식이 아닌 entry type 표기가 있었으므로, 잘못된 원 형식을 임의로 고치지 않고 원 파일을 source_export에 남기는 검사도 추가했다. 원 검색 record fixture를 사용했지만 관계 응답과 BibTeX의 이번 검사는 대역 구조에 근거한다. 실제 새 API 응답을 확보한 것으로 표시하지 않는다.

최근 공개 검색이 한 번 성공했어도 다른 후속 요청은 계속 429였다. 최소 metadata 재조사는 429 뒤 추가 관계 요청 없이 끝냈다. 새 실제 MCP는 data/validation/20260910T103916Z-semantic-scholar-mcp.json에서 첫 검색부터 rate_limited였고 completed=false다. 별도 API 키를 요구하거나 다른 자료원으로 자동 전환하지 않았다. 정확한 지원·검증 범위는 services/scholarly-mcp/SUPPORT.md와 VALIDATION.md가 소유한다.

다음에는 AMS·ScienceDirect·JSTOR·IOP·APS 기관·SIAM의 남은 검색과 원 형식 등, 아직 접근 또는 구현 검증이 끝나지 않은 경로를 재점검한다. 기존 사용자 설정·연구 자료는 건드리지 않는다. 전체 완료 전이므로 푸시하지 않는다.
