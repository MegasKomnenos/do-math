g02의 156개 시험 판본 이후 세 가지 실제 결함을 수리한 166개 시험 판본을 보존한다. 첫째, shard1이 결과 임시 파일을 JSON으로 교체하는 중 Windows PermissionError로 종료됐다. 작업자는 기존·임시 결과를 각각 보존하고 동일 ID, 기존 증거·시도 유지, 추가 시도 1개와 증거 2개, 공통 결과 검사 오류 0건을 대조해 임시 결과를 복구했다. 원자 교체는 PermissionError만 최대 6회, 총 대기 3.1초 안에서 다시 시도한다. 영구 실패 때 기존 JSON과 임시 파일을 모두 유지하며 다른 파일시스템 오류는 재시도하지 않는다. 세 실패·성공 회귀와 실제 두 문헌 pilot을 통과한 뒤 생산을 재개했다. 파일 잠금의 주체는 확인되지 않았으므로 단정하지 않는다.

둘째, 실제 본문이 한국어 '불러오는 중...' 한 줄인 페이지를 content/done으로 저장했다. 영어 Loading과 De Gruyter 초기 화면 검사는 있었지만 이 한국어 형식이 빠졌다. 해당 source의 원문은 아직 unresolved여서 거짓 부재 판정은 확인되지 않았다. 실제 형식의 실패 시험과 준비 완료 대기를 추가한 뒤 1186건 재판정에서 영향 77작업을 retry로 다시 열었다. 실제 EBSCO 출처 6개가 초기 한 줄에서 정상 책 상세로 바뀌는 것을 확인했다. 이 단계는 서지·초록 표시의 준비 완료이며, 이용하기(eBook) 버튼 뒤 reader와 다운로드는 별도의 남은 작업이다.

셋째, Ross1996 Stochastic processes 책에 Wells의 서평 안내 한 문장이 초록으로 붙었다. 실제 Summon 문서는 Book Review·Review, JASA91(436),1754–1755,DOI10.2307/2291619였다. 제목·책 저자·연도가 겹쳤고 유형 검사에서 book 부분 문자열을 사용해 Book Review도 책으로 통과했다. 전수 영향은 Ross와 Linear Algebra 두 문헌의 독립 서평 출처 작업 8개였다. Book/eBook 및 수록 장의 실제 양성과 Book Review·혼합 서평 태그의 음성을 검사했다. reviews라는 단어 일반 거절은 하지 않고 정상 'This paper reviews...'를 양성으로 유지했다. 문제의 한 문장 안내는 해시에 결박한 직접 판독으로 철회했으며 원값과 출처·이력을 남겼다.

루트도 같은 실제 서평을 다른 두 수집기의 함수에 넣어 잘못된 수용을 재현했다. 동일 서평의 4개 관측 행이 g05.document_matches와 g08.response_documents에서 책으로 통과했다. g08에는 입력 규격에 맞게 pages 배열을 공백 결합 문자열로 바꾼 것 외에 서지 의미를 바꾸지 않았다. 최소 고정 반례는 operator/book-review-type-counterexample-0670a8a69c484523.json에 보존했다. 이후 g05와 g08의 담당 자료 조사에서는 해당 Book Review 오수용 행이 각각 0개였다. 함수의 잘못된 수용과 담당 결과의 실제 오염 수를 구별한다. 두 작업자는 자기 형식의 TDD 수리를 계속한다.

Book Chapter는 별도 경계다. g02가 확인한 Poncelet’s theorem은 Book Chapter 태그에도 제목과 publication_title이 같고 목표 책 ISBN9780821843758과 일치하며 장 DOI·페이지·초록이 없는 전체책 서지 형태였다. 따라서 태그 하나로 후보를 전부 버리지 않는다. g05·g08은 책의 자동 승인과 이런 책 서지의 출처 후보 발견을 구별하는 인계를 마련한다. 실제 장의 초록을 전체책 초록으로 승격시키거나, 반대로 태그만 보고 필요한 책 출처를 없애지 않도록 관측 범위를 유지한다.

이 세 수리의 전체 회귀 166개와 1200건 저장 재판정·부분검사가 통과했다. 실제 pilot에는 한국어 초기 화면과 정식 Moonshine 원문 경로도 포함된다. 작업자는 Moonshine의 공식 EMS PDF 10쪽에서 인쇄 607–615의 본문·참고문헌과 빈 616쪽을 확인하고 원문 found로 적용했다. 기존 arXiv v1 후보와 출판본을 구별했다. 두 생산 manifest는 20260908T232335Z-20148과 20260908T232554Z-45720이며 루트는 각 시작파일 72개의 현재 SHA와 새 인증 재사용을 확인했다. 수정 목록 21개와 고정 fixture2개의 해시도 대조했다.

이 커밋 준비 중 다음 CiNii 판독 수리가 시작돼 작업자가 수집을 정상 체크포인트에서 중단하고 새 코드·판독표를 썼다. 루트의 동결 요청을 받은 뒤 작업자는 그 다음 수리를 별도 pending 파일에 보존하고 166개 시험 당시 바이트를 정확히 복원했다. 따라서 이 커밋은 166개 시험 판본이며 다음 수리가 들어갔다고 주장하지 않는다. 커밋 뒤 새 수리와 실제 reader 조사를 이어간다. 전체 6,101건 수집은 여전히 진행 중이다.
