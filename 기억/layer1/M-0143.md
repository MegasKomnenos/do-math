세 신규 작업자의 수집이 계속되는 동안 확인한 인증 상태, 정상 브라우저 경로와 내용 판정 기준을 중간 보존한다. 전체 6,101건의 회수 완료 기록은 아니다. g02는 기존 870건 이후 미처리 구간을 실제로 진행하기 시작했고, g05·g08은 원문 후보 판독과 새 출처 회수, 상태 재판정을 수행 중이다. 네 디렉토리의 신규 작업자는 앞선 배정이 검증 완료돼 슬롯이 열리면 파견한다.

루트는 새 브라우저 context의 KUDOS 화면에 로그인 링크만 있고 로그아웃이 없는 실제 만료를 확인했다. 보호된 자격 파일을 런타임에 읽어 정상 로그인하고 bootstrap을 원자 갱신한 뒤 다른 Chrome·Firefox context에서도 로그아웃 표시로 재사용을 검증했다. 작업자는 정상 작동 중인 출판사 context를 유지하고 새 인증이 필요한 경우 갱신 상태를 사용한다. 인증 만료 자체를 개별 문헌의 제공 제한으로 기록하지 않는다.

ScienceDirect는 같은 정상 KUDOS 연결에서 Chrome이 CPE00001을 표시했지만 기본 Firefox153에서는 정상 홈페이지가 열렸다. 최초 Firefox의 빈 Loading 중계 화면은 정상 도착으로 세지 않았다. 실제 main frame의 검색 입력과 본문을 비교한 결과를 shared-findings와 비추적 operator 증거에 보존했다. CPE의 정확한 원인은 확인하지 않았으므로 기관의 구독 부재라고 단정하지 않는다. 개별 기관 경유 PII는 Firefox에서도 CPE가 발생했으나 공개 PII 상세는 일부 문헌에서 정상 작동했다. g05는 Max-SAT2025의 공개 초록을 MathML을 보존한 HTML로 확보하고 실제 렌더에서 중첩 지수 등을 확인했다. 같은 경로의 다른 문헌은 CAPTCHA였으므로 이 성공을 전건에 복제하지 않는다.

루트는 공개 ScienceDirect의 필요한 쿠키만 수락하고 정상 조직 접근 링크를 따라 Elsevier에서 정확한 Kyungpook National University를 선택했다. 다음 단계가 기관 이메일을 요구했다. 보호된 자격 파일에는 이메일이 없어 주소 또는 저장 경로를 사용자에게 비동기로 질문했다. 이메일은 제출하지 않았고 이 분기만 응답 대기다. 다른 공개 출처·자료 판독·수집기 수리는 계속한다. 링크의 눈에 보이는 문구에 NBSP가 있어 일반 공백 정규식이 실패했지만 실제 aria-label의 정확한 role link로 클릭할 수 있었다. 동의창은 이후 Elsevier 화면에도 별도로 나타났다.

초록의 수집 범위는 저자 원문초록과 출처가 선택해 제공한 완결 요약을 구별한다. 루트는 Tsay2010 제 3판의 MathSciNet Publisher's description이 주제·방법·개정 내용을 완결되게 요약한 것을 읽었다. 반면 Tropical intraseasonal variability2019의 짧은 문구는 대상 독자와 관심 분야 안내뿐이어서 추가정보로 남겼다. 길이 또는 표제만으로 판단하지 않는다. Dynamic modeling의 MR0733454는 실제 Review 절이지만 독립 평가문 없이 From the text로 시작하는 완결 요약 인용 전체를 제공한다. 이 사례는 database_selected_summary로 포함하되 원 절 표제·문구 출처·인용 경계·저자 원문초록 미확인을 보존하도록 공통 계약을 보완했다. 일반 서평·목차·잘린 발췌를 초록으로 올리는 허용은 아니다.

루트는 새 완료 후보 Methods of summation1987의 실제 resolver 본문과 MR 리뷰도 대조했다. resolver는 이용가능한 전자자료가 없다고만 했는데 g02가 이 문구를 트래픽·구독 제한과 같은 정규식에 넣어 restricted 및 unavailable로 처리했다. 제공 경로의 부재와 접근 제한을 분리하는 실물 회귀 수리를 g02에 돌렸으며, 같은 규칙으로 닫힌 완료 결과도 저장 증거에서 재판정하도록 했다. 일치 CiNii 응답의 관측 URI가 출처 목록에 빠진 이유도 함께 확인하도록 했다. 해당 MR 본문에는 실제 서평자의 설명·평가가 있어 전체를 초록으로 올리지 않은 판단은 유지한다. 이 커밋 시점에 수리는 작업자 진행 중이며 공통 검사기 통과가 이 의미 오류를 자동 검출했다는 주장은 하지 않는다.

EBSCO의 Mallat1999 전자책은 상세의 실제 이용하기 버튼을 통해 638쪽 뷰어까지 열렸다. 입력은 1998년판이므로 이 화면을 대상 판본의 확보로 세지 않는다. 루트는 다른 정확한 판본 자료에도 재사용할 정상 전체 다운로드 절차를 조사 중이며 결과 파일은 담당 작업자가 소유한다. 전체 다운로드에 전용 리더가 필요하다는 안내와 챕터 PDF 40쪽 제한을 구별하고, 제한을 나눠 우회하는 수집은 하지 않는다. 관측 URL로 뷰어를 직접 열면 영문 제어가 나타나고 처음에는 책 제목·목차가 아직 없을 수 있으므로, 버튼 또는 dialog의 존재만으로 준비·다운로드 성공을 판정하지 않는다.
