승인·권한·위임·근거 현재성을 다루는 후보28모듈의302개 새 사례와 정상 생산자 도우미를 main에 통합했다. [[M-0460]]의 저장 가족은478c2a47로 확정했다. B45는 제품 동작을 바꾸지 않고 해당 시험 모집단을 검수하여 연결한다.

새 단위 시험은 decision/basis/checker lineage, delegation/grant 범위와 출처, 외부 case identity, import 좌표와 봉인, 질문/기록/개정/교체/rework/semantic check의 정확 반려와 불변을 검사한다. 정상 실제 해석 생산자의 결과를 실제 Repository에서 읽고 복사한 한 필드를 손상시킨다. 정확한 ValueError 문언만 인정하고 저장된 이전 head의 상태가 그대로임도 확인한다. 단순 예외 발생이나 필드 개수로 통과하지 않는다.

새 sim 시험은 추가 감사의 승인 input hash와 verdict mapping, 초기 승인·헌장/configuration 전이, 후속 사건/질문/currentness, 실제 host resource 선택, owner 적용, task scope와 위임 effects를 포함한다. grant의 시작1μs 전/정확 시작/만료1μs 전/정확 만료를 FakeClock으로 비교한다. 정상 grant 기본값 생산 후 proposal을 변경해도 저장 grant가 바뀌지 않는 분리 계약도 검사한다. 복합 plan/model allowed profile과 완료 뒤 미처리 사용자 입력 질문의 보존을 실제 engine 수신자로 검증한다.

governance_cases의 기존 다섯 생산 함수는 AST로 후보와 일치함을 확인하여 그대로 두고 새 정상 생산 함수만 추가했다. policy/context/additional audit는 governance.apply_decision과_save를 거친다. auditor는 실제 등록·종료와_governance_context 입력 봉인을 거친다. review 질문은 unresolved 원 응답을 수신하고 정확 Lean 사실 전건을 제공한다. 최초 승인은 공개 제어 생산자의 전후 원 상태/승인/source를 반환하며, 양도는 실제 두 과제·작업 결과·사용자 transfer 결정과 독립 계획 실행을 저장한다. 별도 sim.restart/engine_lifecycle/governance_sim 차이는 이 범위에 필요하지 않아 복사하지 않았다.

kvxth__2는 기존/새 unit276·sim160·flows4의440개가231초에 모두 완결 통과했고 실행 중 변경은 없다. wildcard는전체ID에 적용되며 보고의 실제 모집단이 선택 정본이다.188개 개별 예산 초과를 보존한다. 새 unit에도 실제 저장 상태의 준비·복원 비용이 있으므로 값싼 순수 시험이라고 잘못 분류하지 않는다. 구조 gsxqcqb4의6개도 통과했으며 smell8.562초는5초를 넘었다. 보고 전문 경로·SHA256·파일 지문은 단계-전환표 current_work.governance_population_integration에 연결한다.

이 통과는 최종 동일 판본 T2/flows/T3·분기·모든 함수 극단변이·시간예산의 성공 증거가 아니다. 승인 가족만231초라는 실제 결과는 전체T2 300초 기준을 별도로 개선해야 할 근거다. 시험 축소·단언 약화·제품 판정 대역화로 시간을 맞추지 않는다. 남은 기능 가족을 통합하고 원1e19/1f61/P2원래12/여섯 부류·2단계11의무와 최종 관문/최소T4/T5·말뭉치를 이어서 완료한다.
