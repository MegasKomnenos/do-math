## 맥락

사용자는 do-math 전체에 표준 verify-rounds를 두 번 요청했다. 첫 라운드는 Opus 5.5 수리와 GPT-6.1 Sol 심사, 둘째는 Astra 전용이다. 매 라운드 시험의 문제를 고치고 기각·무처분은 세션이 판단하도록 위임했다. 이 커밋은 첫 라운드다. 지속 기록은 `임시/do-math_검증_2026-11-05/동결.md`와 `장부.md`다.

41파일 9672행을 문서·실행기·시험의 세 영역과 전건 연결 관점으로 나누었다. Claude Agent 도구가 없어 같은 모델의 CLI로 실행했다. 관점 기의 첫 호출은 provider 안전 분류기 중단으로 산출이 없었고, 동일 파견 재시도로 전건 독해를 마쳤다. 8항목 중 5항목의 수리를 세 Sol 심사자가 모두 승인했다. 설정 구조 오류, 제외 후보의 concern 문서, Claude 모델 거절 회귀, fake Lean 옵션 설명, lease 시험 파이프 처리를 고쳤다.

## 터득한 것

조각 없는 손상 후보 복구 제안은 세 심사자가 모두 인정했다. 원 해시가 바뀐 candidate를 같은 task로 무한 재검토하던 경로다. 공식 무처분으로 기록한 뒤 사용자의 위임에 따른 통상 편집으로 고쳤다. peer output이 원 해시와 같으면 새 위치에 복원하고, 아니면 원 연구와 앞 peer 작업으로 새 후보를 만든다. 손상 바이트와 원 리뷰는 보존하고 새 후보는 다시 독립 검토한다. 기존 취소 review 작업과 충돌하지 않도록 peer별 review 작업 ID를 쓴다. 두 복구 시험은 구 구현에서 실패하고 새 구현에서 실제 게시까지 통과했다.

기각 둘은 유지했다. 루트 해결 뒤 무상한 형식화는 `docs/do-math/rebuild-design.md`의 명시된 사용자 결정이므로 임의로 끊지 않았다. 사용처가 없는 MCP 프로브의 용도 설명은 검증 실행을 주장하지 않으므로 거짓 약속이 아니었다.

기준선 153개, 수정 뒤 전체 156개 시험이 통과했다. 전체 시험이 찾은 브로커 재시작 fixture의 Popen 경고를 수정했고 해당 시험은 경고 검사 활성 상태에서 통과했다. 문서 독해와 미러 드리프트 검사도 통과했다. 원시 파견·시험·독해 로그는 Git 제외 로컬 자료이고, 런의 앵커와 라운드 디렉토리는 둘째 라운드 종료 후 정리될 예정이다. 기각 원문은 추적된 기각보관 파일에 남긴다.
