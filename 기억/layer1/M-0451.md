## 실제 수신 실패와 함께 바꾼 계약

[[M-0450]]의 반환 정산 수리는 504a1470으로 확정했다. 이번 B35는 원 KD-0900~0903과 이미 B32가 수리한 보고 KD-1300의 회귀를 main에 통합했다. nsl6z3du에서 네 native/raw/재전달/종결·개정 리뷰 회귀가 실제 실패했고, 공개 revoke가 만든 과제 없는 권한 대기의 보고 회귀는 이미 통과했다. 보고를 새 제품 실패나 이번 새 수리라고 주장하지 않는다.

live JSON 해석은 strict_json_loads를 사용하여 비객체·중복 키·비유한 수를 반려한다. 원 raw bytes는 그대로 보존하고 unparsed_observation을 tracker가 ValueError 형식으로 처리한다. 리뷰 message/item/content/text/role의 잘못된 형은 지정 ValueError로 반려하며 owner가 그 반려를 실제 observation_fact로 게시하여 같은 batch의 다음 정상 행까지 처리한다. 종결 또는 공개 개정된 리뷰에는 지연 메시지를 쓰지 않고 반려하며 다른 실행은 계속 진행한다. 정상 공개/비공개 블록, 도구 자료, 소수와 큰 정수 및 공급자 raw row는 유지한다.

행 수신의 execution/event_index/offset/raw SHA256으로 안정된 artifact_ref와 수신 이력을 만들고, observation_receipts와 observation_fact_sequence를 실행 스키마에 등록했다. 같은 행과 새 tracker의 재전달은 이미 소비한 자료를 다시 기록하지 않는다. 반려도 소비하며 message ID 충돌의 양 순서와 뒤늦게 온 행의 반려 뒤 후속 입력을 검사한다. CAS 실패에서는 runtime과 tracker를 돌려 다음 동일 입력을 다시 받을 수 있는 기존 트랜잭션을 유지한다.

## 원 후보의 멱등성 공백을 추가로 수리

79xta1p6의 원 회귀와 정상 저장 8개가 통과한 뒤, 코드 검토에서 뒤 행을 소비한 후 앞쪽 이미 소비한 행을 재전달하는 순서를 추가했다. elxvdtto에서 이 순서가 저장 stream 커서를 뒤로 돌리는 실제 실패였다. 행별 이력은 중복을 막아도 stream 투영이 무조건 batch.end_offset을 따르던 원인이다. cursor를 이전 값과 batch 값의 최댓값으로 유지하는 수리를 main과 후보에 함께 반영했다. vrawhxmt의 강화한 원 멱등성 시험이 통과했다. 새 감사 문서나 단일 원인 시험을 늘리지 않고 같은 시험의 빠진 순서를 보완했다.

## 검증과 자료 이동

xtaoh6co의 현재 선택 10개와 o8tjsae6의 기존 관찰/공급자/리뷰 관련 99개가 통과했다. 관련 unit 두 개의 0.235초와 0.406초 예산 초과는 남긴다. raw 검사는 ADAPTERS 두 공급자와 OBSERVATION_MODES 세 모드 및 원시 오형태 일곱 종류의 42조합을 실제 worker/runner/owner/Repository로 실행한다. native 검사도 정상 setUp 대조, 정확 반려 한 번, 같은 batch 후속 처리, 빈 재순회, 충돌 양 순서, fresh tracker와 단조 cursor, 실제 저장 원상을 유지한다. 선택 수를 합산해서 전체 관문 성공으로 계산하지 않는다.

후보의 회차 이름 native_defects/storage 두 모듈은 현재 성질의 provider_native_inputs/provider_native_storage로 옮기고 이전 파일을 제거했다. main은 필요한 native 입력 세 정의만 공유하고 후보는 기존 단일 provider_close_inputs 정본을 유지하여 사본이나 호환 alias를 만들지 않았다. 후보 qy126xl6의 동일 선택 10개도 통과했다. main yfpj9bio의 원장/층/시험 냄새 6개가 통과했으며 기존 냄새 검사 5.140초의 5초 초과는 남긴다. 원 재현 ID는 원장 역사에 남기고 현재 reproduction은 현재 클래스/메서드로 연결한다. 보고 전문 경로·SHA256·실행 중 변경 없음과 열두 정본 파일 지문은 단계-전환표 current_work.native_input_integration에 연결한다.

## 남은 원문 범위

main 원장 43개와 후보 56개 중 미기록 13개는 전체 미구현 수나 완료율이 아니다. 이 native/raw 입구와 실제 보고는 2-A/13-B 모집단의 일부다. 다른 제어·제출·작업자 요청 입구와 입력 필드 추가 축의 일반 census, 모델 영수증/Lean 명시 등록 기반, 사건/반복/관찰 분류, 형식 Git 의미 포트와 원문 19/61/12/여섯 부류/11 전건을 남긴다. 동일 최종 판본의 전체 T2/flows, 재사용 없는 T3·극단 변이·예산, 최소 T4/T5와 말뭉치도 아직 완료하지 않았다. 다음은 정상 모델 영수증·Lean 명시 등록 기반 및 형식 Git 의미 포트와 설치/작업자 소비자 통합이다.
