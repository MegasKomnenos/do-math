# AGENTS 현행 지침의 조건을 보존하며 여섯 표현을 축약함

사용자는 `.agents/AGENTS.md`의 효과를 유지하면서 군더더기를 줄일 수 있는지 검토를 요청하고, 두 차례 재검토 후 제안 적용을 승인했다. 모델 선택, 규정·지침 정의, 과대응 방지 서술, 복창 의무 반복, 규정 목록의 포괄성 반복을 축약했다.

첫 모델 선택 축약안은 수행 가능성의 주체를 생략해 현재 모델이 작업을 할 수 있으면 경량 모델을 쓰라는 뜻으로 읽힐 여지가 있었다. 재검토에서 더 경량의 모델로도 작업을 충분히 수행할 수 있어야 한다는 조건을 복원했다. 조건문의 축약에서는 수행 가능성의 주체를 보존해야 한다.

교착 예방 예시, 짧은 답변에도 직접 적용되는 작문 품질 기준, 상시 보고 의무와 분석 대상의 범위는 유지했다. 문언상 의무 보존과 실제 모델의 준수 효과 동일성은 구별하며, 행동 비교 실험은 수행하지 않았다.

검토 시작 시 대상 파일에는 이미 미커밋 지침 개정이 있었다. 사용자가 제시하고 검토한 현행 파일을 기준으로 편집했으므로 그 기존 개정도 이 커밋에 함께 보존한다. 다른 파일의 기존 변경은 포함하지 않는다.
