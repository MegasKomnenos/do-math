사용자는 AMS·SIAM·Oxford 세 과제 외에는 정말 다른 해법이 남아 있지 않은지 질문했다. 주 세션은 세 과제 재개가 나머지 21개의 소진 판정 승인이 아님을 명시하고, 21개 반환의 방법 원장·성공 범위·미실행 사유를 선별 대조했다. 실행 가능 방법 빈 배열이나 completed 문구를 그대로 신뢰하지 않고 추가 공백 두 개를 원 근거로 확인했다.

De Gruyter DOI10.2202/1558-3708.1089의 원 crossref.json은 2003-01-11 발행이며 등록 생성은 2005년이다. 정확한 ZIP 보존 조회 wayback-asset.json의 year_queries는 2013–2026의 14개 연도뿐이었다. 문헌 HTML은 2003–2026을 조사했어도 원 ZIP의 해당 기간 조사를 대신하지 못한다. 2013 이전 파일 URL이 존재하지 않았다는 공식 이관 근거가 없으므로 보존 경로 소진을 그대로 수용하지 않았다. 2003–2012와 원래 플랫폼의 근거 있는 파일 링크를 확인하도록 같은 thread를 재개했다. 파일이 반드시 있다는 판정은 아니다.

Semantic Scholar는 batch/bulk/match/관계의 양성이 있지만 report에 relevance429와 full-parts batch429가 남았다. 마지막 03:05:39의 batch 성공은 최소 export-only였다. 이를 새 fetch의 metadata·abstract·supplementary 등 모든 parts의 실서비스 성공으로 일괄 확대할 수 없다. 현재 약속 필드와 live/mock 검증의 대조, 미검증 요청 조합, 기본 relevance와 bulk/match의 다른 의미를 명시하도록 재개했다. 외부 서비스의 미래 가용성 보장이나 헤더 없는 고정 10분 규칙을 요구하지 않았다.

실제 추가 지시는 services/scholarly-mcp/dispatch/remaining-20260913/reviews의 degruyter-broken-supplement.md·semantic-scholar-rate.md다. 실행 폴더 20260913T021511Z의 작업별 review-01.md에 같은 내용을 두고 review-requests.json에 고유 요청 ID로 추가했다. 운영기는 기존 프로세스 교체 없이 두 작업을 같은 thread에서 다시 시작했다. 두 과제의 attempt3·running을 확인했고 기존 세 과제와 합쳐 재검토 5개다. 최대 8·같은 자료원 순차·전용 사본 쓰기 계약을 유지한다.

21개 1차 대조는 dispatch/remaining-20260913/REMAINING-REVIEW.md에 보존했다. 수리 양성·별도 표본의 형식 부재·현재 권한 상태·원 서버 작업 미완료·추가 조사를 구별한다. 특히 SWH의 새 양성 작업은 원래 stuck 작업의 완료가 아니고, DBLP KG의 tsv_exact는 원 TSV 직렬화 수리가 아니며, IEEE의 MP4 parser 수리는 false Media flag 반례의 발견이 아니다. 다른 과제에도 독립 코드·범위·통합 검증이 남아 있다. 현재 재개 5개가 추가 공백의 닫힌 전체 목록이라고 주장하지 않는다.
