ACM 교정 뒤 사용자는 과거에 불가능하다고 판단해 기능을 줄인 사례를 현재 구현·과거 기록·잔여 문제 전체에서 조사하도록 했다. 이어 입력 직전과 실패 뒤의 화면을 직접 판독하고 요청·응답·로그를 시각에 결속해 실패 지점을 분석하도록 했다.49개 자료원의 정적 매트릭스를 만들었으며 제한 표현159곳은 결함 수가 아니라 조사 후보 수다. 이 커밋은 그중 공개 API 검색 창·파일 전달·기계 추출의 수리 단위다.

Figshare의 offset 최대5000을 전체 결과의 접근 한계로 해석한 코드는 틀렸다. 현 OpenAPI는 page 최대5000과 page_size 최대1000도 제공한다. 실제 offset5000/limit2와page2501/size2의 문헌 ID가 같았고, offset5002는400이지만page2502는200과다음2건을 반환했다. 원 API 페이지로 임의 구간을 선택하고, 여러 원 페이지와 정확한 records 범위를 따로 보존한다. 컬렉션 구성원 순회도5000에서 끊지 않는다. 기존의 버전별 컬렉션 구성원 API 부재와는 별개의 문제다.

GitHub·Zenodo의 start가 limit 배수여야 한다는 제한도 원 페이지 API를 감싼 구현의 제약이었다. 필요한 인접 페이지에서 요청한 구간을 선택하고 원 내보내기를 유지한다. 중간 페이지의 실패·중복·전체 건수 변화는 이미 확보한 결과를 partial로 남긴다. GitHub의 원1000건 한계와 incomplete_results는 보존한다. 임의 offset 지원과 제공자 자체의 결과 상한은 구별한다.

Figshare 공개 file5714205는 정상적인 native downloader에서 AIP가 아닌 S3 저장소로 전달됐다. 기존 코드는 첫 redirect 응답 뒤, 파일 서버로 요청하기 전 허용 경로 검사에서 source_boundary로 실패했다. 선택한 원 downloader/file ID가 실제 제시한 현재 S3 호스트의 파일에만 전달을 허용하며, 임의 S3 URL을 전역으로 허용하지 않는다. 원 크기·MD5 대조를 유지한다. 실제39,316바이트 파일을 받은 뒤에는 파일이 CIF인데 MIME이 octet-stream이라는 별개의 추출 문제가 드러났다.

이 파일의 첫 SDK는 다운로드와 checksum은 통과했지만 extract가 unsupported였다. 공통 extract는 이제 NUL 없는 유효 UTF-8 octet-stream을 줄로 읽는다. 원 MIME·바이트를 바꾸거나 CIF 의미를 해석하지 않으며, NUL·잘못된 UTF-8에는 문자 인코딩을 추측하지 않는다. 앞 실패 보고를 보존한 뒤 같은 파일1,045줄 중2줄 추출을 실제 SDK로 통과했다.

근거는 services/scholarly-mcp/data/access-research/limitations-audit/의 figshare-pagination-probe.json, figshare-pagination-sdk.json, public-window-sdk.json, figshare-default-file.json, figshare-file-sdk-before-text-extract.json, figshare-file-sdk.json과 VALIDATION.md다. GitHub6건·Zenodo15,833건의 처음4건과start1/limit2, Figshare start5000/5001/5002를 문헌 ID와 원 페이지로 대조했다. 관련59검사와 독립 API 검토가 PASS였으며, 직접 S3 요청·두 번째 외부 redirect 거부, BOM/CRLF 및 원 바이트 보존 반례도 확인했다.

별도 조사에서 Wiley의3행, PQDT의20값, Numdam의10조건 제한과 Scopus·MathSciNet의 정렬·필터 누락도 확인해 수리 중이다. Springer의 HTML 전문·공개 동적 문서·IEEE HTML과 Software Heritage의 Vault 없는 개별 파일 회수도 후속 단위다. AMS는 root가 입력 전후 이미지를 직접 판독했고, 입력이 유지된 정상 HTTP 요청 뒤 오류 message가 반환되어 화면이0건·undefined 정렬로 바뀐 사실을 확인했다. 이것을 정상0건이나 영구 불가로 해석하지 않는다. 전체 조사·구현은 계속하며 푸시하지 않는다.
