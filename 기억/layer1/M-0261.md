## 맥락

사용자는 기억의 모든 문서와 세칙, layer-3, 색인을 읽고 내용을 보존하면서 더 자연스럽고 쉽게 읽히도록 다듬으라고 요청했다. `write-for-reader`의 산문·AI 프롬프트·절차문 기준을 적용했다. 작업 중 별도 세션이 추가한 M-0260까지 포함해 276개 문서를 읽고 195개를 수정했다. 이후 사용자가 이 퇴고의 커밋을 요청했다.

## 수정과 보존

지나치게 압축된 명사 표현, 불필요한 대시, 문장 연결과 띄어쓰기를 고쳤다. 세칙의 긴 단계 설명을 나누고, 노드 제목이 바뀐 부분은 색인에도 반영했다. 과거 기록의 사실·판정·제안·미결정 상태를 구별하고, 당시 기록을 현재의 확정 규칙으로 바꾸지 않았다. 기억 구조와 규칙의 의미를 개정하는 작업이 아니므로 노드의 생성 버전과 세칙 버전은 유지했다.

M-0240~M-0242는 문단 대부분의 띄어쓰기가 빠져 있었다. 직접 띄어쓰기를 복원한 단계에서 공백을 제외한 원문과 수정문이 일치하는지 확인했다. D-0004에 남은 수정 전 문장의 인용은 과거 사례임을 드러내도록 시제만 맞췄다.

## 검증과 시사점

최종 퇴고본에서 숫자의 순서, 코드 표기, 노드 참조, Markdown 링크 대상과 고정 메타데이터가 수정 전과 같은지 대조했다. 파일 삭제는 없었고 색인 무결성 검사와 Git 공백 검사도 통과했다. 이 기계 검사는 의미 대조를 보조하며, 문장 의미의 동일성이나 모델 행동의 동일성을 자동으로 증명하지는 않는다.

낱말을 바꿀 때는 뒤의 조사와 더 긴 낱말의 일부인지도 함께 확인해야 한다. 이번 퇴고에서는 명사만 치환해 생긴 조사 불일치와 약어가 다른 낱말 안에서 확장된 부분을 재검토해 바로잡았다. 단어 치환 후 문장을 다시 읽는 단계가 필요하다는 구체적 사례다.
