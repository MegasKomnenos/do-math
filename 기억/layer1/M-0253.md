De Gruyter에서 DOI 없는 문헌의 인용을 일괄 제외하던 구현을 수리했다. 실제 ISBN9781447378938 책에는 원 RIS가 있었고, 현재 화면은 CITE 버튼으로 모달을 연 뒤 RIS를 제공했다. 기존 구현은 DOM 안에 숨은 RIS 링크가 있다는 이유로 바로 누르다가 실패했다. 독립 세션의 실제 제어 전후 이미지 판독과 root 원본 회귀로 이 로컬 오류를 확인했다. 가시 링크를 확인하고 필요하면 현재 CITE 제어를 여는 방식으로 고쳤다.

검색 결과에서 DOI 없는 행을 먼저 버리지 않고 문헌 URL·DOI·제목을 citation 함수에 넘긴다. DOI가 있으면 원 DOI를, 없으면 URL의 ISBN과 RIS SN을 대조한다. 공통 Publisher fetch가 빈 observed_dois 배열의 첫 원소를 접근하던 IndexError도 함께 수리했다. 두 원본 실패를 먼저 확인한 뒤 Publisher23검사가 통과했다. 기존 SIAM 기관 PDF와 Oxford 렌더 수리는 유지했다.

Root의 새 원본 stdio SDK가7개 조건을 모두 통과했다. caller guide, DOI 없는 책 발견, 검색 RIS, 직접 fetch RIS, DOI 장, CITE 없는 Journal 음성, DOI 논문을 구별했다. 책은234바이트 RIS였고 검색 제목은 부제를 포함하지만 원 RIS의 본제와 ISBN이 일치했다. 장은10.1515/9783035629385-011의353바이트, 논문은10.1515/joc-2026-0248의389바이트였다. 장 표본4개에는 DOI 없는 장이 없었으므로 책의 성공을 DOI 없는 장 전체의 실서비스 성공으로 확대하지 않았다. Journal Groups Complexity Cryptology는 원 CITE가 없어 document_citation_unavailable로 남았다.

처음 가져온 검증 도구의 첫 논문 DOI 고정 기대값은 실시간 검색 순서에 의존했으므로, 실제 선택 행의 DOI와 내려받은 파일을 대조하도록 고쳤다. 원 문헌 정체성 검증을 없앤 것이 아니다. 새 서버는 원본 server.py와 별도 인증·데이터 경로를 사용했고 등록 MCP나 사용자 브라우저는 재시작하지 않았다. 정제 결과는 services/scholarly-mcp/data/access-research/user-criteria-degruyter/root-sdk.json, 원 근거는 private root-user-criteria-20260913T0715Z/degruyter-merge/live-original에 있다.

별도 깨진 첨부 과제도 독립 검토를 통과했다. 현재 snde1089_supplementary_2.zip은 여전히 원 출판사의 Page Not Found지만 원 bepress 문헌의 역사 보존 제어에서 Belaire_Contreras.zip을 회수했다.26,379바이트·10개 구성원·CRC 검사 통과, SHA2564e695f9a5d4813523ea6237021aef00e4d5551cd08aae698c3475190a17db65f다. 실제 전후 이미지에서 보존 문헌과 ZIP 제어·다운로드 경로를 읽고, 파일에는6개국 XLS와 프로그램 및 readme가 있음을 확인했다. 관련 역사 자산의 확보와 현재 깨진 자산의 복원은 구별한다. 둘의 byte-equivalence는 입증하지 않았으며 자동 다른 자료원 fallback도 추가하지 않았다.

해당 진단의 CDX400은 요청 문법을 교정했고,429는 간격 뒤 정상 색인 응답으로 대조했다. 부모 문헌 캡처 시각을 첨부 캡처 시각으로 쓰던404와 실제 첨부 시각의 ZIP200도 구별했다. Common Crawl의 이전502는 동일 요청 재실행에서 명시 No Captures로 바뀌었고 같은 collection의 경로 양성은278행이었다. 일시 오류 자체를 보존 자료 부재의 근거로 쓰지 않는다. 원본의 보충 파일 구현은 이미 부분 실패와 ZIP/CIF 양성을 다뤄 이 별도 과제에서 생산 코드는 바꾸지 않았다.

전체 작업은 계속 중이다. CORE·Semantic Scholar·ScienceDirect의 원본 병합 및 live 검증, SIAM 명시 exact 저자 필터 재설계, AMS 최신 사본 검토가 별도로 남는다. De Gruyter 완료 커밋에 다른 미완료 생산 변경을 섞지 않도록 registry는 이 자료원의 usage와 validation 값만 선택 staging했다.
