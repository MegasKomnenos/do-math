현재 표시된 JSTOR 문자 확인을 직접 판독·입력하여 통과했다. 이후 /new-search는404였으며 이 경로를 검색 실패의 정본으로 사용하지 않았다. 정식 /action/doBasicSearch?Query=algebra는 실제 검색 화면과 원 JSON을 제공했다. 20260912T034048Z-jstor-search-observe.json은 결과 링크25개와 /search-results/grouped-search/·/search-results/snippets/ 응답을 보존한다. 처음3초 관측은 Vue 초기화 전 빈 화면이었으며 이를0건으로 처리하지 않는다.

확인된 기관 세션의 JSON POST는 별도 API 자격 없이 동작했다. 익명 HTTP의200 응답은 확인 HTML이었다. 검색은 이 원 API로 고정하고 citation은 기존 공개 API, 문헌 PDF는 기관 Playwright로 고정했다. API 실패에 따른 브라우저 검색 전환을 넣지 않았다. 서버에는 문자·이미지 인식 기능을 넣지 않았고 Codex·등록 MCP를 재시작하지 않았다.

pageNumber만2로 보내면 첫 페이지25건이 반복됐다. 실제 Next는 pageParams.groupEfq와 pageMark를 제출했다. 원 표식을 그대로 소비하고 page_index·범위·행수·중복을 대조한다. 검색 전체 표시198021건과 문헌 결과군197779건은 다르며 source_total과 total로 분리한다. 이미지 유형은242건의 image-results-matrix로 따로 검색된다. 여러 결과군을 동시에 반환하는 조합은 명시적인 미지원으로 남기고 자료를 버리거나 임의 순서로 합치지 않는다.

원 msFacetFields는 field별 label을 base64 efq로 제출한다. appliedFacets만 주면 조건이 적용되지 않는 것을 직접 관측했다. 자료 유형·주제·언어와 CE 날짜, relevance/newest/oldest 및 available/all을 연결했다. 기본 available은 현재 기관 접근 가능 자료이며 all은 접근할 수 없는 자료도 포함한다. 원 결과의 selected facet을 대조한다. 영어 조건 eng OR en OR EN은 결과 표시에서 eng OR en으로 축소되어 엄격 문자열 비교가 실패했다. 실제 응답 fixture로 재현하고 언어 코드의 대소문자 중복만 비교용으로 정규화했다. 원 label·요청 검색식은 고치지 않는다. 연·월 종료일은 해당 기간의 끝으로 비교한다.

JSTOR의 stable ID에는 비2307 DOI와 community 자료도 있었다. 10.5951/mathteacher.108.9.0696과 community.39607963의 두 원 citation 형식을 직접 회수했다. 이름은 제목 후보로 반환하며 문헌을 자동 선택하지 않는다. 원 citation 파일의 stable ID를 대조하고 검색 결과별 BibTeX/RIS 파일과 오류를 보존한다. 원 JSON의 접근 토큰·권한 ID·요청 식별 필드는 정제하고 source evidence의 그 정제 범위를 명시한다.
