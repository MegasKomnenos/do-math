MathSciNet에서 mr:(2733384)를 검색하면 검색 API는 한 건을 반환하지만 화면은 곧바로 문헌 페이지로 이동했다. 기존 내보내기는 결과 목록의 div.article·Export·checkbox를 기다렸기 때문에 시간 초과가 났다. 최초 실제 SDK 보고 20260910T224121Z-mathscinet-lookup-probe.json은 미완료로 남겼다. 내보내기 없는 같은 검색과 직접 문헌 조회는 정상이어서 검색 부재나 기관 접속 실패로 분류하지 않았다.

문헌 페이지의 실제 Cite 제어는 ams,bib,tex,end 형식과 ids=2733384로 publications/format 응답을 받았다. 배열의 각 항목에는 paperId·arxivId와 네 형식의 완성 문자열이 있었다. 기존 Playwright 기관 context에서 이 원 응답을 회수하도록 연결했다. 별도 API 자격을 도입하거나 브라우저와 API 사이의 자동 실패 대체를 넣지 않았다. 화면의 결과 목록이 사라지는지에 의존하지 않게 됐다.

원 paperId 집합·중복을 요청 MR 번호와 대조한다. BibTeX MRNUMBER와 EndNote label도 해당 MR과 일치해야 한다. 원 배열의 순서와 요청 순서는 별도 필드로 유지하고, 자료원이 만든 문자열을 빈 줄로 연결하며 인용문 문체를 다시 작성하지 않는다. 검색 내보내기 실패는 레코드·받은 인용문·오류를 함께 반환한다. 단건 fetch의 export도 HTML 서지 페이지 대신 원 네 형식을 제공한다.

이름 입력은 ti 필드의 후보 검색으로 연결했다. DOI 입력은 원 DOI 검색과 BibTeX DOI 대조를 모두 통과할 때 MR 문헌으로 조회한다. 이름은 한 건이어도 후보로 남기고, DOI가 확인되지 않으면 자동 확정하지 않는다. 실제 Natural Proofs의 DOI는 MR1473047로 확인됐다. 원 리뷰 페이지·Review PDF와 논문 전문을 구별하는 계약은 유지한다.

새 SDK 보고 services/scholarly-mcp/data/validation/20260910T225607960428Z-mathscinet-workflow.json은 completed=true다. 제목 검색 5건, MR2733384의 네 인용 형식·3쪽 리뷰 PDF, 정확한 MR 검색 내보내기, 이름 후보 14건, DOI를 통한 MR1473047 조회·내보내기를 검증했다. 앞선 20260910T225327093090Z-mathscinet-workflow.json도 성공했으며 마지막 보고는 원 인용문 내부 MR 대조를 추가한 뒤의 재검증이다. 공통 196개 검사가 통과했다.

JSTOR 검색 화면의 공개 query-builder 코드에서는 기존 doBasicSearch와 new-search 경로를 확인했으나 별도 검색 API는 아직 관측하지 못했다. 원 검색 연결은 계속 조사 중이다. 전체 구현은 미완료라 푸시하지 않으며 재시작 조작을 다시 작업의 선행 조건으로 삼지 않는다.
