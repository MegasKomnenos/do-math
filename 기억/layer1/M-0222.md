---
id: M-0222
layer: 1
title: APS 기관 검색의 원 인용문과 본문·보충 PDF를 회수함
convention_version: 24
---

전용 Chrome에서 KUDOS의 실제 APS 기관 경로가 열린 뒤 기존 검색 조건·정렬·페이지 기능을 원 인용문, 복수 facet, 절대 날짜 범위와 문헌 회수에 연결했다. 공개 APS Harvest API와 기관 자료원은 계속 별도 source이며 한 호출에서 서로 전환하지 않는다.

같은 facet 그룹의 복수 값은 원 journal[] 반복 query 필드였다. 단일 값으로 덮어쓰거나 임의 쉼표 값으로 바꾸지 않고 현재 체크 상태와 제출 조건을 함께 대조한다. 절대 날짜는 start_date·end_date를 함께 YYYY-MM-DD로 받아 실제 날짜로 검사하며 원 custom 범위로 전달한다. 원 HTTP HTML의 MathML과 브라우저가 이후 그린 표현을 구별해 수식이 있는 검색 제목을 보존한다. 초기 HTML의 selected 상태와 현재 렌더된 상태가 다를 수 있어 원 검색 의미와 현재 제어를 각각 확인한다.

BibTeX·RIS는 해당 문헌 DOI의 원 Export Article 모달과 export 경로에서 회수한다. 검색 내보내기는 요청 창의 DOI·순서를 유지하고 일부 파일 실패가 레코드를 지우지 않게 한다. 문헌 본문의 metadata·초록·인용문·PDF 상태도 서로 분리한다. PDF의 Chrome viewer 문제는 [[M-0218]]의 새 전용 프로필 설정으로 교정했고, 정확한 DOI의 원 제어에서 받은 파일을 검사한다.

보충자료는 같은 저널·DOI의 원 supplemental 경로와 파일 제어에 결속한다. source landing 링크를 임의 파일로 취급하지 않는다. 실제 LHFSupplementary.pdf 제어는 늦게 나타났으므로 supplementary 요청에서만 최대10초 기다린다. 같은 URL이 중복 렌더된 경우 하나로 회수하고 다른 DOI나 외부 호스트로 자동 이동하지 않는다.

실제 SDK의 20260912T115954Z-aps-search-mcp.json은 기본 검색37,997건·CSV·start19/limit2 경계·제목 검색814건과 선택 문헌 metadata·초록을 통과했다. 130617Z-aps-extended-mcp.json은 algebra·journal=[prd,prl]·1960-01-01부터1980-12-31까지의847건 중1건, 원 RIS·BibTeX, 초록과 PDF1,148,858바이트·14쪽 및 각 추출을 completed=true로 통과했다. 131701Z의 같은 스크립트는 supplement-only 범위이며 문헌10.1103/PhysRevLett.115.250402의 원 보충 PDF1,884,893바이트·16쪽과 추출을 별도로 통과했다. 전용·기존 APS 검사17개가 통과했다.

이 커밋은 APS 기관 전용 클래스와 회귀·실제 SDK 스크립트 단위다. 공통 서버 등록과 전체 사용 설명은 후속 통합 단위로 남긴다. 최초 접근 실패나 제어가 없는 다른 표본을 사이트 전체의 기능 부재로 바꾸지 않는다. 전체 프로젝트의 남은 고급검색·관계 회수를 계속 구현하며 푸시하지 않는다.
