## 독해가 바꾼 설명 배치

초기 교재 독해에서는 형식 타당성·해설 동일성·목표 충족·행동 허가·실행 상태라는 다섯 판단을 구별했다. 그러나 첫 수업에서 검사를 거쳐 보존한 형식 결과의 집합 K와 결과의 저장·적용 조건까지 함께 도입하는 대목이 어렵다는 지적이 반복됐다. 용어마다 짧은 정의를 덧붙이는 수정은 첫 수업의 부담을 줄이지 못했다. 최종 판본에서는 첫 수업을 다섯 판단에 집중시키고 K를 03강에서 다뤘다. 관계 제출의 두 단계 JSON은 개념 수업에서 빠른 참조로 옮겼다.

구현 세부에는 판단에 필요한 연결을 보충했다. 검토 실행 수의 하한은 단계별 횟수 표와 숫자 예로 풀었고, 미지 지평 U와 겹치던 사용 횟수 기호를 교재에서는 E로 바꿨다. 응답 계약과 저장 계약은 제출·기록의 책임 및 snapshot 경로·Git ref·메모리 보기의 차이로 설명했다. 별도 독해자는 관찰을 반환했고, 교재 작성자는 원고·확정된 작성 요구·원문에 대조해 지적의 수정 또는 유지 이유를 기록했다. 바로 뒤 표나 문단이 제공하는 설명까지 첫 문장에 반복하지는 않았다.

## 사용자 교정과 산출 보존

처음에는 오프라인 원문 HTML과 raw 바이트 사본, 합본 원고·독해 사본·화면 캡처·시험용 PDF를 모두 교재 폴더에 두었다. 사용자는 중간 산출물과 sources raw 등을 적당히 정리하라고 했고, 삭제가 안 되면 한 디렉터리로 모아두는 대안도 허용했다.

raw 253개가 기준 Git 커밋의 blob과 바이트까지 같음을 확인한 뒤, 재생성 도구가 manifest의 고정 커밋을 배치로 읽고 파일별 SHA-256을 검증하도록 바꿨다. 현재 working tree의 최신 원문으로 대체하지 않는다. 따라서 독자는 기존 원문 HTML을 오프라인으로 읽을 수 있고, 재생성에는 해당 커밋을 가진 저장소와 Git이 필요하다. 첫 수업의 저작 원문도 중간 검토 폴더에서 `content/lesson-01.md`로 옮겨 불필요한 산출물에 대한 의존을 끊었다.

재귀 삭제 명령은 자동 승인 검토에서 `blocked by policy`로 거부됐으며 더 구체적인 이유는 반환되지 않았다. 같은 삭제를 다른 수단으로 재시도하지 않고 사용자가 허용한 이동으로 정리했다. 분리한 원문 사본·중간 산출물·캐시는 `임시/do-math-교재-삭제대기-20260928/`에 모았다. 이 폴더는 Git 제외 로컬 자료이고 사용자가 통째로 삭제할 수 있다.

**재생성·검사 도구의 출력 기본값.** 학습에 필요한 HTML과 재생성용 저작 원문·출처 manifest를 배포물로 삼고, 중간 합본·검사 증거는 명시적으로 요청할 때만 출력하도록 바꿨다. `build_course.py --draft`는 독해용 합본 원고를, `verify_course.py --output-dir`는 검사 보고서와 해당 검사의 화면·인쇄 증거를 지정한 경로에 남긴다. 기본 검사에서는 교재 폴더에 캡처·PDF·보고서를 다시 쌓지 않는다. 산출물을 전부 남기는 방식은 이후 정리 요청을 받았을 때 빌드 의존성까지 재검사하게 만든다.

## 보존 근거와 검증 범위

추적할 진입점은 `docs/learning/do-math/index.html`, 새 과정의 `validation.json`, `reference/sources/manifest.json`, `content/`, `assets/`다. 전체 원고의 별도 독해와 대조 원본은 `.codex/writing-flow/01a0e351-738e-7051-914d-8b515b32bb78/`에 남으며 Git 제외 로컬 자료다. 저장소를 복제해도 이 독해 원본이 따라오지는 않는다. 추적되는 validation에는 요약·원고 해시·로컬 보존 위치를 남겼다. 이 보존 구별은 [[L-0006]]의 근거 경로 원칙을 따른다.

raw 의존을 제거한 뒤 다시 만든 전체 원고의 SHA-256은 기존 독해 판본과 같고, 학습 HTML 36개도 같은 바이트다. 원문 HTML 253개에서는 raw 파일 링크만 제거했다. 정리 뒤 289개 HTML의 링크·앵커 90,426개와 원문 전 행 대조를 통과했다. 최초 제작 때 문항 선택 78개, 용어·파일 검색, 상태 비교 5개, 데스크톱·모바일·인쇄를 확인했으며, 정리 뒤 본문이 같아서 그 문항 동작 검사를 반복하지 않았다. 제품 전체 회귀 시험과 연구 효능, 사용자 이해도는 검사하지 않았다.

작업 기억을 종합해 현행 원칙에 반영하는 dream 단계에서 함께 볼 후보는 [[L-0005]]의 독해·경중 배분과 [[L-0006]]의 증거 보존 경계다. 첫 수업의 반복된 독해 어려움은 설명을 계속 추가하기보다 도입 위치를 바꾸어 처리했고, 산출 정리는 원자료의 정확한 복원 가능성과 빌드 의존성을 확인한 뒤 수행했다.
