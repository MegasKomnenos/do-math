# P vs NP 연구 방식의 통합 HITL 티켓으로 지도를 재구성함

## 맥락

사용자가 승인한 제목, 본문, 라벨과 관계로 wayfinder 티켓 「P vs NP 연구 방식의 통합 설계를 확정한다」를 만들고 지도 「P vs NP 연구 체계 재설계」의 미차단 하위 이슈로 연결했다. 새 티켓은 표현 체계, 연구 지도 구조, 확실 판정, 문헌 수집·활용, 모델 배정, 운용 루프, 현행 국면 승계와 구체 예시를 같은 HITL 대화에서 결정한다.

기존 「연구 지도 표현 체계를 확정한다」, 「연구 작업자 모델 배정을 확정한다」, 「문헌 활용 메타 전략의 요건을 확정한다」, 「문헌 수집 확장을 설계한다」, 「연구 운용 루프를 설계한다」, 「현행 do-dag 국면의 처분을 확정한다」와 「연구 지도 스키마 시제품을 만든다」는 통합 대체 사유로 닫았다. 먼저 닫은 「'확실' 판정 기준을 확정한다」에도 새 티켓 링크를 남겼다.

지도 본문의 `Not yet specified` 전건도 새 티켓이 흡수하므로 비웠다. `Decisions so far`는 반증 재작성 규약과 도구 지형 실사만 유지했다. 통합 대체로 닫은 티켓은 해결 결정이 아니므로 결정 색인에 넣지 않았다. 컨텍스트 정본의 미결정 목록은 새 통합 티켓 하나를 가리키도록 고쳤다.

## 터득한 것

개별 결정이 서로의 전제를 바꾸는 설계에서는 티켓을 잘게 나눈 구조가 오히려 정합성을 해칠 수 있다. 확실 판정이 Lean의 지위를 요구하고, Lean의 지위가 표현 체계를 요구하며, 표현 체계가 다시 검토 역할을 바꾸는 순환이 실제 대화에서 나타났다. 새 티켓은 이 상호 의존을 한 대화의 결정 순서 안에서 풀고, 기존 결정을 최종 체계에 맞춰 유지·수정·폐기한다.

통합 대체는 해결과 다르다. 닫힌 기존 티켓은 결정 색인에 들어가지 않고 새 티켓의 입력으로 남는다. wayfinder 지도는 열린 질문의 정본을 새 티켓 하나로 줄이고, 기존 이슈와 저장소 문서는 고해상 맥락과 검토 이력을 보존한다.
