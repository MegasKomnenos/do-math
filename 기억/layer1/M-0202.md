일곱 자료원 재검증에서 IEEE와 IOP의 검증 범위를 넓혔지만 JSTOR 웹 접근은 여전히 확인 화면이었다. Chrome에서 원 음성 파일도 회수했다. 보호된 20260911T050456Z-jstor-audio-0.bin은 WAV106312바이트·mono·8000Hz·8bit·13.2835초다. 실제 키보드 이벤트로 화면 문자를 입력한 뒤에도 Client Challenge가 남았다.

현재 모델은 audio 입력을 지원하지 않아 직접 들을 수 없었다. Windows 설치 음성 인식기도 조회 결과가 없었다. 별도 무시 경로 data/jstor-audio-env에 PocketSphinx5.0.4를 설치해 로컬 인식을 시도했다. 현재 환경의 바이너리 설치에서 5.1.1은 매칭되지 않았다. 일반 인식과 문자·숫자 문법을 제한한 인식 모두 신뢰할 수 있는 정답으로 확인하지 못했다. 추정 문자열을 정답이나 통과 근거로 사용하지 않는다. MCP 본체 환경·requirements에 음성 모델을 추가하지 않았다.

요약은 services/scholarly-mcp/data/validation/20260911-jstor-audio-diagnostic.json이다. 음성 회수 성공, 인식 실패, 웹 확인 미통과를 구별한다. 음성과 이미지가 같은 정답을 요구하는지도 확정하지 않았다. 출판사 확인의 원인이나 영구적인 접근 가능성을 단정하지 않는다.

최신 구현의 기준은 M-0198부터 M-0201까지다. IEEE 네 인용 형식·선택 창과 IOP 서지·초록·16쪽 PDF·BibTeX/RIS·최신순 RSS API·원 검색 필터·0건은 해당 보고 범위에서 실제 MCP를 통과했다. 공통 234개 검사가 통과했다. APS는 첫 페이지·CSV·원 MathML·부분 결과를 제공하지만 후속 접근이 제한된다. AMS·SIAM·ScienceDirect·JSTOR의 미해결 항목은 SUPPORT.md와 VALIDATION.md에 남는다.

정확한 재개 계약은 C:\Users\wogud\AppData\Local\Temp\학술자료-MCP-후속구현-인계-20260910.md다. 이 문서는 최신 상태로 갱신한다. CLI·기존 Codex 세션 재시작 조작, 추가 API 자격·웹 계정·연락 이메일 요청은 하지 않는다. 전체 구현은 부분 완료이며 푸시하지 않는다.
