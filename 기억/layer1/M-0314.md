사용자는 do-math를 실사용해 발견한 문제와 [[M-0313]]의 충분성 검토를, 현행 스킬의 세부 구조를 다시 읽은 뒤 구체적인 구현 계획으로 발전시키라고 요청했다. 앞선 ‘이미 읽은 것을 반복해 읽지 말라’는 제한과 달리 이번에는 필요한 원문을 꼼꼼히 다시 읽으라는 지시였다. 수정할 파일·함수·계약뿐 아니라 새 정보의 생산자·소비자, 상태 전이, 실패·대기 해소, 다른 절차에 미치는 영향과 검증 사례까지 연결하는 것이 요구 범위였다.

산출물은 `docs/do-math/review-2026-09-18/implementation-plan.md`다. 초기 분석의 29개 발견과 이를 묶은 이전 plan.md의 수정 단위 P01~P12를, 이번 문서의 12개 구체 변경 묶음에 대응시켰다. 개정 대상 선언과 파견 순서, 판단에 사용한 내용이 같은지와 그 사용 효력이 유지되는지의 검사, 기존 계약 승인 재사용, 원 요청에서 이어지는 수리·재시도 관계에 따른 복구를 함께 구현하는 안을 제시했다. 나머지 안도 실제 사용하는 곳까지 계획에 포함했다. 예를 들어 Claude의 여러 응답 구간을 worker와 수집기가 같은 규칙으로 해석하게 하고, 공급자 한도는 연구 실행기와 독립 운영의 호출 양쪽에서 기다리게 한다. 운영 코드 수리에는 검증한 설치본의 해시와 실제 배포 판본의 일치까지 요구한다. 질문·기한·입력·계약·문헌 인계의 구체적인 변경은 계획 문서에서 이어 읽는다. 새 필드와 함수는 제안이며 이번에 구현하지 않았다.

구체화 과정에서 개정 의무를 다른 과제에 넘길 때의 자기 차단을 확인했다. 지식 A를 고치도록 맡긴 과제 D의 계약 검토까지 A 개정 대기로 막으면 개정을 시작할 수 없다. 계획에서는 원 요청과 D의 소유 관계를 결박해 그 의무 자체에 따른 차단은 피하고, 다른 실행과의 실제 충돌 검사는 유지하도록 했다. 이미 선택되어 performing이지만 실행 전인 개정 대상의 옛 선택 취소, 누적 호출 수를 제한하며 순차 실행하는 구 모드에서, 개정 대기로 막힌 요청 뒤의 독립 요청을 선택하는 처리, 새 대기 종류를 일반 resume으로 되살리지 않는 소비자 처리도 포함했다.

공급자 한도가 풀렸는지 재관찰할 때 연구 실행기의 호출을 독립 운영보다 우선시키는 규칙을 검토했으나, 두 프로세스 사이에 추가 조정이 필요해 채택하지 않았다. 최종 안에서는 연구 실행기와 독립 운영 가운데 허가된 실제 요청이 있는 한 프로세스만 SQLite 전이로 재관찰 권한을 얻는다. 연구 실행기를 깨우는 일과 공급자가 실제로 사용 가능함을 확인하는 일은 구별한다. 기한 예고도 권한 회수와 구별하며, 짧은 run에서는 예고 구간을 함께 줄여 최초 착수 자체가 막히지 않도록 했다.

Claude 수집 규칙을 정하기 위해 원 로그의 여러 응답 구간을 대조했다. 각 구간의 usage와 누적 modelUsage가 다른 범위의 사용량을 나타낸다는 관측을 보존했다. 여러 구간에서 최종 제출을 고르는 새 규칙이 설치된 Claude CLI와 호환되는지는 구현 후 실제 호출로 검증해야 한다.

계획의 전체 독해에서는 실제 연결 누락과 문맥으로 충분히 정해진 표현을 구별했다. 확인된 연결 누락은 수정했고, 마지막 독해의 중심 이해 20개를 사용자 요청과 확정된 조건을 적은 작성 전 합의 파일에 대조한 뒤 남은 표현 지적 14개는 본문·역할 범위·독자 배경에 근거한 유지 이유를 기록했다. 독해는 코드 사실이나 미래 구현 성능의 독립 검증을 대신하지 않는다. 원문 위치·내용 해시·항목 대응·연구 정지 등의 문서 검산 14개를 통과했으며 제품 전체 회귀를 이번 문서 작업에서 다시 실행하지는 않았다.

근거 진입점은 같은 폴더의 `implementation-evidence.json`, `implementation-verification.json`, `implementation-reading` 계열 파일이다. `implementation-baseline.patch`는 이번 구현 변경이 아니라 기존 운영 담당의 미커밋 정본 4개 파일 diff를 복원용으로 보존한 자료다. 그 코드와 생성 사본 4개, 병행 scholarly 서비스 변경은 건드리지 않았다. do-math가 실행하던 수학 연구 인스턴스는 기존 HOLD와 paused snapshot을 유지했고 자동 예약도 비활성이었다. 독해 호출은 Claude Opus 5만 사용했다. 원 독해 CLI 증거와 읽기 보조 기록은 `.codex/writing-flow/`와 `.skill-workspace/do-math-detailed-plan-20260918/`의 Git 제외 로컬 보관이며 정리로 사라질 수 있다.
