title: 작업 트리 전체를 정리하고 연구 재시작 상태를 명시함
convention_version: 25
---

사용자는 working tree 전체에서 보존할 것은 커밋하고 불필요한 것은 제거하며 연구를 empty slate에서 다시 시작하도록 지시했다. 첫 응답이 research와 experiments 중심으로 범위를 설명하자 사용자는 두 디렉터리가 예시라고 정정했다. 정리 범위를 예시 경로에 고정하지 않고 추적·미추적·무시 파일 전체를 조사했다. 이후 예시 해석은 특정 경로를 우선순위로 삼기 전에 전체 범위 문언과 함께 판단해야 한다.

기존 탐사 DAG 1,599개, 실험 6개, 연구 산출물 742개, .sdd 상태 2개, 임시 기록 34개를 추적 대상에서 제거했다. 미추적 수집·요약·실행 결과와 Git 무시 원문·환경도 같은 디렉터리 단위로 작업 트리 밖으로 옮겼다. 원래 수정된 문헌 체계 명세를 포함한 이전 연구 입력·배경 세 문서는 보존하되 새 연구의 활성 계약이나 재개 지시가 아님을 표시했다. 이전 wayfinder 컨텍스트에도 같은 현재 상태를 연결했다. 새 목표와 연구 계약을 이번 정리에서 만들어내지 않았다. 핵심-정의-명세.md는 착수 시에도 없었고 복원하지 않았다.

공통 스킬·서비스·설계·검증 기록·작업 기억·키 반복 도구를 보존했다. 미추적 설계 검토 기록 16개를 보존하고 다섯 낡은 상대 링크를 수정했다. 기존 .codex/config.toml의 gpt-6-astra 모델 변경과 삭제된 초안에 대한 .gitattributes 규칙 제거를 커밋했다. 연구 파서 의존성 분리는 [[M-0271]], 교육 자료 정리는 [[M-0272]]에 있다.

재귀 삭제 명령은 자동 승인 검토에서 blocked by policy로 거부됐으며 구체적 이유는 없었다. 이를 사용자에게 알리고 복구 가능한 대안으로 C:\math-retired-20260914에 원래 상대 경로를 유지해 이동했다. 저장소에서는 제거된 상태지만 영구 삭제나 공간 회수는 아니다. .skill-workspace의 과거 실행·검증 자료도 이동하고 do-math-toolchains는 실행 기반으로 유지했다. 인증 정보·실행 중 MCP의 .venv·서비스 자료와 검증 근거는 유지했다. Git 푸시에는 로컬 보관 폴더가 포함되지 않는다.

Windows 접근 권한 때문에 .skill-workspace/do-math-hook-probe-wck5bjg6와 docs/do-math/구현-검증-2026-09-14/elevated-cli-profile/do-math-codex-ntiwy50w는 이동하지 못했고 ACL 읽기도 거부됐다. 후자의 prompt.bin·request.json은 착수 시부터 Git에 삭제로 나타났으므로 그 상태를 반영했다. 이 폴더들은 물리 정리의 잔여이며 README에 명시했다. 과거 문서의 삭제된 연구·임시 경로는 정리 전 Git 이력이나 로컬 보관 폴더에서 찾아야 한다.

검증은 연구 수집 디렉터리 제거 뒤 서비스 639검사, 교육 HTML 17개의 브라우저 로딩, 교육·진입 문서·설계 검토의 로컬 참조 3,743개, 기억 색인 검사와 스테이징 diff 검사를 수행했다. 새 연구를 실행하거나 외부 이슈의 상태를 바꾸지는 않았다.
