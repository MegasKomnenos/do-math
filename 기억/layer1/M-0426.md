## 독립 통합의 의미

[[M-0425]]의 KD-1200 main 통합은 10ce0461로 확정했다. 그 뒤 후보에서 찾은 공개 전제 복제 불일치의 수리를 main의 별도 변경으로 가져왔다. knowledge_records.review_publication_premises가 고정 명제의 동일성 기초, 활성 신뢰 환경, 채택 검토 정책, 헌장을 제외한 거버넌스를 만든다. 검토 생산자와 단계 신뢰 활성화의 수신 검증이 같은 함수를 사용한다. 헌장을 제외하는 이유는 연구 목적의 변경이 이미 고정한 수학 명제의 의미를 바꾸지 않기 때문이다. 수학 목표 판정의 현재성은 직전 KD-1200 수리에서 별도로 검사한다.

main에는 후보의 나머지 신뢰 전환 수리를 덮어쓰지 않았다. 기존 검토 장면과 도메인 함수를 써 새로운 회귀를 기존 unit.test_review_engine_staged에 추가했다. 승인된 거버넌스, 보존 사용자 원문, 실제 governance.apply_decision과 charter_change 생산자로 연구 목적 변경을 적용했다. 수리 전 `9se3jbwj`는 activate_transition에서 publication premises changed를 내며 실패한다. 처음 진단 초안 `aogvbuiv`는 헌장 내용만 직접 바꾼 합성 입력이었다. 이를 유효한 사용자 결정 생산자 경로로 바로잡은 뒤 위 red를 확정했으며, 첫 초안을 유효한 결정의 증거로 사용하지 않는다.

수리 뒤 관련12개 `ys5o6lj5`와 구조5개 `zbemhh4u`가 통과했다. 정상 활성화의 새 검토/형식/설명 기록, 기존 기록 보존, 실제 검토 소유자 경로, 독립 검토, Git 저장 왕복을 유지했다. 기존 반려 시험에서 다섯 전제 필드를 각각 변조해 정확한 반려와 입력 원상 보존을 확인했다. 오래된 정책과 위조된 영수증의 기존 검사도 유지한다. main 원장에 KD-0805의 원인과 main 재현을 추가했고 열린 결함14개는 그대로다.

## 판본과 실행 한계

후보의 B06 동적 전체 신뢰 전환3개 통과와 main의 도메인/검토12개 통과를 같은 전체 통과로 합산하지 않는다. 정상 전체 신뢰 전환에 필요한 main의 다른 수리는 남아 있다. main 두 unit 시험과 구조 냄새 검사에 개별 시간 예산 초과가 있어 성능 조건도 닫지 않았다.

일반 기준선 knvwwf8d는 아직 실제 실행 중이며 원 수리 트리는 고정했다. 새로 전송 직전 정지 시험의 옛 오류 문구 기대값도 실패했다. 수리판은 외부 실행을 먼저 등록하고 prepared 게시의 권한 관문에서 정지를 처리하므로 HTTP는 0회, 실행/용량은 취소와 반환으로 끝나며 실제 오류 문구는 stopped before authorization이다. 후보에서 이 기대값과 저장 재시작을 교정 중이다. 초안에 transmission_phase=not_started를 단언했으나 공개 prepare_operation은 그 필드를 만들지 않고 중단된 prepared 초안도 게시되지 않는다. 원문을 읽고 필드 부재·attempts=[]·효과 부재·실패 사실을 정확히 단언하도록 고쳤다. 이 초안 오류는 제품 수리나 통과 증거로 세지 않는다.

근거 진입점은 추적되는 단계-전환표의 current_work.review_premise_integration이다. 사용자 Temp 보고와 .skill-workspace 패치는 Git 제외 로컬 자료다. 전체 T2/flows, fresh T3, 함수 전건 변이, 예산, T4/T5, 말뭉치와 나머지 main 통합은 계속 진행한다. 이 커밋은 commit-harness의 기억 결합과 미러/색인 게이트를 적용하며 푸시는 하지 않는다.
