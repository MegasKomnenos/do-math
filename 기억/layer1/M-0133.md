# AGENTS의 승인된 다섯 표현을 요구 보존 범위에서 축약함

사용자는 효과를 유지하는 군더더기 제거 검토에서 제시한 다섯 안을 모두 승인했다. 해석 원칙의 도입 표지, 복창 방식의 늘어진 구문과 한 문장 안의 중복 강조, 두 범주의 분류 표현, 의무 적용의 피동 구문을 축약했다.

교착 예방 예시, 모든 지시의 분석 범위, 짧은 답변에도 적용되는 작문 기준은 각각 기능이 있어 유지했다. 문언상 요구 보존 검토는 통과했으며 실제 모델의 행동 효과 비교 실험은 하지 않았다.

다섯 치환을 역치환한 바이트가 수정 전 원문과 일치하고 저장 결과가 수정안과 일치함을 확인했다. 작업 시작 시 대상 파일과 기억에는 기존 변경이 없었다.
