## 맥락과 범위

작업 트리 정리 제안 뒤 사용자는 문헌조사와 do-math 설계를 계속 수행 중이라고 확인하고, 해당 작업을 정지하지 않도록 지시했다. 완료된 virtual-f-key-repeater만 현재 저장소에 커밋하도록 요청했다. 프로그램 27파일과 이 기억·색인만 커밋 대상으로 삼았다. 드라이버 설치나 입력 실행은 하지 않았다.

## 검증

tests/validate.py의 HID 계약 검사와 C 주기 동작 검사가 통과했다. controller의 Release 빌드는 경고·오류 없이 통과했다. 드라이버 빌드와 실제 장치 동작은 이번 커밋 대행에서 재검증하지 않았다.

## 정리 판단

앞선 제안은 문헌조사 쓰기 종료 뒤 커밋하고 전용 worktree로 이관하는 순서였다. 사용자는 실행 연속성을 우선하고 gitignore 활용을 물었다. 정리 목적만으로 활성 작업의 정지나 이관을 전제하지 않도록 작업 상태와 허용 범위를 먼저 구분해야 한다.

문헌조사의 runs/.gitignore는 events.jsonl·stderr.txt·work 디렉터리를 이미 제외한다. version-review-evidence는 실행 계약이 보존하도록 정한 근거 기록이다. 외부 참조 checkout 두 곳은 무시 후보지만, 나머지 ignore 변경은 제안 단계로 남겼다.
