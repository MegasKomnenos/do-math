기존 PQDT의 빈 options 제한과 RIS 외 내보내기 미연결을 현재 기관 UI에 맞춰 구현했다. query의 필드·Boolean 문법은 그대로 두고 relevance/oldest/recent, ISO 발행 날짜, Subject·Index term·University·Location·Language의 include/exclude를 추가했다. 같은 그룹 include는 원 OR, exclude는 NOT이며 서로 다른 그룹은 함께 제한한다.20행 페이지의 실제 위치와 선택 문서를 대조한다.

필터는 현재 그룹의 More dialog에서 정확한 Include/Exclude와 반대 mode의 상태를 대조한 뒤 적용한다. 이어 해당 그룹의 navigation 전후 applied Counter가 기존 상태에 그 표현 1개만 더한 결과인지 확인한다. 마지막 전체 Counter만으로 그룹을 추정하지 않는다. 다른 그룹의 동일 label도 occurrence를 잃지 않으며 이전 검색 조건은 값별 Clear로 모두 해제한다. 실제 조합은 148건 중 start19/limit2 두 페이지와 Text4,012바이트를 반환했고 뒤 0건·단건 요청도 통과했다.

원 서지 형식은 RIS·Text·RTF·XLS·PDF, EndNote alias와 Cite의 BibTeX다. 실제 같은 문헌에서 RIS 2,707바이트·Text2,726바이트·RTF 6,680바이트·XLS9,216바이트·서지 PDF 51,994바이트를 회수했다. EndNote는 같은 내용의 원 RIS와 동일 바이트여서 새 문법으로 표시하지 않는다. BibTeX 2,098바이트는 키 없는 원 Cite 문자열이며 [[M-0225]]의 보존적 추출로 id 빈 문자열과 경고를 유지한다. 단순한 예비 204·빈 응답은 파일로 세지 않고 최종 200·형식·DocID·제목·선택 범위를 검사한다.

export_content는 여섯 다운로드 형식의 Citation/abstract/indexing 또는 Citation/abstract를 실제 제어에서 설정한다. Cite BibTeX에는 이 내용 제어가 없어 fixed_cite_bibtex로 구별하며 명시 export_content와 함께 요청하면 브라우저 전에 invalid_options다. 초기 보고가 일곱 형식을 모두 citation_abstract 아래 묶었던 표현을 교정했다. 외부 RefWorks·NoodleTools·EasyBib import는 제출하지 않으며 provider 기능 부재라고 쓰지 않는다.

독립 검토의 네 반례도 수리했다. 선택 1건에 같은 RIS/BibTeX2건을 반환하면 parsed count와 순서 검사가 거부한다. fulltext TimeoutError는 준비된 metadata를 지우지 않고 부분 결과로 남긴다. 동명 필터 2개를 applied1개로 축약하는 반례는 group별 제어와 occurrence 변화로 거부한다. Cite에서 무시되던 export_content는 위 고정 범위와 명시 거부로 해결했다. 실패한 최종 파일은 source_export로 보존하며 키·문헌을 새로 만들지 않는다.

Firefox의 새 SDK는 일곱 형식·extract, 논문 전문 40쪽과 별도 보충 PNG529,775바이트·ImageContent를 통과했다. 서지 PDF 1쪽은 논문 전문 40쪽과 다른 역할이며 문헌 번호가 URI annotation에만 있어도 원 링크를 대조한다. 교정 뒤 sdk-recheck.json이 완료됐고 PQDT12검사·RTF 6개 검사와 독립 review의 원 반례 재실행이 PASS였다. 근거는 services/scholarly-mcp/data/access-research/pqdt-final/의 contract.json, 보고.md, sdk-live.json, sdk-supplement.json, sdk-recheck.json, review.json이다.

이 커밋은 PQDT 모듈·재현 스크립트·회귀 단위다. 공유 설명과 지원표는 최종 통합에 포함한다. WOS의 추가 검토 교정과 전체 회귀가 남아 있으므로 전체 완료나 푸시를 선언하지 않는다. 별도 계정·API 자격·연락 이메일과 기존 사용자 세션 재시작은 사용하지 않았다.
