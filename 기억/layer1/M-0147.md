무관한 전역 PDF 디렉터리와 관련 도서로 확장하던 g02 수집기를 수리한 판본을 보존한다. 문헌6건에서 무관한 작업56,168개, 관측 단계989개, 다운로드 시도 하한391개가 확인됐다. 하한은 PDF 작업의 실제 단계 기록을 센 값이며 과거 SDK 내부 재시도 횟수까지 뜻하지 않는다. 발견 당시 일부 분기 수와 중단 후 전체 작업 수도 구별한다. 원래 작업과 증거는 삭제하지 않고 제외 이유와 이전 상태를 유지했다.

새 선택자는 출판사 화면의 다운로드 제어와 PDF 경로를 읽고 참고문헌·추천·footer 문맥, Wiley의 명시적 Reference 매개변수, 전역 FTP, Perlego의 다른 책 식별자를 구별한다. 해당 문헌의 DOI와 명시된 장·전체 책 제어를 유지한다. 같은 제외 수리를 다시 적용할 때 부모 증거를 자식 결과로 잘못 읽어 정상 형제 경로까지 닫거나, CPE 재검사가 제외한 분기를 다시 열던 오류도 회귀로 고쳤다. 실제 Springer243개·Perlego132개 링크에서는 무관한 확장이 없었고 Epstein의 정상 장 PDF는 유지됐다. 민감 Save chapter 링크는 이전 단위에서 정제한 새 내용주소 자료를 참조한다.

142개 회귀의 전체30개 실행이 종료코드0이고, 실제2건 수리 실행20260908T211735Z-43476도 공통 부분 검사를 통과했다. 현재 두 고정 흐름의 manifest는20260908T212406Z-39028과47292다. 루트는 실제 두 Python 프로세스와 시작 파일63개씩의 SHA를 대조했고 모든 값이 일치했다. 이 목록에는 런타임 초록 판정 자료2개와 공통 검사기·작업 큐도 포함된다. 신규 original_title 모듈과5개 시험은 현행 수집기가 수입하지 않는 별도 준비본이므로 이 실행 판본과 섞지 않는다. 일부 범위 시험은 현행 결과 JSON의 실제 작업을 읽으므로, 이를 최소 고정 fixture로 보완하는 후속 재현성 개선을 작업자에게 전달했다.

루트는 Hulek1995 The Horrocks–Mumford bundle을 EBSCO의 정상 장 다운로드로 회수했다. 정확한 부모 책의 목차를 연 뒤에도 다운로드 선택은 Cover로 남아 있어 실제 combobox에서 목표 장을 선택했다. 허용100쪽 안에서 한 번의 다운로드로40쪽 PDF를 얻었다. 첫 면 제목·Klaus Hulek·1995, 파일2–39의 인쇄140–177, 파일40의 빈 끝면을 확인했다. 입력 끝177과 UI 끝178은 문헌의 실질적 마지막 쪽과 빈 끝면의 차이로 기록하며 원입력을 고치지 않았다. g08이 독립 확인한 뒤 담당 원자료와 결과에 채택했다. MyEBSCO 개인계정이나 다운로드 제한 분할은 사용하지 않았다.

g08이 예약한 초록5건을 루트가 실제 PDF 이미지와 DB·출판사·MR 증거로 검토했다. Ajtai1996은 첫 면 왼쪽 단에 정식 ABSTRACT가 있어 기존 not_found가 잘못됐다. Benci2000은 저장된 n∈:N의 콜론이 원문에 없고 Kabanets–Impagliazzo2004는 RP 위첨자와 중첩 지수가 평문에서 손상됐다. 원문 초록 구획을3배 렌더링해 모두 읽었으며 마지막 문장까지 포함하고 서론·옆 단·키워드를 제외한 좌표를 전달했다. Benci의 비영점 CropBox는 page-relative clip과 구별했다. 결과는 담당 작업자가 단독으로 수정하고 이전 손상 값과 원자료를 보존하며 실제 회귀를 추가한다.

Taylor1989와 Cheeger1999는 원문 시작·출판사 화면·정확한 DOI 검색·완결된 제목/저자 검색을 함께 읽어 확인 범위에 별도 초록이 없음을 지지했다. Taylor 검색에 나타난 Jarvis의 같은 제목 박사논문은 저자·연도·유형이 달라 제외했다. Cheeger 출판사는 Without Abstract를 명시하고 원문은 목차와0 Introduction으로 시작한다. Bas Edixhoven과 William P. Minicozzi II의 독립 리뷰에는 논평·비교·해설이 있어 초록으로 바꾸지 않는다. 구획 경계와 결정 파일은 operator-checks/g08-five-abstract-review.json에 남겼다.

이 단위는 g02 수리 코드·시험·실행 판본과 루트의 실물 검토 근거를 보존한다. 전체6,101건 회수는 진행 중이며 g05의 수식·그림을 보존하는 HTML 수집, g08의 ISBN 후보·정상 PDF 목적지·내용 검토도 계속된다. 문헌을 한 번 처리한 수와 검증 완료 수는 여전히 구별하며 신규 네 디렉터리는 전담 작업자 슬롯이 확보되면 이어 파견한다.
