g05가 요청한 7건을 루트가 직접 검토했다. 기존 PDF 5개의 해시가 결과 기록과 일치했고 실제 첫 면·끝면 이미지를 읽었다. Sipser1996은 책 전체가 아니라 SIGACT News27(1)의 27–29쪽 서문·목차 기사다. 첫 면 위에는 Rocky Ross의 앞 칼럼 끝이 있고 목표 표제·Sipser·Preface(Abridged)는 아래에서 시작한다. Regan1993의 5–15쪽 기사도 첫 면 위 Hemaspaandra의 편집자 소개와 아래 Guest Column을 구별한다. DB가 Regan에게 붙인 Grandjean/Olive2004 인용, Loui1991에게 붙인 Loui1996 인용은 각각 다른 논문의 서지 문자열이므로 초록으로 세지 않는다. Loui1991 원문 날짜 July29와 ACM의 June1991 표시는 별도로 보존한다.

Loui1996의 5문장 Computer and Information Systems Abstracts 값은 보고서의 범위·연구 방향·응용·성과·협업 목적을 완결되게 요약한다. DOI10.1145/242223.242240, 저자·1996·28(4)·575–590을 대조해 DB의 for Research와 원문의 in Research 표제 차이를 해소했다. 실제 원문은 Introduction으로 시작하므로 이 값을 저자 원문 초록이라고 주장하지 않고 database_indexing_abstract로 유지한다. 해당 16쪽 PDF의 끝 590쪽 참고문헌까지 직접 확인했다.

Gasarch2000 Book Review Column의 10쪽 PDF는 인쇄 10–19를 포함하고 끝면 아래 Judy Goldsmith의 다음 서평을 문장 중간까지 포함했다. ACM과 DB는 목표의 시작 Page10만 명시하여, 처음에는 전체 6책 서평을 확보했다고 볼 수 있는지 질문을 열었다. 작업자가 실제 ACM 목차를 추가로 열었고 루트도 원자료와 링크를 읽었다. 목표 DOI1008648과 Goldsmith1008649(19–22), Masum1008650(22–24), Narendran1008651(24–26)이 분리돼 있었다. 목표 DOI의 출판사 제공 PDF는 유효하며 Gasarch의 소개·합동 3책 서평과 다음 글의 일부가 들어 있는 경계를 명시한다. 전체 6책 서평 파일이라고 하지는 않는다. 최초 질문을 지우지 않고 g05-column-unit-review.json이 해소 근거를 덧붙인다.

수식 대조 중 공개 arXiv의 실제 상세와 View PDF 링크를 Playwright로 읽어 두 파일을 회수했다. Secant varieties 논문은 arXiv2503.21972v2가 J.Symbolic Comput.135(2026)102546과 배정 DOI10.1016/j.jsc.2025.102546을 명시한다.34쪽 원고의 표제·두 저자·첫 면 Abstract·번호 2–34·끝 참고문헌과 소속을 확인했다. 수식의 지수와 사영공간 표기를 보존하는 초록 구획도 직접 읽었다. arXiv 웹 초록의 문구와 현행 PDF 문구에 작은 차이가 있으므로 혼합하지 않고 6Jan2026 저자본 PDF의 구획을 사용한다. g05가 명시적으로 연결된 저자본 원문과 그 초록을 채택했고 루트는 반영된 파일 해시도 재확인했다.

Prophet inequalities의 31쪽 arXiv2301.01700v2는 8Aug2024 버전이다. 두 저자·완전 제목·초록·다섯 결과가 대상과 대응하지만 상세에는 2026 학술지 DOI가 없어 이전 저자본 후보로 유지한다. 실제 첫 면과 3–4쪽 정리,31쪽 참고문헌을 읽었다. 손상된 2k+2k는 2의 k+2승에 k를 곱한 식이며 유한체는 F의 아래첨자 p다. DB 필드의 앞 두 문단은 완결 초록이고 뒤 bullet 다섯 항목은 하이라이트다. 출판사 웹 렌더링도 Abstract와 Highlights를 따로 표시하며 arXiv의 정식 초록도 같은 두 문단 구조여서, 원 DB의 두 문단을 그대로 추출하고 하이라이트를 추가정보로 나눈다. 브라우저의 공개 경로는 사람 확인 화면, 정상 KUDOS 기관 경로는 CPE00001이었고 우회하지 않았다. 제목·결과가 맞는 이전 원고와 목표 출판본을 동일 판본이라고 보고하지 않는다.

g05가 앞서 확보한 HTML 한 건은 참고문헌 제목의 k 한 글자가 원 MathML 없이 CHTML로 남아 재검토 상태로 돌렸다. 작업자는 실제 MathJax MathItem에 남은 MathML을 표제·초록·본문·참고문헌 모두에서 회수하고, 실제 DOM currentSrc에 대응하는 브라우저 이미지 응답을 보존하는 수리를 진행했다. 새 Maximum in-general-position set 논문의 저장 HTML은 루트가 인터넷을 차단한 Firefox에서 독립 열람했다. 배정 DOI10.1016/j.jctb.2026.05.001,4저자·179권·2026/07/01과 실제 조판 제목을 대조했다. 제목의 아래첨자 q·위첨자 d는 평문 DOM 순서와 화면 순서가 달라도 원 MathML에서 구별된다.

이 새 HTML은 본문 1–9절·References, MathML1309개, 남은 CHTML0, 내장 그림 2개를 포함한다. 실제 419×210·328×98 도식과 캡션, 첫 면의 제목·초록·수식, 끝 참고문헌 38까지 직접 읽었다. 오프라인 HTTP 요청 시도는 0건이었다. g05-0500-offline-observation.json과 별도 내용 검토가 SHA7a96e243으로 시작하는 824,058바이트 파일을 결박하며 작업자는 원문 found 판정을 반영했다. 외부 서비스의 표시만으로 확보를 선언하지 않고 저장 파일이 필요한 수식·그림과 함께 실제로 읽히는지 확인한 단위다.

Micromechanics of Materials, with Applications의 공식 723쪽 책도 루트가 독립 검증했다. 표제 4쪽·판권 5쪽의 두 저자·ISBN2개·DOI·Springer2018, 끝파일 723의 인쇄 712쪽을 실제 이미지로 읽었다. 표지 1쪽에 관측된 앞부분·7개장·뒷부분 722쪽을 순서대로 대조해 전부 들어 있음을 확인했다. 유일한 텍스트 차이는 목차의 공백 하나다. 출판사가 지정한 쪽번호 건너뜀을 삭제나 누락으로 오해하지 않는다. 작업자의 273개 저장 책 후보 집계에서 대부분은 짧은 부속자료였고, 정상 분량에서 놓친 것은 이 책의©출판사명…2018 판권 형식이었다. 분량 검사를 느슨하게 만들지 않고 해당 실제 형식을 좁게 보완한다.

이 커밋은 루트의 검토·관측 기록을 보존한다. g05의 전체 HTML 구현은 70건 수집을 진행하며 다음 검증 판본 목록을 준비 중이므로 이번 단위에 섞지 않는다. g08은 Google Books의 전자책 판매 없음과 실제 제한된 미리보기를 구별하는 후속 UI 조사를 계속한다. g02의 두 흐름도 수집 중이다. 전체 6,101건 및 아직 파견하지 않은 네 디렉터리 작업은 완료되지 않았다.
