## 검수에서 구별한 사실

최종 정본과 미러의 관련134개 통과는 이번 범위의 증거다. 원반환 각84개와 각875Python 판본을 대조했고, 기존33문서시험과 helper를 보존했다. 검사 helper는 명시된 단계/부분 JSON/명령 모드만 소유한다. 존재하는 단어를 다른 역할의 산출로 차용하는 오류를 반려하되 모든 산문 이름을 자동 필드로 해석하지 않는다.

초기 실패 중 같은 채택 요청은 내용 주소 영수증을 재사용했으므로 다른 원문으로 새 요청을 만들어야 했다. 다른 실패는 C:/temp와 실제 C:/Temp 문자열 차이였고, 제품이나 단언을 바꾸지 않고 전용 TEMP의 실제 정규 표기로 해결됐다. Git text blob과 Windows 작업트리 바이트도 구별했다. task의 보조검산 오류는 보존하고 시작SHA가 일치하는025 archive 원바이트로 검수했다. 이런 과거 실패를 최종 성공으로 덮거나 새 runtime 결함으로 옮기지 않았다.
