## 맥락

`docs/do-math/통합-설계.md`·루트 `CONTEXT.md`·`docs/wayfinder/pvsnp-재설계/컨텍스트.md` 셋의 문서 간·내부 정합을 검증하는 verify-rounds 런(`임시/삼문서-정합성_검증_2026-09-02`)의 라운드 1이다. 체급 전면(수리 6·관점 2·심사 3/3·하한 3·상한 8), 수리 opus high, 병합 opus low, 심사는 사용자 지시로 gpt-5.6-sol high. 산출물 셋이라 앵커와 사본을 디렉토리로 만들었고, 통합-설계(2845행)는 7.1절 표 행 868/869와 19.1절 코드 블록 행 1858/1859의 유일 인접 행 쌍에서 셋으로 갈랐다. 제기 39건(조각 37·상신 제안 2), 묶음 6, 심사 대상 31, 승인 23(수리 20·무처분 2·상신 1), 기각 8, 본표 25행 적용.

## 터득한 것

- 주요 적용 내용: 27절 15항의 `GLOSSARY.md` 링크 문구를 확정 편집 15(「–다른 `do-math` 구현 정본」)로 동기화(수리자 셋이 독립 수렴, 커밋 3717277이 수정안만 고치고 통합-설계를 놓친 드리프트). 4.1절 `lean/` 환경 파일 셋을 29절 예외에 추가. 15.2절 「외부 안전 조건」을 `CONTEXT.md`의 상하 관계대로 「점검 발동 조건」으로 교정하고 14.5절 `§N` 표기를 `N절`로 통일. 9.1절 역할표의 「씨앗 생성자」·「처분 심사자」를 1.3·30.3절 이름으로 통일. 컨텍스트 정본 6절의 동시 용량 소유를 연구 설정으로 교정, 「충분한 경량 모델」을 「검증된」으로. `CONTEXT.md`에 「자료·근거」 표제어 신설, 「작업 씨앗」 목적을 학술 검증까지 넓힘, 「감시 기록 원장」 열람 금지 문구, 「운영 점검 실행」 발동 조건 정정, 「심사 미완료」의 「심사자」 주어 제거, 이중 빈 줄 제거. 통합-설계 0.1절 우선순위 3순위에 스킬 문서 추가, 3.3절 저장 분류 사상 오배정, 7.7절의 옛 「6.1절에 잠근 씨앗 계약」을 `skill_documents` 기구로, 9.0절 차단 사건 필드, 10.1·10.5절 `output.json` 누락, 20.1절 「비교 전용 신뢰 시대」 어휘 위반, 25.4절 학술 검증 상태 다섯 값의 배타 조건, 23.1절 계약 구성 재서술, 19.11절 제목 「최종 형식 검사」를 「인증 최종 검사」로.
- 상신 1건(R1-21): 6.5절 「수학 해설 ID」의 종류 접두사가 2.1절 목록에 없음. 심사 셋이 만장일치로 해설 파일 참조·해시 대체(선택지 나)를 추천했으나 설계 결정이라 세션이 자체 처리로 무처분 전환하고 종료 보고에 올린다.
- 기각 8건의 유형: 대체 문구가 근거 없는 주체(「제안」)를 더함(R1-31, 0/3), 수정 대상이 경로 사상의 전제(역할 ID와 `record_id`의 관계)를 먼저 요구함(R1-M3, R1-M6), 심사 지급 밖 실물(과거 자료 좌표)을 심사자가 확인할 수 없음(R1-36), `CONTEXT.md`의 기계 리터럴(상태값·`task_id`) 문제를 상신 제안으로 냈으나 심사 셋이 「조각 항목으로 닫을 수 있다」며 항목 종류 위반으로 기각(R1-39). R1-39의 결함 자체는 셋 다 인정했으므로 라운드 2 회수 대상이다.
- 심사자 gpt-5.6-sol high 3기는 31건 전체를 심사, 재개 0, 각 20분 안팎이었다. Agent 호출의 `run_in_background: false`는 이번에도 비동기로 돌았다(M-0093 재현).
