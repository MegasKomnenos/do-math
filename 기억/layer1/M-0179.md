title: PQDT의 원 보충 파일 제어와 이미지 추출을 연결함

PQDT의 Supplemental files 탭에서 원 파일을 회수하는 기능을 연결했다. 실제 MCP에서 문헌 2485541561의 PNG 529,775바이트와 이미지 추출이 통과했다. 공통 검사 145개가 통과했다. 전체 구현은 계속 진행하며 다른 출판사 첨부·검색 등의 남은 범위를 완료로 표시하지 않는다.

공개 ProQuest 문헌 설명에서 보충 파일이 있는 표본을 찾고, 실제 작업은 KUDOS의 PQDT 기관 바로가기로 접속해 수행했다. 원 문헌 탭에는 TLTC_Teaching_Learning_Teaching_Continuum.PNG 한 개가 있었다. 탭을 선택한 뒤 원 h5의 파일 건수와 .suppFiles 항목 수를 대조한다. 파일 다운로드 동작에 포함된 파일명도 원 표시명과 같아야 한다. 카운트 누락·파일 누락·잘못된 이름을 명시적 0건과 구별한다.

실제 다운로드는 각 파일의 원 Terms of Use 제어가 가리키는 동작이다. 그 경로는 서명된 미디어 URL을 인자로 포함한다. 앞선 M-0177에서 그 경로의 정제 결함을 수리했으므로, 이번 파일 목록에는 내부 action URL을 반환하지 않고 이름·순서·파일 참조를 남긴다. 원 페이지와 최종 파일 출처의 URL도 공통 정제기를 거친다. 보존 fixture는 정제된 파일 제어 영역이며 인증 값을 포함하지 않는다.

원 동작은 www.proquest.com에서 image/png를 반환했고 실제 PNG 서명을 확인했다. metadata·supplementary를 함께 요청한 MCP가 성공했으며 extract는 구조화 이미지 결과와 MCP ImageContent를 제공했다. 정확한 보고 경로는 services/scholarly-mcp/VALIDATION.md가 소유한다. 이미지의 내용 판독이나 OCR은 수행하지 않았다.

보충자료는 파일별 상태를 유지하며 한 파일 실패로 다른 성공 파일을 잃지 않는다. Supplemental files 탭이 노출되지 않은 문헌에는 source_page를 반환한다. 권한 차이·다른 레이아웃까지 모두 파일 부재라고 단정하지 않는다. PNG 외 PDF·ZIP의 기본 형식 검사와 원 바이트 보존 경로는 연결했지만 이 커밋에서 실제 MCP로 확인한 보충 파일 형식은 PNG다.

다음에는 Taylor & Francis 등 아직 개별 첨부가 연결되지 않은 출판사와 남은 검색·내보내기를 계속 확인한다. IEEE 그래픽 초록은 직전 7cdb73c/M-0178에서 결정화했다. 기존 사용자 설정·연구 자료는 보존하며 전체 완료 전이므로 푸시하지 않는다.
