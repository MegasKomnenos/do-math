JSTOR 이미지 검색의 원 메뉴에는 제목·제작자의 양방향 정렬과 해상도 정렬이 있었다.082405Z-jstor-image-controls.json의 실제 요청에서 item_title_str·primary_agents_str·cc_media_resolution과 별도 sortOrder를 확인했다. 호출자는 title_asc/title_desc·creator_asc/creator_desc·resolution을 사용하며 원 전송 값은 서버가 처리한다. 이미지·파노라마로 한정된 조건에 적용한다.

추가 facets는 원 응답의 field와 label을 사용한다. display는 원하는 항목을 찾는 표시명이다. 지역·분류의 label에는 내부 구분 문자가 있지만 호출자가 이를 생성하지 않고 반환값을 복사한다. 구조화된 기존 필드와 같은 facet을 중복 지정하지 않는다. 반환된 선택 상태를 대조해 서버가 조건을 무시한 결과를 성공으로 전달하지 않는다.

083058Z-jstor-image-search-mcp.json은 제공기관 조건에서 filter_mismatch였다. cc_portal_id의 숫자 label만 보내면242건의 무필터 결과가 돌아왔다. Collection 계층의 원 제공기관 체크박스를 찾아084340Z 요청을 관측했으며 원 전송 값은 cc_portal_id#식별자였다. 응답의 선택 label은 숫자 그대로다. 하위 컬렉션 cc_compilation_ids에는 접두사를 붙이지 않는다.085108Z 원 UI 요청은 제공기관26건을 하위 컬렉션22건으로 좁혔다.

085459Z-jstor-image-search-mcp.json은5개 정렬,10MP 초과47건·Europe5건·Northern State University26건·NSU Pasque Collection22건을 completed=true로 통과했다. 필요한 label은 실제 facet artifact에서 추출해 다음 호출에 사용했다. 제작자 원 표시는 records.creators에 보존한다. 공통269검사가 통과했다.

남은 코드 표지를 대조하면서 IOP 검색 결과의 BibTeX/RIS 결선이 빠진 것을 확인했다. 원 문헌별 내보내기는 이미 있으므로 이 연결을 독립 단위로 계속 구현한다. 이 커밋에는 JSTOR 단위만 포함한다. AMS·SIAM·APS는 실제 체크박스·키보드 조작 뒤에도 제한됐고,085244Z APS 실제 MCP도 첫 검색부터 restricted였다. ScienceDirect는 해당 사이트 쿠키만 지운 격리 복사에서도 CPE였다. 등록 MCP·Codex·다른 실행 세션을 재시작하지 않았다. 전체 작업 종료 전에는 푸시하지 않는다.
