# 일반 AI 작업 템플릿 기준선

## 맥락

새 저장소는 기존 작업 환경의 `.claude`, `.agents`, `.codex`, `기억` 구조를 유지한다. 일반 절차, 실행 계약, 테스트, 각색 근거를 함께 이관했다. 특정 프로젝트의 소스, 실행 상태, 작업별 layer-1 기록은 포함하지 않았다.

이관된 dream 절차는 사용자의 명시 호출로만 시작한다. 시작된 dream의 내부 반복은 실익이 소진될 때까지 이어진다.

## 터득한 것

프로젝트 고유 문언과 절차 근거는 같은 파일에 함께 있을 수 있다. 파일 전체를 제외하면 절차의 적용 경계와 재검토 근거가 사라진다. 따라서 활성 절차의 프로젝트 식별자만 일반화하고, 세칙과 원본 대조 기록은 보존했다.

정본 스킬은 `.claude/skills/`에 둔다. `.agents/skills/`는 기존 생성기로 만든다. 두 런타임 사본을 따로 편집하지 않는다.

## 작업 너머 시사점

템플릿 이관은 파일 종류가 아니라 정보의 역할로 판정한다. 실행 규칙, 검증 근거, 원본 추적은 보존한다. 특정 프로젝트의 산출물과 실행 상태는 제외한다.
