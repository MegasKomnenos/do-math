g12의 저자 페이지 근거 형식 1건을 전담 Astra medium 작업자가 처리하고 루트가 독립 검토해 편입한다. 대상은 Kobayashi의 Discontinuous groups acting on homogeneous spaces of reductive type 저자 preprint26쪽이다. 저자 페이지는 출판본 1992년 59–75쪽과 preprint PDF·DVI를 구별해 연결한다. 실제 PDF 링크에서 받은 바이트는 이미 등록된 03e45d57로 시작하는 전체 SHA와 일치한다. 첫 면 제목·저자, 연속 26쪽, 끝 참고문헌을 확인했고 preprint 날짜는 확정하지 않아 null을 유지한다. 관련 출판본의 1992년을 이 판본에 대입하지 않는다.

초록은 확인한 출처 범위에서 not_found다. 원문 첫 면은 Let H be a closed subgroup으로 시작하는 도입 설명과 Question A-0이며 다음 면의 예시·정의로 연속된다. 독립 초록 구획이 없다. 저자 페이지는 서지와 판본 링크만 제공한다. 실제 Summon 정확 제목 검색은 보유 범위 0건, 비구독 포함 8건이고 작업자는 8개 Quick Look을 모두 읽었다. 같은 제목 7건은 관련 출판본 서지이며 초록이 없고 부모 책 1건의 값은 목차였다. 제목·저자 확장 검색도 21건을 모두 수신해 같은 7건과 다른 문헌 14건을 구별했다. MathSciNet MR1190750은 출판본과 Shvartsman의 독립 리뷰다. 루트도 원 PDF 1·2·26쪽 이미지, 저자 페이지, MR 리뷰를 직접 읽었으며 도입부·목차·독립 리뷰를 preprint 초록으로 만들지 않은 판정을 지지한다.

수집기의 인식·검색 범위·재개·새 근거와 옛 판독의 결박을 실제 자료와 구조 변형 시험으로 검증했다. TDD 기록은 6개 실패 뒤 7개 시험, 재개 2개 실패 뒤 9개 시험, 결박과 호출수 3개 실패 뒤 12개 시험 통과의 단계를 구별한다. 실제 브라우저 실행 21484는 검색 3회·저자 출처 1회·관측 PDF다운로드 1회이고 선행 MathSciNet UI 근거는 재사용했다. 저장 재판정과 완료 결과 재사용에서는 새 브라우저 호출 0회를 기록했다. 루트가 12개 시험과 공통 전체 검사를 다시 실행해 passed=true·complete=true·남은 작업 0을 확인했고, 결과의 증거·원문 21개 참조의 파일 해시도 모두 일치했다.

초기 작업자 진단에서 Summon documents 전체를 출력해 bx_open_url의 res_dat 안 token이 도구 출력에 포함됐다. ID·PW·저장 인증 상태를 출력한 사건과는 구별하며 이 중계 토큰이 로그인 권한을 부여하는지는 확인되지 않았다. 원시 응답 1개를 보호된 .credentials 영역으로 옮기고 공개 자료는 서지 필드 허용 목록으로 만들었다. 루트는 bx_open_url이 완전 URL이 아닌 query 문자열인 것을 확인해 중첩 토큰 1개를 실제로 추출한 후, 그 값과 URL 인코딩 형태를 공개 57개 파일과 비교했다. 일치 0건이고 자격값·길이 12이상 쿠키값 비교도 0건이었다. 최초 파서가 token0개를 찾은 상태를 성공 근거로 쓰지 않고 query 표현에 맞춰 다시 검사했다. 이전 도구 출력 자체를 지웠다는 뜻은 아니다. 공개 로그에 전체 응답을 출력하지 않는 규칙과 실제 검사 범위를 유지한다.

g12를 맡기기 위해 g02 모델 슬롯을 잠시 교대했을 때, 계속 실행될 것으로 예상했던 두 자식 수집 프로세스가 사라졌다. 마지막 로그에는 정상 종료나 예외가 없어서 정확한 종료 메커니즘은 확인되지 않았다. 루트가 같은 수집기를 자신의 실행 세션에서 재개했고 신규 결과 진행을 확인했다. 이후 사용량 소진과 사용자 재로그인이 있었으며 새 세션의 프로세스 감사·작업자 재파견은 별도 실행 기록에 남긴다. g12는 이미 완료된 상태이므로 재로그인 뒤 전체 검증만 다시 하고 수집을 반복하지 않았다. 다른 여섯 디렉터리의 작업은 별도이며 이 한 건의 완료로 전체 6101건 완료를 선언하지 않는다.
