전체 학술자료 MCP 구현을 계속했다. Crossref의 원 변환 형식, WOS의 제목·URL 입력, arXiv HTML과 TeX 추출, KNU FRIC 소장 검색, 저자·학회·저널 공개 문서 URL 회수를 연결했다. 전체 작업은 여전히 부분 완료다. 현행 지원과 실제 보고 경로는 services/scholarly-mcp/SUPPORT.md·VALIDATION.md·registry.py가 소유한다. 별도 계정·키·연락 이메일을 요구하는 기능은 사용하지 않는 결정을 유지했다.

Crossref는 공개 transform API의 BibTeX·RIS·CSL JSON·plain·RDF·Turtle·UNIXREF·UNIXSD를 검증했다. 원 DOI 등록 JSON과 각 변환을 함께 보존하며 형식 변환이 원 등록 어휘를 모두 유지한다고 주장하지 않는다. 실제 MCP의 DOI 필터 검색·BibTeX·여덟 형식·CSL DOI 대조를 통과했다. 테스트 DOI 10.1145/321250.321251은 A Turing Machine Simulator다. 이를 연구상 관련성 검증으로 쓰지 않는다. 이름은 제목 후보 검색으로 반환한다. Crossmark가 같은 구현을 상속한다는 사실과 Crossmark의 별도 실측은 구별한다.

WOS의 문헌 URL·이름 입력이 invalid_target인 것을 재현해 full-record URL의 accession과 제목 후보 검색을 연결했다. The status of the P versus NP problem의 후보 1건을 받고 URL로 서지·참고문헌을 회수했다. 원 Full Record에 AB가 없는데도 모든 component의 available을 요구한 최초 검증은 기준이 잘못되었다. 원 응답의 초록 부재를 확인하고 partial을 정확하게 검사했다. 성공 보고의 completed는 모든 요청 내용이 존재한다는 뜻이 아니다.

arXiv HTML URL이 PDF를 반환하던 결함과 source archive의 main.tex가 format_not_supported인 것을 실제 2408.02321v1로 재현했다. 요청 URL의 html/src 형식을 유지하고 TeX MIME을 줄 추출에 연결했다. 실제 MCP에서 지정 판본 HTML·제목, 원 제출물 11개 파일과 main.tex 564줄 중 앞 3줄을 확인했다. 판본을 바꾸거나 TeX를 컴파일하지 않았다.

KNU FRIC의 OpenAPI는 등록 key가 필수이므로 사용하지 않았다. 경북대 센터 홈페이지의 journal/article 선택과 실제 검색 폼을 사용했다. computer 1,121건의 페이지 경계 2건·CSV, ISSN 2263-8733의 유일한 소장 기록, 무작위 문자열 0건이 MCP에서 통과했다. 0건 화면의 안내 li는 문헌이 아니다. RISS 문헌 링크와 공개 소장 정보를 보존하며 외부 RISS로 자동 이동하거나 원문복사 신청을 제출하지 않는다. 이 검색 endpoint가 즉시 제공하지 않는 전문·초록과 복사 신청 경로를 구별한다.

저자·기관 공개본과 학회·저널 범주에는 알려진 공개 문서 URL의 회수를 연결했다. 단일 검색 색인을 발명하지 않는다. 별도 공개 context로 기관 인증 상태를 공유하지 않고, 로컬·사설망 주소와 다른 호스트의 리디렉션을 거부한다. 등록 자료원 주소에는 해당 어댑터 선택을 안내한다. 저자 홈페이지의 Bellantoni–Cook 14쪽 PDF와 공개 링크 128개, Electronic Journal of Combinatorics DOI 10.37236/1181의 서지·초록·10쪽 PDF와 공개 OJS RIS/BibTeX가 실제 MCP에서 통과했다. 링크 목록 보존을 연결 파일 전부의 확보라고 표현하지 않는다.

일반 웹은 아직 정상적인 후보 검색 검증이 남았다. Bing HTML과 공개 RSS는 query를 유지했지만 무작위 문자열에도 무관한 결과를 반환했고, Google은 결과 목록 없는 페이지, DuckDuckGo HTML은 HTTP 202와 목록 부재였다. 이들을 정상 검색으로 등록하지 않았다. FRIC 진단에서 형제 요소의 텍스트를 나열하다 공개 select 변경 JavaScript가 출력된 적이 있어 출력 대상을 다시 제한했다. 그 출력에 비밀값은 확인되지 않았다. 원 HTML·JS의 일반 출력 금지는 계속 지킨다.

공통 검사 96개가 통과했다. 네트워크·동적 서비스의 통과 범위를 해당 입력과 판본으로 한정해 VALIDATION.md에 기록했다. 기존 연구 변경과 사용자 .codex/config.toml 변경은 보존했다. 전체 작업이 끝나지 않아 푸시하지 않는다.

다음 ScienceDirect 구현을 위한 새 양성 관측이 있다. 문헌 본문·abs 경로는 접근 오류여도 KUDOS 기관 context의 /sdfe/arp/cite는 PII S002200009791494X의 원 RIS와 994자 초록을 반환했다. DOI는 https://doi.org/10.1006/jcss.1997.1494이며 T1이 제목 태그다. 이 원 RIS는 현재 services/scholarly-mcp/tests/fixtures/science-direct.ris에 미커밋 상태로 있으며 이번 단위에 포함하지 않았다. application/x-bibtex·text/x-bibliography 요청은 provider_error, pdfft는 HTML이었다. 이들을 전체 서비스 부재로 묶지 않고 RIS 경로를 다음에 먼저 연결해야 한다.
