title: ACM 보충 ZIP과 내부 PDF 회수를 연결함
convention_version: 24
---

ACM 문헌의 보충 ZIP과 내부 PDF를 실제 MCP에서 회수했다. 원 페이지의 잘못된 URL이 정제기를 중단시키던 결함도 수리했다. 공통 검사 151개가 통과했다. 전체 자료원의 남은 구현은 계속 진행한다.

대상은 Greed Is Good: Exploration and Exploitation Trade-offs in Bayesian Optimisation, DOI 10.1145/3425501이다. 원 보충자료 목록의 george.zip은 9,708,127바이트였고 내부에는 디렉터리와 george/3425501.suppl.pdf가 있었다. 실제 MCP에서 서지·초록·원 BibTeX·ZIP을 확보하고 내부 PDF 10,527,022바이트·27쪽 중 첫 쪽을 읽었다. 서버가 연구 코드나 문헌의 학술적 타당성을 판정하지 않는다.

첫 진단에서는 정상 문헌을 받았지만 clean_html이 ValueError로 종료했다. 원 HTML에 잘못된 포트를 가진 URL 한 개가 있었고, Sanitizer의 port 조회가 예외를 던졌다. 원 예외 문자열이나 URL 값을 출력하지 않고 스택의 파일·행·함수를 확인했다. 파싱할 수 없는 URL은 표시용 표지로 바꾸면서 주변 문헌을 보존하도록 수리했다. 잘못된 포트·IPv6에 합성 인증값이 들어간 경우도 그 값을 노출하지 않는 검사로 보호한다. 이 문제는 새 인증값의 노출이 아니라 문헌 보존을 중단시킨 예외다.

보충 제어는 core-supplementary-materials의 원 파일 설명과 /doi/suppl/DOI/suppl_file/파일명 경로에서 읽는다. 현재 문헌 DOI를 대조하고 기존 공유 보충 회수 함수에 ACM의 호스트 범위를 전달한다. 원 참고문헌 문맥과 이전 source_page 참조도 유지한다. 별도 새 전송·압축 구조를 만들지 않았다. 정확한 보고 경로는 services/scholarly-mcp/VALIDATION.md가 소유한다.

이 단위와 별도로 공개 API를 다시 호출했다. data/validation/20260910T094831Z-public-followup-mcp.json에서 Semantic Scholar·OpenAlex·CORE의 natural proofs 검색 2건과 추출이 성공했으며 DBLP는 access_challenge였다. 그러나 후속 20260910T095105Z-public-fetch-followup-mcp.json에서 Semantic Scholar·CORE fetch는 다시 rate_limited였고 OpenAlex fetch는 메타데이터만 확보했다. 검색 성공을 전체 fetch 성공으로 확대하지 않는다. 다음에는 이 공개 어댑터들의 남은 입력·초록·관계 처리와 여전히 남은 기관 검색 범위를 계속 검토한다. 별도 API 자격은 사용하지 않았고 전체 완료 전이므로 푸시하지 않는다.
