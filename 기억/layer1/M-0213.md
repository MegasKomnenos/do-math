JSTOR의 기본 Download를 PDF·JPEG/PNG·MP3로 확장하고 원 supplement 목록과 WebVTT 전사문을 연결했다. 오디오·동영상 전사문은 자료원이 제공한 파일이며 transcript_type=auto를 유지한다. 서버가 전사문을 생성하거나 그 정확성을 판정하지 않는다. 일반 파일과 첨부를 함께 요청할 때 문헌 페이지를 두 번 열던 재현을 확보한 뒤 같은 페이지에서 처리하고 한 번 닫도록 했다.

community.13581670의 초기10초 관측에는 이미지 제어가 없었지만30초 뒤 원 JPEG를 회수했다. 구조용 #cdt[data-content-id]는 비어 있는 div이므로 visible 대기는 틀린 조건이었다. attached로 읽은 뒤 원 다운로드 API의 UUID·stable DOI·access 상태를 대조한다.062834Z-jstor-image-mcp.json은168854바이트·1024×821·ImageContent와 별도 문헌의 restricted를 통과했다.063140Z는 기존11쪽 PDF 회귀를 통과했다. 추가 확인 과제는 현재 이미지를 직접 판독·입력했으며 그 답은 기록하지 않았다.

community.39607963은 이미지가 아니라 The Globe의 serial 자료이며 원 다운로드 권한이 restricted였다. community.41259097의 오디오는 download였고 community.39197180의 동영상은 disabled였다. 제한된 권한과 자료원에서 비활성화한 다운로드를 구별한다. 동영상 전사문 회수는 동영상 파일 회수와 다른 결과다.

오디오는 /audio/download/UUID에서 Artstor 저장소의 서명된 MP3로 이동했다. 선택 문헌의 원 UUID endpoint에서 시작한 실제 request redirect 연쇄가 있어야 파일을 받아들인다. 서명된 S3 주소를 직접 만들어 넣지 않는다. 직접 파일 요청의45초 timeout인070854Z를 보존하고 생산 구현은 원 Download로 고정했다. Media ID는 별도 transcript URL의 경로에도 대조한다. 허용 파일 호스트는 실제 관측한 artstor-collections와 sequoia-forum-media 저장소에 한정했다.

26581894의 보충 링크는 /stable/get_asset/10.2307/26581894?supp_index=0이며 원 파일 크기는863887바이트다. 부모 DOI·경로·파일 크기를 검사하고 파일별 상태를 보존한다. 첫 쪽에 주 문헌 제목이 있을 것이라고 단언한071522Z 시험은 틀렸다. 원 보충 PDF는34번 쪽부터 이어지는21쪽이고 첫 쪽에 ATHEY, TIBSHIRANI AND WAGER가 있다. 원 자료로 그 전제를 교정했다.

074059Z-jstor-extras-mcp.json은 MP3의24416379바이트, 자동 전사문33159바이트와 줄 추출, 보충 PDF21쪽, 동영상의 원 다운로드 비활성 상태와 전사문까지 completed=true다. 공통267검사는 진행 중인 DBLP 원 문헌 검사3개도 포함한 작업트리 수치다. 이 커밋에는 JSTOR 단위만 포함한다. DBLP의 별도 원 문헌 구현과 검사, 남은 출판사 접근·내보내기는 이어서 수행한다.

AMS·APS의 원 스크린샷에는 사람인지 확인하는 체크박스가 있었다. DOM의 숨은 성공 문구를 실제 화면 상태로 쓰지 않는다. AMS의074611Z·075258Z에서는 좌표 클릭·키보드 조작 후에도 확인 화면이 남았다. 마지막 출처 상태와 실제 입력을 보존하고 성공으로 세지 않는다. 등록 MCP·Codex·다른 실행 세션을 재시작하지 않았고 전체 작업이 남아 있어 푸시하지 않는다.
