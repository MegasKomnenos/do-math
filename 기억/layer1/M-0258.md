최종 범위 검토에서 실제 EuDML 책 레이아웃 검증이 빠져 있음을 찾아 같은 CLI를 재개했다. 문헌204358은 Peter Barlow의 New mathematical tables(1814)다. 원 HTML34,533바이트에는 Access Full Book과14개 Book Parts가 있고, 실제 NLM8,336바이트에는 book/front/book-meta와14개 book-part-meta가 있었다. 책형 실물 검증 공백은 해소했지만 CLI가 body 존재를 fulltext available로 받아들인 판정은 잘못됐다.

Root와 독립 검토가 실제 원 XML 전체를 다시 읽었다. body 아래 태그는 book-part14, book-part-meta14, book-part-id14, title-group/title14, self-uri14뿐이었다. body 밖의 책 링크까지15개는 모두 외부 GDZ 참조였다. 문단·표 내용·수식·section·장 본문은 없었다. 파서와 동일하게 body 존재를 성공 조건으로 삼은 새 fixture 검사도 같은 오판을 강화했다. 노드의 존재와 요청한 내용의 존재를 분리해야 하는 실제 false-GREEN 사례다.

has_native_body는 현재 문헌의 직접 body/book-body에서 시작하고, body/book-body/book-part 구조 컨테이너를 순회하며 front·article/book/part metadata·toc·ID·링크만 있는 구조를 본문으로 세지 않는다. 다른 문헌의 metadata에 있는 body를 전체 트리에서 끌어오지 않도록 root가 시작 범위를 결속했다. 임의 글자 수 하한은 추가하지 않았다. 실제 article body/sec/p와 중첩 book-part body/p는 available로 유지한다. 목차형 책은 metadata·supplementary available, fulltext not_offered인 partial이며 원 XML과15개 링크는 보존한다.

원본 검사에서 ok 대 partial의 실패를 먼저 확인한 뒤 EuDML7검사가 통과했다. root는 같은 실제 XML을 새 원본 stdio 서버에 재생해 수정 전 ok/fulltext available과 수정 후 partial/fulltext not_offered를 직접 비교했다. 두 입력은 모두8,336바이트, SHA256 a9a574160ccae0b03307fe254ea2253fed9b7d927495279ceccdffc61ab66a47이었다. ID·제목·14개 장을 보존하는6판정도 통과했다. 두 재생의 직전·직후·안정6이미지를 실제로 열어 읽었고, 실제 HTML의 오프라인 렌더에서 책 유형과 외부 원문·장 링크도 읽었다. 재생을 새 원격 호출이라고 하지 않는다.

별도 실제 원본 API 호출은13:26:04UTC에504와122,858바이트 HTML을 반환했다. 실행 전후·안정 이미지를 읽고 원 body를 다시 렌더해 Site is currently down for maintenance라는 안내를 확인했다. 처음 렌더러가 UTF-8을 가정해 decode 오류가 났고, 선언 charset이 없는 HTML에 인코딩 감지를 적용하자 windows-1250으로 읽혔다. 원 bytes는 보존했다. 이전 정상 NLM과 현재 유지보수를 구별하며 더 긴 로컬 timeout이나 다른 자료원 자동 전환으로 처리하지 않았다.

초기 책 점검의 ID 미발견도 로컬 속성 조회 실수였다. 실제 pub-id-type을 book-id-type만으로 검색해 놓친 것이며 기존 typed-ID 파서는 맞았다. untyped ID를 넓게 허용하던 임시 사본 수리는 철회됐고, 공급자 ID가 현재 EuDML ID를 대신하지 못하는 검사를 유지했다. 이번 생산 변경은 본문 판별뿐이며 기존 CQL90/NLM120/connect20과 공통 client의45초 계약은 유지한다.

최종 원본 전체633검사가63.146초에 통과했다. 정제 근거는 services/scholarly-mcp/data/access-research/user-criteria-eudml/root-book-review.json, 원 재생은 private eudml/book-20260913T125115Z와book-20260913T130058Z, 실제504는book-20260913T132416Z다. CLI의 최초 book not_reproduced/fulltext available 보고를 이 root 검토가 정정하며, 같은 thread에 새 원격 요청 없이 사본·보고를 바로잡도록 후속 지시했다.

이 커밋은 EuDML 코드·fixture·검사·해당 guide와 검증 문서 및 두 추가 재검토 프롬프트만 포함한다. ScienceDirect의 최종 코드·새 원본SDK4기능과 대기 수리 재검증도 통과했으며 그 별도 커밋과 최종 지원표·인계 집계가 남아 있다.
