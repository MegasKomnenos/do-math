title: 학술자료 MCP의 Wiley·Springer 검색과 계정 요구 기능 보류를 반영함

사용자는 결정화된 기억과 필요한 문서를 다시 읽고 남은 구현을 끝까지 진행하도록 지시했다. 이번 착수에서 M-0156~0158과 관련 핵심층, 원 구현 인계와 자료원 목록을 다시 읽었다. 전체 구현은 계속 진행 중이다. Wiley·Springer의 검색·내보내기·조회 검증을 하나의 보존 단위로 커밋하며 나머지 출판사와 추가 기능을 완료로 세지 않는다.

사용자는 별도 Scopus 웹 계정과 Unpaywall 연락 이메일이 필요한 기능을 일단 사용하지 않도록 교정했다. 이전 기억에 있던 자격 정보 질문을 대기 중 요구사항으로 승계하지 않는다. Unpaywall은 자료원 상태를 deferred로 바꾸고 MCP 실행 경계에서 네트워크 요청 없이 source_deferred를 반환한다. 사용 안내만 기능 목록에 남기며 서버에 어댑터를 연결하지 않는다. Scopus의 검색·원 JSON·기계적 CSV는 유지하고 native RIS·BibTeX에는 export_deferred와 검색 결과를 반환한다. 공개 문서의 존재와 실제 무자격 이용 가능성을 구별하는 기존 공개 API 기준도 유지한다. 추가 자격 정보가 없음을 구현 차단으로 삼기 전에 사용자가 그 기능을 보류했는지 확인해야 한다.

Wiley는 KUDOS 기관 바로가기에서 실제 고급검색 필드와 20건 페이지를 확인했다. 제목 random graphs의 684건 중 두 페이지에 걸친 두 문헌을 실제 MCP에서 검색·내보내고 추출했다. 내보내기는 별도 문헌 선택 창, Next, 형식 선택, Export 순서다. 선택 체크박스는 일반 check가 시간 초과됐고 focus·Space로 실제 체크 상태가 바뀌었다. 각 체크박스의 DOI와 검색 결과 DOI를 대조하고, native BibTeX의 DOI URL 표기도 식별자 대조에 사용한다. 원 파일의 DOI 표현은 바꾸지 않는다. 같은 제목의 별개 문헌과 판본을 제목만으로 합치지 않는다.

Wiley의 citation_pdf_url은 PDF 파일 대신 뷰어 HTML을 반환했다. 실제 브라우저의 pdf-iframe이 file 매개변수를 채운 뒤 pdfdirect 경로의 PDF를 내려받는 것을 확인했다. 초기 file 값은 비어 있을 수 있다. 준비 조건과 별도 src 읽기 사이의 값을 혼동하지 않도록, 준비 조건을 만족한 src를 같은 JavaScript 관찰의 반환값으로 회수한다. 그 링크를 허용 호스트 안에서 다운로드하고 PDF 파싱을 확인한다. Weakly saturated random graphs, DOI 10.1002/rsa.21210의 18쪽 PDF와 첫 쪽 제목을 실제 MCP에서 대조했다.

양성 검색 성공만으로 0건 검색을 검증했다고 간주하지 않았다. Wiley의 0건 화면에는 양성 결과의 result__count가 없고 result__current=0과 search-result__no-result가 있었다. 원문 조회 뒤 0건 재검색에서 시간 초과가 난 것을 직접 재현하고 별도 레이아웃을 처리했다. 최종 MCP 흐름은 검색·페이지 경계·BibTeX·서지·초록·PDF·첫 쪽 제목·0건 재검색을 모두 통과했다. 근거는 services/scholarly-mcp/VALIDATION.md의 최신 Wiley 검증 기록과 data/validation/20260909T145413656979Z-wiley-workflow.json이다. 앞선 실패 보고의 completed=false는 유지한다.

Springer는 제목·저자·저널·날짜의 고급검색, 필터와 20건 페이지, 문헌별 native BibTeX·RIS·EndNote를 연결했다. 기존 논문 화면의 Download citation과 장 화면의 .RIS/.ENW/.BIB는 같은 citation-needed 서비스와 format·flavour 매개변수를 썼다. 해당 서비스의 공개 호스트와 실제 기관 프록시 전송 호스트를 파일 회수 범위에 포함했다. 프록시는 원 호스트의 하이픈을 두 번 표기하므로 citation--needed-springer-com을 관측대로 처리한다. native BibTeX의 DOI가 별도 doi 필드가 아니라 항목 키에만 있는 실제 형식도 대조한다.

Springer의 실제 MCP에서 제목 검색 두 건·BibTeX 추출, 10.1007/s00037-008-0249-x의 서지·초록·28쪽 PDF·인용문, 전체 검색의 19·20번째 위치 경계와 기계적 CSV를 통과했다. 근거는 data/validation/20260909T144928167948Z-springer-workflow.json이다. 원 사이트의 일괄 CSV 제어는 idp 로그인 경로로 이동했다. 현재 CSV는 회수 레코드의 기계적 직렬화이며 원 사이트의 일괄 CSV로 표시하지 않는다. 문헌별 native 인용문과 구별한다.

공통·자료원 검사 65개가 통과했다. 새 고급검색 옵션 중 모든 조합과 모든 내보내기 형식을 실서비스로 시험한 것은 아니다. 최신 구현 범위는 services/scholarly-mcp/README.md·SUPPORT.md·registry.py, 실제 검증 범위는 VALIDATION.md가 소유한다. 기존 연구 수집 코드·산출물과 사용자의 .codex/config.toml 변경은 보존했다. 이 커밋으로 전체 작업을 종료하거나 푸시하지 않는다.

후속 관찰은 보호된 .credentials/scholarly-mcp/probes와 무시된 data/observations에 있다. Oxford·AIP·Cambridge·Project Euclid·De Gruyter·JSTOR·IOP·AMS·SIAM·ScienceDirect·APS의 현행 진입 화면을 다시 확인했고, Taylor & Francis는 이번 바로가기 시험에서 대기 실패였다. 앞선 CPE 관측만으로 ScienceDirect가 계속 닫혔다고 판단하지 않는다. Oxford는 q 검색과 제목 고급검색 cqb·qb 구조를 확인했으며, 제목 검색 후 DOM과 주소의 갱신 완료를 기다려야 한다. Export title list는 개별 문헌 인용문이 아니라 해당 결과를 포함하는 책·저널 목록이고 CAPTCHA를 요구했다. 해당 제어의 존재를 문헌 CSV 확보로 세지 않는다. Oxford 문헌별 Cite 제어와 나머지 검색·내보내기 구현은 계속 조사한다.
