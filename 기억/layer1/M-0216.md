남은 코드 표지를 대조해 IOP의 문헌별 원 내보내기는 존재하지만 검색의 BibTeX/RIS 입력은 거절되는 연결을 확인했다. 검색의 최신순 RSS·관련도 또는 추가 조건의 원 검색 방식은 유지하고, 선택한 결과 창에 기존 문헌별 원 내보내기를 적용했다. 인용문이 실패했다고 검색이나 자료원을 바꾸지 않는다.

RSS 원 응답으로 페이지 경계의 2건을 선택하고 두 번째 인용문이 제한되는 재현을 만들었다. 검색에서 bibtex를 거부하는 실제 실패 뒤 원 연결을 추가했다. 결과 2건·첫 원 파일·두 번째 오류와 partial을 함께 보존했다. 문헌 페이지는 파일마다 닫고 원 링크·파일 DOI 검증은 기존 iop.citation을 재사용한다.

090332Z-iop-search-citations-mcp.json은 현재 접근 확인으로 제한됐다.090654Z-iop-verification-control.json은 현재 표시된 나무 제품 과제를 판독해 응답값이 생겼지만 제출 후 동일 페이지 URL 대기는 timeout이었다. 보고의 completed=false를 유지한다.091136Z-iop-search-citations-mcp.json은 새 SDK에서 최신순 RSS의 BibTeX, 관련도 검색의 RIS, 각 1건의 원 파일과 실제 extract의 DOI add557을 completed=true로 통과했다. 원 파일 회수 성공은 이 별도 실행으로 판정한다.

공통 270개 검사가 통과했다. IOP XML의 별도 연락·검토 공급 경로를 제외하는 결정은 유지하고 새 자격이나 이메일을 요청하지 않았다. 남은 AMS·SIAM·ScienceDirect·APS 기관 접근 문제와 Semantic Scholar의 호출 제한은 각각 실제 실패로 남긴다. 개별 구독은 구체 대상이 없고 SWH 특정 flat 작업은 준비 대기다. 전체 완료로 확대하거나 푸시하지 않는다.
