title: OpenAlex의 그룹·검색 창·초록과 문헌 입력을 보완함

OpenAlex의 원 그룹 집계, 임의 검색 창, 커서 종료, 위치 색인 초록과 문헌 입력을 보완했다. 실제 MCP에서 검색 창 대조·그룹 두 페이지·복원 초록·참고/관련 문헌·이름과 DOI 조회가 통과했다. 공통 검사 162개가 통과했으며 다른 자료원의 남은 작업은 계속 진행한다.

기존 group_by 구현은 응답의 group_by 배열을 읽지 않고 results를 참조했다. 실제 응답으로 이 실패를 재현했다. 공식 문서의 meta.count는 집계 대상 문헌 수이고 groups_count는 현재 페이지 그룹 수다. 전체 그룹 수로 사용하지 않는다. 원 커서의 key 순서로 그룹을 순회하고 문헌 sort/select와의 결합은 명시적으로 거절한다. 일반 커서가 끝났을 때 전체 문헌 수를 start=0과 비교해 빈 마지막 페이지를 오류로 만들던 조건도 교정했다.

일반 검색 start를 limit 배수로 제한하지 않고 필요한 페이지를 결합한다. 원 페이지·전체 건수·행 수를 대조하고 요청 창만 반환하며 여러 원 응답의 참조를 기록한다. 후속 페이지 실패 때 앞서 받은 결과를 partial로 유지하는 검사도 통과했다. 커서 결과의 start=null은 위치가 커서에 의해 정해졌음을 뜻한다. 실제 구문 검색에서 앞 4건과 start=1/limit=2의 두 문헌이 일치했다.

OpenAlex 짧은 W ID·works/W ID·공개 문헌 URL·DOI를 구별해 조회하며 이름은 원 텍스트 검색 후보를 반환한다. 원 ID를 대조하되 공식 canonical redirect는 보존하고 허용한다. 다른 canonical DOI로 해석된 조회는 후보 선택으로 남긴다. 합쳐진 work와 특정 출판 판본을 조용히 같은 식별자로 만들지 않는다.

초록은 단어별 위치 색인을 검증해 원 순서로 놓고 한 칸 공백으로 연결한다. 위치의 겹침·음수·잘못된 값·누락은 오류로 남기고 말을 만들어 채우지 않는다. 원 색인도 metadata에 유지한다. W2741809807의 복원 텍스트는 1,630바이트였고 나가는 참조 54개·관련 문헌 10개를 별도 배열로 보존했다. DOI 10.1006/jcss.1997.1494는 초록 index가 없고 참조가 36개였다. OpenAlex 색인상 초록의 출처는 다양하므로 출판사 저자 초록의 원 서식·내용과 동일하다고 주장하지 않는다.

현행 공식 도움말은 help.openalex.org이다. 기본 API에 계정·키가 필요 없다는 설명과 실제 익명 성공을 대조했다. 일반 개요의 100건 상한 문구와 달리 실측 per_page=200은 실제 200건을 반환해 기존 상한을 유지했다. 원 API를 실패 뒤 다른 자료원이나 브라우저로 바꾸지 않았다. 정확한 실제 MCP 보고 경로는 services/scholarly-mcp/VALIDATION.md가 소유한다.

다음에는 Semantic Scholar의 이름·링크 입력과 요청한 내용에 맞는 관계 회수, 남은 기관 검색·형식을 계속 진행한다. Semantic Scholar의 최근 검색은 성공했지만 개별 fetch는 rate_limited였으므로 그 상태를 숨기지 않는다. 다음 단위용 semantic-scholar-public-record.json fixture만 미추적 파일로 남아 있다. 전체 완료 전이므로 푸시하지 않는다.
