## 터득한 것

**옛 대역을 "저장된 상태 템플릿 + 실제 엔진"으로 바꾸는 모양이 자리 잡았다.** 작업자는 `ReviewFakeEngine`의 상태를 제품의 `initialize_state`로 채워 저장 계약을 지나 한 번 저장하고, 시험마다 같은 절대 경로로 복원해 실제 `ResearchEngine`에 적재했다. 모델 호출은 옛 대역처럼 건너뛰되, 저장과 적재는 실제다. 소유자 경로는 따로 `Sim`과 흐름 시험이 돈다. 검토자는 우회 범위가 옛 대역과 한 줄씩 같고, 소유자 경로 시험이 실제로 배선을 지남을 확인했다. 대역이 엔진 전체를 대신하던 영역에 쓸 수 있는 모양이다.

**이음매가 없는 자리를 시험 쪽에서 돌아가는 길이 있었다.** `cli.execute`는 포트를 받지 않아 CLI 시험은 실제 Git이 필요했다. 작업자는 `Sim`의 메모리 Git 객체를 느슨한 객체 파일로 내보내, 실제 git과 실제 CLI가 `Sim` 저장소를 읽게 했다. 이음매를 둘지 판단할 때 이 우회도 선택지로 둔다.

**되풀이되는 병합 충돌은 규칙이 분명하면 도구로 푼다.** `SHARDS` 충돌은 늘 "양쪽이 모듈 이름을 지우기만 함"이다. 구간마다 양쪽에 모두 남은 이름만 남기고, 디스크와 등록을 대조하는 도구를 두었다.
