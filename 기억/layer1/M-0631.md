## 맥락

사용자는 재구축 문서와 세 대화의 확정 사항을 기준으로 현재 대체 산출을 verify-rounds 전면 체급으로 검증하도록 요청했다. 모든 파견 모델은 gpt-6.1-sol이다. 기존 대화의 독립 개발 승인을 승계하여 미커밋 산출을 별도 기준선으로 보존한다. 이 커밋은 검증 통과를 뜻하지 않는다.

## 검증 범위와 남은 확인

새 구현은 do-math의 runtime, roles, reference와 SKILL.md, README 및 docs/do-math다. v2와 기존 최상위 실행기는 이번 대체 산출이 아니며 기존 연구 인스턴스를 위해 유지된다. 검증 동결과 장부는 `임시/do-math_검증_20261105/`에 있다. 그 안 sources의 대화 추출과 실행 로그는 Git 제외 로컬 자료다.

기준선 미러 검사는 33개 do-math 파일에서 실패했다. 새 구현의 바이트 동일 복사와 기존 생성기의 경로·제공자 이름 치환 정책이 어긋난다. 생성 규칙을 검증 범위에 넣었으며 기존 실행기를 무조건 재생성해 문제를 감추지 않는다. 문서의 독자별 전달과 강한 역할 서술, 시험의 실제 구현 경로·실패 검출·모듈별 및 전체 덮개를 함께 검증할 예정이다.
