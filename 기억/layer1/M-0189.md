title: IEEE Media 탭의 원 MP4와 중복 제어 처리를 연결함
convention_version: 24
---

IEEE의 그래픽 초록과 별도 Media 탭은 다른 제공 영역이다. 이전에 검증한 두 문헌은 multimedia=false였으므로 다른 문헌을 찾았다. 저자 공개 논문에 Media 링크가 제시된 8626436에서 실제 metadata.sections.multimedia=true를 확인했고, 등록된 MCP의 기존 구현은 첨부 not_implemented를 반환했다.

원 Media 화면에는 같은 media-tab 영역이 두 번 들어 있었다. .media-item의 다운로드 URL로 중복을 제거하고 문헌 번호가 포함된 /ielx 경로를 대조했다. 텍스트 없는 MP4 앵커 옆에 파일 설명이 있었으며 일반 Supplemental Items documentation 링크는 /Xplorehelp/Help_Multimedia.html이었다. 도움말을 문헌 첨부로 넣지 않고 원 설명·파일명을 별도 native_index에 보존한다.

새 파일 회수는 기존 그래픽 초록의 구간 다운로드를 재사용한다. 동일성·파일 길이·버전 검증자를 유지하며 Media 탭 실패가 기존 그래픽 초록과 참고문헌을 지우지 않게 한다. 다운로드는 supplementary_media 역할로 구별한다. 새로운 운영 설정이나 연구 코드 실행 기능은 추가하지 않았다.

새 실제 SDK stdio 보고 services/scholarly-mcp/data/validation/20260910T124350Z-ieee-media-tab-mcp.json은 completed=true다. BioLSTM_RA-L_video.mp4 40381857바이트를 10구간으로 회수했고 Last-Modified 검증자와 MP4 컨테이너를 확인했다. 참고문헌 30개도 함께 확보됐다. 이 실측은 MP4에 대한 것이며 다른 Media 탭 파일 형식까지 검증했다고 주장하지 않는다.

원 화면 fixture의 중복·일반 도움말 제외·다른 문헌 번호 거절 검사와 기존 그래픽 초록·파일 구간 검사를 포함한 공통 175개가 통과했다. 재시작된 Codex 연결의 최신 코드 확인은 M-0187 시점의 사실이다. 이번 기능은 그 뒤 수정했으므로 새 SDK stdio에서 검증했으며 이미 실행 중인 등록 연결의 자동 갱신을 주장하지 않는다. 전체 구현은 진행 중이며 남은 출판사 검색·HTML·추가 형식을 계속 처리한다. 푸시는 하지 않는다.
