g05의 최종 코드·시험 28개와 문서 2개를 검증 판본으로 보존한다. 명령 로그 45개, 실제 실행 manifest 12개, 원자료·링크 범위 fixture를 포함한 목록 118개 항목의 SHA가 현재 파일과 일치했다. 최종 전체 100개 시험은 64.107초에 모두 통과했고 공통 부분검사는 382건에서 passed=true·errors0이었다. 당시 식별 369건·초록 271건·원문 242건이 확보 상태였지만 잔여 문헌 185건과 complete=false도 기록돼 있었다. 원자료는 비추적 intake에 두며 코드와 검증·실행 근거를 버전 관리한다. 테스트의 example.org 세션 매개변수는 명시적인 synthetic 값이며 실제 자격·세션값이 아님을 별도로 확인했다.

resume.py는 구성요소와 남은 작업을 기준으로 공통 큐를 소비하고 새 후보를 처리 전후 inventory에 합류시킨다. 이전 ACM·Summon의 독립 main 완료 표시는 전체 종료 기준이 아니다. 페이지를 순회한 실제 검색 응답과 건별 오류·다운로드 실패를 보존하며 다른 PDF 후보를 계속 조사한다. 실제 PDF의 OCR 경계 수리와 원본 초록 영역 판독도 같은 인계 상태에 연결한다. 이번 구현에는 DOI·제목·저자·판본을 검증한 원문·초록, 출처별 오류와 미해결 내용 검토를 분리하는 시험과 실제 관측이 포함된다.

ScienceDirect의 전문 HTML은 정상 Firefox 기관 경로에서 실제 #body가 로드되고 #references가 나타나는지 확인한다. References만 있거나 Loading이 남아 있으면 전문으로 세지 않는다. 본문 절과 목차 ID를 대조하고, MathJax가 조판한 수식은 실제 MathItem의 원 MathML로 보존한다. 그림은 실제 DOM의 currentSrc에 맞는 브라우저 응답을 수신해 내장한다. 오프라인 재열람은 절·참고문헌·수식·그림의 개수와 가시성, 외부 요청 0건을 검사한다. 그림이 있는 문헌은 구조 검사를 통과해도 직접 도식과 내용을 읽는 검토를 남긴다.

루트가 독립 검증한 0500a5b의 실제 HTML은 이 새 경로의 양성 자료다. 수식 1309개·내장 그림 2개·참고문헌 38개와 전체 1–9절을 보존하고 오프라인에서 읽힌다. 표제의 F 아래첨자 q·위첨자 d는 평문 DOM 순서와 화면 순서가 다를 수 있어 원 MathML의 텍스트 구조와 메타데이터를 사용한다. 실제 70개 문헌 브라우저 순회의 시작 판본과, 순회 종료 후 제목 표기·전 영역 수식 검사를 보강한 100개 시험 최종 판본은 manifest와 runtime_version으로 구별한다. 최종 코드 전체가 이전 70개 문헌 프로세스에 소급 반영됐다고 주장하지 않는다.

기존 판독 재사용도 좁게 연결했다. Nature of Computation 서평의 올바른 PDF는 표제 변형 때문에 새 자동 판별을 통과하지 못했지만 이전 직접 판독이 남아 있었다. review_reuse는 동일 paper_id, 명시적 verified 판독과 설명, 정확한 목표 DOI 경로, 동일 아티팩트 경로·SHA, 현재 파일 바이트, 판독 이미지, 기존 validation 설명을 대조한다. 철회·미검토·바뀐 DOI나 해시는 재사용하지 않는다. 활성 HTML 수집 목록은 별도 수정에서 제외해 단일 작성자를 유지한다. 재사용에 쓰는 현행 검토 목록의 검사 시점 해시도 루트 검증 기록에 남겼으며, 이 동적 목록을 불변 실행 코드라고 취급하지 않는다.

2bb의 참고문헌 k 문제는 실제 표시 소실이 아니었다. 작업자가 남은 CHTML을 발견해 검토를 열었고 루트는 한때 글자가 보존되지 않았다고 보고했지만, 직접 검증 전의 과한 표현이었다. 기존 d6b2de741d426479 HTML의 sb11을 오프라인 Firefox에서 열어 직접 읽으니 On decomposing a hypergraph into k connected sub-hypergraphs의 기울임 k가 정상 표시됐다. DOM에는 U+1D458 문자 자체가 있고 실제 가시 영역은 9.733×18px, HTTP 요청은 0건이었다. 루트는 사용자에게 보고를 정정하고 같은 파일의 기존 원문 승인을 복원할 수 있다고 알렸다. 이 단일 Unicode 잎과 동일 파일의 실물 판정을 복잡한 CHTML 일반 보장으로 확대하지 않는다. 수식을 반드시 MathML로 재구성해야만 보존된다는 판단도 이 경우에는 철회했다.

문서의 현행 진입점 모순도 수리했다. interface.md의 현재 collect.py/acm_collect.py 안내와 feedback-response.md의 현재 resume.py 안내가 충돌했다. 작업자는 초기 독립 도구를 과거 단계로 명시하고 현행 resume·HTML/MathML/그림·오프라인 검증을 기술했다. 오래된 non-PDF 보존의 남은 통합 표현도 현재 상태로 갱신했다. 최종 checkpoint 해시는 8c778f88027405e0e7f59a75de216cbf6c9a1869d82b5b1af4d581584e37cd43이다.

수집은 계속된다. g05는 학술지 온라인 연도와 권호 연도 차이로 남은 식별을 실제 DOI·저자·표제·기사번호로 대조하고, 초록 found이면서 공통 검토 인계가 빠진 32건의 기존 판독을 검토한다. Beame/Pitassi2001 항목에서 저자 사이트가 2000년 출판사 제출본을 명시적으로 연결한 사례도 별도 검토 중이다. g08은 Google 미리보기에서 Hall217–219 전체를 확보한 경우와 Udupa215–216이 실제로 빠진 경우를 구별했다. 전체 요청은 완료되지 않았으며 후속 독립 작업과 수집을 계속한다.
