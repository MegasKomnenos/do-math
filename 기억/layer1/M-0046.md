# 입증 검토 역할과 이의 심사 판정 구조 확정

## 맥락

wayfinder 티켓 「'확실' 판정 기준을 확정한다」에서 입증 검토 역할을 전체 검토자, 부분 전문 검토자와 이의 심사자로 분리했다. 전체 검토자는 논증 의무 전건을 판정한다. 부분 전문 검토자와 이의 심사자는 필요한 부분을 검토하지만 전체 검토를 대체하지 않고 전체 검토자 수에도 들지 않는다.

검토 독립성은 같은 입증 문서 판본에서 다른 검토자의 판단과 다른 검토 역할에 노출되지 않은 절차 상태로 정했다. 검토자와 이의 심사자는 자기 기록을 봉인하기 전에 다른 검토 기록을 보지 않는다. 작성자, 수정자와 다른 검토 역할을 맡은 사람은 같은 판본의 독립 전체 검토자로 세지 않는다. 모델 오류의 통계적 독립성과 모델 다양성은 별도 문제로 남겼다.

검토자가 제기한 이의는 독립된 이의 심사를 거친다. 문헌 증명은 높은 사전 신뢰를 적용하고, 자체 생산 증명은 증명과 이의 어느 쪽에도 사전 우위를 주지 않는다. 이의 심사 판정은 `승인`, `기각`, `예외`로 닫았다. `예외`는 판정 불능을 뜻하며 이의를 해소하지 않는다. 이의 심사 결과를 반영하면 새 입증 문서 판본을 만들고 이전 판본의 전체 검토 기록을 새 판본 승인에 쓰지 않는다.

전체 검토자도 각 논증 의무에 `승인`, `기각`, `예외`를 남긴다. 기각된 논증 의무마다 이의를 생성한다. 논증 의무 전건이 승인일 때만 전체 검토가 승인된다. 논증 의무와 판정 목록의 기계 대조가 검토 누락을 잡는다.

## 터득한 것

검토자의 결함 발견과 그 발견의 심사를 분리하면 거짓 양성과 거짓 음성을 다른 자리에서 다룰 수 있다. 이의 심사 결과를 새 판본의 일부로 넣고 전체 검토를 초기화하면 이의 심사자 위에 상급 심사자를 끝없이 쌓지 않아도 된다. 다음 전체 검토가 수정된 증명과 이의 해소 근거를 전건으로 다시 판정한다.

`verify-rounds`의 `승인`과 `기각`을 재사용하되 `예외`를 추가한 이유는 판정 불능과 이의 부당성을 구별하기 위해서다. 현행 검증런의 「확신이 없으면 기각」 규칙을 입증 심사에 그대로 적용하면, 판단하지 못한 이의를 부당한 이의로 잘못 해소할 수 있다.
