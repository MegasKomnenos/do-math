첫 전문 HTML 원문이 회수됨에 따라 공통 파일 검사를 보강한다. 기존 검사기는 fulltext의 HTML이 비어 있지 않고 해시가 맞으면 잘못된 UTF-8 바이트나 공백뿐인 파일도 통과시켰다. 두 실패 시험을 실제로 관찰한 뒤 UTF-8 디코딩과 빈 텍스트 검사를 추가했다. 수식·비ASCII 문자를 포함한 정상 HTML은 유지하며 공통23개·재개4개·작업 큐12개 시험이 통과했다. 실제 g05 후보597,466바이트도 형식 검사를 통과했고 원 후보 파일이 나중에 바뀌어도 근거가 유지되도록 루트의 비추적 내용주소 fixture에 복사했다. HTML의 본문 완전성이나 수식의 의미는 이 바이트 검사가 대신하지 않는다.

보존용 전문 HTML은 UTF-8로 작성하고 필요한 자원도 함께 보존하여 오프라인에서 실제로 읽는 절차를 계약에 명시했다. g05의 Reachability in arborescence packings는 DOI10.1016/j.dam.2022.05.018, Hörsch·Szigeti, Discrete Applied Mathematics320(2022),170–183에 대응한다. 작업자는 본문1–5절·Acknowledgment·참고문헌25개와 MathML1291개를 보존하고 HTTP 요청이 없는 Firefox 재열람을 검사했다. 이 실제 기사에는 그림이 없었다. 루트도 첫 화면과 식(1)의 이미지를 읽어 표제·저자·초록·Introduction, 수식의 위첨자·아래첨자·식번호가 표시되는 것을 확인했다. 최종 원문은 d6b2de741d426479로 시작하는 해시의 HTML이며 PDF로 보고하지 않는다.

PDF 주소를 받는 방식과 실제 다운로드 제어 클릭은 구별하여 조사했다. g05의 일부 주소는 Preparing your download HTML을 반환했고, g08의 Tolksdorf는 실제 활성화된 View PDF를 클릭하여 새 탭까지 열었지만 CPE 본문이었다. 충분히 로드된 g05 상세에는 전문이 있었지만 g08의 그 상세는 References로 바로 이어져 전문 HTML로 세지 않았다. 같은 접근 표시나 같은 출판사라는 이유로 본문 존재를 복제하지 않는다. g05는77개 시험을 통과한 코드 목록을 보냈으나, 아래 일반 링크 선택자의 범위 결함이 확인돼 전체 구현 커밋은 수리 뒤 새 목록으로 진행한다. 첫 HTML 자체의 유효성은 유지한다.

g08은 MathSciNet6건의 별도 읽기를 끝내고 브라우저를 닫았다. 실제 DOM의 script[type=math/tex]에 원본 수식이 있어, 텍스트 레이어에서 사라진 지수나 기호를 추측하지 않고 그 원문 TeX를 보존했다. 수식의 이중 prime을 산문 인용의 닫는 부호로 잘못 읽는 경우도 시험했다. 루트는 Handbook of neuroimaging의 완결 설명과 Horrocks–Mumford 필드를 직접 판독했다. 전자는 통계 모형·신경영상 분석의 내용과 목적을 설명하므로 독자 안내가 있다는 이유만으로 제외하지 않는다. 후자는 완결된 첫 요약 문단 뒤에 감사말·첫 본문 절이 붙었고 실제 Cambridge Summary에서도 구획이 확인돼 첫 요약 부분만 추출할 수 있다. 전체 원 필드와 제외 범위를 보존하는 계약을 보완했다.

g02는 짧은 DB 값의 전수 판독에서 No detailed description 안내, 기여자·권리·서지 메모 등이 초록 found로 들어간 오류를 발견했다. 짧은17값 중6개 적격 값을 유지하고11개는 부적격 또는 불확실 판정의 이력과 원자료를 보존했다. 루트도 실제 안내문과 기여자 메모, 짧지만 정상인 quadrature domains 요약을 대조했다. 길이 하한을 높이는 수리를 하지 않았다. De Gruyter의 초기 외곽 화면을1초 뒤 done으로 저장하던 오류도 실제 지연 로딩으로 확인했다. 올바른 준비 상태를 기다린 Epstein2012의 관측 다운로드는38쪽 PDF를 반환했고, 작업자는 인쇄1–37과 빈 끝면·초록을 확인했다. 이 수리까지 반영한128개 회귀와 저장956건 재판정 뒤 두 흐름을 재개했다.

그 후 링크 범위의 큰 오류가 발견돼 g02 두 흐름을 다시 중단했다. URL 어디에나 pdf/download가 있으면 후보로 받는 규칙이 Europe PMC의 전역 PDF 디렉터리와 Perlego의 관련 도서까지 확장했다. 루트가 중단 후 읽은 Scholarship of teaching and learning의 결과는54,692개 작업과172개 시도,21.7MB JSON이었고 Kobayashi 책은815개 작업과228개 시도였다. 발견 때의 부분 분기 수와 현재 전체 작업 수를 구별한다. Tsay 책의560개 작업도 같은 원인인지 실제 부모 출처와 관계를 조사하도록 했다. 큰 수 자체를 오류로 판정하거나 임의 후보 수 상한을 복구하지 않고, 대상 문헌에 연결된 다운로드 문맥과 무관한 전역·추천·참고문헌 분기를 구별하는 수리를 진행한다. 실제 g02 수집 프로세스가 없고 디스크 여유가32.65GB인 것도 확인했다.

g05는 일반 publisher 선택자에서 같은 넓은 문자열 검사를 확인했지만 HTML 디렉터리의 재귀 확장은 없었다. 이미 실제 참고문헌 View PDF를 목표 PII와 구별하는 ScienceDirect 회귀는 있었고 일반 선택자를 보완한다. g08은 현재 전역 FTP·Perlego 대상이0건이고 PDF 후보의 최대 발견이4개였으나, PDF Document Information 도움말을 후보로 읽은 사례를 따로 열었다. 정당한 전체책의 Download PDF(zip)는 제거하지 않고 실제 클릭으로 조사한다. 탐색 제한을 줄이는 것과 무관한 자료의 확장을 제거하는 것을 구별한다.

g05가 읽은 g02 Springer 링크 자료에 Save chapter의 요청 위조 방지용 _csrf 값이 있었고 작업자의 첫 도구 출력에 한 번 포함됐다고 보고했다. 루트는 그 사실과 조치를 사용자에게 알리고 값을 반복하지 않았다. g02는 원본2개를 보호된 .credentials 영역으로 옮기고 정제한 새 내용주소 사본으로 경로·해시 참조를 함께 갱신했다. 실제 _csrf URL 또는 Save chapter 방문은0건이었다. 루트는 관련 작업 파일과 이 경로의 기존 커밋7개를 값 출력 없이 검사해 해당 토큰 형태가 남은 파일을 찾지 못했다. 이 검사 범위와 결과는 operator-checks/csrf-audit.json에 남겼다. 수집물 정제는 앞선 도구 출력 자체를 지웠다는 뜻이 아니다.

이 커밋은 공통 HTML 검사·계약·검증 기록의 단위다. g02·g05의 링크 범위 수리와 나머지 문헌 회수는 아직 진행 중이며, 이들을 완료로 포장하거나 개발 중 코드와 섞지 않는다. 전체 요청이 끝날 때까지 전담 작업자와 루트의 수집·검토·수리·재실행을 계속한다.
