title: 자동 회수 근거 기록을 Git 비추적 로컬 보존으로 전환함
convention_version: 24
---

사용자는 대량 미추적 내역 정리를 요청하고, 자동 회수 근거 약 2만 4천 개를 Git에서 제외해 로컬에 보존하는 방안을 승인했다. Git 복구에서 빠지고 별도 백업·이관이 필요하다는 조건을 설명한 뒤 받은 결정이다. 기존 결정문의 Git 추적 방침을 이 범위에서 변경한다.

.gitignore에 catalog/version-review-evidence/의 루트 한정 규칙을 추가하고, 선별 절차 결정문과 v2 실행 계약에 로컬 보존·별도 백업·목적지 경로와 해시 확인을 반영했다. 두 정책 문서는 기존 미추적 파일이어서 이번 커밋에 개정본 전체를 편입한다. 판정·감사·manifest와 다른 연구 산출물은 제외하지 않는다. 실행 중인 작업과 파일 경로는 유지했다.

적용 전 git status -uall은 26,332행, 적용 후 1,435행이었다. 근거 파일 24,898개가 로컬에 남아 있음을 확인했고 check-ignore가 새 규칙을 사용했다. 병행 실행 때문에 수치는 변동한다. 별도 백업 정책을 명시했으며 이번 작업에서 백업 사본을 만들지는 않았다.
