[[M-0512]] 뒤 형식 결과와 평가 재검토의 직접 계획 발동을 실제 호출로 연결했다. 실제 후보 생산자·중앙 형식검사·worker·Lean 외부 대역을 통과해 검증 성공과 존재하지 않는 선언의 컴파일 실패를 비교한다. 실패는 formal_target=K1의 계획을 실제1회 수락하고 뒤 두 순회에 같은 요청이 다시 생기지 않는다. 성공에는 이 실패 진단 계획이 없으며 첫 owner 순회에서도 계획 호출이 없다. 성공 뒤 일반 동일성 검토의 후속 계획까지 없다고 주장하지 않는다.

기존 적격 보고 재평가 흐름은 활동의 종료·next_owner·unresolved에서 멈췄다. 이를 실제 계획 입력과 호출까지 확장하면서 KD-1914를 발견했다. assessment_reassessment_applied는 올바른 assessment_id/review_cycle_id/판정/다음 소유자/재방문 조건을 만들지만 _enqueue가 이미 있는 계획과 병합할 때 이유 문자열만 보존하고 identity_review를 버렸다. czyl5hpd 원출력에 정상 적용 history, 올바른 활동 followups, 해당 사유만 가진 queued plan이 함께 기록돼 원인이 확정됐다.

처음에는 모든 계획 호출이 아직0일 것이라 가정했으나, 기존 평가 효력 중지에 따라 별도 지식 현재성 계획이 이미 실행돼 있었다. 이후 자원 종료 경로가 evidence_refs로 전달하는 경우로 잘못 추정해 실패를 반복했다. 실제 history를 확보한 뒤 그 추정을 철회했고 정상 재평가 게시의 identity_review 병합 유실로 확인했다. 이 중간 구성 오류와 실제 진단 원보고를 모두 보존한다. 현재 시험은 재평가 cycle에 결속된 요청과 assessment ID를 추적하고 같은 요청의 실제 호출1회·수락·후속 중복 없음을 검사한다.

_enqueue는 기존 compare_keys와 명시적인 병합 필드 외의 extra 데이터를 판단 입력으로 보존한다. 동일 필드의 값이 서로 다르면 별도 요청으로 남기고, 같거나 한쪽에만 있으면 독립 복사하여 병합한다. 새 요청도 해당 데이터를 복사한다. 사유·사건·영수증·근거 목록과 개정 대상의 기존 병합 규칙은 유지한다. identity_review만의 임시 특례를 만들지 않았다. 직접 검사는 재평가 데이터·형식 대상·외부 반려의 두 입력 순서, 동일 요청 중복, 충돌 시 분리, 호출자 사후 변경의 비전파와 실제 저장 왕복을 검사한다.

중간 병합 검사는 최초 요청 alias와 불충분하게 조립한 input_overflow 저장 전제를 드러냈다. 최초 요청 데이터 복사는 교정했다. input_overflow는 구체적인 저장 계약을 가진 자료여서 임의의 execution_id만으로 만든 fixture를 제거하고 직접 검사에는 실제 저장 가능한 위3종을 사용했다. 실제 입력 초과 경로 전체를 이 직접 검사로 입증하지 않는다. 최초 alias 실패와 교정 결과도 원보고로 보존한다.

형식 직접1개20.5초 통과, 중간 병합 교정 뒤 실제 재평가 흐름 통과, 최초 요청 복사까지 교정한 직접2개14.0초 통과를 거쳤다. 최종 구조48·Sim37·flows3, 총88개가198.4초에 통과했고 실행 중 소스 변경은 없다(정확 시간은 원보고). 실제 재평가 본문90.656초는 전체 원입력/리뷰/계획 연쇄를 유지하는 비용으로 docstring과 보고에 남겼다. 추적 원보고는 검증/2026-10-05-형식-검토-발동/이며 report.json SHA256은 c9636aafd93f9ed16cd00ae7c6fbdb6d692e5bb8354ed9a5addd124ac230d0fd다.

11-B 전체는 아직 미완료다. 이번 범위는 형식 실패와 assessment 재평가 게시이며, 일반 identity review 게시와 review resource disposition, trust transition, knowledge/revision/readiness 등의 다른 직접 원천은 계속 연결할 대상이다. 큐의 이유 문자열만으로 실제 판단 입력 보존을 판정하면 안 된다는 구체적 공백을 고쳤다. 최종 전체 일반·fresh T3·변이·외부·문서 관문도 남아 있다.
