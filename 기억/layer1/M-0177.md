title: 경로 인자에 중첩된 다운로드 서명 URL을 정제함
convention_version: 24
---

PQDT 보충 파일 조사에서 서명된 URL이 특수 인코딩된 경로 인자로 들어 있어 정제기를 통과해 진단 출력에 나타났다. 이 사실을 사용자에게 알리고, 중첩 URL 정제와 진단 출력 축소를 적용했다. 합성 값으로 재현한 두 회귀 검사가 통과했다. 이미 표시된 출력의 삭제나 서명 무효화는 확인하지 않았다.

기존 원칙은 인증 쿼리·헤더·숨은 입력을 출력하지 않고 진단에 호스트·경로·제어 구조만 남기는 것이었다. 그러나 ProQuest의 docview.supplementalfiles 다운로드 동작은 미디어 URL 전체를 경로 인자로 실었고 슬래시·물음표·등호 등을 $와 16진수로 표현했다. 외부 URL의 query만 검사하는 정제기로는 내부 서명을 찾지 못했고, 그 정제된 HTML에서 다시 뽑은 path도 안전하지 않았다. 호스트와 경로가 언제나 비민감 정보라는 진단의 가정을 수정했다.

Sanitizer는 경로 안에 있는 Tapestry 또는 percent 인코딩 URL을 인식하고, 인증 필드나 userinfo가 있으면 중첩 URL 인자를 제거한다. 외부 다운로드 동작과 파일명은 남긴다. 인증 정보 없는 공개 DOI 연결은 그대로 유지한다. 테스트에는 실제 값을 넣지 않았다. 로컬 정제 사본은 새 정제기로 덮어썼고 인코딩된 서명 인자의 잔존 여부가 false임을 확인했다. 원 응답은 기존 보호 경로에만 둔다. 이후 진단은 임의의 다운로드 path를 출력하지 않는다.

이 수정은 IEEE 미디어 개발과 분리 가능한 보안 정제 단위라 먼저 커밋한다. 동시에 작업 중인 IEEE 구현은 실제 104,143,825바이트 동영상의 25개 구간 조립과 표지 이미지 회수를 MCP에서 통과했지만 다음 커밋으로 결정화한다. PQDT 표본 2485541561의 Supplemental files 탭에서 PNG 한 개를 확인했고, native 다운로드 제어의 실제 회수 구현은 아직 진행 중이다. 전체 작업을 완료했다고 보고하지 않는다.
