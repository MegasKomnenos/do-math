DBLP의 접근 확인을 영구적인 검색 실패로 취급하지 않고 실제 응답의 구조를 읽었다. Chromium의 060822Z 관측은 Anubis Access Denied였다. HTTP 클라이언트에 주어진 응답은 metarefresh 알고리즘이며 원 meta 태그 또는 Refresh 헤더에 2초 뒤 이동할 URL이 있었다. 브라우저의 거부를 모든 클라이언트의 거부로 일반화하지 않았다.

20260912T063810Z-dblp-refresh.json은 같은 공개 HTTP 클라이언트에서 원 대기 2초·확인 302·검색 JSON 2건을 확인했다. source=dblp의 API 요청에만 이 원 확인을 연결했다. 확인 endpoint와 원 API URL의 호스트·경로·검색 인자, 원 challenge의 id·값을 대조하고 서버가 같은 요청으로 되돌려야 진행한다. 확인 값·쿠키·확인 URL은 artifact에 보존하지 않는다. 별도 API 키·신청·계정을 요구하지 않고 브라우저 검색으로 전환하지 않는다. 다른 확인 방식과 10초 초과 지시는 restricted로 남긴다.

064842387254Z-dblp-workflow.json은 실제 describe_source, P versus NP 검색 49건 중 2건, extract를 completed=true로 통과했다. 원 metarefresh HTML의 구조를 보존하되 일회성 값·IP 등은 합성값으로 바꾼 fixture를 사용했다. 헤더·태그 양성 사례, 다른 호스트·다른 검색식의 확인 주소 거부, artifact의 확인값 비노출을 검사했고 공통 261개 검사가 통과했다. DBLP 원 BibTeX endpoint도 실제 778바이트를 받았다. 원 내보내기와 이름 후보 등 추가 연결은 이어서 수행하며 이 커밋을 전체 DBLP 작업 완료로 세지 않는다.

IOP의 2026년 7월 공식 XML 공급 안내는 연락·사용 목적 제출과 검토를 요구했다. 기존 문헌에서 일반 XML 다운로드 제어를 찾지 못한 사실과 함께, 별도 연락·자격 경로를 쓰지 않는 사용자 결정에 따라 이 공급 경로를 제외하는 설명을 갱신했다. 안내의 MCP 등 자동 접근에 대한 별도 서면 합의 요구도 기록했으며 기관의 실제 합의 여부를 기능 시험으로 확인한 것은 아니다. 추가 연락·신청이나 기존 IOP 코드 삭제는 하지 않았다.

독립 작업 중인 JSTOR 이미지 코드는 이번 커밋에서 제외했다. 그 코드는 062834Z-jstor-image-mcp.json에서 JPEG·ImageContent·restricted 구별,063140Z-jstor-document-mcp.json에서 기존 11쪽 PDF를 통과했다. 현재 조사에서는 오디오의 원 MP3와 실제 보충 PDF 링크도 확보했으므로 계속 구현한다. 원 서명 URL은 보호 파일에서만 읽고 값이 포함된 URL·헤더·예외 메시지를 출력하지 않는다. 사용자 연구 자료와 다른 실행 세션은 유지하고 전체 작업 종료 전에는 푸시하지 않는다.
