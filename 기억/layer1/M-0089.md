## 맥락

세 수정안(지식층-OKF, 상시생성-목차열람, pvsnp-분리)의 통합-설계 반영 충실성과 내부 정합성을 검증하는 전면 체급 런(`임시/통합-설계_검증_2026-09-02`)의 라운드 1이다. 심사자는 사용자 지시로 gpt-5.6-sol medium. 수리 6기(관점 2·영역 4, opus high)가 23건을 제기(조각 26·발견 4·상신 제안 0), 3묶음 병합 후 심사 대상 20건, 승인 19건(수리 14·무처분 1·전달 4)·기각 1건, 본표 17행 적용. 불변식 4(`P vs NP|pvsnp|PVSNP|survival_generation` 잔존 0) 재실측 통과.

## 터득한 것

- 발견(전달) 4건의 실체는 근본 원인 하나다: 루트 `CONTEXT.md`가 세 수정안 반영에서 빠졌다(마지막 변경 커밋 e629114, 반영 커밋 fe5a47f가 건드리지 않음). 상시생성 수정안 3.1·6절 3단계·완료 기준 6항이 「작업 씨앗 생성 근거」 넷째 항 등의 동시 개정을 명시로 요구했으나 미이행. 수리 1~4기가 독립 수렴했고 발견 항목은 병합 간선이 없어 4건 각각 승인됐다. 런 종료 후 사용자 결정 사항.
- 주요 적용: §1.3 포트폴리오 선택자 행의 개편 전 문구(문자열 그물 밖 표현이라 두 수정안 통독이 놓친 자리), §2.2 단조 시계 전칭 규율과 §7.7 벽시계 주기 판정의 충돌, `seed_contract` 계약 검사의 소유 절 부재(§21.1·§24.2), 씨앗 계약의 `description` 저작 지침 부재(절차에만 있고 계약에 없어 비회차 생성 경로에 안 걸림), 외부 대기 가드의 갈래 한정 누락, §25.1 첫 선택 서사·전문 동봉 열거 결손, P03 목차 기준 미개정, shuffle seed 기록 소유의 이중 문구.
- 파견 방식 이탈 실측: Agent 호출에 `run_in_background: false`를 명시하지 않아 수리·병합 파견이 비동기로 돌았다. 완료 통지를 완료 신호로 삼아 절차 등가로 운전했고 장부 운영 기록에 남겼다.
- 수리 5기가 산출 계약 이탈(저장소 루트에 diff용 임시 파일 생성 후 삭제)을 자기 보고했다. 작업 트리 복원을 실측 확인했고 산출물 오염은 없었다.

## 작업 너머 시사점

수정안이 지시한 하류 정본 동기화(CONTEXT.md)가 통합-설계 본체 반영과 별도 단계라서 통째로 누락된 채 verify-rounds 두 번(상시생성 런, 통합 런)을 통과했다. 산출물 목록이 통합-설계 하나로 닫혀 있어 검증 그물 밖이었다. dream에서 묶을 후보: 수정안 수행 세션의 완료 보고가 완료 기준 각 항의 증거를 실물 좌표로 요구하는데도 미이행이 통과된 경위(보고-실행 탈결합 계열, M-0075와 같은 뿌리).
