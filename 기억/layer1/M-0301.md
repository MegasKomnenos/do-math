title: 학술 과제의 반려된 모델 평가를 후보 준비에서 수리하고 재검토하도록 연결함
convention_version: 25
---

사용자는 [[M-0300]]의 전면 검증에서 남은 R1-01·13·15를 직접 수리해 반영하도록 지시했다. 세 항목은 사용자 학술 요구에 결박된 과제의 모델 평가가 반려된 뒤 수정할 경로가 없다는 문제를 공유했다. 검토의 findings와 질문은 이미 전달됐으므로, 전달 자체가 없다는 앞선 지적은 수리 근거로 삼지 않았다. 이번 작업은 새 verify-rounds 라운드가 아니라 지정된 잔여 결함의 직접 수리다.

[[M-0299]]에서 확정된 역할 분담은 후보 준비가 난이도·중요도 평가를 작성하고 계약 검토가 그 근거를 독립적으로 판단하는 것이다. 이 경로에서 후보 준비의 권한은 평가 작성에 한정되며, 사용자의 학술 요구와 완료 기준을 변경하는 데에는 미치지 않는다. 일반 후보 개정이 학술 과제에서 거부되는 현행 보호를 유지하면서, 평가만 작성하는 기존 `assessment_targets` 경로를 반려 이후에도 연결했다. 새 평가 전담 역할이나 임의의 재반려 횟수 문턱은 만들지 않았다.

세션 예산의 학술 과제가 계약 검토에서 `revision_required` 또는 `unresolved`를 받으면, 실행기는 이전 평가를 `model_assessment_history`에 계약 판본·해시·검토 실행 참조와 함께 남기고 현행 평가에서 분리한다. 후보 준비는 과제의 `reviews`와 평가 이력, 원자료를 읽고 평가를 다시 작성한다. 기존 구현에서 이미 반려 상태로 남은 과제도 다음 준비 상태 계산에서 이 경로에 들어간다. 구 구현이 남긴 미시작 일반 개정 요청은 같은 검토 실행 참조를 확인해 제거하며, 실행 중인 요청은 제거하지 않는다.

평가 수신 뒤에는 새 독립 계약 검토를 명시적으로 요청한다. 입력 보충 후 평가가 이전과 같은 내용이면 계약 해시도 같을 수 있다. 이때 과거 반려 기록이 있다는 이유로 재검토를 열지 않으면 다시 정체되므로, 평가 내용의 변화만을 재검토의 조건으로 삼지 않았다. 평가 제출은 승인이나 과제 완료가 아니며, 새 검토가 승인한 뒤 다른 착수 조건을 만족해야 배정 후보가 된다.

평가 수정만으로 반려 사유를 해소할 수 없으면 기존 `model_assessment_deferrals`로 필요한 자료·조치와 재개 조건을 보존한다. 사용자 요구 자체를 바꿔야 하는 경우에는 변경할 요구와 근거, 필요한 사용자 결정을 명시한다. 같은 입력으로 보류를 자동 반복하지 않는 기존 동작을 유지한다. 반려 횟수만으로 AI가 담당할 평가 수리를 사용자에게 넘기지 않는다. 일반 AI 계약의 개정과 구 실행횟수 모드의 처리 경로는 이번 수리로 바꾸지 않았다.

검증 자료는 `임시/do-math_평가재수리_20260917/`에 있다. 집중 검사 23개가 통과했고, 새 사례 5개를 실제 임시 Git 저장소에서도 실행해 모두 통과했다. 검사에는 이전 반려 상태의 이행, 평가 이력과 의견의 입력 전달, 수정된 평가와 같은 평가의 재검토, 사용자 계약 보존, 보류·재개, 계약 변경 동안 도착한 늦은 응답의 미적용이 포함된다. 같은 새 사례를 수정 전 코드에 적용한 결과는 `수정전.log`에 실패로 보존했다. 전체 회귀의 시험별 결과는 `전체회귀.log`, 최종 집계와 검사 판본은 `검증결과.json`에서 확인한다. 모델 응답은 대역이므로 실제 평가의 의미적 품질이나 장기 연구 성능을 검증한 결과로 확대하지 않는다.

전체 회귀는 417개 중 415개 통과, 1개 실패, 1개 미실행이었다. 미실행은 Windows 심볼릭 링크 생성 권한 부족이다. 실패한 병렬 정지 시험은 세 실행의 시작을 최대 15초 기다린 뒤 정지 요청을 보내며, 기록된 실행 수가 반드시 3개라고 단언한다. 이번에는 2개여서 마지막 단언이 실패했다. 그보다 앞선 정지 상태·활성 실행 없음·작업 슬롯 반환 검사는 통과했다. 같은 판본의 단독 재검사는 통과했으며, 세션 배정 시험 파일 전건의 추가 결과는 `세션배정재검사.log`와 `검증결과.json`에 보존한다. 이 재검사로 최초 전체 실행의 실패 기록을 지우거나 전체 실행을 무실패로 표기하지 않는다. 시험의 시작 대기 시간과 단언은 이번 수리에서 변경하지 않았다.

변경한 문서와 공통 필수 참조 8문서를 별도 독해에 제공했다. 첫 독해는 일반 연구 흐름을 설명했지만 새 반려 경로의 이해를 확인할 근거가 부족했다. 독자가 이해해야 할 내용과 확정된 조건, 원고는 유지하고 독자 정보를 실제 반려 처리 상황으로 구체화한 뒤 다시 독해했다. 두 번째 독해는 평가 수리 권한, 사용자 요구 보호, 보류와 재검토를 원문 근거로 설명했다. 두 번째 독해자가 읽기 어렵다고 지적한 표현 두 곳은, 주 에이전트가 인접 문단의 정의와 독해자의 실제 이해에 대조한 뒤 유지했다. 대조 근거는 `문서대조.json`에 있다.

기존 연구 인스턴스와 예약 작업은 재개하지 않았다. R1-16의 구 실행횟수 계획 입력 대조 문제는 이번 지정 범위 밖에 남는다. 후속 dream에서 함께 검토할 후보는 [[M-0299]]·[[M-0300]]이다.

> 참조 정비(D-0006): 위에 적힌 `수정전.log`·`전체회귀.log`·`세션배정재검사.log`·`문서대조.json`은 미추적 자료였고 [[M-0303]]의 작업 트리 정리로 삭제됐다. 같은 디렉터리에는 추적된 `검증결과.json`만 남는다.
