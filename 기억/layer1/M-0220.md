미구체화 범주였던 개별 구독을 KUDOS 학술 DB의 실제 KNU 개별전자저널과 KNU P+O Journal 제공 목록으로 연결했다. 개별전자저널 36행과 인쇄·전자 59행의 합 95행이며 SIAM6종이 포함된다. catalogue, field, coverage_year 조건과 정확한 start/limit 창, JSON·CSV, 행 또는 목록 식별자의 metadata/export를 제공한다. 보유 목록을 논문 색인이나 실제 원문 권한으로 표시하지 않는다. fulltext는 이 목록 endpoint에서 not_offered다.

두 원 workbook의 일부 제목 셀에는 별도 서비스 ID/PW가 포함돼 있었다. 초기 조사에서 그 값이 도구 출력에 노출된 사건은 [[M-0217]]에 보존했다. 후속 구현은 두 workbook 모두의 셀·하이퍼링크·주석과 주석 작성자를 먼저 확인해 발견한 자격값을 정제기에 적재한 뒤 레코드를 만든다. 원 XLSX는 artifact나 fixture로 내보내지 않는다. 특정 행이 나중에 나타나더라도 앞 행의 값이 정제 누락되지 않도록 발견 단계와 반환 단계를 분리했다. 해당 값의 사용이나 외부 계정 접속은 하지 않았다.

표시 URL과 실제 하이퍼링크가 다른 행은 둘을 남기고 충돌을 표시한다. 잘못된 ISSN·URL도 원 표기와 오류를 보존하며 자료를 버리거나 유효한 값으로 꾸미지 않는다. ISSN에서 잘못된 앞부분을 삭제해 정상화하는 결함과 공백·포트·IPv6 URL 오류의 처리 실패를 교정했다. coverage의 current는 각 목록의 기준연도 2026 또는 2025까지로 해석한다. 인쇄·전자 2025년 목록을 미래 권한으로 확대하지 않는다.

검토에서 서식만 있는 빈 행의 허위 레코드, header-only workbook의 역전 좌표, 정확한 목록 fetch가 무관한 다른 목록의 장애에 의존하는 문제를 재현해 수정했다. 물리 데이터 좌표 범위와 논리 레코드 수를 구별한다. 현재 실제 두 workbook에는 완전 빈 데이터 행이 없어 95건 실측은 변하지 않았다. 전용 11개 검사와 data/access-research/integration-review.md의 수리 후 검토가 통과했다.

실제 새 SDK의 services/scholarly-mcp/data/validation/access-research-20260912/individual-subscription-mcp.json은 SIAM6건의 JSON·CSV 식별자, 행 fetch·추출, 개별전자저널 36행의 metadata와 fulltext not_offered,2026년 조건 1건, start35/limit3의 두 목록 경계,0건, 외부 URL 거부를 completed=true로 통과했다. 알려진 workbook 값 2개를 SDK artifact23개와 스테이징 파일에서 검사해 일치 0건이었다. 이 검사는 알려지지 않은 모든 자격 형식이나 이미 노출된 출력의 삭제를 입증하지 않는다.

이 커밋은 전용 어댑터와 회귀 검사 단위다. 공통 등록·사용 설명과 다른 출판사 구현은 후속 통합 단위로 남긴다. 사용자가 금지한 별도 API 자격·계정·연락 이메일과 자료원 자동 전환은 추가하지 않았다. 전체 작업은 진행 중이며 푸시하지 않는다.
