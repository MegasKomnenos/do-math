## 맥락

세 번째 라운드는 실제 Lean 4.32의 실패 관찰과 재현 코드를 추가 원자료로 받아 진행했다. 수리 9항목을 병합한 심사 6항목이 모두 만장일치 승인되었고 장부 9행을 적용했다. 컴파일러 캐시의 동반 산출물과 대역의 계약을 함께 고쳤으며, 중복 빌드의 소스·새 컴파일 조건, native payload 보존, 문서 본문 전달 시험과 실패 시 시험 프로세스 회수도 보완했다.

## 실제 경계 확인

전체 109시험과 미러 검사가 통과했다. 실제 Lean을 사용하는 브로커 검사도 최초 Basis·Target 빌드, 캐시 대상의 독립 검토 거부, 캐시 의존성을 쓰는 새 Target 빌드, 실제 audit_formal 수락까지 통과했다. 캐시는 컴파일러가 실제 만든 파일 목록을 보존하고 불완전한 항목은 재사용하지 않는다. `.olean`만 복원하도록 임시 사본에 결함을 주입하자 강화된 대역 기반 시험도 의도대로 실패했다. 단순히 시험 수를 늘리는 대신 기존 시험의 관측 능력을 보강했다.

## 남은 기록

이번 보고서 수리는 당시 원자료에 있던 실제 실패를 미해결로 기록했다. 수리 뒤 성공은 더 늦은 관찰이므로 다음 라운드에 성공 원자료를 주고 보고서의 현재 상태를 정합하게 고친다. 두 관찰은 로컬 Git 제외 sources 디렉토리에 별도로 보존한다. 이전 라운드의 빌드 상태 및 취소 경합 관련 기각은 장부에 유지하며, 검증 종료 시 처리 결과를 다시 확인한다.
