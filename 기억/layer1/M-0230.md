제한 판단 감사에서 Wiley의 총 3행, IEEE의 미구현 HTML, Nature에만 한정했던 Springer HTML, 공개 문서의 script-only 응답 거부를 다시 열었다. 자료원의 실제 제어·응답과 SDK를 대조해 구현했으며 이 단위의 52개 검사가 통과했다. 모든 자료원과 모든 문헌을 전수 실측했다는 뜻으로 확대하지 않는다.

Wiley의 원 Add 제어는 3행 이후에도 계속 동작해 최소 9행을 생성했다. 기존 추가 2행 상한을 제거하고 요청한 행마다 원 제어를 확인해 추가한다. 행이 생성되지 않으면 일부 조건으로 검색하지 않고 오류를 반환한다. 실제 Title algebra와 AllField matrix·methods·analysis·polynomial의 5개 조건이 순서대로 유지됐고 667건·문헌 1건을 SDK로 확인했다. 기존 3행과 Date 정렬도 검증했으며 Date가 Earliest를 제출하는 것은 원 제어의 동작이었다.9를 새 상한으로 만들지 않았다.

IEEE fulltext_html은 현재 문헌 번호·DOI·제목과 원 본문 계층을 대조한다.10488889는 본문 44,364자·heading18개와 기존 12쪽 PDF를 회수했다. 검색 showHtml=false였던 7780459도 실제 HTML 전문을 제공했으므로 그 flag를 부재 판정으로 쓰지 않는다. 초기 구현의 1000자·heading2·paragraph2 하한도 근거 없는 축소여서 제거했다. 유효한 native 구조의 짧은 한 문단 반례가 통과한다. 실제 HTML 제어가 있는데 본문이 준비되지 않으면 오류·source artifact를 반환하며, 제어와 본문이 모두 없었던 825845는 해당 문헌의 관측으로 구별한다.

Springer의 비 Nature 문헌10.1016/S1018-3639(18)30727-X에서 원 SecN 본문 7개, HTML 86,902바이트, TeX13개, 그림 8개를 실제 SDK로 검증했다. DOI에 결속된 그림과 본문을 회수한다. 다른 문헌10.1007/s00037-008-0249-x의 이미지는 root가 직접 판독했다. 경북대 기관 접근 표시와 PDF 다운로드 제어가 있었으므로 paywall이라는 초기 설명을 철회했다. 초록·Article PDF·서지 영역과 HTML 본문 미인식을 구별하며 이 이미지들만으로 PDF 바이트 회수 성공을 주장하지 않는다.

공개 문서의 script-only 응답에는 인증 상태를 공유하지 않는 공개 context의 렌더 경로를 연결했다. 처음 넣었던 전역 단일 h1·제목 외 100자 하한도 짧은 문서와 복수 heading을 배제해 제거했다. 일반 공개 페이지의 visible 내용·서지 제목·문서 title을 사용하며 빈 로딩 상태·로그인·보안 확인은 성공 자료로 표시하지 않는다. 실패의 정제 source_page를 보존한다. OSF preprint에는 실제 관측된 main h1 준비 신호를 적용한다. 중간 SDK가 navigation shell의 제목 OSF를 너무 일찍 채택한 실패를 교정한 뒤,9apsq_v1의 정확한 제목·HTML 168,088바이트·추출을 completed=true로 확인했다.

근거는 services/scholarly-mcp/VALIDATION.md, data/access-research/ieee-html-sdk.json과 limitations-audit의 independent-wiley-sdk.json, independent-springer-sdk.json, independent-springer-negative.json, independent-webdocuments-osf-sdk.json, root-image-review.md다. EuDML은 실제 미인식 NLM을 발견하지 못해 형식을 발명하지 않았다. 좁은 CQL은 200이었고 다른 요청의 TTFB timeout과 구별했다. Scopus·MathSciNet·WOS 추가조건, 다른 입력 상한과 Software Heritage의 개별 파일 회수는 후속 단위에서 계속하며 전체 완료·푸시를 선언하지 않는다.
