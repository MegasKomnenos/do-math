zbMATH의 라이선스 안내문을 초록 확보로 표시하던 결함을 수리하고, 원 리뷰·요약 구분과 참고문헌 회수를 연결했다. DOI·이름·기존 문헌 링크와 임의 검색 창도 지원한다. 실제 MCP와 공통 검사 122개가 통과했다. 전체 학술자료 MCP의 남은 출판사·첨부 작업은 계속 진행한다.

Natural proofs의 문헌 ID 1079979, Zbl 번호 0884.68055에는 summary 한 개가 있었다. 그러나 text는 라이선스 충돌로 내용을 제공하지 않는다는 75자 안내문이었다. 기존 fetch는 필드 내용을 검사하지 않고 abstract를 항상 available로 설정했다. 실제 응답으로 실패를 재현하고 해당 안내를 restricted/content_license_restriction으로 구별했다. 리뷰·요약에 텍스트가 있으면 원 contribution_type을 유지한 source_page로 반환하고 저자 초록으로 추론하지 않는다. 정상 빈 배열도 별도 상태로 검사한다.

원 레코드는 참고문헌 40개를 제공했다. supplementary는 그 배열과 extract용 selection을 가리킨다. 외부 문헌 링크를 방문하지 않는다. DOI 조회는 원 구조화 검색 뒤 선택된 문헌을 회수하고, 그 문헌의 links에서 DOI를 대조한다. 참고문헌 DOI나 다른 문헌의 응답으로 식별하지 않는다. ID와 Zbl 번호는 원 id·identifier에서 대조하며, 이름은 후보를 반환한다. ?q=an:0884.68055와 DOI 10.1006/jcss.1997.1494를 실제 MCP로 확인했다. 10.으로 시작하는 점 구분 번호와 DOI의 슬래시 형태를 구별하는 대역 검사도 추가했다.

기존 start는 limit의 배수만 허용했다. 원 API의 페이지를 필요한 만큼 읽고 요청 창을 선택하도록 바꿨다. 전체 건수·원 페이지 행 수가 달라지면 오류로 구별하고, 읽은 원 페이지들의 참조를 모두 문헌 artifact에 보존한다. 실제 start=1, limit=2의 결과는 start=0, limit=4의 같은 구간과 일치했다. native export는 전체 원 페이지들이고 json 레코드는 요청 창이다.

공식 /v1/openapi.json은 별도 자격 없이 받아 문헌 경로를 확인했다. 별도로 시험한 두 웹 BibTeX 후보 주소는 403이었으므로 경로가 유효하다거나 native BibTeX가 회수됐다고 기록하지 않는다. API 실패 후 브라우저로 자동 전환하지 않았다. 정확한 성공 보고와 원 관측 경로는 services/scholarly-mcp/VALIDATION.md가 소유한다.

지원표·describe_source·회귀 흐름을 갱신했다. 사용자 설정과 기존 연구 산출물을 보존한다. 이 단위의 구현·검증은 끝났지만 전체 자료원의 남은 검색·내보내기·첨부는 완료로 세지 않으며 푸시하지 않는다.
