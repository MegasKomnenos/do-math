사용자는 지난 장기 실행의 비효율을 지적한 뒤, 압축 후 복구를 잘하는 방식보다 애초에 압축 없이 끝낼 수 있는 작업 방식을 요구했다. 이어 전체 목표의 작업 목록과 이전 작업들의 재검토를 그 방식으로 수행하라고 명시했다. 이전의 전체 목표 자동 계속·세부 작업 누적을 기본 실행 단위로 두지 않고, 필요한 원문과 현재 코드·산출물·검증·종료조건을 지정한 독립 작업자에게 대화 이력을 상속하지 않는 fork_turns=none으로 배정했다.

이번 회차는 요구 작업 목록, 문서 검사기 독립 검토, 이전 변경 담당 매핑과 B107~B109 코드 검토의 세 작업을 먼저 배정했다. 문서 검토에서 확정된 선택 옵션 오류는 새 네 번째 작업자에게 최소 수정과 관련 검증까지 별도로 맡겼다. 각 작업자는 지정한 산출 뒤 반환했고, 새 문제를 같은 구현에서 계속 확장하지 않았다. 상위는 산출물·실제 diff·원보고를 검수해 기존 단계-전환표의 current_work.independent_execution에 통합했다. 로컬 .skill-workspace 초안은 Git 미추적이므로 그 내용과 상세 근거를 이 추적 JSON 안에 보존했다.

원래19+11의무·보존61·P2 원래12를 모두 매핑했고 의존성 누락/순환은 없다. 102개 초안은 50개 요구 영역, 보존11묶음, P2 8묶음, 변이17파일묶음, 최종/연결 항목을 포함하며102개 신규 구현이라는 뜻이 아니다. 검수 후 AST 생산자 추정 교체5범위와 완료된 선택 옵션 수리를 더한108개 추적 항목이다. 큰 영역 제목은 바로 실행하지 않으며 실제 입력 경로·구간·한 산출물·검증으로 한정한 지시서를 먼저 확정한다. 검토 종료와 원래 요구 충족은 별도 상태다.

초안의 R27 우선 사유가 직전 focus라는 점은 받아들이지 않았다. 직전 작업을 관성으로 계속한다는 사용자 지적과 충돌하기 때문이다. R28 읽기 한도 확인을 R27 단독 이름에 종속시킨 것도 제거했다. AST 교체는 새 단독 이름 지원에 묻지 않고 순수 반환/CLI/역할 입력/검토·수입/신뢰의 명시 범위로 나눴다. 다음 후보는 R07 스키마 격리의 기존 증거와 B22 검토, R17 지급 명령, 순수 반환 교체, 독립 읽기 한도다. 모든 재검토를 구현의 일괄 선행 관문으로 만들지 않는다.

이전 B01~B109의109행을25개 변경 영역에 중복/누락 없이 연결하고, 기반 단계·보존 대비136경로·이행 처분표46개도 대응했다. 이는 기존 변경 전체를 재검토했다는 뜻이 아니다. 실제로 검토를 끝낸 PR23(B107~B109)은 정확한 실행 대상, 변경 근거, 고정 입력, 사건 소비 의미를 보존하며 즉시 제품 수리나 새 시험이 필요한 결함이 확인되지 않았다. 원보고·실제 diff·현재 소비자를 대조했다. 현행 옛 시험 ID가1932개로 원문1931개와 다른 점은 PR05의 명시 종료 질문으로 남겼다. 보조 소스 경로4개는 존재가 확인되지 않아 actual diff 경로로 해소하기 전에는 파견 입력으로 쓰지 않는다.

문서 검사기 검토는 실제 schema 소유자/배열 경로/동명 변수의 owner/함수·상수 이름 검사를 유지할 실익이 있다고 판단했다. AST 복원은 result의 ghost를 삭제하거나 재대입으로 없애도 존재한다고 통과시키고, 같은 결과의 dict(...) 표현에는 실패하는 반례를 재현했다. 이를 제품 반환 계약의 증명으로 취급하지 않으며 소스 구문 분석기를 더 키우지 않는다. 기존 경계 결과나 제품이 실제 쓰는 공유 계약으로 바꾸는 작업을 배정했다. 과거59개 구조 통과를 삭제하지 않고 무엇을 입증하지 못하는지 현재13-C 상태에 반영했다.

확정 수리 하나는 command_issues에서 [--flag VALUE] 문서 개요가 명령별 옵션 검사를 우회하는 것이었다. 평문 status --goal-file은 거부했지만 대괄호를 붙이면 통과했다. bracket를 옵션 비교 전에 제거하는 최소 변경을 적용하고, 단축/정식 명령·정상 선택 옵션·PowerShell/backslash 줄 연결·무관한 산문 분리를 기존 시험에 추가했다. 수정 전1실패, 수정 후 문서 모듈17개 통과(원보고6.2초), 두 실행의 changed_during_run은 비어 있다. 원보고는 검증/2026-10-05-문서-선택인자에 바이트 그대로 보존했다. 전체 셸 해석기나 새 AST 기능은 추가하지 않았다.

목록/재검토/한정 수리의 확정은 전체 재편 완료가 아니다. 현재 동일 판본 일반/fresh T3/극단 변이·정상 기준/T4·T5·말뭉치·지침·미러/main 목표를 그대로 유지한다. 시간 예산은 소프트이며 timeout·push·graphify 갱신·기존 연구 재개/삭제는 수행하지 않았다.
