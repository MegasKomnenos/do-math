title: AIP의 외부 보충자료 참조와 Figshare 공개 파일 회수를 연결함
convention_version: 24
---

AIP의 보충자료가 별도 Figshare 컬렉션으로 연결되는 것을 확인해, AIP에서는 자료원·DOI 참조를 반환하고 Figshare는 독립된 공개 API 자료원으로 구현했다. 실제 MCP에서 참조 선택과 Figshare 검색 범위·컬렉션 구성원·명시적 버전의 보충 PDF 회수 및 추출을 검증했다. 전체 구현 작업은 계속 진행하며 완료로 보고하거나 푸시하지 않는다.

AIP DOI 10.1063/5.0282369의 원 supplementary material 링크 두 개는 같은 컬렉션 DOI 10.60893/figshare.aip.c.7956296을 가리켰다. 문헌 section의 실제 제어를 읽어 중복을 제거하고 source=figshare·target DOI·selection_required를 반환한다. AIP 호출이 Figshare까지 자동 순회하지 않으므로 지정 자료원 경계를 유지한다. 다른 보충 레이아웃은 원 페이지 참조를 남긴다.

Figshare 공식 OpenAPI의 public articles/collections 경로는 security=[]이며 토큰 없이 실제 검색·서지·파일 요청이 성공했다. 컬렉션 7956296은 문헌 29678765 하나를 포함했다. 그 문헌 버전 1의 Supp.pdf는 2,790,536바이트·5쪽이며 제공된 MD5와 일치했다. 파일의 실제 저장 경로는 Figshare downloader에서 AIP 전용 S3 bucket으로 연결됐다. 공유 S3 호스트 전체를 열지 않고 확인된 bucket 경로를 허용했다. 다른 Figshare 저장소는 추가 확인 전 source_boundary다.

공개 검색은 POST JSON이며 기존 API helper의 GET 동작을 보존하면서 JSON body가 있는 요청만 POST로 보냈다. 301·302·303과 307·308의 메서드 유지 규칙 및 외부 리디렉션 차단을 대역 검사했다. 공식 일반 문서의 offset 상한은 1000, 최신 OpenAPI는 5000으로 달랐다. 구현은 OpenAPI 상한을 사용하고 서버 거절을 보존한다. 실제 높은 offset을 검증했다고 표현하지 않는다. 전체 건수는 응답에 없어 null이며, 임의 시작 위치의 결과를 앞선 넓은 창과 실제 대조했다.

과거 컬렉션 metadata에는 버전 경로가 있지만 버전별 구성원 조회 경로는 명세에 없고 추측 경로도 404였다. 현재 구성원 목록과 과거 버전 자료를 혼합하지 않도록 명시적 컬렉션 버전의 supplementary는 not_implemented로 남겼다. 현재 구성원은 전체 페이지와 metadata 건수를 대조하며 후속 실패의 이전 결과를 유지한다. 문헌의 명시적 버전은 그 endpoint로 파일 목록을 고정한다. 외부 is_link_only 파일은 자동 방문하지 않으며 공개 다운로드 제한·메타데이터 전용 기록·파일 무결성 실패를 구별한다. repository description을 저자 초록으로 단정하지 않는다.

이번 단위 전에 진행한 ScienceDirect 재조사도 결정화한다. 처음 Enter 제출은 action 없는 홈페이지 폼에서 /?qs=algebra로 이동했고 검색 결과를 만들지 않았다. 스크립트는 모두 정상 응답하고 pageerror도 없어 자산 로딩 장애로 단정하지 않았다. React handler 준비 뒤 키보드 입력은 autosuggest 응답을 받았으며 원 Submit quick search 버튼 클릭은 실제 /search?qs=algebra로 이동했다. 그 문서 응답은 HTTP 403·CPE00001이었다. KUDOS의 자료원 깊은 링크로 같은 검색에 진입해도 CPE 오류였다. 정상 검색 경로의 제한을 확인한 것이며 0건·특정 원인·검색 API의 존재를 주장하지 않는다.

실측 보고의 정확한 경로와 수치는 services/scholarly-mcp/VALIDATION.md가 소유한다. 기존 연구 자료와 사용자 설정은 건드리지 않았다. 다음에는 남은 출판사 검색·첨부·원 형식을 계속 확인한다. 별도 API 키·Scopus 추가 웹 계정·Unpaywall 이메일 보류는 유지한다.
