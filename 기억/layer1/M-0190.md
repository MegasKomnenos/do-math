title: Nature 원문 HTML·TeX와 문헌 그림의 명시적 회수를 연결함

Nature의 원 페이지에는 HTML 전문과 그림이 있지만 기존 fetch에서 별도 HTML 전문을 요청하면 invalid_parts였다. 기본 PDF 회수와 다른 원 형식을 요청할 수 있도록 springer 자료원에 fulltext_html을 추가했다. 공통 도구 설명은 자료원별 추가 항목을 describe_source에서 확인하도록 연결했다. 다섯 MCP 도구와 자료원 경계는 유지한다.

실제 The complexity of NISQ 페이지에는 c-article-body 하나와 그 안의 main-content가 있었다. 본문에는 TeX 수식과 그림 한 개가 있고 추천 문헌 위젯도 섞여 있었다. 관측된 본문 영역을 보존하되 추천 위젯을 제외한다. 초록만 있는 영역은 전문으로 수용하지 않는다. 그림의 MediaObjects 경로에 부모 DOI가 있는지 대조하고 PNG/JPEG 바이트를 기계적으로 검사한다. HTML의 그림 src는 저장된 artifact ref로 바꿔 호출 AI가 같은 그림을 extract로 읽게 한다. MathJax 실행·OCR·의미 판독은 서버에 넣지 않았다.

새 SDK stdio 보고 services/scholarly-mcp/data/validation/20260910T125713Z-nature-html-mcp.json이 completed=true다. HTML 151275바이트와 원 TeX 두 항목을 추출했고, 그림 PNG 56058바이트·685×220을 확보했다. 그림 extract는 실제 MCP ImageContent 한 개를 반환했다. 원 HTML은 기계적 읽기용 artifact이며 독립 웹페이지 렌더링으로 검증한 것은 아니다. 이 레이아웃을 다른 Springer 문헌 전체로 확대하지 않는다.

원 그림·수식의 축소 fixture와 초록 전용 반례, 그림 요청 실패 후 본문 보존을 검사했다. 새 검사는 3개이며 마지막 공통 검사는 178개다. HTML 본문·이미지의 현재 지원 범위와 부분 실패 의미를 describe_source·README·지원표에 함께 반영했다.

별도 공개 API 재검증도 실행했다. CORE의 20260910T125019Z-core-public-mcp.json과 Semantic Scholar의 20260910T125018Z-semantic-scholar-mcp.json은 첫 실제 요청에서 rate_limited였다. 이전 공개 검색 성공을 새 조회·관계·인용문 성공으로 확대하지 않고 두 보고를 미완료로 보존했다. 자격증명·웹 계정·연락 이메일을 요청하지 않는다.

전체 작업에는 기관 검색과 추가 레이아웃·형식의 구현·검증이 남아 있다. 재시작 이후 새 기능은 SDK의 새 stdio 프로세스에서 검증했다. 이미 실행 중인 Codex scholarly 프로세스가 이번 코드를 자동으로 읽었다고 주장하지 않는다. 전체 완료 전이므로 푸시하지 않는다.
