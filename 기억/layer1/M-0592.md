title: graphify 업데이트 모델과 기본 동시성을 변경한다
convention_version: 27
---

사용자는 graphify update가 `gpt-6-sol` 대신 `gpt-6.1-sol`을 사용하고 기본 동시성을 3에서 8로 높이도록 지정했다. 의미 추출의 모델 상수는 캐시 검증에도 쓰이므로, 다음 업데이트에서는 구 모델로 만든 의미 추출 캐시가 재사용되지 않고 해당 문서를 다시 추출한다. 이번 작업에서는 설정만 변경했으며 실제 그래프 재생성은 실행하지 않았다.

모델 호출과 그래프 메타데이터·보고서·도움말이 같은 상수를 참조하도록 맞췄다. 정본 문서와 Codex용 생성 사본도 동기화했다. 기존 graphify 테스트 10개, 모델·동시성·시간 제한의 CLI 기본값 검사와 미러 드리프트 검사가 통과했다. 실제 새 모델 호출의 성공 여부는 확인하지 않았다.
