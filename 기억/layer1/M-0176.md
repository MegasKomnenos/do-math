Cambridge와 Oxford의 문헌 보충자료 제어를 기존 파일 회수 흐름에 연결했다. 실제 MCP에서 Cambridge PDF 6쪽·ZIP과 내부 R 소스 줄 추출, Oxford PDF 32쪽을 확인했다. 공통 검사 133개가 통과했다. 다른 출판사 검색·첨부 등 남은 구현은 계속 진행한다.

Cambridge의 Exponential-Family Random Graph Models for Multi-Layer Networks, DOI 10.1007/s11336-020-09720-7은 현재 Cambridge Core에서 원 보충자료를 제공했다. Supplementary materials 표에 같은 제목의 두 파일이 있었고 다운로드 앵커 자체에는 텍스트가 없었다. 처음 앵커 문구와 URL에 supplementary가 포함되는지 살핀 진단으로는 파일을 못 찾았지만, 원 표의 구조를 확인해 PDF·ZIP 두 제어를 확보했다. 표 제목으로 중복을 제거하면 둘 중 하나를 잃으므로 각 제어의 파일 경로를 유지한다.

실제 파일은 static.cambridge.org의 S0033312300006608sup001.pdf·sup002.zip이다. PII를 원 citation_pdf_url의 파일명과 대조한다. 이 문헌의 DOI 접두사가 다른 출판사의 과거 발행과 연결되더라도 현재 Cambridge 문헌 URL과 제어를 기준으로 같은 자료원에서 회수한다. 기관 접속은 기존 KUDOS 바로가기 경로다. ZIP의 구성 항목은 code_to_reproduce/ 디렉터리, PMET.RData, PMET.R이며 소스는 154줄이었다. R 코드를 실행하거나 직렬화된 환경을 불러오지 않았다.

Oxford의 Normal Approximation in Large Network Models, DOI 10.1093/restud/rdag022는 본문의 여러 정리·절 참조에서 같은 보충 파일을 가리켰다. 본문 링크를 첨부 목록으로 중복 수집하지 않고 ArticleDataSupplements 위젯의 원 파일 제어 한 개를 읽는다. oup.silverchair-cdn.com의 PDF 경로는 DOI를 밑줄로 부호화한 문자열을 포함했다. 밑줄을 슬래시로 되돌리는 추측 대신 현재 DOI를 같은 방식으로 부호화해 대조한다. 다운로드 호스트는 문헌 호스트와 분리해 추가했다.

문헌 PII가 다른 첨부는 다운로드하지 않는 검사와 표별 파일·설명 보존 검사를 추가했다. PDF·ZIP 검증 및 파일별 실패 보존은 기존 공유 처리를 사용한다. 새 파일 회수 구조를 만들지 않았고 원 연구 파일은 커밋에 포함하지 않았다. 제어 영역만 fixture로 보존했다. 정확한 실제 보고 경로와 재현 시나리오는 services/scholarly-mcp/VALIDATION.md와 tests/live_publisher_supplements.py에 있다.

다음 작업 대상으로 IEEE와 PQDT의 별도 첨부 회수, 남은 출판사 검색·원 형식을 살피고 있다. 기존 구현에서 IEEE supplementary는 참고문헌을 확보하지만 attachments가 not_implemented이고, PQDT도 별도 보충 파일은 not_implemented다. 아직 이 부분을 완료로 변경하지 않았다. 전체 완료 전이므로 푸시하지 않는다.
