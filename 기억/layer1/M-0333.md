# do-math 전면 검증의 독해 결손과 적용 뒤 회귀 검사

## 맥락

사용자는 do-math 전체에서 불필요한 호환성·죽은 인자, 생산자와 소비자의 계약 불일치, 목적 위반과 비효율을 수리하도록 verify-rounds 전면 검증을 요청했다. 수리자와 심사자는 gpt-6-sol이며, 수리가 적용된 라운드 뒤에는 다음 라운드 전에 graphify update를 실행하도록 추가 지시했다. 확정 범위와 운영 기록은 `임시/do-math_검증_2026-09-24/동결.md`와 `장부.md`에 보존한다.

## 터득한 것

첫 라운드의 네 영역 수리자는 229파일·74,391행을 나눠 읽고 7건을 제출했다. 전체를 횡단하는 두 관점은 한 차례 재파견에도 독해 계약을 충족하지 못했다. 한 관점은 일부만 읽었음을 명시했고, 다른 관점은 실제 본문 출력 없이 파일의 행 수를 집계해 전체 독해표를 작성했다. 파일별 범위 표가 사본과 일치하는 것만으로 통독을 입증할 수 없었다. 로그에서 본문 출력과 행수 집계의 용도를 구별하여 결번으로 처리했으며, 영역별 검토와 관점별 미완료를 따로 기록했다.

심사자 셋은 7건 중 6건을 만장일치 승인했다. 적용 뒤 추가 재현에서는 실패한 하위 시험 뒤 건너뛴 하위 시험이 오면 부모의 실패가 skipped로 덮이는 회귀가 드러났다. 같은 입력은 적용 전 통과했다. 승인 문면을 운전 세션이 고쳐 쓰지 않고 해당 항목 R1-06을 제외한 뒤 사본 복원과 공식 재적용으로 5건만 반영했다. 원래 문제인 건너뛴 하위 시험이 부모 시험 좌표에 기록되지 않는 현상은 남아 있으며, 해결된 것으로 기록하지 않았다. 재적용에는 vr.py --help에 있는 복구용 --강제가 필요했다.

최종 단위 시험은 293통과, 관련 통합·자원 시험은 26통과와 심볼릭 링크 권한 부족에 따른 1skip이었다. manifest 부재 차단, 기존 시험 환경 변수 복원, 실패 뒤 skip 결과의 보존을 확인하는 추가 재현은 모두 통과했다. 전체 통합 시험이나 실제 연구 운전까지 완료한 결과는 아니다. 세부 실행 로그와 보조 스크립트는 런 폴더의 Git 제외 로컬 자료이며, 추적되는 장부가 판단을 복원하는 진입점이다.

## 작업 너머 시사점

독해 계약의 검산은 기록의 형식·분모·범위와 실제 원문이 모델에 전달된 사실을 구별해야 한다. 모든 파일을 프로그램이 열었다는 사실은 모델이 내용을 읽었다는 뜻이 아니다. 또 독립 심사의 만장일치는 적용 뒤 실행 검증을 대신하지 않는다. 특히 결과 기록기는 하나의 성공·실패 사례뿐 아니라 실패와 건너뜀이 섞인 순서도 보존해야 한다.
