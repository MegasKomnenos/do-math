IEEE Media parser가 정상 영상 옆의 DOI 인용 링크를 파일로 오인해 source_boundary를 내던 결함을 원본에서 수리했다. /ielx 파일 후보에는 기존 같은 문헌 ID 검증을 적용하고 다른 인용·도움말 링크는 파일 후보에서 제외한다. 해당 구조의 원본 회귀가 실패한 뒤 Media 9개 검사가 통과했다. Numdam 수리와 함께 전체 534개 검사가 46.398초에 통과했으며 Numdam은 직전 별도 커밋으로 분리했다.

주 세션은 10463014의 실제 문헌 도착·Media 로딩·안정 이미지를 직접 읽었다. 마지막 화면에는 VIDEO 카드와 10.1109/ACCESS.2024.3374782/mm1 DOI 인용 링크가 함께 보였다. 같은 캡처 HTML에 d98d672의 parser와 수정본을 적용하는 로컬 실행을 다시 수행하고, 각각의 직전·직후·안정 이미지 여섯 개도 직접 읽었다. 이전 코드는 source_boundary, 수정 코드는 supp1-3374782.mp4 하나를 반환했다. 이 진단은 실제 저장 응답의 parser 재생이며 새로운 원격 페이지 방문이 아니다.

이어 종료된 IEEE worker의 전용 인증 상태를 새 root 전용 디렉터리로 복사해 원본 server.py의 새 SDK를 실행했다. 기존 공유 인증 상태나 worker 기록을 수정하지 않았다. 결과는 전체 ok, supplementary available, 참고문헌 30개 available, MP4 45,091,657바이트를 포함한 첨부 available이었다. 원 근거는 .credentials/scholarly-mcp/probes/root-user-criteria-20260913T0715Z/ieee, 정제 요약은 services/scholarly-mcp/data/access-research/user-criteria-ieee/root-sdk.json이다.

이 복원과 Media flag 가설은 구별한다. 사본이 조사한 공식 55개 문헌 중 Media 양성 12개의 flag·화면 제어·응답은 일치했다. 모든 문헌에서 flag가 영구히 정확하다고 일반화하지 않는다. 과거 References timeout과 9개 문헌의 직접 REST 401은 같은 입력의 후속 UI·응답 검증에서 재현되지 않았다. API의 다른 endpoint 성공으로 최초 실패를 대체하지 않고 각각의 근거를 보존한다.

통합 검토 중 SIAM Author 후보의 새 회귀도 독립 검토가 입증했다. 단일 underscore exact facet은 근거가 있지만, Boolean·wildcard·괄호와 복수 Author 행을 invalid_options로 거부하는 것은 원래 자유 질의 지원을 줄인다. 공식 Search Tips가 Boolean·wildcard를 설명하므로 exact 변환 불가를 원 질의 거부로 바꾸면 안 된다. 단순 통과만으로 underscore 무시가 해결됐다고 보고해서도 안 된다. 원본에는 이 후보를 넣지 않았다.

dispatch/remaining-20260913/reviews/siam-author-criteria-code-review.md에 구체적 반례와 원 자유 질의·exact facet의 결합 검증을 적었다. runtime의 기존 SIAM 요청 하나를 user-criteria-02-siam-author-code로 교체했고, 이전 목록은 review-requests-before-siam-code-review-03.json으로 보존했다. 같은 CLI thread가 원 화면 전후를 읽으며 반복 facet과 AND/OR 의미를 재검토한다. 과거 요청을 활성 목록에 누적해 재개가 순환하는 방식은 사용하지 않는다.
