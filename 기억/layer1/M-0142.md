g02 신규 작업자의 수집이 오래 지속되므로, 실제로 시험하고 실행 중인 수집기와 회귀 증거를 중간 커밋한다. 전수 회수 완료 커밋이 아니다. 결과 전건과 다른 작업자의 개발 중 코드는 이 단위에 넣지 않는다. 기준은 g02/runs/20260908T160858Z-17572.json의 코드 SHA 목록이며, 작업자와 루트가 현재 파일과의 불일치0을 각각 확인했다. g02/tdd/current-regression-green.txt에는 비라이브80개 검사의 직접 실행 명령과 EXIT0이 있다. 실물 PDF·MR·페이지 순회·필드 검색 증거는 별도 TDD 로그와 비추적 원자료에 남는다.

커밋 검사에서 test_run.py의 행 끝 공백 한 개가 발견돼 그 공백만 제거했다. AST 동일성과 해당4개 테스트 통과를 g02-checkpoint-verification.json에 기록했다. 수집기 모듈은 바꾸지 않았고, 실행 시작 시점 테스트 파일의 SHA도 역사 기록으로 유지했다. 따라서 커밋의 테스트 파일 SHA와 시작 manifest의 해당 SHA 차이는 이 명시된 정돈에 해당한다.

새 resume.py는 저장 증거에서 현재 판정을 복구하고 명시된 검색·출처·PDF·검토 작업을 이어 처리한다. 최대6개 식별자 묶음 검색을 재사용하고 잘림·분할·재사용 횟수를 분리한다. 개별 오류와 제한된 재시도 뒤에는 다른 작업이 계속된다. 이후 실측을 반영하여 새로운 후보가 생긴 때만 다시 판정하고, PDF·출처를 추가 검색보다 먼저 선택하도록 고쳤다. 세 구성요소의 현재 검토와 초록·전체 원문 확보가 모두 성립해야 남은 불필요 탐색을 닫는다. 후보만 받은 상태를 확보로 올려 조기 종료하지 않는다.

g02의 새 실물에는 단어·수식이 손상된 DB 문구, primary 유형은 Journal Article이지만 다른 유형 값은 Book/eBook인 정확한 책, 응답 ISBN이 빠진 정확한 장문 표제의 책, 본문 범위가 앞뒤 부속 자료뿐인 PDF가 있다. DOI·제목·저자·발행정보·자료 유형·판본의 실제 대응을 유지하면서 해당 반례를 수리했다. Viana2006 논문에서는 Received2005를 출판연도로 오인하는 반례를 시험했고, 전체94쪽과 첫 면 초록 구획을 확인했다. 검색 결과에 있던 RSL 공개 열람 표지는 실제 화면에서 href=#인 숨은 템플릿 링크여서 원문 제공으로 인정하지 않았다.

루트는 Summon의 제목·저자 필드 검색을 직접 탐색했다. 진입은 고급검색이라는 링크가 아니라 `옵션` 버튼의 dialog였다. 제목·저자 옵션은 TitleCombined·AuthorCombined였으며, 숨은 submit과 본 화면의 offscreen submit 때문에 넓은 선택자는 실패했다. dialog의 visible data-aid=submit-search 버튼을 사용하고 초기화를 기다린 뒤 두 필드를 먼저 고르고 값을 채워 제출 직전 상태와 응답의 질의를 검사했다. 성급한 설정에서는 첫 행의 필드나 값이 사라져 저자만 검색된 실제 실패가 있었다. 검증된 응답은 Gradient Flows·Ambrosio의 두 필드와 ho=f를 포함했고18문헌을 전부 반환했다. g02도 이 관측 질의를 일반 검색 UI에 입력하여 같은 범위와2005판 대응을 확인했다.

루트는 초록 not_found와 unavailable의 의미를 보완했다. 읽을 수 있는 필수 초록 확인 범위에 적격 값이 없으면 not_found다. 다른 필수 출처에도 없고 초록 확인에 필요한 상세나 원문 내부를 명시적 접근 제한으로 읽지 못했으면 unavailable이며, 초록 존재 자체는 미확인이라고 적는다. 원문 상태값의 단순 복제와 미방문·도구 오류의 종결은 허용하지 않는다. 이 음성 판정 수리는 g02가 새 파일로 준비 중이며, 현재 실행 판본에 아직 연결하지 않았다고 보고했다.

g05의 DOI10.1145/3263801은 원입력 표제가 Session details: Regular features이고, 같은 출판사 DOI 단위의 PDF는 Gasarch의 The Book Review Column4–6쪽이었다. 루트는 원입력·출판사 상세·첫면 이미지·3쪽 파일의 끝을 직접 읽었다. 출판사가 그 DOI 단위의 full content로 제공한 파일이고 작성자·권호·시기가 맞으므로 채택하되, 두 표제를 관측 메타데이터에 구별하고 전체호나 더 넓은 regular-features 집합을 확보했다고 표현하지 않도록 판정했다. 표제 문자열의 동일성 대신 해당 입력이 실제 지정한 출판사 단위와 제공 파일의 대응을 근거로 삼은 사례다.

현재 세 신규 작업자는 계속 수집·검토 중이다. g08은 재개한27건의 공개 검색54회를 수행했고 발견한 정상 출처의 브라우저 회수를 진행한다. g05는 PDF 판독과 기관 출판사·중계 화면의 연결을 보완한다. 루트는 새 결과와 실제 원문, 실행 코드 판본을 대조하며 남은 네 배정을 위한 슬롯이 열리면 디렉토리별 신규 작업자를 이어 파견한다. 전체 완료 후에만 최종 집계와 푸시를 수행한다.
