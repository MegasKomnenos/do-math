# 컨텍스트 적재 경제

컨텍스트에 무엇을 언제 얼마나 적재할지 정하는 원리다. 적재량을 줄이는 작업은 비용 절감과 정보 보존을 함께 다룬다.

## 두 가지 비용

세션 초반에 적재한 텍스트는 이후 턴에서 반복 비용을 만든다. 따라서 자주 읽는 큰 파일을 줄이는 작업이 일회성 출력 축소보다 효과가 크다.

적재 실패는 조용할 수 있다. 선별 로드가 필요한 파일을 놓쳐도 명령은 성공할 수 있다. 적재를 줄일 때는 두 장치를 함께 둔다.

- 보상 장치: 덜 읽은 정보를 다른 색인, 선택 출력, 발동 스킬에서 회수한다.
- 경보 장치: 보상 경로가 깨지거나 출력이 잘리면 실패를 알린다.

창이 충분히 크면 토큰 절감액의 가치는 줄 수 있다. 그러나 중복 description과 겹치는 규범이 만드는 선택 모호성은 창 크기와 무관하다. 적재 절감과 라우팅 모호성 감소를 따로 평가한다.

## 읽기 단위와 파일 단위

두 소비자가 한 파일의 다른 큰 부분을 반복해 읽으면 파일을 나눈다. “이 절까지만 읽는다”는 지시는 준수에 의존한다. 파일 분할은 읽기 도구의 자연 단위와 소비 범위를 맞춘다.

분할 전에는 모든 소비자를 찾는다. 본문을 읽는 도구, 헤더만 파싱하는 도구, 경로를 단언하는 테스트를 구별한다. 절을 옮기면 해당 절의 경로를 검사하는 테스트와 참조도 함께 고친다.

## 성장 파일

작업이 진행될수록 계속 커지는 파일을 상주 소비자가 전문으로 읽으면 비용이 작업량과 함께 증가한다. 소비자가 필요한 부분만 받도록 읽기 경로를 바꾼다.

- 기억 색인은 현행 색인과 아카이브로 나눈다.
- 상태 원장은 현재 처리할 항목을 기계가 선별 출력하게 한다.
- 완료된 기록은 보관부로 옮기되, 현재 상태 판정에 필요한 요약은 유지한다.

선별 출력은 전문 읽기를 대체하므로 같은 판정 로직을 공유해야 한다. 서로 다른 로직으로 “준비된 항목”을 계산하면 전문과 선별 출력이 갈라진다.

## 첫 행동의 적재

문서 안의 금지 조항은 그 문서를 읽은 뒤에만 작동한다. 첫 행동에서 읽지 말아야 할 파일이 있으면 파견 프롬프트의 해당 경로 옆에 직접 금지를 적는다.

파일 편집 도구가 선행 읽기를 요구하면 전문 비적재만 금지할 수 있다. 줄 번호 검색과 범위 읽기 같은 대체 절차를 함께 제공한다.

## 측정

컨텍스트 비용은 추정만으로 결정하지 않는다. 가능하면 트랜스크립트의 사용량과 각 읽기 사건을 대조해 어떤 파일이 얼마를 더했는지 측정한다.

문자, 바이트, 토큰은 다른 단위다. 훅 출력 상한은 해당 런타임이 정한 단위로 잰다. 경로를 POSIX 도구와 Windows 도구 사이에서 넘길 때는 두 도구가 같은 경로를 가리키는지 확인한다.
