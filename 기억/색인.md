# 색인

`memory-harness` 그래프의 현행 색인이다. layer-3 노드 전체와 반영 수위 이후의 layer-1·layer-2 노드를 나열한다. 수위 이하의 layer-1·layer-2 줄은 `기억/색인_아카이브.md`에 둔다.

- layer-3 형식: `- L-#### [주제] -- <현재 내용>`
- layer-1 형식: `- M-#### [제목] -- <한 줄 요지>`
- layer-2 형식: `- D-#### [제목] -- basis: <근거 ID> -- <한 줄 요지>`

---

## layer-3

반영 수위: 없음. layer-1·layer-2 노드가 없다.

- L-0001 [검증 설계 원리] -- 검증 신뢰의 네 차원, 사각의 세 축, 거짓 GREEN 방지, 검증 계약, 도구 운용
- L-0004 [문서 추출과 렌더 판독] -- 바이너리 문서 추출, PDF 페이지 판정, vision 판독, 완전성 검증
- L-0005 [AI 편향과 작업 방법론] -- 값싼 기본값, 표상 드리프트, 정박 편향, 외부 관점, 사용자 교정 해석
- L-0006 [기억 하네스 운영] -- 통제 경계, 세 층의 역할, 읽기 경로, 삭제 무결성, 세션 경계
- L-0009 [스킬 지형과 외래 스킬 각색] -- 스킬 정본의 관할, description 라우팅, 외래 스킬 처리, 각색, 사본 동기화, ponytail 계열
- L-0012 [지시 거버넌스와 규범 발화] -- 발화층과 실체층, 세 도달 경로, 신호 배치, 지시 분해, 형해화 점검
- L-0015 [컨텍스트 적재 경제] -- 적재 비용, 보상과 경보, 파일 분할, 성장 파일 선별 출력, 적재 측정
- L-0016 [위임 파이프라인 운영] -- 상태 파일, 분해와 병렬화, 파견 계약, 재개, 회수 검증, verify-rounds
- L-0019 [do-dag 실행 체제] -- 발동 조건, 역할과 상태, 분해와 검산, 격리와 병합, 게이트, 검증, 예산

## layer-1

- M-0001 [일반 AI 작업 템플릿 기준선] -- 기존 작업 환경의 구조와 일반 절차를 보존하고 프로젝트 고유 산출물·실행 상태를 제외함
- M-0002 [do-dag 반환 계약 표준화] -- 공통 첫 줄과 역할별 확장 필드를 분리하고 검사기·계약·예외 처리를 같은 문법으로 맞춤
- M-0003 [결함 상신과 승인 범위의 분리] -- 사용자 결정 필요 여부를 먼저 판정하고 발견 비용·결정 효과·추천 최종 상태를 계약에 결선함
- M-0004 [반례 실험 도구 기준선의 병합과 광고·증거 대조] -- 보고 기재가 아니라 증거 실물을 열어 광고와 로그의 어긋남을 잡고, 측정 실패와 결과 부재를 같은 값으로 적는 스키마 결함을 수리 행이 닫음
- M-0005 [pvsnp-탐사-1 조기 종결 — codex-full 전환과 여섯 마디 파킹] -- 다섯 마디 전개의 자식은 전부 여섯 마디라 예외가 재분해 없이 못 닫힘. Codex 첫 줄 위반이 지시로 안 막힘
