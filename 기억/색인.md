## layer-3

반영 수위: M-0303 · D-0006

- L-0001 [검증 설계 원리] -- 검증 신뢰성의 네 측면, 사각지대의 세 측면, 거짓 GREEN 방지, 검증 계약과 증거 종류·결합 검증, 도구 운용
- L-0004 [문서 추출과 렌더링 결과 판독] -- 바이너리 문서 추출, PDF 페이지 판정, vision 판독, 완전성 검증과 종료 코드, HWP 편집·저장 검사
- L-0005 [작업 판단과 AI 편향] -- 다음 행동과 한계 공개 뒤 보완 판단, 원문 독해의 단계, 원인과 관찰, 기존 구조 재사용, 독립 검토, Playwright 화면 탐색 후 자동화, 독자 관점 퇴고와 독립 독해의 한계
- L-0006 [기억 하네스 운영] -- 통제 경계, 세 층의 역할, 읽기 경로, 삭제 무결성, 세션 경계와 근거 경로의 추적 상태
- L-0009 [스킬의 역할과 외부 스킬 도입] -- 스킬별 역할, description을 통한 스킬 선택, 외부 스킬 도입, 프로젝트에 맞춘 수정, 사본 동기화, ponytail 계열
- L-0012 [지시의 관리와 전달] -- 규범의 전달과 본문, 세 전달 경로, 신호 배치, 지시 분해와 결정 소유의 양방향 오배치·위임 재량의 경계, 실제 적용 여부 점검
- L-0015 [컨텍스트를 읽는 범위와 비용] -- 현재 원문 재사용, 압축 뒤 재확보, 합산 출력 한도, 계속 커지는 파일과 실제 읽기 측정
- L-0016 [위임 파이프라인 운영] -- 공통 처리와 분해, 위임 권한, 새 실행 경로 확인, 적용 경로 선택과 통합 판단, verify-rounds의 독해 범위·결합 결과·기각·종료 정리
- L-0019 [do-dag 실행 체제] -- 발동 조건, 역할과 상태, 분해와 검산, 격리와 병합, 게이트, 검증, 예산
- L-0020 [do-math 구현과 운영] -- 사용자 요구와 AI 자율의 경계, 파생 상태의 전이 경계, 생산자 제출 검사, 검증 증거 범위, Windows·Codex 실행 환경, 독립 운영과 연구 인스턴스, 기록된 잔여
