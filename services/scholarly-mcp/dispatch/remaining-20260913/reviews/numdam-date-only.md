# Numdam 한쪽 날짜 경계의 의미와 선제거부 재검토

두경계Date-only와qdt페이지수리는보존한다. 그러나official-research.md는until1956만주면76,864건,from1956만주면92건이고두경계1956–1956은359건이라고기록한다. 의미가불확실하다는이유로blankquery의한쪽경계를invalid_options로미리거부한부분은사용자에게모든해법이소진된것으로설명할수없다.

1. 새원UI에서한쪽경계입력전·제출직후·안정화뒤의폼값,숨은q1,qt,실제POST,redirect된검색키와결과를대조한다. 입력이무시됐는지,단일연도정확검색인지,범위검색인지,자동기본값인지구별한다.
2. 현재Numdam공식도움말·실제JS·공식공개구현/원검색문법에근거해한쪽경계를표현하는방법이있는지조사한다. wildcard범위나다른현재제어는공식근거와실제결과를확인한경우에만쓴다. 임의최소·최대연도로무한범위를꾸며내지않는다.
3. source가한쪽입력을상하한과다르게해석한다면그실제의미를밝힌다. source가값을조용히무시한다면MCP가그입력을성공으로보내지않도록정확히알린다. 단순미검증을영구미지원으로바꾸지않는다.
4. Date NOT은숨은제어와-qD가양의조건과같았다는기존근거가있으므로그자체만재반복하지않는다. 새공식제외표현이발견되었을때만별도확인한다.

필요한가장작은수리·설명·회귀·새SDK를마친다. 새로운미확정범위가남으면그근거와범위를명시한다. 기존976/0건과교차페이지양성을훼손하지않고,전용사본/이미지직접판독/공개API경계계약을유지한다.
