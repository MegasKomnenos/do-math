# Oxford 종료 판단 재검토

사용자는 실패 직전·직후 화면을 실제로 읽었다면 더 해결할 수 있는 문제가 남아 보인다고 지적했다. 주 세션은 네 실제 rollout에서 view_image와 반환 input_image를 확인했고, 프록시 모달·직접 검색 화면·기관 검색 결과 화면을 직접 다시 읽었다. 이미지 열람 여부는 확인됐지만 현재 보고만으로 모든 방법 소진을 수용하지 않는다. 기존 결과·원근거를 보존하면서 아래 미확인 축을 끝까지 조사한다.

1. 직접 호스트의 SAMS Sigma 기관 검색은 정식명 하나 입력 뒤 빈 결과 화면이다. 이 화면은 직접 기관 로그인 경로 전체가 없다는 증거가 아니다. 현재 native 후보 요청의 발생·응답·입력 결속을 기록하고, 실제 양성 대조어로 검색기가 작동함을 확인한다. provider가 제공한 기관 데이터/공식 KNU 식별 정보를 바탕으로 짧은 이름·표시명 변형·공식 도메인·목록 탐색을 대조한다. 검증되지 않은 고정4초를 완료 기준으로 삼지 않는다.
2. root가 본 직접 검색 화면은 Save search만 있고 title-list 제어가 없다. 이 조건에서 제어가 없는 이유를 현재 공식 JS의 렌더 조건, 기관 인식/권한 상태, 직접·프록시의 같은 query·사이트·문헌 유형·DOM 준비 상태로 대조한다. 선택자0건과 조건이 충족되지 않아 숨겨진 기능을 구별한다. 이용 가능한 기존 KUDOS 기관 경로로 직접 호스트의 정상 기관 세션에 도달할 수 있는지 조사한다.
3. reCAPTCHA의 invalid-domain 오류 자체는 인정한다. 그러나 이를 '관리자 외에는 할 수 없다'로 일반화하기 전에 공식 Oxford/KUDOS 안내가 제공하는 프록시 진입·정규 호스트·기능 사용 경로가 있는지 확인한다. 현재 공식 제어·문서·응답이 제공한 이동만 정상 수행한다. 토큰 위조·타도메인 토큰 이식·보호 제거·새 계정·지원 문의는 하지 않는다.
4. 신규 각 입력 전·직후·응답 안정 뒤를 고유PNG로 촬영하고 즉시 직접 읽는다. 화면이 제시하는 다음 제어를 시도했는지와 하지 않았다면 그 근거를 기록한다. title-list 성공은 원 집계 CSV와 범위가 검증돼야 한다. 문헌 record CSV를 대체 성공으로 쓰지 않는다.

기존 공개 보고와 사본을 유지하고 새 실험을 추가한다. 성공 시 실제 SDK까지 연결한다. 실패 시 위 축별로 관측된 정확한 경계와 남은 외부 조건을 적는다. 사진을 다시 읽은 사실만 추가한 최종 반환으로 종료하지 않는다. 이번 추가 지시는 원 파견 계약의 사용자 보류·한 자료원·자격 비노출·쓰기 범위를 유지한다.
