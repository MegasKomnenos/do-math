# 보충 ZIP 소진 범위의 연도 공백 재검토

사용자는 AMS/SIAM/Oxford 외에는 정말 다른 해법이 없는지 질문했다. 주 세션이 네 report.md·experiments.json과 보존 crossref.json을 직접 대조해 구체적인 공백을 확인했다. DOI10.2202/1558-3708.1089는2003-01-11발행이고 Crossref 등록 생성은2005년이다. 과거 article XML URL의 캡처는2003–2026을조회했지만, 정확한 원 ZIP URL의 보존소 조회는2013–2026만 수행했다고 기록돼 있다. 따라서 그 정확한 ZIP의 공개 보존 경로가 모두 소진됐다는 결론을 현재 그대로 수용하지 않는다.

기존404·보충제어·2018공식보존페이지·양성ZIP·SDK·원자료를 보존하고 다음을 수행한다.

1. 정확한 원 ZIP URL에 대해2003–2012를 제외할 공식 이관·URL 생성 시점 근거가 있는지 확인한다. 없다면 정상 응답하는 보존소 인터페이스로 이 기간을 대조한다. 캘린더0건,조회실패,재생실패를 구별한다. CDX400을 전체 인덱스 부재로 읽지 않는다.
2. 논문의 발행·원래 출판 플랫폼·현재 De Gruyter 이관 이력을 공식 문헌·보존페이지·등록 metadata에서 회수한다. 이전 시기의 다른 정확한 원 파일 링크가 실제 자료에서 나오면 그 링크를 따라 조사한다. 근거없는 파일명/호스트/URL 변형을 대량 조합하지 않는다. 2018 상대 href가2003의 유일한원경로였다고 가정하지 않는다.
3. 새 경로나 보존 캡처를 발견하면 실제 페이지 전후·응답·파일을 대조하고 직접 이미지를 읽는다. ZIP회수 시정확한문헌·파일명·내용·구조를검증한다. 새 양성이 없어도 각 시기·경로의 조회범위를 정확히 남긴다.
4. 수동 진단에서 공개 보존소를 읽는 것은 기존처럼 허용된다. 이를 생산 De Gruyter 호출의 자동 cross-source fallback으로 추가하지 않는다. 보존소에서 파일을 찾았으면 확보경로와 원출처를구별해주세션에보고한다.

목표는 반드시파일을찾았다는결론을내는것이아니라실제로남은미조사범위를닫는것이다. 소진종료라면제외한연도·경로와제외근거를명시한다. 사진재열람만추가하거나과거결론을반복하고종료하지않는다. 기존계정·권한·전용쓰기경계는유지한다.
