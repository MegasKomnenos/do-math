SIAM의 같은 CLI thread에서 반복 exact Author의 빠진 양성 대조를 확인한다. 기존 USER-CRITERIA와 권한·전용 사본 계약을 유지한다. 이전 복합식·mixed-row 수리를 되돌리거나 전체 실험을 불필요하게 반복하지 않는다.

현재 보고는 [Stetter,Stetter]16건, [Stetter,불가능]0, 반대 순서0, [Stetter,Börgers]0을 근거로 반복 ContribRaw의 AND를 판정한다. 이 대조는 OR/last-wins를 배제하지만 서로 다른 두 실제 공동저자가 같은 논문에서 함께 일치하는 양성 대조가 없다. 이는 새로운 구현 결함 확정이 아니라 남은 검증 항목이다.

기존에 확보한 SIAM 결과나 그 문헌의 실제 Authors/Editors 제어에서 공동저자 두 명이 있는 문헌을 고른다. 추측한 저자 철자 대신 원 UI가 생성하는 정확한 ContribRaw 값을 각각 확보한다. 같은 Title 조건 또는 동일한 통제 범위에서 저자A 단독, B 단독, A+B, B+A를 비교하고 원 대상 논문이 반복 필터 양성에 포함되는지 DOI·제목·저자로 대조한다. 필요하면 서로 다른 공동저자 세 명도 같은 방식으로 확인하되 대표 양성 하나로 현재 누락을 충분히 닫을 수 있으면 확대하지 않는다.

실제 입력 직전·직후·안정 화면을 캡처해 직접 판독하고 요청·응답·원 ID 집합을 결속한다. Source가 반환한 양성 교집합이 단독 집합들과 일치하면 현재 AND 안내를 유지한다. 실패하면 먼저 이름·문법·중복 파라미터 처리·캐시·문헌 선택 실수를 재검토하고 필요한 기술적 수리를 한다. 두 저자가 다르다는 이유만으로 항상0이 되는 요청을 AND 지원으로 보고하지 않는다. 기존 새 SDK와 관련 회귀가 여전히 맞는지 필요한 범위에서 확인한다.

완료하거나 권한 안의 실행 가능한 방법을 근거로 모두 소진했을 때만 반환한다. 이 검토는 현재 원본에 미통합인 반복 exact 후보의 의미를 확인하기 위한 것이며, 등록 MCP·공유 인증·원본 코드·다른 사본을 수정하지 않는다.
