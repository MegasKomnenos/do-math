# ScienceDirect Preface 검색 행의 마지막 구체 경로 확인

기존 사용자 기준과 권한을 그대로 따른다. 현재 Preface의 상세 View PDF는 같은 문헌 HTML로 돌아오며 fulltext_unresolved다. localhost 404의 잘못된 귀속은 이미 철회되었으므로 다시 공급자 실패 근거로 쓰지 않는다.

최신 반환에는 정확한 Title=Preface와 정상 docId=0065-230X를 함께 지정하여 검색 결과의 PII S0065230X26000631 행에서 원 View PDF를 직접 실행한 근거가 없다. 이 결합 경로를 실제 KUDOS→자료원 바로가기→기관 프록시 세션에서 확인한다. 검색 조건 직전, 결과와 정확한 행, PDF 동작 직전·직후·안정 화면을 캡처하고 이미지를 직접 열어 판독한다. 문법과 전송 조건이 실제 UI에 맞는지 확인하며 PII·제목을 대조한다. 로컬 기술 오류는 고치고 재시도한다.

원 제어가 내놓는 실제 응답과 다운로드만 관찰한다. 제한을 우회하거나 토큰을 만들거나 제삼자 solver를 사용하지 않는다. 기존 양성 PDF 실험은 같은 브라우저 동작 비교가 필요할 때만 다시 실행한다. 실패가 지속되면 정확한 요청 단계, 최종 문헌 정체성, 응답 유형과 화면을 서로 대조해 정리한다. 성공하면 검색 행 경로와 기존 상세 경로의 차이를 입증하고 기존 private 후보에서 최소 수리를 한다.

원본과 root의 통합 사본, Git, 등록 MCP, 사용자의 브라우저는 수정하지 않는다. 기존 자기 private 작업 공간과 소유한 브라우저만 쓴다. 현재 root가 PDF와 export를 합치고 있으므로 옛 파일 전체를 통합안으로 요구하지 말고 새 변경만 changes.json으로 제시한다. 원시 응답·서명 URL·인증은 private에 보존한다.

이 구체 실험과 필요한 수리·검증을 완료했거나, 실제로 실행 가능한 정상 경로를 모두 시도해 근거로 남겼을 때만 반환한다. 중간 상태를 완료로 제출하지 않는다. result, report, criteria-review, visual-review에 정확한 전후 이미지 경로와 실제 판독 내용을 포함한다.
