# 줄별 출현 횟수 CLI

UTF-8 텍스트 파일 하나를 받아 줄별 출현 횟수를 JSON으로 출력한다.
빈 줄은 세지 않는다. 공백만 있는 줄은 빈 줄과 다르게 취급한다.
대소문자와 앞뒤 공백을 보존한다. LF, CRLF, CR을 줄 경계로 인정한다.
출력 키는 문자열 오름차순으로 정렬하고 비ASCII 문자를 그대로 출력한다.
성공하면 stdout에 JSON 객체와 마지막 LF 하나만 출력하고 종료 코드 0을 낸다.
파일 읽기나 UTF-8 해독에 실패하면 stdout은 비우고 stderr에 오류를 알린다.
그때 종료 코드는 2다. 파일 경로를 하나 주지 않은 경우도 종료 코드 2다.

정확한 오류 메시지 문구와 내부 구현 방식은 개발자가 정할 수 있다.
대용량 스트리밍, 파일 여러 개 처리, 설치 패키지 배포는 이번 범위에서 제외한다.
