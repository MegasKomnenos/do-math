# 현재 계획

phase 001에서 core와 CLI를 구현한다. 두 task는 S1을 공유한다.
core task는 문자열 집계와 단위 검증을 맡는다.
cli task는 파일·인수·출력·오류를 맡고 S1 테스트 대역으로 자체 검증한다.
CLI의 대역은 테스트 안에만 두며 실제 실행 경로에는 남기지 않는다.

두 task가 끝나면 manager가 report를 읽고 실제 상태를 확인한다.
구현이 준비됐으면 다음 task에서 실제 두 구현을 연결해 G1~G3을 검증한다.
구현이나 S1에 문제가 있으면 필요한 수정·조사를 먼저 배정한다.
후속 phase의 수와 배정은 아직 확정하지 않는다.

최종 review는 G1~G4, S1 일치, 실제 명령 실행, 미검사 범위를 확인한다.
review에서 수리가 필요하면 work phase를 만들고 그 뒤 다시 review한다.
