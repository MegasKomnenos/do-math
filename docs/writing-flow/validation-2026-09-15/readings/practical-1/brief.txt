# 작성할 내용
수행계획서의 「과제 목적 및 필요성」 중 필요성을 설명하는 하나의 독립 절을 작성한다. 분량을 채우는 목표는 없다.

# 확정된 목적
학술 문서에서 구체적인 의미로 사용된 용어와 개념을 그 문서의 의미대로 정리하고, 실제 학술 문헌에서 찾은 관련 개념과 비교해 사용자가 두 목록 및 분석 문서를 참고하도록 돕는 시스템이다. 입력 문서의 뜻을 외부 정의로 바꾸지 않는다. 용어 표현의 유사함과 의미의 유사함을 모두 살펴 후보를 찾는다.

인공지능 분야의 주요 논문을 모은 학술 DB를 만들고 추출한 개념과 관계, 출처를 탐색할 수 있는 시맨틱 레이어를 구축한다. 기존 Codex·Claude Code 같은 에이전트 환경에서 조회 도구와 분석 스킬로 이를 활용한다.

# 이 절이 전달해야 할 것
독자는 학술 문서의 개념을 기존 연구와 비교해 볼 필요, 그 비교에서 정의와 사용 맥락을 확인해야 하는 이유, 자료를 찾고 대조하는 부담, 제안된 지원이 작성자의 어떤 판단에 도움이 되는지를 연결해 이해할 수 있어야 한다. 이 절에 시스템의 구현 절차를 전부 나열할 필요는 없다. 의미 차이가 언제나 오류라는 과장은 하지 않는다. 효과를 이미 입증한 결과처럼 쓰지 않는다.

# 원자료
original-request.txt는 최초 사용자 설명이다. user-example.md는 사용자가 직접 첨삭한 첫 페이지다. 최초 요청의 논문 초안은 후속 합의에서 학술 문서로 일반화되었다. 위 확정된 목적을 현재 범위로 적용한다. 예문의 우연한 어순이나 쉼표 사용을 보편 규칙으로 만들지 않는다.
