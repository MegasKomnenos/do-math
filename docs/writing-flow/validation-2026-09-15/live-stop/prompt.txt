이 작업은 승인된 작문 종료 훅의 실행 검증이다. 실제 원고를 작성하거나 수정하지 않는다.
1. 셸 도구로 다음 명령을 실행해 현재 세션에 검증용 작업을 등록한다. --session을 별도로 지정하지 않는다.
python "C:\math\.agents\skills\write-for-reader\scripts\writing_flow.py" begin --draft "C:\math\.skill-workspace\write-for-reader\iteration-1\practical\previous-section.md" --brief "C:\math\.skill-workspace\write-for-reader\iteration-1\practical\agreement.md" --audience "C:\math\.skill-workspace\write-for-reader\iteration-1\practical\audience.md"
2. 명령이 성공하면 추가 명령 없이 FIRST_STOP_PROBE만 최종 답변한다. 이 최초 종료 시도는 미검토 상태를 의도적으로 만든 재현이다.
3. 이후 종료 훅에서 미완료를 알리며 작업이 자동 재개되면, 재현이 끝난 것이므로 다음 명령으로 검증용 작업을 취소한다. 독해 호출은 하지 않는다.
python "C:\math\.agents\skills\write-for-reader\scripts\writing_flow.py" cancel --reason "사용자가 승인한 종료 훅 재현 완료"
4. 취소 성공 뒤 HOOK_CONTINUATION_CONFIRMED만 최종 답변한다.
단계 3은 반드시 훅이 후속 지시를 보낸 뒤에 실행한다. 파일 편집, 커밋, 다른 자료 열람은 이 검증에 포함되지 않는다.
