# 학습 작업 메모

- 학습 목표는 지정된 세 문서의 내용을 총체적으로 이해하는 것이다. 원자료는 docs/do-math/통합-설계.md, CONTEXT.md, docs/wayfinder/pvsnp-재설계/컨텍스트.md다.
- 사용자는 12개 수업과 대화 설명 모두를 독자 입장에서 자연스럽고 부드럽고 이해하기 쉽게 다시 써 달라고 요청했다.
- 설명은 구체적인 상황에서 시작하고, 무엇이 왜 필요한지 설명한 뒤 원문 용어를 소개한다. 조건과 예외, 판단 주체와 근거는 유지한다. 상태 이름과 구현 세부는 역할을 설명한 뒤 모아 보여 준다.
- 작문 방법에는 사용자가 제공한 write-for-reader 본문과 명료한_산문.md, 의도_발굴.md, 절차문.md, AI_프롬프트.md를 적용했다. 연구 내용의 근거를 넓히기 위해 다른 자료를 읽지는 않았다.
- 사용자의 선수지식·직무·추가 활용 목적은 확인하지 않았다. 문체 선호를 그 정보의 근거로 삼지 않는다.
- 교재는 12개 HTML 수업과 전체 지도, CONTEXT.md의 정의 115개를 모은 원문 용어집, 세 원문의 줄 번호 열람본으로 구성된다.
- 일반 목표는 G로 표기해 복잡도 클래스 P와 구별한다. 연구 사례는 원문의 절차를 연결한 교육용 가정이며 실제 연구·Lean 실행·인증의 증거가 아니다.
- 문항은 브라우저에서 즉시 해설한다. 회상 답변은 저장하거나 전송하지 않는다.
- 이해도는 아직 확인하지 않았다. 문체 수정 요청이나 교재 제공을 학습 완료의 근거로 기록하지 않는다. 실제 답변과 피드백에서 확인한 이해와 교훈이 생기면 learning-records에 남긴다.
- 다음 대화에서는 사용자가 설명한 내용이나 막힌 문장을 받아 그 지점부터 피드백한다. 전체 순환은 12강과 reference/0001-course-map.html의 세 질문으로 확인할 수 있다.
- 최초 교재는 원본 해시와 원문 열람본의 전 줄, 내부 링크·앵커, Chromium의 수업 12개·문항 27개·사례 9단계·인쇄 표시·용어 검색을 확인했다. 퇴고판도 세 원본의 해시와 열람본 내용, 17개 HTML의 링크·앵커, 12개 수업의 데스크톱·모바일 화면, 27개 문항의 피드백, 9단계 사례의 이동·인쇄, 양화 예시와 115개 용어 검색을 확인했다. 교재 동작 검증을 통과했으며 사용자 이해도는 여전히 미확인이다.
