# 학습 목표

사용자가 지정한 세 문서의 내용을 총체적으로 이해한다.

사용자의 요청: “docs\do-math\통합-설계.md 문서와 CONTEXT.md 그리고 컨텍스트.md 세 문서만 읽고, 그 내용을 내가 총체적으로 이해할 수 있게 가르쳐줘.”

학습 범위는 보편 개념, do-math의 연구·실행·검증·복구 계약, P vs NP 프로젝트의 목적·입력·해결 조건과 세 문서의 소유 관계다. 지정된 컨텍스트는 docs/wayfinder/pvsnp-재설계/컨텍스트.md다.

설명 후 자기 말로 전체 흐름을 재구성하고, 사례에서 판정·권한·상태·보증의 차이를 설명하는 것을 확인 방법으로 삼는다. 이는 수업의 확인 방법이며 사용자의 직무·배경·궁극적인 활용 목적을 추정한 것이 아니다.
