25 The caller owns the repository lock and saves this runtime together with

27 provider termination. Already ended executions may still need settlement.
28 Only an admitted execution has a launch barrier whose end can be confirmed.
29 """

38 return False
39 candidate["capacity"] = deepcopy(execution["capacity"])
40 execution.clear()
41 execution.update(candidate)
