1"""Records for tests of pure domain functions: governance, task contracts, submissions.
2
3Each function returns new plain records (dicts); none opens a repository or
4runs an engine. Records carry explicit synthetic approvals and evidence, never
5an actual user decision or model judgment.
6
7Governance
8----------
9- ``domain_governance()``: instance ``I`` whose charter ``CH1`` (goal "Prove P")
10 the user adopted in decision ``D`` from source ``S``
11 (``research_fixtures.approved_governance``).
12- ``governance_import()``: ``(instance, runtime, source, output)``, an
13 interpretation of the public input ``IN`` into one unit ``U`` that asks one
14 optional question ``Q``; ``source`` is that input's exact source.
15- ``checked_import(kind='charter', handlers=None, payload=None)``:
16 ``(instance, runtime, bundle, request)``, that interpretation changed to
17 propose ``payload`` (default: charter ``CH2``, goal "Prove Q", superseding
18 ``CH1``), independently checked, waiting for the user's later exact approval
19 ``request``.
20- ``audited_governance()``: ``(instance, runtime)`` with an active additional
21 goal audit ``AU`` over ``CH1``.
22- ``applied_initial_intent(text)``: ``(instance, runtime, bundle ID)``, a newly
23 initialized instance whose original input ``text`` was interpreted, checked
24 and applied to its adopted charter.
25
26Task contracts
27--------------
28- ``task_contract()``: the planned contract ``TK-1`` with obligations ``OB-1``
29 (evidence ``EV-1``) and ``OB-2``.
30- ``approved_task()``: ``(task, instance, runtime)``, ``task_contract`` as a
31 nonformal task of ``domain_governance`` with one source ``SO-1``, one work
32 profile and grant, and an approved contract review (``approve_task``).
33- ``task_disposition(identifier, kind='selected')``: one plan disposition row.
34- ``transfer_assessment()``: ``(instance, runtime, assessment)``, ``approved_task``
35 returned with ``EV-1``, a user decision ``DC-1`` transferring ``OB-2`` to
36 ``TK-2``, and the plan assessment that closes ``TK-1`` by that transfer;
37 ``apply_assessment`` applies an assessment as the plan execution ``EX-plan``.
38- ``completed_with_knowledge()``: ``(instance, runtime)`` after a completed
39 assessment of ``TK-1`` that cites a candidate theorem ``KN-proof``.
40- ``specialist_assessment(judge='identity_review')``: ``transfer_assessment``
41 whose single obligation is judged by ``judge`` and a verified theorem
42 (``knowledge_fixtures.verified_knowledge``) cited as its evidence.
43- ``withdrawable_task()``: ``(instance, runtime, input_tasks)``, an approved
44 AI-prepared task ``TK-AI`` with a dependent, a queued review and a waiting
45 work action; ``withdraw_prepared`` withdraws it as the plan ``EX-plan``.
46- ``installation_repair_state()``: ``(runtime, record)``, a failed plan
47 execution held for an accepted installation repair diagnosis.
48- ``contract_check(title='one', **changes)``: one preparation self-check row;
49 ``preparation_issues(entries, candidates=..., context=preparation_context(), workspace=...)``
50 is the receiver's issue list for a preparation output carrying those checks.
51
52Submissions and surfaces
53------------------------
54- ``execution_state(role='formal_check')``: ``(instance, runtime)`` under the
55 stored lifecycle gate with default profiles and one execution ``EX-1`` of
56 ``role`` in activity ``AT-1``.
57- ``two_observation_output()``: a research_work output with two independent
58 observations in two integration bundles; ``observation_knowledge(title)`` is
59 one such row and ``research_work_context()`` its fixed input context.
60- ``surface_state()``: ``(instance, runtime)``, ``IN-1`` with an adopted
61 charter, default profiles and one running research_work execution ``EX-1``;
62 ``stored_surface_state()`` is the same under the stored lifecycle gate.
63"""
