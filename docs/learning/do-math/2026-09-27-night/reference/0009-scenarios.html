사건에 따라 상태를 나누어 보기

각 카드는 앞 카드와 독립적인 교육용 상황입니다. 사건이 바뀌었을 때 서로 다른 상태 축이 어떻게 달라지는지 비교하세요. 실제 실행 증거는 아닙니다.

상황 1

제안만 제출했다

형식: 검사 전동일성: 검토 전목표: 미해결완료: 계약 대조 필요

중앙 수신 성공이 있더라도 Lean·동일성·목표 판정은 후속에 남습니다.

상황 2

H → G의 검증과 K 편입이 끝났다

형식: 유효동일성: match목표: H가 남음완료: 의무에 따라 다름

정확한 조건부 결과를 보존했습니다. 조건 없는 G가 목표라면 H의 입증·제거가 남습니다.

상황 3

외부 자료를 기다리며 실행을 끝냈다

형식: 기존 근거 유지동일성: 기존 근거 유지목표: 현재 근거에 따름실행: 종료, 활동: 대기

논리적 대기는 활동이 소유합니다. 로컬 종료를 확인한 뒤 작업 슬롯을 반환합니다.

상황 4

사용한 원자료가 바뀌었다

형식: 실제 영향 대조동일성: 실제 영향 대조목표: 근거 현재성 대조완료: 이력과 효력 구별

전제 변경의 실제 의존을 확인합니다. 완료 과제를 다시 열지 않고 낡은 판정 사용과 새 후속 의무를 나눕니다.

상황 5

필수 목표 감사가 모두 해결을 확인했다

형식: 현재 사용 가능동일성: 현재 유효목표: mathematically_solved학술: 요구가 남을 수 있음

현행 해결 근거를 보존하고, 헌장이 정한 학술 후속과 외부 효과를 별도로 확인합니다.
