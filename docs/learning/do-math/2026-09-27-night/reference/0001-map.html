전체 흐름과 역할별 책임

목표와 기존 지식에서 남은 질문을 찾고, 계약을 만들어 독립 검토한 뒤, 준비된 과제를 선택해 수행합니다. 산출은 근거를 보존한 채 수학 검증과 완료 판정으로 이어지고, 결과와 실패는 다시 다음 계획에 반영됩니다. 상태·권한·현재성 검사는 이 흐름 전체에 걸쳐 있습니다.

역할맡는 판단·산출작업 슬롯다음 소비자

설치 복구 AI는 위 내부 역할 읽기표와 별도의 고정 프롬프트를 받으며 live 설치 수리만 맡습니다. 정상 예약 감독은 모델 없는 기계 경로입니다. 형식 검사·신뢰 검사·신뢰 활성화·외부 행동은 기계 역할로 구별합니다. SKILL.md · 역할 읽기 대응표

역할이 받는 문서

내부 역할 공통 순서는 SKILL → GLOSSARY → 공통 실행 → 지식 저작과 재사용 → 학술자료 활용입니다. 이어 해당 역할의 추가 reference와 계약을 받습니다. 모델과 실행예산은 후보 준비·계획·계약 검토에, 과제 착수조건은 준비·계약 검토에, 자기 점검은 연구 수행·운영 점검에, 입력 소비자는 의도 해석에 추가됩니다. 실제 배정은 입력 manifest의 문서 경로·해시로 확인합니다.

이 역할 문서를 읽는 것만으로 그 역할의 실행 권한이 생기지는 않습니다. 실제 action·stage·입력·출력 스키마·허가가 이번 배정을 정합니다. 설치 복구의 지시 정본은 scheduled_operator의 고정 프롬프트이며 독립 운영 계약은 그 경계를 사람 운영자에게 설명합니다.

먼저 읽을 경로

  • 전체 개념: 01–04강 → 26강에서 흐름 회상.
  • 연구 과제와 산출: 07–15강 → 17–18강에서 검토와 완료.
  • 실제 운전: 05–06강 → 10강 → 19–23강.
  • 코드 변경과 검사: 24–25강 → 전파일 색인 → 해당 원문 함수와 시험.

막힌 지점에서는 해당 수업 끝의 원문을 열고 정확한 범위를 읽습니다. 용어집은 정의를 찾는 자료이고, 수업은 그 정의들이 어떤 판단으로 이어지는지 설명하는 자료입니다.
