예약 비활성화·제거만으로 이미 실행 중인 연구가 정지됐다고 단정하지 않습니다. install은 기존 Disabled를 보존하고 HOLD·사용자 정지를 풀지 않습니다. 자동 operator 출처는 사용자 정지를 해제하거나 목표·정책·학술 요구·외부 행동·신뢰 판정을 만들지 못합니다. 출처 필드는 같은 OS 사용자 사이의 강한 인증 장치가 아닙니다.

반환과 재전송

응답 봉투에는 schema_version·response_contract·request_id·command·exit_code와 result 또는 error가 있습니다. exit 0은 명령 처리 종료, 1은 check 결함 또는 profile 미검증, 2는 입력 계약 오류입니다. 5는 도구·저장·실행 계층 오류나 내부 계약 오류일 수 있으므로 kind와 다음 담당을 읽습니다. 상태 저장 후 예약 등록만 실패한 init·configure도 exit 5일 수 있으며 보존된 ID로 이어가고 init을 중복하지 않습니다.

제어 응답은 accepted·effect·reason·status·snapshot을 함께 읽습니다. lock이 busy이면 접수 후 적용 대기일 수 있습니다. 같은 논리 요청은 같은 키로 재전송하고, 새 의도적 반복은 새 idempotency-key를 사용합니다. 최초 영수증 재생은 현재 상태 조회를 대신하지 않습니다.
