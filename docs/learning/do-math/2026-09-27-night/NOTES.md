# 학습 메모

- 2026-09-27 밤 요청: .claude/skills/do-math 전체를 현행 판본에서 새로, 상세·정확·세밀하되 쉽고 직관적이며 좋은 작문과 흐름으로 가르친다.
- 기존 교재는 9월 12일 세 문서 범위다. 새 판본은 별도 디렉터리에서 처음부터 배울 수 있도록 작성했다. 번호도 새 과정 안에서 0001부터 시작한다.
- 작성 중 자정이 지났지만 원자료 기준은 사용자 지정 9월 27일 밤으로 유지한다. 실제 파일 포착 시각과 해시는 manifest에 있다.
- 선수지식은 확인되지 않았다. 이전 교재의 제공을 학습 완료로 가정하지 않는다. learning-records에는 실제 답변으로 드러난 이해가 생겼을 때 기록한다.
- 설명은 구체적 상황→문제와 원리→정확한 용어·필드→예외·근거→판단 연습으로 이어진다. 과도한 필드 나열은 빠른 참조로 옮겼다.
- 공통 CSS·문항·회상·단계 보기·검색은 기존 teach-do-math 자산을 읽고 재사용했다. 외부 폰트·네트워크·전송·브라우저 저장 없이 동작한다.
- 다음 대화에서는 사용자의 회상 답이나 막힌 문장을 받아 해당 범위부터 피드백한다. 첫 확인 질문은 01강의 다섯 판단, 전체 확인 질문은 26강의 사례 재구성이다.
- 교재의 저작 원문은 content/course.py와 content/lesson-01.md에 있다. assets/build_course.py build로 HTML을 재생성한다. 원자료는 assets/course_sources.py가 manifest의 고정 Git 커밋에서 읽고 해시를 확인하므로, 재생성에는 해당 커밋을 가진 저장소와 Git이 필요하다. HTML 열람에는 Git이나 네트워크가 필요 없다.
- 독해용 합본이 필요할 때만 build 명령에 --draft <출력 경로>를 지정한다. assets/verify_course.py static 또는 browser는 기본적으로 교재 폴더에 검사 산출물을 남기지 않는다. 증거를 보관할 때만 --output-dir <출력 경로>를 지정한다. 원고 변경 후 독해 기록을 갱신하고 링크·화면 검사를 별도로 수행한다.

- 최초 제작 때 전체 원고의 별도 독해와 합의 대조, 원문·링크·화면·문항·인쇄 검사를 마쳤다. 검증 요약과 독해 원본의 보존 위치는 validation.json에 있다. 제품 전체 회귀 시험과 실제 연구 효능은 검사하지 않았다.
- 정리 후에는 중복 raw 사본·중간 원고·화면 캡처·시험용 PDF를 교재 폴더에 두지 않는다. 원문 열람본과 출처 manifest, 저작 원문, 재생성·검사 도구와 검증 요약을 유지한다.
