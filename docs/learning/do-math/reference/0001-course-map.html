수치·기호의 읽기 주의점

수업에서 일반 목표는 G로 적었습니다. 원문의 조건부 정리 예시가 쓰는 P와 복잡도 클래스 P를 혼동하지 않기 위한 표기 변경입니다. H→G만으로 G는 해결되지 않습니다.

반복 교정 문턱 각각 3, 연구 재검토 간격 PT24H, 최근 이력 창 10, 이의 심사 회차 상한 3은 본문의 초기 제안값입니다. 실제 인스턴스의 승인값이나 이번 수업의 실행 설정으로 해석하지 마세요. N=3일 때 검토 8회·14회는 명시된 최소 배치의 하한이지 자동 소비량·성공 보장이 아닙니다.
