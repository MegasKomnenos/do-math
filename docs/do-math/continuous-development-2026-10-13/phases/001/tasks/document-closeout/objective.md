## 목적과 역할

원래 13-C와 G3의 관점에서 문서 검사기 재작업을 유한하게 끝낼 범위를 정한다. 최근 B119~B134의 실제 반환 결속을 다시 구현하지 않는다. 현재 실제 문서가 요구하는 이름과 코드/공유 계약/실제 결과를 대조해 유지할 부분, 교체할 부분, 불필요한 부분, 남은 한정 작업을 결정한다.

## 완료 조건

### A1 현재 문서와 소유자 목록

doc_code.documents()의 현재 파일 모집단과 실제 점 경로/명령/정책 참조를 확인한다. field_schemas의 남은 AST 추출·수동 조립마다 실제 사용하는 문서, 의미상의 생산자/소비자, 이미 있는 검증을 자기 evidence/binding-inventory.json에 연결한다. 같은 이름이 있다는 이유로 서로 다른 생산자를 합치지 않는다. 명시적으로 쓰이지 않는 결속도 실제 소비를 확인해 유지/제거 후보로 구별한다.

### A2 최근 교체의 유지 판단

B115의 독립 반례 및 B130~B134의 원보고·현재 diff/시험으로 지정한 기존 성질이 유지되는지 검토한다. 원래 단언/실제 호출이 제거되었는지, 실제 반환 대신 다른 객체를 빌리는지, defer가 모든 경계를 건너뛰게 하는지 등 판단을 바꾸는 지점에 한정한다. 이미 확인된 모든 행을 다시 전수 실행하지 않는다. 발견이 없으면 그 범위와 근거를 남기고 종료한다.

### A3 유한한 후속 작업

남은 _context 결속을 실제 경계가 공유되는 묶음으로 나눈다. 예를 들면 운영 증거·체크포인트·복구 자료, 원자료·물질화된 파일/과제 결과, 실행 창·학술·형식 검사 환경이다. 이는 미리 정한 정답이 아니며 실제 코드/문서/기존 시험으로 묶음을 결정한다. DOC-RETURN-REVIEW/TRUST와 단독/조합 이름·정책 의미·실제 읽기 한계도 중복 없이 원래 13-C에 연결한다. 각 후속 묶음에는 정확한 원문, 파일/심볼, 재사용 시험, 필요한 정상·반례, 종료와 남김을 적는다.

### A4 범위와 실익의 판정

더 이상 새 표기법을 발견할 때마다 추론기를 확장하지 않도록 이번 마감의 실제 분모와 경계를 제시한다. 기존 실제 반환/공유 계약으로 표현할 수 없는 항목은 구체적 이유와 의사결정 질문으로 남긴다. 형식/name-only 검사와 실제 의미 검증, 실행 자료와 정적 판단을 구분한다. 이 검토의 complete는 13-C 완료가 아니다.

## 판단과 경계

writes=[]이며 코드·문서·기존표를 수정하거나 제품 시험을 돌리지 않는다. 실제 문서 범위에 계약/ 폴더도 포함되는지 documents() 원문을 확인한다. helper를 import해 제품 초기화 부수 효과를 내기보다 정적 정의와 기존 raw 결과를 읽는다. 요구별 전체 상태 매핑은 closure-map, 도구 실행 절차·환경 판본은 gate-readiness 책임이다. 다른 task의 중간 산출물은 읽지 않는다.

새 범용 AST/dataflow/schema 프레임워크, 코드와 중복되는 출력 정의, 문서 구조 검사 안의 새 엔진 실행을 해법으로 자동 선택하지 않는다. 선택적/실패 반환의 실제 변형은 같은 생산자의 검증된 변형과 다른 생산자 키의 합집합을 구분해야 한다. 새로운 제품 결함을 확정하면 재현 가능한 입력/현재 계약/파일 위치만 finding으로 인계한다.

## 검증 방법

cwd는 repo다. doc_code.py와 test_doc_code.py의 필요한 구간, documents()가 가리키는 원문, 그 결속의 직접 제품 생산자와 기존 시험만 읽는다. 기존 작업표 current_work의 document_review와 B119~B134 근거 키에서 원보고를 선택 조회한다. 특히 일반 재개 결과와 운영 진단 복구 자료의 동명 result_source/checkpoint_source가 올바른 실제 소유자를 가리키는지 확인한다.

목록의 문서/심볼/시험 경로 누락과 중복, 닫힌 소유자 재배정 여부를 기계적으로 확인하고 실제 출력과 위치를 evidence에 남긴다. 완전한 새 의미 감사나 전체 테스트를 시작하지 않는다. report와 A1~A4를 작성하고 check.py report <repo> <run> 001 document-closeout을 통과한 뒤 반환한다.
