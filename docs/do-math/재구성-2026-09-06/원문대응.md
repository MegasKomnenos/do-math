# 원문 대응표

기준 판본의 절 경계를 빠짐없이 대조한 기록이다. 상위 표제는 구성으로 구별하고, 실제 내용의 보존·교체 이유는 각 행에 적었다. 원문의 범위는 기준 사본의 행 번호이며 현재 초안의 행 번호가 아니다. 이 표는 과거 규칙을 새 실행 계약으로 재발동하지 않는다.
