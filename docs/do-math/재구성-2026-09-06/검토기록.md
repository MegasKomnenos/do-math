# 통합 설계의 비교우위 보존 검토

작성일: 2026-09-07

[기존 설계](../통합-설계.md)의 본문·표·워크스루·테스트 벡터를 [7차 초안](../통합-설계-초안.md)과 대조했다. 연구에 기여하는 보장을 적용 대상·조건·예외·실패·후속까지 판정하고 확인한 결손과 연결 모순을 수정했다. 이 기록은 처분과 검증 범위를, 초안 본문은 실행할 규칙을 소유한다.

최종 검사 상태: 통과. 아래 범위에서 확인한 보존 결손과 문서 모순은 모두 처리했다.

이번 요청의 완료 조건은 원문 전체의 처분, 보존 결손의 수정, 초안과 전환 자료의 정합성, 반례·시간선 대조 및 문서 검사의 통과다. 기존 구현 정본의 채택·교체, do-math 구현, 공급자·Lean·AI 효능 실험은 별도 단계다. 초안의 V01 이후 벡터는 구현할 검증 명세이며 실행한 do-math 테스트 수가 아니다.

보존은 같은 이름의 존재가 아니라 같은 조건에서 제공하는 판단 기회·자료·권한 경계·결과·후속으로 판정했다. 수단 대체는 그 효과를 다른 구조로 연결한 경우다. 정정은 원문의 오류나 목적과 충돌하는 규칙을 근거를 밝혀 바꾼 경우다. 실제 성능의 크기가 미측정이면 설계 보장과 기대 효과까지만 판정한다.

## 4. 보존하지 않은 수단과 정정한 주장

- 다중 가변 ref, 별도 AI 메인 heartbeat, 역할별 실행 생명주기, 관찰 세대 복사본은 필수 수단으로 인정하지 않았다. 단일 작성자·공통 실행·불변 자료·기계 사건으로 책임과 실패 경계를 연결했다.
- 거친 F 전건의 계약화와 사용자 대기의 강제 분할은 정련된 계약의 사전 검토와 지속 과제의 대기로 대체했다. 의무·검토·재개 자료는 유지했다.
- 기존 L11의 모든 해시 변화→새 제안 기대는 기존 19.11의 훼손 처리와도 맞지 않는다. V24·V25는 훼손과 의도적 수정을 구별한다.
- 기존 L28의 회차 상한 분열→approved_objection은 성립한 결함과 미확정을 섞는다. 편입 차단은 유지하고 unresolved·구체 주장·후속으로 정정했다.
- 기존 10.6의 같은 검사기를 쓰므로 이전 실패를 주지 않는 규칙은 환류를 보존하지 못한다. 후속 실행은 실제 실패·좌표·입력 차이를 받는다.
- 목표의 사실 상태와 연구를 계속할 권한을 구별한다. 이미 유효한 허가의 재개·정확한 직접 승인에 보편 재승인을 추가하지 않는다. 새 범위·효과와 반복 문턱의 선택은 사용자에게 남긴다.
- 특정 모델명·노력값·출력 64K·여유 8,192토큰·고정부 절반이라는 숫자 자체의 성능 우위는 입증되지 않았다. 정확한 프로필·실측 여유·역할별 능력·효능 평가로 옮겼다. 낮은 품질을 같은 보장이라고 선언할 권한은 부여하지 않았다.
- 큰 제안의 분할은 기존 19.4에도 있으므로 분할 자체의 결함 주장은 기각했다. 들어가는 경우의 전문 우선과 결론 폐쇄·전체 연결을 대조했다.
- 6차에 이미 있던 전면 재검토·대화 전건·이의 답변·관찰 적응·정지 기록·K 우선·복합 조건은 새 누락으로 세지 않았다. 이번에는 그 적용 조건과 연결을 검증했다.

## 5. 검증과 이후의 재검토

의미 대조는 주 에이전트가 원문과 최종 규칙을 직접 비교한 결과다. 별도 독립 AI 세션의 통과로 표현하지 않는다. 표·예시는 규칙과 함께 읽고, 지적을 다른 절이 이미 해소하는지 확인했다. 수정 뒤 입력 구성·판정·적용·대기/실패·복구를 다시 대조했고, 정지 뒤 관찰을 재예약하지 않는 조건과 회차가 알 수 있는 시각의 기준도 맞췄다.

다음 검사를 수행해 통과했다.

- 네 Markdown 문서의 UTF-8·BOM 없음·LF·NFC·끝 개행·후행 공백, 코드 울타리·표 구조와 열 수, 로컬 링크·명시 anchor를 검사했다. 초안의 절 참조, 19개 anchor, V01~V189의 유일성·연속성, 7차 이름공간과 83개 판정 행의 대상 절도 대조했다.
- 원문 SHA-256과 테스트 벡터 246개의 존재를 재확인했다. 기존 설계는 변경하지 않았다. 이 계수는 원문 내용의 의미 대조를 대신하지 않는다.
- `git diff --check`와 `git apply --check`를 통과했다. 패치를 별도로 해석해 두 대상에 적용한 결과가 전환 안내를 제외한 두 개정안의 바이트와 정확히 일치했다.
- 목차 배정 8개, 관찰 응답 5개, 고갈 발동 6개의 경계 계산을 확인했다. 이는 계약을 설명하는 작은 기준 계산이며 실제 tokenizer·AI·do-math 실행 시험이 아니다. 큰 균일 격자의 반복 계수는 보존 증거로 사용하지 않았다.

대표 목차 계산은 고정부를 제외한 추상 공간 10에 K 8개·후보 8개를 각각 단위 크기로 놓으면 K 8개·후보 2개·이력 0이고, 공간 16이면 두 목차 전건과 이력 0이다. 부분 제공의 공간 10에서 K 항목 크기 [3,9], 후보 크기 [8,1]이면 뒤 후보 1과 K 3을 먼저 확보하므로 거짓 입력 초과가 나지 않는다. 실제 입력 구성은 전체 직렬화와 tokenizer의 실측을 따른다.

최대 관찰 간격 10의 계산에서는 시각 10의 새 유효 응답 뒤 다음 시각이 20, 시각 15의 같은 응답 재전송 뒤에도 20, 시각 20의 유효 응답과 규칙 거부 뒤에는 30이다. 유효하지 않은 응답은 기준을 바꾸지 않는다. 도구 대기와 정지는 본문의 별도 관찰·권한 조건으로 대조했다. 고갈의 외부 대기·재생성 시각·문턱이 모두 닫혀 있어도 독립된 주기 사건은 보존한다.

실제 역할·실행기·공급자·Lean 실행과 별도 독립 AI 검증은 수행하지 않았다. 해당 능력과 연구 효능은 초안 17.5·18절의 구현·평가 담당 및 채택 관문에 남으며, 이번 설계 보존 작업의 미처리 결함으로 기록하지 않는다.

후속 세션은 새 지적에 원문의 보장·적용 조건, 현재 대응, 남는 행동 차이의 사례와 이전 처분을 바꿀 근거를 제시한다. 표 밖의 실제 원문 요구도 검토할 수 있다. 해소된 차이는 보존 검증을 통과했다고 판정한다. 개선 제안·보존 누락·미측정 성능 가설을 구별한다. 새 근거는 이전 판정을 바꿀 수 있지만 다른 표현이 가능하다는 사실만으로 작업을 다시 미완료로 만들지 않는다.
