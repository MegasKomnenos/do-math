GitHub 자료는 저장된 요약이 아니라 현재 이슈 API에서 조회했다. 지도 본문, 하위 이슈 목록과 각 차단 관계를 따로 조회했다.

파일 상태는 다음 방식으로 확인했다.

- `git status`로 추적·미추적·수정 상태를 구별했다.
- `git log`로 컨텍스트 정본의 반영 커밋 순서를 확인했다.
- 편집 대상 네 파일의 SHA-256을 기록했다.
- 파일 편집 직전 다른 세션의 변경이 없는지 다시 검사할 준비를 마쳤다.

외부 웹 자료는 아직 다시 검색하지 않았다. 저장소 내부의 현행 소유권과 중복 정리가 먼저이기 때문이다. 외부 사실을 새 정본에 직접 싣는다면 해당 사실은 별도로 최신 검증해야 한다.
