# A30: 재사용 없는 전체 T3의 예산 재보정

전체 T3의 시간 예산을 2,400초에서 3,300초(55분)로 재보정한다. 일상 증분 T3의 720초와 T2의 300초는 유지한다. 시험 모집단, 실제 제품 경로, 단언, 분기 관문, 극단 변이, 재사용 없는 최종 측정은 바꾸지 않는다. 이는 설계 A29의 실측 재보정과 사용자 위임 U8·U9에 따른 AI 결정이다.

기존 2,400초는 1,990초의 이전 전체 측정에 여유를 붙인 값이다. 마지막 옛 시험73개의 이행, 하네스 보완과 임시 포트 기본 경로 제거를 통합한 새 판본의 전체 측정은 2,927.4초였다. 계측 대상은 301개 모듈·2,159개 시험이고, 별도 격리 시험 하나를 포함한 결과 합계는 2,160개다. 모듈 전체 비용의 합계를 세 작업자에 완전히 균등하게 나눠도 약 2,523초다. 현재 관측값을 고정한 이 계산만으로 다음 실행 시간을 보증할 수는 없지만, 배분 개선만으로 2,400초를 달성한다고 주장할 근거도 없다.

3,300초는 새 실측 위에 372.6초, 약 12.7%의 운영 여유를 둔 정책 수치다. 통계적 신뢰구간이나 미작성 영역 시험의 비용 추정은 아니다. 준비·종료를 포함한 모듈 비용 기록으로 다음 배분의 불균형을 줄이고, 결과·진행 파일을 쓸 때 반복하는 coverage 중지·시작을 줄이는 좁은 최적화 후보는 실제 효율과 증거 보존을 확인한 뒤 적용한다. 아직 측정하지 않은 절감량을 예산 근거로 넣지 않았다. 일반 개발 확인의 T2는 마지막 전체 실행에서 286.1초로 300초 안이었다.

과거 전체 측정의 초과와 실패는 그대로 남긴다. 그 실행은 당시 예산 2,400초를 527.4초 넘었고, 일반 오류 3개·실패 1개와 분기 빈틈 97개 모듈이 있었다. 빈 메모리 최저는 3,702MB였다. `closing_eligible=true`는 재사용 없는 온전한 측정 형식이 갖춰졌다는 뜻이며 시험·분기 통과를 뜻하지 않는다. 새 예산이 그 실행이나 1f(옛 시험 이행과 분기·변이 마감 단계)를 성공으로 바꾸지 않는다.

다음 전체 실행은 교정한 실제 판본에서 재사용 없이 측정한다. 통합자는 일반 시험 결과, 알려진 결함, 분기 관문, 시간 예산, 메모리 상태를 따로 판정한다. 아직 구현하지 않은 영역 의무와 변이 검사는 완료로 세지 않는다.
