# 실제 의미 검토의 두 사례

[심사 왕복](dispute/README.md)은 합성 초기 판단 2건으로 논쟁 경로를 연 뒤 실제 CLI 8회로 이의 정리·심사·원 자리 답변·재심을 검증한다. 자기 자리의 이전 대화 복원과 같은 단계 동료 결과의 비공개도 실제 입력을 대조했다.

[부정 사례](negative/README.md)는 참인 Lean 명제의 양화 순서를 해설에서 뒤집고 실제 초기 검토자 2명을 실행했다. 두 명 모두 불일치를 찾았으며 K는 생성되지 않았다. 정리 단계 전에 멈췄으므로 최종 이의 심사 전체의 불일치를 확정한 사례와 구별한다.
