# do-math feature 2 검증 증거

이 묶음은 통합 설계의 필수 기능을 구현한 CLI 실행기의 실제 운전과 회귀를 보존한다. 전체 대응은 [기능 완료 대응](../../기능-완료-대응.md)에 있다. 각 시험의 실행 당시 소스는 manifest와 ZIP으로 고정한다. 이후의 작은 변경은 해당 소비자 회귀와 연결하며 서로 다른 판본의 증거를 같은 실행이라고 표현하지 않는다.

| 사례 | 실제 수행과 결과 | 근거 |
|---|---|---|
| 전체 연구와 학술 후속 | 실제 CLI 18회, Lean 1회. K 생성·목표 해결·재현 설명의 학술 완료, 대기 action 없음 | [전체 흐름](workflow/README.md) |
| 이의 왕복 | 합성 초기 판단 2건 뒤 실제 CLI 8회. 정리·3인 판정·원 자리 답변·같은 3인 재심을 거쳐 유효한 match | [심사 왕복](semantic/dispute/README.md) |
| 의미 반례 | 실제 Lean과 실제 초기 검토 2회. 양화 순서 오류를 두 명 모두 탐지, K 생성 없음. 정리 단계 전 중단 | [부정 사례](semantic/negative/README.md) |
| 관찰·정지·회수 | 실제 긴 명령 중 별도 운영 CLI, checkpoint·부분 파일의 정확한 회수와 Job 종료. 구버전 pause 결함과 수정 판본을 구별 | [관찰 시험](observation/README.md) |
| 신뢰 환경 | 실제 Lean 재검증과 허용 밖 공리의 거부. 합성 선행 동일성 판정은 별도 표시 | [환경 전환](trust/report.json) |
| CLI 도구 | 제한 모드의 쓰기 실패와 현재 로컬 권한 모드의 실제 쓰기·읽기 통과 | [프로필 시험](cli-profile/README.md) |
| 상태·Git·HTTP·프로세스 회귀 | 전체 261건 중 260건 통과·1건 환경상 skip. 최종 변경 관련 45건 전부 통과 | [회귀](regression/README.md) |

`workflow/state/`는 최종 snapshot의 파일 보기이며 Git bundle은 이전 snapshot과 불변 산출의 전체 이력을 보존한다. 모델 대역의 상태 검사와 실제 CLI·Lean·프로세스·HTTP 검사는 각각 입증하는 범위를 구별한다. 작은 수학 사례는 일반 연구 성능이나 의미 판단의 무오류성을 보증하지 않는다.
