# 회귀의 판본과 범위

[전체 동결 회귀](full/result.json)는 261건 중 260건 통과, 실패 0건, 환경상 skip 1건이다. Skip은 Windows 토큰의 symlink 생성 권한 부재다. 모델 대역을 사용한 연구 시간선, 순수 상태 검사, 실제 임시 Git·Windows 프로세스·Lean·loopback HTTP 검사를 포함한다.

전체 회귀 뒤에는 착수 조건에서 source·trust·review·instance 기록을 조회하고 학술 요구의 참조도 계약 해시에 포함하도록 planning을 변경했다. 이 변경과 관련 학술·수명·연구 소비자의 [최종 45건](planning-final/result.json)은 전부 통과했다. 각 디렉터리의 manifest, tested-skill.zip, stdout·stderr와 원 result를 보존한다. 검사 수가 겹치므로 두 실행을 서로 다른 306개 검사라고 합산하지 않는다.

[첫 targeted 실행](first-targeted-diagnosis/result.json)은 45건 중 1건이 실패했다. Loopback 양성 사례의 전송 결과가 unknown이었으며, 당시 원 예외가 기록되지 않아 원인을 확정하지 않았다. HTTP 시험 서버가 요청 본문을 끝까지 읽고 길이를 명시한 응답을 보내며 예외를 기록하도록 보강했다. 좁은 반복 검사와 학술 검사, 최종 45건이 통과했다. 실행기의 unknown 처리와 영수증 없는 완료 거부는 유지했다.

`result.json`은 원 실행 결과에 검사 수와 범위를 덧붙인 보기이고 `original-result.json`은 원 result다. 원시 테스트 로그와 동결 소스의 ZIP 멤버 해시는 대조했다. 별도 v9 오프라인 명세 80건은 이 CLI 회귀와 구별한다.
