# do-math 기능 완료 대응

이 문서는 [통합 설계](통합-설계.md)의 기능 목적을 현재 기능 판본 2 구현, 검증 기록과 남은 판단에 연결한다. 새 승인 절차나 별도 기능 정의가 아니다. 공통 용어는 [GLOSSARY.md](../../.claude/skills/do-math/GLOSSARY.md), 전체 연구 흐름은 [SKILL.md](../../.claude/skills/do-math/SKILL.md), 구체 CLI 표현은 [CLI 실행 계약](../../.claude/skills/do-math/references/CLI-실행-계약.md)이 소유한다.

구현 수단이 통합 설계의 예시와 다르다는 사실만으로 미완료라고 판정하지 않는다. 기능 목적에 필요한 의미·판정·후속 효과가 실제로 이어지는지를 본다. 반대로 코드 경로·필드·테스트 이름이 있다는 사실만으로 목적 완료를 선언하지 않는다.

기준 시점은 2026-09-15이다. 2026-09-14 기능 판본 2 증거는 당시 동결 소스에 대한 역사 근거다. 이후 공통 정의·역할 문서·입력 전달과 후속 계약이 바뀌었으므로 현재 판본의 문서 독해·독립 검토·자동 검증은 [문서 검증 기록](문서-검증-2026-09-15/README.md)에서 별도로 확인한다. 이번 개정의 문서 검토와 필요한 보완 검증은 마쳤으며, 아래의 지원 범위와 미평가 사항은 유지한다.

## 증거를 읽는 법

- **현재 구현**은 2026-09-15 판본의 코드와 문서가 제공하는 연결이다. 구현 경로의 존재와 실제 검사 범위는 구별한다.
- **현재 판본 검증**은 문서 검증 기록이 보존한 소스 manifest, 독해 시나리오, 독립 검토와 자동 검사다. 최초 실패와 교정 후 통과를 각 실행 판본에 상대적으로 읽는다.
- **역사적 실제 증거**는 `구현-검증-2026-09-14/feature2/`의 실제 Codex CLI·Lean·Windows 프로세스 실행이다. 그 실행 당시 소스에 상대적이다.
- **결정적 검사**는 의미 판단을 대신하지 않는 상태·참조·저장·시간선 검사다. 모델 대역, 임시 Git, 실제 로컬 프로세스·loopback HTTP를 각각 입증 범위에 맞게 읽는다.
- **연구 효능**은 별도 평가 대상이다. 작은 자연수 항등식과 지정 반례의 성공을 일반 수학 연구 성능이나 판정 무오류성으로 확대하지 않는다.
