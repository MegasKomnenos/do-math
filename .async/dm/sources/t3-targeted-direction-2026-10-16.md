이 지시는 다음 T3 배정과 실행 범위에 적용한다. 과거 plan/objective의 전체 fresh T3 반복 조건보다 이 최신 사용자 지시를 우선한다. 이미 끝난 g45-final의 전체 측정과 원보고는 보존한다.

## 다음 manager의 배정·판정

1. 정확한 잔여 경로·입력·현재 계약을 위 5모듈 범위에서 판단하고 필요한 수리와 직접 검증을 묶는다. 다음 T3는 이 모듈의 잔여/변경 경로를 확인할 관련 시험만 선택하여 추가 측정한다. 제품 모듈 경로를 그대로 시험 ID로 취급하지 않고 기존 함수·시험 색인과 실제 직접 소비를 사용해 유한한 선택을 정한다.
2. 다음 T3에 위치 선택 없는 전체 실행 또는 전체 `--full` 재실행을 배정하지 않는다. 미도달 수리나 최종 판본이라는 이유만으로 전체 측정을 자동 반복하지 않는다. 기술적 제약이 발견되면 해당 제약과 기존 자료의 유효 범위를 보고하며 사용자 지시를 조용히 무시해 전체 실행으로 대체하지 않는다.
3. 기존 전체 coverage/store/index·원소스 판본과 추가 측정의 결과·판본·범위를 보존한다. 변경 없는 범위의 기존 측정 재사용은 현재 파일/해당 경계와 대조해 판단하고, 도구가 지원하는 결합 방식과 한계를 기록한다. 일부를 추가 측정한 결과를 '전체를 새로 실행했다'고 주장하지 않는다. 별도 판본의 통과 수를 합산해 기능 전체 재실행 성공으로 표시하지 않는다.
4. 다음 plan/objective에 이 선택과 기존 측정 재사용 책임을 명시한다. 새 전수 감사·계측 프레임워크나 과거 완료 작업 재실행은 만들지 않는다. 기존 원증거와 유효한 수리는 보존하고, 다른 완료 기준을 임의로 충족 처리하지 않는다.

현재 g45-final 작업은 전체 실행을 끝내 보고를 마감 중이다. 진행 중 배정을 중간에 바꾸거나 완료된 실행을 취소하라는 지시가 아니며 다음 manager의 후속 T3부터 적용한다.
