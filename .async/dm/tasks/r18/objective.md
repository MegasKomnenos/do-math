R18 외부 경계의 현재 호출 모집단과 공유 규칙 소비를 자기 workspace의 이관 검수판에서 판정한다. 원래9-A 중 tracking-state R18의 남은 현재 호출 누락 여부를 판정한다. R17의 지급 console_python/실제 pythonw와010~018의 Job/Lean/held예약 실경계 승인 성질은 조건부 재사용한다. 지금의 구조 검사가 선언하는 직접 subprocess·주입 starter·native CreateProcess·_job_run·sys.executable·실행파일 정규화·파일 교체·stdlib 충돌의 대상 파일/호출 집합과 실제 코드를 비교한다. Windows 실경계를 새로 실행하거나 전체 OS 안전성 감사로 넓히지 않는다.

이 작업은 유한한 남김의 판단 자료를 만드는 work다. G1/G2/G3의 지정 질문을 닫거나 정확 수리로 바꾸며 최종 review가 아니다. 다른 async task 결과를 기다리거나 소비하지 않는다.
