# Readers

The documents are the public front page of a software repository (`README.md`) and its guide to running the software (`docs/do-math/running.md`). They are read on GitHub, in English.

Three kinds of reader come to them.

- A research mathematician who has heard that an AI system does mathematical research and wants to judge what its results can be trusted for. This reader knows mathematics and what a proof assistant is in general terms, may never have used Lean, and does not know how AI command-line tools or multi-agent systems work.
- A researcher or engineer who builds AI systems and wants to evaluate the design: how the sessions are organized, what is checked by whom, and what has been verified about the implementation. This reader knows large language models and agent tooling, and knows little about Lean or about research mathematics.
- A person who intends to run the software on a statement of their own. This reader can use a terminal, Git and Python, has Claude Code or Codex installed or is willing to install them, and has not used this software before.

None of them has seen an earlier version of these documents or of the software, and none has access to anything but the repository. Each reads the README from the top and may stop after the opening; the reader who intends to run the software goes on to the running guide.
