# 3단계 합의: 흐름과 친절함의 개정

대상은 이 세션이 쓴 영어 산문 넷이다. `README.md`, `docs/do-math/first-run-parking-unimodality.md`, `docs/do-math/running.md`, Zenodo v2 설명문. 사실·수치·날짜·귀속과 압축 진술·경중 선언은 `../합의.md`의 것을 그대로 쓴다. 이 파일은 그 위에 더해진 작문 계약만 적는다.

## 기준

영어 산문의 일반 원리를 우선한다(given–new 연결, 행위자는 주어에 행위는 동사에, 주어와 동사의 근접, 문말 강조, 정의는 부류와 차이로). 사용자 작문 선호 문서는 영어 독자에게 해가 없는 범위에서 적용한다. 갈린 자리는 보고에 적는다.

## 결함 유형

1. 정의 없는 시스템 용어, 시스템의 뜻으로 쓴 일상 형용사(fresh, retained, standing), 영어에 없는 낱말 짝(runs research), 동사 자리의 명사화(a program for research on), 부류 없는 소개(do-math organizes …). 일반 낱말을 일반 뜻으로 쓴 것(autonomous)은 결함이 아니다.
2. 독자가 판단에 필요로 하는 맥락과 정보(무엇을, 어떤 범위에서, 어떻게, 왜)를 빼고 결론만 적은 것.
3. 원인 대신 효과나 독자 반응을 단정한 것.
4. 문장 사이의 끊김: 앞 문장과의 연결이 보이지 않거나 지시어의 대상이 없는 것. 앞 문장에 기대는 짧은 문장도 끊김이다.
5. 문단의 주제 이탈과 문단 사이의 끊김.
6. 문장 내부의 어색함: 주어와 동사의 분리, 머리 무거운 문장, 수식어의 걸림, 눈에 띄는 낱말의 연이은 되풀이.

## 확정 문장

사용자가 리드의 첫 두 문장을 확정했다.

> do-math is a system for autonomous mathematical research in which many AI sessions work together to prove or refute a single mathematical statement. The sessions share nothing but a knowledge base: each is a new Claude Code or Codex conversation that knows nothing of the others, and what one session proves, writes up or judges is published there as a record for later sessions to read.

적용 시 "judges"는 본문의 어휘(assess/assessment)에 맞추어 "assesses"로 썼다.

## 고치는 범위

문장 교정, 문단 재배치, 재작성 허용. 결과의 근거나 한계를 밝히는 구절은 지우지 않고 자리만 옮긴다. 1·2단계의 구조는 흐름을 위해 필요할 때만 바꾼다.
