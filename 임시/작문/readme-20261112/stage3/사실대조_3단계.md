# 3단계 사실 대조: 흐름·친절함 개정판과 커밋 453f6a33 판본

**전체 판정.** 네 문서(README, 첫 운전 문서, 운전 안내, Zenodo 설명문 Description 절)를 문장 단위로 대조한 결과, 의도된 갱신에 속하지 않으면서 뜻이 달라진 자리는 18곳이다. README 13곳, 첫 운전 문서 2곳, Zenodo 설명문 3곳이고, 운전 안내(running.md)에는 없다. 그 가운데 README 리드 둘째 문장의 2곳(U1·U2)은 `합의_흐름.md`에 사용자가 확정한 문장으로 적혀 있고, Zenodo의 2곳(Z1·Z2)은 그 문장을 옮겨 온 것이다. 이 넷은 고칠지 사용자가 판단해야 한다. 가장 무거운 것은 첫 운전 문서의 F1이다. "a weaker property than unimodality"는 수학적으로 틀렸다. 조건부 로그 오목성은 단봉성을 함의하므로 단봉성보다 강하다. README의 U12("a weaker property suffices")도 무엇보다 약한지 밝히지 않아 같은 오독을 부른다. 그다음으로 무거운 것은 리드에서 조건이나 행위자가 바뀐 자리(U4 게시 결정 탈락, U5 finding의 행위자 확대, U13 점유 종료 조건 탈락)와 과장된 주장(U8, U10)이다. 의도된 갱신은 기록과 맞는다. 첫 운전 문서의 14:15 행을 보면, 입력 파일 `control/inputs/1794460539425838800-…txt`의 시각이 2026-11-12 14:15:39 KST이고, 그 제목이 r030ffaeb 원천 봉투 표가 기대는 「탈출 봉투의 y-감소성」과 「여섯 조각의 k-단조성」의 증명을 최우선으로 요청한다. 세 기록의 게시 사건 시각은 rfc69320 16:12:58, r0e82912d 17:36:13, rc56f637b 18:18:08 KST이다. 검토는 각각 13개, 22개, 8개 주장을 모두 supported로 판정했고 concern은 0건이다. rc56f637b의 검토는 이 기록의 생산자 정리 A–E를 "같은 명제의 옳은 셋째 증명"으로 판정했으므로, "each prove them"은 성립한다. 수치 갱신 가운데 세션 1,237(`sessions/` 1,237개), 기록 340과 게시 커밋 426(`knowledge/events/`의 사건 426건 중 기록 340건, 마지막 사건 18:56:56), 노드 108(`state.json`)을 확인했다. 활성 파이프라인 10은 파일로 확인하지 않았다. 공백 서술은 14:15 행 밖에 두 곳 남아 있다. README 한눈 보기의 Evidence 행에 있는 "which includes the proofs of 12 November"(U11)와, 첫 운전 문서의 Zenodo 문단에 있는 "taken after the three records of 12 November were published"(F2)이다. 둘 다 v3 자리 표시자를 넘어 해결된 문제를 가리키는데, README는 그 증명을 어디에서도 설명하지 않는다. F2는 사실로도 부정확하다. 12일에 게시된 기록은 46건이고, v2 압축(01:52) 뒤로만 쳐도 40건이다. 참고로 인스턴스 루트의 `knowledge.7z`는 2026-11-12 23:25:51 KST, 349,034,614바이트이다. 이것이 v3라면 18:18 뒤에 압축되었고 기록 340건을 담는다. README의 "taken later on 12 November"와도 맞는다.
