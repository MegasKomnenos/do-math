# T2-적용 경중 선언

대상 글: `C:\math\임시\경중-표본비교\산출\T2-적용.md` (홀의 결혼 정리의 증명 해설)

## 입력

- **수신자**: 그래프 이론을 처음 수강하는 학부 3학년. 해설만 읽으며 작성자에게 질문할 수 없다.
- **수신자가 읽고 할 일**: 증명을 스스로 다시 구성한다.
- **수신자가 이미 아는 것**: 수학적 귀납법, 그래프, 이분 그래프, 매칭, 이웃 집합 N(S)의 정의. 이 정리의 증명은 처음 본다.
- **작업 기록**: 원본 없이 작성자가 아는 수학으로 쓴다. 증명을 밟으며 회의적인 독자가 의심할 단계를 찾은 결과는 아래 분류표의 `고비` 행이다.
- **주된 기여**: 파견문이 이미 정했다. 알려진 정리의 증명을 위 수신자가 재구성할 수 있게 설명하는 것이다. 새로운 수학적 결과는 없으므로 고비만 무거운 것으로 둔다.

## 압축 진술

충분성 증명은 |X|에 대한 강한 귀납법이고, 증명 전체가 "|N(A)| = |A|인, 공집합도 X 전체도 아닌 부분집합 A(꽉 찬 집합)가 있는가"라는 하나의 경우 나눔 위에 서 있다. 꽉 찬 집합이 없으면 모든 부분집합에 여유가 1 이상 있으므로, 아무 변 하나를 매칭에 넣고 그 양 끝점을 지워도 홀 조건이 남는다. 꽉 찬 집합 A가 있으면 그래프를 A와 N(A) 쪽, 나머지 쪽의 둘로 쪼개어 각각에 귀납 가정을 쓰는데, 나머지 쪽의 홀 조건은 S가 아니라 S ∪ A에 원래의 홀 조건을 적용한 뒤 |N(A)| = |A|를 빼서 얻는다.

## 경중 선언

**무거운 것**

1. 경우 나눔의 동기. 변 하나를 골라 지우는 단순한 귀납이 어디에서 실패하는지를 구체적인 예로 보이고, 그 실패의 원인이 꽉 찬 집합임을 밝혀 경우 나눔이 어디에서 나오는지 설명한다.
2. 경우 2에서 나머지 그래프 G₂가 홀 조건을 만족함을 보이는 단계. S 하나에 홀 조건을 적용하는 접근이 왜 실패하는지, S ∪ A에 적용한다는 아이디어, 등식 N(S ∪ A) = N₂(S) ∪ N(A)가 서로소 합집합이라는 확인, |N(A)| = |A|가 쓰이는 정확한 위치.

**가벼운 것**

- 정리의 진술과 표기의 고정(홀 조건, X를 덮는 매칭, 꽉 찬 집합이라는 이름).
- 필요성의 증명.
- 귀납 명제 P(n)의 정확한 진술과 기저 n = 1. (아래 분류표에서는 부수적 고비다. 전개는 완전하게 하되 앞세우지 않는다.)
- 경우 1의 세부: N'(S) = N(S) ∖ {y}, 매칭을 합칠 때 끝점이 겹치지 않는다는 확인.
- 경우 2에서 G₁의 홀 조건과 두 매칭을 합치는 단계.
- 두 경우가 모든 경우를 덮는다는 확인(정수이므로 등호가 아니면 +1 이상).
- 재구성할 때 기억할 골격의 요약.

**뺄 것**

- 정리의 역사, '결혼'이라는 이름의 유래, 상이한 대표계(SDR) 판본.
- 다른 증명법(증가 경로, 쾨니그 정리, 최대 흐름-최소 절단)과 매칭 알고리즘.
- 무한 그래프에서의 반례.
- 수신자가 이미 아는 정의(그래프, 이분 그래프, 매칭, N(S))의 재설명, 귀납법 자체의 설명.

## 내용 단위 분류표

대상 독자는 학생(학부 3학년)이다. 알려진 결과의 해설이므로 `새로운 것`은 없다.

| 내용 단위 | 분류 | 처리 |
|---|---|---|
| 그래프, 이분 그래프, 매칭, N(S)의 정의 | 표준 | 다시 설명하지 않는다. 표기만 고정한다. |
| N의 단조성(S ⊆ T이면 N(S) ⊆ N(T))과 N(S ∪ T) = N(S) ∪ N(T) | 표준 | 쓰는 자리에서 한 문장으로 근거를 댄다. |
| 필요성 | 기계적 | 짧게 증명한다. 매칭이 S의 꼭짓점마다 서로 다른 짝을 N(S) 안에 준다는 것이 전부다. |
| 귀납 명제를 "X쪽 크기가 n인 모든 이분 그래프"에 대한 명제로 고정하는 것, 강한 귀납법이 필요한 이유, 기저 | 고비(부수) | 완전히 전개한다. 위치와 표지는 가벼운 것처럼 받는다. 처음 배우는 독자는 "이 그래프 G"에 대한 귀납으로 오해해 더 작은 다른 그래프에 가정을 쓰는 단계를 의심하기 쉽다. |
| 단순한 귀납(아무 변이나 지우기)의 실패와 경우 나눔의 동기 | 고비(주) | 완전히 전개한다. 무거운 것 1. |

| 경우 1: G'의 홀 조건 | 고비(부수) | 추론 단계를 모두 쓴다. S가 X의 진부분집합이 되는 이유(x ∉ S)를 밝힌다. |
| 경우 1: M' ∪ {xy}가 매칭임 | 기계적 | 끝점이 겹치지 않음을 한 문장으로 확인한다. |
| 경우 2: G₁의 홀 조건 | 고비(부수) | 추론 단계를 모두 쓴다. N(S) ⊆ N(A)이므로 이웃 집합이 그대로라는 점. |
| 경우 2: G₂의 홀 조건 | 고비(주) | 완전히 전개한다. 무거운 것 2. |
| 경우 2: |A| < n과 |X ∖ A| < n, 두 매칭의 합 | 기계적 | 짧게 확인하되 A ≠ ∅와 A ≠ X가 각각 어디에 쓰이는지 밝힌다. |
