## 목적 진술

작은 주차 함수 연구에서 얻은 피드백 이후 do-math에 추가·개선한 기능과 계약이 사용자 확정 사항을 충실하고 정확하게 구현하는지 검토한다. 대화 세션 원문, 기억, 결정과 검증 자료를 추적하여 누락·불일치·오구현과 계약 간 모순을 실제 사실로 입증하고, 승인된 수리를 반영한다. 특정 결함의 존재나 결함 수를 전제하지 않는다. 문서·코드·스키마·시험 및 다음 역할로 이어지는 실제 경로를 함께 대조한다.

## 불변식 목록

- 결론: 없음. 문제의 존재나 전체 통과를 미리 정하지 않는다.
- 필수 논거: 결함별 적용 기준, 실제 구현 좌표, 구체적 영향과 재현 가능한 근거. 잘못된 지적은 기각한다.
- 필수 전거: 기준 원문의 실제 문언. 사용자 확정은 대화의 질문·응답 문맥과 후속 번복을 함께 확인한다. 기억과 검증 보고는 원자료를 찾는 연결이며 사용자의 명시적 후속 결정을 덮지 않는다.
- 분량 상한: 없음.
- 현행 사용자 결정이 과거 설계보다 우선한다. 운영 세션 기본값은 최종 변경인 모델별 3개를 사용한다. 작업자 제출 검사는 세션예산 작업에서 제외됐다가 별도 형식·절차 작업에서 구현된 요구다. 이전 제외를 영구 금지로 읽지 않는다.
- 기존 연구 인스턴스, HOLD, 예약 작업의 복구·재개·변경은 제외한다. 검증 목적으로 실제 연구를 시작하지 않는다.
- 수리는 do-math 정본 파일에만 제안한다. 생성 사본은 세션이 공식 미러 생성기로 재생성한다. 과거 대화·기억·검증 기록은 역사적 자료이므로 현재 구현과 다르다는 사실만으로 고치지 않는다.
- 적용 뒤 python -m unittest discover -s .claude/skills/do-math/scripts/tests -p "test_*.py"로 회귀 전건을 실행하고, python .claude/skills/do-math/scripts/probe_codex.py --skill-only 및 미러 --check를 실행한다. 환경으로 인한 미실행을 통과와 구별한다. 검증·설치 명령의 정확한 인자는 해당 --help와 README에서 확인한다.
