# do-math 결정 대조 검증 장부

## 신호 처리 절

신호 6 자체 처리: 세션이 작성한 동결문의 검사 명령이 실제 README와 달랐다. README의 unittest discover와 probe_codex.py --skill-only로 정정하고 같은 1라운드를 수리부터 재시작한다. 오판 비용은 검사 누락으로 검증 신뢰성을 해치며, 원문 명령으로 고치면 낮다. 되돌리기 비용은 초기 수리 파견 재실행뿐이고 산출물 변경은 없다. 판단 근거는 현행 README 설치본 검사 절이다. 사용자 의도 변경은 없다.

상신 R1-04: 미평가 과제에 대한 계약 검토의 등급이 문서와 구현에서 다르다. 조각 없는 상신 제안이므로 승계 검사 밖이다. 선택지 1은 역할 기본값 유지·문서 명확화, 선택지 2는 미평가 과제의 계약 검토도 상 등급 배정이다. 추천은 현행 역할 하한을 유지하고 적용 범위를 명확히 하는 1이다. 오판 비용은 상급 슬롯 점유와 검토 품질·대기 정책 변경이며, 문서 수정 자체는 되돌릴 수 있지만 사용자 자원·품질 선호가 필요하다. 기존 결정은 두 기본 규칙의 우선관계를 닫지 않았다. 사용자에게 선택을 요청했고 회신 전 적용하지 않는다.

R1-04 사용자 회신: 미평가 계약 검토를 중·상 고정값으로 처리하는 대신, 일반·개정 후보의 평가 일대일 대응을 생산자·수신자에서 확인하고 자동 학술 과제는 기존 후보 준비가 평가만 보충한 뒤 독립 계약 검토로 보내는 방안을 승인했다. 사용자 원문은 “좋아 그러면 그렇게 하자”다. 조각 없는 상신 제안의 방향 확정이므로 §7 사용자 지시 경로로 공식 적용 7건 뒤 반영한다. 이 작업은 새 라운드가 아니며 스크립트 적용 계수에 섞지 않는다.

승계 기록(성립 자리: 심사): R1-02 / 심사자 2 / 근거/계약-학술자료-독립운영.md 136~138행. R1-10 / 심사자 2 / 같은 파일 136~146행. R1-12 / 심사자 1 / 같은 파일 170·249·262행; 심사자 2 / 같은 파일 170·249행 및 원본 대화 374행의 승인. R1-03의 심사자 2 승계 인용은 최종 기각으로 적용하지 않았다.

  - 1기: 관문 4의 개선을 통과하지 못한다. 대체 문면은 head와 최종 status만으로 변경 여부를 판정하지만, 둘이 같아도 이번 반복에서 사건과 큐가 바뀔 수 있다. 예를 들어 운영 슬롯이 모두 찬 capacity_waiting 중 재고 시각이 도래하면 새 준비 사건과 요청이 메모리에 생기지만, 여전히 실행할 슬롯이 없어 head와 status는 직전과 같다. 대체 문면은 이 실제 변경도 저장하지 않아 다음 별도 저장이나 루프 종료까지 외부 조회와 복구 기록에서 사라지게 한다. 원래 분기는 이를 저장했다. 변경 없는 poll의 과잉 저장은 확인되지만, 제시된 대체 문면은 변경 있는 poll의 공개를 누락하는 새 결함을 들인다.
