# do-math 검증 장부

## 신호 처리 절

신호 4 자체 처리: Claude Agent 도구가 없어 Claude CLI로 같은 모델·노력·파견문과 독립 컨텍스트를 사용한다. 모델 호출 사전 확인에서 일시 OAuth 갱신 실패 후 재시도 성공을 확인했다. 파일 쓰기 권한은 산출 계약 그대로다. 오판 비용은 동일 모델의 수송 차이이며 산출 검산으로 확인한다. 재실행으로 되돌릴 수 있고 CLI 실제 반환을 근거로 판단한다.

## 운영 기록

- 사용자 지정에 따라 1라운드, 수리 8기와 관점 4기, 수리 opus 5.5와 심사 astra를 확정했다. 영역·관점은 기능 경계로 나누고 시험은 관련 모듈과 분량을 고려해 배정했다.
- _prepare.py: 동결·파견 슬롯 작성. 공식 스크립트가 덮지 않는 작업이다.
- Windows 실행은 Python subprocess로 Codex CLI를 병행 시작한다. Bash가 아닌 수송을 쓰되 인자·PATH 정비·완료 대기는 같은 계약을 유지한다.
