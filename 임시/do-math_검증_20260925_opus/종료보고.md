- 재심사의 정확한 판정·근거 파일을 기존 수신자에 연결하는 CLI 요청을 제공했다. 일반 제보만으로 효력을 바꾸지 않고 적격 근거와 원 정책을 검사한다.

R1-03은 상태 조회를 버리는 비용을 없애되 시험용 호환 래퍼를 만들지 않았다. R1-08은 허가 후보가 없어도 시각을 검사한 뒤 공통 범위 검사를 쓴다. R1-16은 누락된 probe 소비자를 포함해 cli_path 하나로 정리했다. R1-40은 무효 연산을 공개 스키마와 내부 변경 전 경계에서 거부한다. R1-10은 이미 있던 Python API의 적격 근거 처리와 유한 재심사에 CLI 생산자를 연결했다. 별도의 전 상태 자동 검색기를 추가한 것은 아니다.
