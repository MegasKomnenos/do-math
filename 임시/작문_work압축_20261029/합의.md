# 합의: do-math 끝난 세션의 work/ 자동 압축 계약

대상 원고: `.claude/skills/do-math/RUNTIME.md`와 `.claude/skills/do-math/protocol.md`의 현행 판본 전체. 이번 변경은 두 문서에 끝난 세션의 `work/` 압축을 추가한다. 독해자는 원고 본문만 받는다.

## 독자가 읽고 이해할 내용

1. 반영(`integrated`)이나 실패(`failed`)로 처리가 끝난 세션의 `work/`는 실행기가 같은 세션 폴더의 `work.tar.xz`로 압축하고 원본 디렉터리를 지운다. 실행 중·공개 중 세션의 `work/`는 건드리지 않는다.
2. 압축은 실행기와 분리된 보관 프로세스 하나(`runner.py _archive <instance>`)가 한다. 실행기는 세션 처리를 끝낸 뒤와 기동할 때 이 프로세스를 띄운다. 이미 돌고 있으면 끝난 뒤 다시 띄운다. 그래서 수집·파견이 압축 때문에 멈추지 않는다. 실행기가 꺼져 있던 동안이나 이 기능 이전에 끝난 세션도 다음 기동에서 처리된다. `runner/archive-lock`으로 인스턴스당 하나만 실행되고, 오류는 `runner/archive.log`에 남는다.
3. 원본 삭제 조건(데이터 보존): 압축본을 끝까지 다시 읽어 모든 디렉터리·파일이 같은 이름과 SHA-256으로 들어 있음을 확인한 뒤에만 `work/`를 지운다. 쓰기·검증 실패 시 `.part`만 지우고 `work/`를 보존하며 다음 보관 실행에서 다시 시도한다. 기존 `work.tar.xz`는 덮어쓰지 않는다. 삭제가 중단되어 남은 `work/`는 그 내용이 압축본에 같은 해시로 있을 때만 지우고, 다르면 둘 다 보존하고 오류를 남긴다. 심볼릭 링크·정션이 있으면 그 세션은 압축하지 않는다.
4. 압축 뒤에는 `work/` 경로로 읽을 수 없고, 압축본을 풀어 되살린다.

## 압축 진술

끝난 세션의 `work/`는 분리된 보관 프로세스가 검증을 마친 `work.tar.xz`로 바꾼 뒤 지운다. 검증을 통과하지 못하면 원본은 그대로 남는다. 압축 뒤의 원본은 압축본을 풀어서만 얻는다.

## 경중 선언

- 무거운 것: 대상과 시점(끝난 세션만, 분리 프로세스, 기동 시 소급 처리). 원본 삭제 조건과 실패 시 보존.
- 가벼운 것: 잠금·로그 경로, `ARCHIVE_PRESET`(기본 9) 노브, xz 솔리드 tar 형식, 링크 거부, 복원 방법, 구현 진입점과 시험 목록의 갱신.
- 뺄 것: 압축 알고리즘의 일반 설명, 이번 디스크 부족 사건과 크기 수치, 해시 계산 구현 세부.

## 확정 사실(코드)

- `FINISHED = ("integrated", "failed")`, `ARCHIVE_PRESET = 9`.
- `Runner.finish`가 두 종료 경로에서 `archive_due`를 켜고, `Runner.run` 기동 시 켠다. `Runner.tick`은 `collect` 직후 `Runner.archive`를 호출해, 기존 보관 프로세스가 없거나 끝났고 끝난 세션 중 `work/`가 남은 것이 있을 때만 `_archive`를 분리 프로세스로 띄운다.
- `archive_finished`는 `runner/archive-lock`을 비차단으로 잡고 못 잡으면 아무 일 없이 끝난다. 세션별 오류는 stderr(실행기가 `runner/archive.log`로 연결)에 JSON 한 줄로 남기고 다음 세션으로 넘어간다.
- `archive_work`: `work.tar.xz.part`에 `w:xz`로 쓰고 다시 읽어 대조, 일치하면 `os.replace` 후 `shutil.rmtree(work)`.
- `protocol.md` 3단계의 "세션 폴더도 그대로 남긴다"는 새 동작과 정합하게 고친다. `RUNTIME.md:116`의 "새로운 프로세스 종류를 두지 않는다"는 동료 단계 개편 절의 진술이며 보관 프로세스와 모순되게 읽히지 않아야 한다.
