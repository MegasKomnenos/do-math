# 독자 정보

독자는 do-math의 연구 책임자이자 이 저장소의 사용자다. do-math의 목적과 운영, 세 경량화(검사 경량화, 2라운드, 시험 경량화)의 경위와 그때 자신이 내린 결정(예산 단일 풀, 결과 캐시 제거, 상주 git 프로세스 기각, 안 C 등)을 알고 있다. 개별 모듈의 내부 코드는 세부까지 기억하지 않는다. 소프트웨어 공학 용어(이음새, 순환 의존, 캐시 무효화)는 이해한다.

문서 종류: 두 검토 지시에 대한 결과 보고서. 독자는 이 보고서로 정리 작업을 채택할지, 어떤 결정을 내릴지 정한다. 후보별 세부는 필요할 때 통합표에서 찾는다.
