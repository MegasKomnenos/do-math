# 독자 정보

독자는 코드 검토를 맡은 AI 에이전트(Claude Opus 계열, 높은 추론 노력)다. 이 작업의 대화 맥락은 없다. 소프트웨어 공학 일반 지식(리팩터링, 결합과 응집, DRY, 기술 부채)은 갖췄다. do-math의 내부 구조와 지난 경량화 경위는 모르며, 기준 문서와 파견문, 그리고 두 문서가 가리키는 파일로만 안다.

문서 종류: 병렬로 파견되는 여러 검토자가 공유하는 작업 계약. 각 검토자는 작업을 시작하기 전에 전문을 읽고, 작업 중에는 판정할 때마다 해당 절을 다시 본다. 질문할 수 있는 채널은 없다.
