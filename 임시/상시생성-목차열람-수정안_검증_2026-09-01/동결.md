## 영역 배분

수리 6기 = 영역 4기(1~4) + 관점 2기(5~6). 영역은 절의 자연 경계에 가장 가까운 비공백 인접 행 쌍으로 가른다. 행 번호는 동결 시점(라운드 1 사본, 총 252행) 기준이고 라운드마다 재정박한다.

축자는 원문 그대로다(래핑·이스케이프 없음).

- 기 1 — 영역 1: docs/do-math/상시생성-목차열람-수정안.md 행 1-75 — 0~1절과 2절 머리(지위·읽기 계약·개편의 본질·유지/기각 목록)
  시작 축자: # 통합-설계 상시 생성·목차 열람 개편 수정안
  끝 축자: - 씨앗 생성 근거는 넷으로 닫혀 있다: 초기화, 작업 종결 공용 편입, 승인된 외부 변화, 빈 실행 껍질의 생존 규칙(§7.1 `generation_basis`, 루트 CONTEXT.md 「작업 씨앗 생성 근거」).
- 기 2 — 영역 2: 같은 파일 행 76-122 — 2절 나머지와 3.1~3.3절(배경 사실·생성 회차 규칙·절차·렌즈 지시)
  시작 축자: - 생존 절차(§7.7)는 "목표 unsolved + 활성 연구 작업 없음 + 빈 실행 껍질"에서만 씨앗 생성 세션을 열고, 7단계 절차(기존 씨앗 전수 검사 → 외부 대기 보고 → 세션 개설 → 제안 작성 → output ref 봉인 → 기계 검사·독립 착수 검토 → `survival_generation` 원자 편입)를 수행한다.
  끝 축자: - 거리가 먼 개념의 연결을 피하지 않는다. F 객체의 `selection_relevance`는 추측적 관련이어도 그 추측을 명시하면 충분하다.
- 기 3 — 영역 3: 같은 파일 행 123-191 — 3.3절 끝~4절 대부분(packet 개편·열람 지시·검토자 모델·개편 지도·테스트 벡터)
  시작 축자: - 씨앗 제안의 근거는 확인된 근거, 추론, 가설, 직감을 구분해 기록한다.
  끝 축자: - 후보별 처분 완결성이 목차 방식에서도 검사됨
- 기 4 — 영역 4: 같은 파일 행 192-252 — 4절 끝(무변경 목록)과 5~8절(유래 구분·수행 절차·완료 기준·경위)
  시작 축자: - `seed_generation` 명칭의 스키마·검사 정합
  끝 축자: - 이 문서의 한계: 인용한 통합-설계 절 번호는 지식층 수정안 반영 전 기준이다(0.1절의 대응 규칙). `PT24H` 기본값은 운용 실측 전의 초기값이며 연구 설정으로 조정한다.
- 기 5 — 관점 A: 대화로그 대조. 수정안 전문을 대화로그 전문과 적대적으로 대조한다 — 사용자 확정·기각·교정의 왜곡·누락·창작, 5절 유래 구분의 오배치(AI 세부를 승인 골격으로, 승인 사항의 누락), 대화에서 확정됐으나 수정안에 빠진 결정.
- 기 6 — 관점 B: 수행 프롬프트 품질과 원문 정합. 문서를 수행 세션의 프롬프트로 보고 검토한다 — 내부 정합(3절 대 1·4·6·7절), 통합-설계·지식층 수정안·CONTEXT.md 원문 대비 사실 서술의 정확성, 수행 세션이 단독으로 판정할 수 없는 지시·완료 기준, write-for-reader 기준(명확성·충분성).
