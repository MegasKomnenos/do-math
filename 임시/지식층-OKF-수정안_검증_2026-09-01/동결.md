## 목적 진술

수정안이 ① 대화 로그에 기록된 연구 책임자의 승인 결정을 왜곡·누락 없이 반영하고 ② 통합-설계·CONTEXT.md·컨텍스트 정본과 정합하며 ③ 개편 수행 세션이 수정안 0.1절의 필독 목록만으로 오독 없이 개편을 수행할 수 있도록 정확·명확·충분·간결한지 검증하고 결함을 수리한다.

이 수정안은 미래의 신규 세션이 `docs/do-math/통합-설계.md`를 개편할 때 쓰는 실행 계약이다. 연구 책임자가 개편 골격을 승인한 뒤 적대 검증을 지시했다.

## 불변식 목록

1. 수정안 4절의 골격 결정(지식 기록 7종 전환 범위, 기능 대체 원칙과 `id`·`type`·`@` 합성 표기, 정규 YAML형과 파일 바이트 해시, 의미 경로+frontmatter `id`+재생성 색인, 전면 ID 링크, 관계의 별도 기록 유지, 부재 의미 4규칙, OKF v0.2 잠금, 파생 보기 최소 집합, 저작 관례와 승격)의 의미를 뒤집는 수리는 금지한다. 그런 결함 인식은 수리 항목이 아니라 상신 제안 또는 발견 항목으로 처리한다.
2. 수정안 6절의 결정 유래 구분(승인 골격 / AI가 채운 세부 / 잔여 재량)은 유지한다. AI가 채운 세부의 내용 개선 수리는 허용하되, 수리로 세부가 바뀌면 6절의 해당 기재도 같은 항목에서 정합하게 고친다.
3. 수정안은 자기충족적이어야 한다. 개편 수행 세션이 이 대화를 읽지 않고 0.1절 필독 목록만으로 수행할 수 있어야 한다.
4. `.claude/CLAUDE.md` 작문 절의 품질 계약(정확성·충실성·정합성, 그리고 명확성·충분성·간단성·간결성의 순서)을 적용한다.
