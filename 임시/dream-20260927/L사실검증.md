# L 노드 추가분의 사실 검증

## 검사 범위와 방법

검사 대상은 `git diff -- 기억/layer3/`에서 `+`로 시작하는 행이다. 기존 행을 고친 경우에는 수정된 행 전체를 읽었고, 삭제 행은 남은 문장과 어긋나는지 보는 데만 썼다.

근거로 삼은 원본은 다음과 같다.

- 기억 노드: 추가 행이 인용하는 `기억/layer1/M-0339.md`~`M-0351.md`와 `기억/layer2/D-0010.md`를 전문으로 읽었다.
- 현행 소스:
  - `.claude/skills/do-math/scripts/do_math/state_contract.py`, `file_io.py`, `repository.py`, `formal.py`, `engine.py`, `execution_profiles.py`
  - `.claude/skills/do-math/scripts/이음새-정본.md`, `run_tests.py`, `test_categories.py`, `tests/시험-지침.md`, `tests/*_fixtures.py`
  - `.claude/skills/do-math/references/모델과-실행예산.md`, `SKILL.md`, `README.md`
  - `docs/do-math/implementation-v5/README.md`, `docs/do-math/`의 문서 목록과 역사 기록 표지
  - `.skill-workspace/` 목록, `schtasks`로 조회한 `DoMath-*` 예약 작업, `.agents/AGENTS.md`와 그 git 이력, `.claude/CLAUDE.md`, `.claude/skills/commit-harness/SKILL.md`

파일별 문장 수는 추가·수정 행 안에서 문장 끝 "다."를 센 근사치다. 수정 행에서는 바뀌지 않은 기존 문장도 함께 셌다.

### 8. L-0020: 검사 경량화 통합 결과의 수가 맞지 않는다

- **유형:** 내부 모순(원본에서 이어짐)
- **L 노드 인용:** "integration 1,414개 중 1,387개가 통과했고, 실패 28개를 기존 결함 18개·부하 흔들림 1개·환경 차이 1개·시험 쪽 회귀 8개로 분류했으며"
- **근거:**

- **고칠 방향:** "integration과 archive를 합쳐 실패 28개" 식으로 모집단을 밝힌다. 확정할 수 없으면 수가 맞지 않는다는 사실을 덧붙인다.
