## Destination

P vs NP 연구 체계의 재설계와 보편 수학 연구 스킬 `do-math`의 확립. Lean 정본,
입증·인증 기준, 문헌 수집·활용, 작업 씨앗·깊이 1 실행 껍질 운전, 모델 배정과 과거 자료의 참고 경계가
전부 결정되고, `do-math`가 구현·검증되어 실제 연구를 시작할 수 있는 상태가 종착이다.
실제 문헌 수집, Lean 연구 정본 구축과 증명·반증 시도는 이 지도의 범위 밖이다.

## Notes

- 컨텍스트 정본: `docs/wayfinder/pvsnp-재설계/컨텍스트.md`. 모든 세션은 어느 티켓이든
  착수 전에 이 문서 전문을 읽는다.
- 같은 티켓을 이어가는 세션은 결정마다 `CONTEXT.md`와 컨텍스트 정본을 증분 수정하지 않는다.
  handoff, 티켓 종료나 그 밖의 세션 종결 시 그 세션의 확정 결정을 원자료와 대조해 한 번에
  갱신한다. 새 결정이 대체한 문면과 중복을 함께 제거한다. 티켓을 닫는 세션은 이 일괄 갱신을
  커밋하고, 바꿀 것이 없으면 해결 댓글에 「정본 갱신: 영향없음」을 명시한다.
- 컨텍스트 정본에는 현행 공유 결정과 소유권만 둔다. 결정 경위와 대체된 설계는 해결 댓글과 연결 문서에 둔다.
- 도메인: 계산 복잡도 이론 연구 체계와 보편 수학 연구 스킬 설계. 그릴링 티켓은
  `/grilling`과 `/domain-modeling`을, 조사 티켓은 `/research`를 쓴다.
  산문은 `write-for-reader`를 적용한다.
- `do-math` 구현은 `skill-creator`, `writing-great-skills`와
  `write-for-reader`를 적용한다.
- 수학 판단 역할은 `gpt-5.6-sol max` 개별 에이전트를 사용한다. `do-math`가 병렬화를 직접 운전하고 연구·평가 하위 세션에서 Codex `ultra`를 사용하지 않는다.
- 이 지도는 `do-math` 구현·검증을 실행 범위에 포함한다. 실제 수학 연구 실행은
  포함하지 않는다.
- 열린 질문과 실행 작업의 정본은 GitHub 하위 이슈 목록과 차단 관계다. 지도 본문은
  열린 티켓을 나열하지 않는다.

## Decisions so far

- [반증 재작성 규약을 확정한다](https://github.com/MegasKomnenos/math/issues/7) — 좁은 부정 결과는 실제 범위의 독립 결과로 다룬다. 당시의 연구 지도 상태 전이는 후속 Lean 정본 구조가 대체했다.

- [연구 지도 도구 지형을 실사한다](https://github.com/MegasKomnenos/math/issues/8) — Lean 생태계·Blueprint 계열·Equational Theories·MMT의 표현력과 검증 경계를 실측해 현행 통합 설계와 핵심 Lean 정의의 사실 입력으로 고정했다.

- [P vs NP 연구 주제 선호를 확정한다](https://github.com/MegasKomnenos/math/issues/17) — `do-math`가 소유하는 보편 연구 방법과 분리해, P vs NP의 의미·원하는 결과·범위·연구 방향·문헌·학술 검증 선호를 확정했다.

- [보편 수학 연구 스킬 do-math의 통합 설계를 확정한다](https://github.com/MegasKomnenos/math/issues/18) — 일회성 입력 수입, K·F·U, 작업·실행·포트폴리오·프로세스 격리, 해설–Lean 동일성 인증과 Git 원자 편입을 자기충족적 구현 명세와 테스트 벡터로 확정했다.
