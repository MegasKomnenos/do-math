# do-math 검증 장부

## 신호 처리 절

- 0단계 신호 4 자체 처리: Claude Agent 도구가 없으므로 같은 Opus 5.5를 CLI로 파견한다. 입력·산출·정족은 유지한다. 오판 비용: 운송 실패는 완료·검산에서 잡힌다. 되돌리기: 해당 파견 재실행. 판단 가능성: 실제 claude-opus-5-5 및 gpt-6-astra READY 호출 성공.
- 라운드 1 심사 승계: R1-06은 M-0597·M-0601 및 common.md의 상충 정의, R1-11은 M-0598의 사용자 허용 공리 예외, R1-13과 R1-M2는 M-0600의 연속 계획 실패 정지를 근거로 심사 자리에서 수리 처분을 받았다. 7개 승계 기록은 4개 항목에 해당한다. 세션의 처분 전환은 없다.

## 운영 기록

- 사용자 지정 직접 재검토는 라운드 사이 통상 편집 경로로 반영하고 공식 심사와 분리 기록한다.
- 영역·관점은 파일의 자연 경계와 교차 정합성 관점으로 정했다.
- _prepare.py: 동결·영역 명세·파견문 슬롯·라운드 머리 재료 작성. 공식 스크립트에 입력 파일 작성 기능은 없다. 앵커·사본·검산은 vr.py만 실행한다.
- _dispatch.py: Windows에서 독립 CLI 병행 실행과 UTF-8 stdin 공급. 공식 스크립트에 파견 실행 기능은 없다.
- 라운드 커밋은 commit-harness의 미러·기억 노드·색인 절차를 함께 수행한다.
- 기준선 시험: `python -m unittest discover -s .claude/skills/do-math/tests -q`는 20개 중 3개 실패(89.111초). 모두 RunnerTests.until 기본 12초에서 전체 흐름·커밋 후 복구·입력 후 재개가 미완료인 실패였다. 제품 코드와 단언을 유지하고 런타임에서 until의 기본값만 60초로 조정한 진단 실행은 RunnerTests 7개 모두 통과(33.482초). 제품 실패와 시험의 벽시계 한계를 구분한다. 기준선 미러 `--check`는 185파일 드리프트 없음.
- 수리 1기 첫 반환은 계약이 요구한 작문 참조 셋을 읽지 않았다고 명시했다. 산출의 공식 서식·축자 검산은 통과했으나 수행 미달이므로 원 산출·반환·로그를 보존 이름으로 옮기고 같은 파견문으로 1회 재파견한다. 지정 모델·노력을 유지하고 원 컨텍스트에서 이어 수행한다.

## 라운드 1 — 사유 절

- **R1-02** (승인 2/3)
  - 3기: 관문 4·5 미충족. 원래 문면이 모든 설정을 실행기 재기동에 묶는 문제는 실재하지만, 대체 문면은 Lean 설정을 읽는 시점을 새 세션 기동으로 고정한다. SKILL.md의 “세션이 뜰 때마다”와 RUNTIME.md의 “그 뒤 새로 뜨는 세션부터 적용된다”는 현행 전달 계약이 보장하지 않는 경계를 만든다. 변경 전에 뜬 세션이 변경 뒤 처음 settings.json을 읽어 컴파일하는 경우에도 바뀐 값을 읽을 수 있다. 파일 경로 전달과 세션의 직접 읽기를 설명하는 데서 나아가 적용 시점을 단정하므로 새 부정확성이 생긴다.
- **R1-04** (승인 2/3)
  - 2기: 관문 3에서 성립하지 않는다. 영향 칸은 잘못된 노력이 공식 검사를 통과해 기동 실패가 되고, 같은 요청의 재게시가 반복되는 손상을 기술한다. 대체 문면은 허용 값과 실패 결과를 알리지만 check.py의 허용 범위와 plan.md의 launch_error 재게시 지시는 그대로다. 영향 칸의 예시 요청이 게시된 경우를 따라가면, 수정 뒤에도 검사를 통과하고 동일한 기동 실패와 재게시 경로가 남는다. 문서의 허용 값 누락만으로 결함을 좁히면 개선이지만, 계약상 해결 판단의 잣대인 영향 칸 전체를 없애지는 못한다.

  - 1기: 관문 4·5를 통과하지 못한다. 어댑터 시험의 tomllib 하한을 전체 시험의 실행 환경으로 옮기면서, 공식 검사기와 실행기가 요구하는 Python 3.12 조건을 3.11로 낮추는 새 오류를 넣었다. Python 3.11에는 Path.is_junction이 없어 전체 시험은 안내된 하한 환경에서 실행되지 않는다. 현재의 두 패턴 제한이 시험 범위를 빠뜨린다는 지적 자체는 타당하지만, 그 지적을 고치는 대체 문면은 기존 환경 계약과 맞지 않는다. 변경본이나 시험을 실행하지 않고 문서·호출 코드를 대조해 판정했다.
