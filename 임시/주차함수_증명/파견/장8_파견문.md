### 5.1 노드 FLQ와 관계

명제 6에서 버릴 수 있는 것은 무게 성장, Quad, 그리고 줄기의 하계를 넘는 몫이다. 무게 성장을 버리려면 꼬리합이 음이 아니어야 하고, 줄기의 하계는 띠에서는 공표 bvtheta-band가, 벌크에서는 Stem ≥ 0만이 준다. 그렇게 적으면 둘째 층의 양이 전혀 남지 않는다. 크기 k+1의 꼬리합은 따로 요구할 필요가 없다. 크기 k에서는 M ≤ k−1이라 π_k(k) = 0이고 f_k = −2(k−1)π_k(k−1)이므로, 정확히 T_(k+1) = T_k + 2(k−1)π_k(k−1)(≈ T_k + 2/e)이다.

**노드 제안 FLQ** (`s3ecdd70238dc414eb88520eb4c580813-qstar2-first-layer-tail`). root와 같은 원 주차 과정에서 A_(m,ℓ), b_(m,ℓ), p_m을 root와 같이 두고 π_m(ℓ) = b_(m,ℓ)/p_m이라 하자. 정수 k ≥ 2와 1 ≤ ν ≤ k에 대해 t = 2k+ν, a = k+ν로 두고, k ≤ m ≤ 2k에서
  f_m = 2[(k+1)π_m(k) − (k−1)π_m(k−1)] (m ≤ a),  f_m = (k+t−m+1)π_m(k) − (k+t−m−1)π_m(k−1) (m > a),
  T_m = Σ_(i=m)^(2k) f_i,  w_m = C(t−1,m)·p_m·A_(t−1−m,k−1)/A_(t,k−1)
라 하자. ν ≤ 0.48k이면 θ = 2(1+1/k)·A_(a,k−1)/A_(a,k) − 1, ν > 0.48k이면 θ = −1로 둔다. **모든 정수 k ≥ 6667과 max(2k+103, 20001) ≤ t ≤ 3k인 모든 정수 t에 대해 (가) k+2 ≤ m ≤ 2k인 모든 정수 m에서 T_m ≥ 0이고, (나) w_(k+1)·T_k + θ·w_a·A_(a,k)/p_a ≥ 0이다.**

FLQ에 나오는 양은 크기 ≤ 2k의 열 값뿐이다(w_m의 A_(t−1−m,k−1)도 t−1−m ≤ k+ν−1 ≤ 2k−1). w_a·A_(a,k)/p_a = N_thr이다.

**관계 [peer, 증명].** FLQ ∧ bvtheta-band(`s72a79340e4cd411691b0fe6d923db6ea-bvtheta-band`, 확립) ⇒ Q⋆₂.

*증명.* (k,t)를 Q⋆₂의 범위에서 잡는다. 보조정리 1(r317/c-ledger)과 명제 6의 Abel 합으로
  src_k(t)+FL_k(t) = w_kT_k + (w_(k+1)−w_k)T_(k+1) + Σ_(m=k+2)^(2k)(w_m−w_(m−1))T_m − N_thr + Quad_t + Stem_t
이다. 보조정리 2(c)(r317/c-thmQ2와 r051bfe18/c-sharp)로 w_m − w_(m−1) ≥ 0이다. T_(k+1) ≥ T_k이므로 앞의 두 항의 합은 w_kT_k + (w_(k+1)−w_k)T_k = w_(k+1)T_k 이상이다. FLQ(가)로 셋째 합은 음이 아니고 Quad_t ≥ 0이다. 그러므로 src+FL ≥ w_(k+1)T_k − N_thr + Stem_t이다.
ν > 0.48k이면 Stem_t ≥ 0이고 θ = −1이므로 src+FL ≥ w_(k+1)T_k + θN_thr ≥ 0(FLQ(나))이다.
ν ≤ 0.48k이면 k ≥ 6668이다(k = 6667에서는 ν = k뿐이다). 그러면 t는 bvtheta-band의 범위 max(2k+103,20001) ≤ t ≤ 2k+0.48k에 있고 BV_t ≥ Θ_t, 곧 Σ_(m=2k+1)^(t−1)C(t,m+1)p_(t−1−m)(b_(m,k)+b_(m,k−1)) ≥ C(t,k)k^(k−2)A_(t−k,k−1)이다. t ≤ 3k에서 크기 m > 2k인 자식의 형제 크기는 ≤ k−2라 A_(t−1−m,k−1) = p_(t−1−m)이고, C(t,m+1) = C(t−1,m)·t/(m+1) ≤ C(t−1,m)·t/(2k+2)이므로 A_t·Stem_t = Σ_(m>2k)C(t−1,m)p_(t−1−m)(b_(m,k)+b_(m,k−1)) ≥ ((2k+2)/t)·BV_t이다. 또 A_(k−1,k−1) = p_(k−1) = k^(k−2)와 C(t,k) = C(t−1,k−1)·t/k에서 Θ_t = (t/k)·A_t·N_thr·A_(a,k−1)/A_(a,k)이다. 그러므로 Stem_t ≥ 2(1+1/k)·(A_(a,k−1)/A_(a,k))·N_thr = (θ+1)N_thr이고 src+FL ≥ w_(k+1)T_k + θN_thr ≥ 0이다. □

증명은 모두 공표 지지 주장(r317/c-ledger, r317/c-thmQ2, r051bfe18/c-sharp)과 노드 bvtheta-band의 진술(r030ffae/band-node로 확립)만 쓴다. peer는 이 사슬의 정확한 항등식 부분(장부, Abel 꼴)을 §2.6에서 정확 유리수로 확인했다.

t = 3k에서 FLQ는 이미 성립한다. a = 2k이므로 T_m = 2Ũ(m) ≥ 0은 (V)이다. (나)에서는 ν = k > 0.48k라 θ = −1이다. w_(k+1) ≥ w_k이므로 N_thr/w_(k+1) ≤ N_thr/w_k < 1.3502 ≤ 2c(k)이고(r317 정리 T의 증명), 따라서 w_(k+1)T_k − N_thr ≥ w_(k+1)[2c(k) − 1.3502] > 0이다.

**개정의 까닭.** 이 후보의 첫 판은 (가)를 k < m ≤ 2k 전체에서, (나)를 w_k·T_k + θN_thr ≥ 0으로 적었다. §5.4의 명시 도구로 재 보니 첫 판에서 가장 빠듯한 것은 (나)가 아니라 (가)의 m = k+1, 곧 T_k ≥ −2(k−1)π_k(k−1)이었다. 위치 k = 9949, ν = 103에서 선도 몫을 참값으로 넣은 명시 사슬의 여유는 m = k+1에서 −0.018이고, m = k+2에서는 +0.52이다(§5.5). 개정판은 그 한 자리를 위의 정확한 항등식으로 T_k에 흡수하고, 그 값으로 (나)의 무게를 w_k에서 w_(k+1)로 바꾼다. 참값으로 보면 (나)의 여유는 0.002N_thr 안에서 같고(계산한 위치에서 w_(k+1)/w_k ≤ 1.0013), (가)의 창 최솟값은 1.75에서 2.29로 오른다(§5.2). 두 판은 서로를 함의하지 않지만 둘 다 bvtheta-band와 함께 Q⋆₂를 준다. 띠에서는 θ > 0이다(§5.4의 사슬 상계로 θ ≥ 2(1+1/k)^(1−ν) − 1 > 0). 그러므로 T_k ≥ 0이면 (나)는 저절로 성립한다. 곧 띠에서 FLQ의 실제 내용은 "T_k가 −θN_thr/w_(k+1) ≈ −1 아래로 내려가지 않고, 크기 k+2 이후의 꼬리합은 음이 아니다"이다.

### [re71a735] §5 귀결(402–411행)

## 5. 귀결: Q⋆₂ 경로로 root에 이르는 둘째 증명

FLQ가 받아들여지면 승인된 관계로 다음이 차례로 따른다. 앞의 셋은 frontier가 아직 미해결로 적고 있는 노드다.
1. FLQ ∧ bvtheta-band(확립) ⇒ Q⋆₂.
2. Q⋆₂ ∧ source-side(확립) ∧ critical-tilt-first-layer-tail(확립) ⇒ qstar-columns-from-3131.
3. qstar-columns-from-3131 ∧ qstar-columns-2001-3130(확립) ⇒ one-step-local.
4. one-step-local ⇒ left-residual-reduced ⇒ left-residual-increase ⇒ left-interior ⇒ cross-pairs, 그리고 split-four-position-pairs로 root.

판 344의 root는 이미 P◇ 경로로 비형식 증명되어 있다. 두 경로는 bvtheta-band, 띠·중앙의 공표 입력(정리 B‴·H*₊ 등이 bvtheta-band를 받친다), qstar-columns-2001-3130 이후의 사슬(W_L♭ ⇒ root)을 함께 쓴다. 다른 것은 둘째 층 벌크를 닫는 방식이다. P◇ 경로는 쌍 부등식(정리 W, binary64 컴퓨터 보조)과 B⁺ ⇒ LRP₂(rb6a2cd0e의 P⁺⁺ 유한 확인)를 쓴다. Q⋆₂ 경로는 이 기록의 첫 층 부등식 FLQ와 source-side, critical-tilt를 쓴다. 그러므로 P◇ 경로의 어느 고유 입력에 의문이 생겨도 root는 이 경로로 남는다. 다만 두 경로가 함께 쓰는 입력과, 이 기록이 기대는 벌크 점질량 상계·따름정리 E(둘 다 n ≤ 20000 정수 인증을 거친다)에 대해서는 그렇지 않다.
