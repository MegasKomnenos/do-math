## 1. 가장 큰 발견: 위험률에서 \(1/k\) 크기의 정보를 버려서 먼 영역의 별도 논증이 생겼습니다

**관련 위치: 보조정리 6.3, 식 (6.10), 정리 7.70–7.73 및 SRC+를 위한 먼 영역 전달 부분.**

이 부분은 단순한 상수 개선보다 훨씬 중요합니다. 원고의 기존 입력으로 위험률을 \(1/k\) 크기로 제어할 수 있는데, 실제 후속 증명에서는 이를 \(1/n\) 크기로 약화합니다. 그 결과 \(n\)이 커질수록 하계가 사라지고, 먼 영역을 처리하기 위한 별도의 장치가 필요해집니다.

원고의 기호를 따라
\[
g(x)=(x-1)\log(1+1/x)
\]
라 두면, 제한 성장비에 관한 기존 결과가
\[
\mathfrak r_N\le e^{g(k)},\qquad
\mathfrak r_N=(1-\mathrm{hz}_k(N))e^{g(N+1)}
\]
를 줍니다. 따라서 곧바로
\[
\mathrm{hz}_k(N)\ge 1-e^{-\varepsilon_N},
\qquad
\varepsilon_N=g(N+1)-g(k)
\]
입니다.

여기서 \(N+1\ge2k\)이면 원고의 기존 \(g\) 상하계를 이용해
\[
\frac{3}{4k}-\frac{17}{24k^2}
\le \varepsilon_N\le\frac{3}{2k}
\]
를 얻고, 따라서
\[
\boxed{
\mathrm{hz}_k(N)
\ge
\frac1k\left(\frac34-\frac{11}{6k}\right)
\ge\frac1{2k}
}
\]
가 됩니다. 필요한 \(k\ge2001\)에서는 넉넉하게 성립합니다.

원래 쓰던 \(.14/n\)과 비교하면, 중요한 차이는 **\(n\)이 커져도 이 하계가 약해지지 않는다는 점**입니다.

### 이 개선을 실제 SRC 계산에 넣으면

원고에 이미 있는 꼭대기 301개 뿌리의 질량 하계와 결합하면
\[
\boxed{
\mathrm{src}_{n,k}-\mathrm{inhlin}_{n,k}
\ge
\frac{\mathcal P_n(k)}k
\left(
\frac{\sqrt{k}}2-\frac{301}{2k}-1
\right)
>
20\,\frac{\mathcal P_n(k)}k>0
}
\]
가 **모든 \(k\ge2001,\ n\ge3k+1\)**에서 나옵니다. 여기서 \(\mathcal P_n(k)\)는 원고의 마지막 차 자리 확률입니다.

이 계산에서는 항의 중복 사용 여부도 확인했습니다. 꼭대기 보상에서 사용하는 왼쪽 자식 크기는 \(n-k\ge2k+1\)이므로 첫 층 선형 상속과 겹치지 않습니다. 음의 문턱 항도 한 번만 포함됩니다.

그러므로 SRC+를 증명하기 위해 따로 만들었던 중간 구간 판정과 먼 극 영역으로의 전달을 유지할 필요가 없어집니다. **polar-PD, SRC+용 별도 전달, 균일 X-cert 인증으로 이어지는 분기를 주정리의 필수 입력에서 제거할 수 있습니다.**

다만 작은 열의 G′ 판정이 쓰는 소인·갱신 기본식과 유한 크기 전달까지 없어지는 것은 아닙니다. 이 구별은 보고서에서 명시했습니다.

이 발견은 원고의 구조를 읽는 데도 중요합니다. 뒤의 복잡한 장치가 반드시 새로운 수학적 장애 때문에 생긴 것은 아닙니다. **앞에서 확보한 강한 하계를 약화한 선택 때문에 생긴 장애**인 부분이 있습니다.

## 2. 강한 대각선 비교를 정규화하면 긴 경로 손실 분석이 망원곱으로 바뀝니다

**관련 위치: 정리 5.50, 정리 6.21, 정리 6.47, 명제 6.49·6.50.**

이곳은 사용자가 말씀하신 “일반적인 내용을 찾아 서로 다른 구체적 경우에 적용할 수 있는데 개별적으로 중복한 수학”에 특히 잘 들어맞습니다.

원고는 약한 대각선 비교를 반복 적용하면서 경로별 이동 인자, 조화합, 제곱 오차, 지수 상수를 계산합니다. 그런데 더 강한 정리 6.21에는 **정확하게 망원되는 정규화**가 들어 있습니다.

원고의
\[
c_m(Y)=\frac{b_{m,Y}}{p_m}
\]
를 사용하면, 정리 6.21의 약화만으로
\[
c_{m+1}(w+1)
\ge
\frac{w(m+2)}{(w+2)(m+1)}c_m(w),
\qquad w=m-d
\]
가 나옵니다. 따라서
\[
\boxed{
H_d(m)=
\frac{(m-d)(m-d+1)}{m+1}c_m(m-d)
}
\]
는 \(m\)에 대해 비감소합니다.

이것을 독립적인 공통 보조정리로 앞에 두면 뒤의 여러 계산을 다시 할 필요가 없습니다.

### 2.1 첫 층 질량 \(W_0\)의 상계

원고의
\[
W_0(k)=\sum_{n=k+1}^{2k}\operatorname{Bor}(n)c_{n-1}(k-1)
\]
를 생각합시다. 서로 다른 행의 질량을 위 정규화로 하나의 행 \(2k-1\)에 옮기면
\[
c_{k-1+d}(k-1)
\le
\frac{(2k-1-d)(2k-d)(k+d)}
{2k^2(k-1)}
c_{2k-1}(2k-1-d).
\]

이제 오른쪽의 \(c\)들은 **같은 행의 서로 다른 수준에 있는 확률질량**입니다. 합이 1 이하라는 사실을 한 번 쓰면
\[
\boxed{
W_0(k)
\le
\frac{2k-1}{\sqrt{2\pi}\,k^2\sqrt{k+1}}
<
\frac2{\sqrt{2\pi}}k^{-3/2}
\qquad(k\ge2)
}
\]
가 나옵니다.

원고의 지수 보정 \(e^{.0031}\)이 필요 없어지고, 이 상계 자체의 적용 범위도 \(k\ge3131\)에서 \(k\ge2\)로 넓어집니다.

핵심은 상수를 조금 줄였다는 데 있지 않습니다. **여러 경로의 손실을 각각 추적하던 계산을 같은 행의 총확률질량 1로 바꾸었다는 것**입니다.

### 2.2 합산 손실도 직접 제어할 수 있습니다

같은 대각선 비교로
\[
\begin{aligned}
D_{n,k}
={}&(k+1)\operatorname{Bor}(n+1)c_n(k)\\
&-(k-1)\operatorname{Bor}(n)c_{n-1}(k-1)
\end{aligned}
\]
를 비교하면
\[
D_{n,k}
\ge
-\frac{k-1}{2n}\operatorname{Bor}(n)c_{n-1}(k-1)
\ge
-\frac12\operatorname{Bor}(n)c_{n-1}(k-1).
\]

이제 지표를 한 칸 옮겨 합하면
\[
\boxed{
\frac{\mathcal U_k(m)}e
\ge
(k+1)\operatorname{Bor}(m+1)c_m(k)
-\frac12W_0(k)-E_3
}
\]
가 됩니다. 원고의 손실계수
\[
\frac12+\frac{5}{2k}+\frac1{4k^2}
\]
가 단순히 \(\frac12\)로 바뀝니다.

후속 논증이 필요로 하는 것은 바로 이 합산 하계입니다. 따라서 정리 6.47의 경로별 손실 장치와 명제 6.49의 상당 부분은 주증명에서 제거할 수 있습니다.

다만 **정리 5.50의 증명 안에 들어 있는 양의 경로 표현**은 다른 정리들이 사용합니다. 약한 수치 하계를 삭제하더라도 이 표현 자체는 별도 보조정리로 남겨야 합니다. 정리의 결론만 검색해서 삭제하면 놓치기 쉬운 의존성입니다.

## 3. 두 가지 추가 재연결로 16,229쌍 기저 인증과 1130개 열 인증도 필수 입력에서 빠집니다

### 3.1 임계 창의 양면 귀납은 실제 소비되는 하계보다 훨씬 많은 것을 증명합니다

**관련 위치: 정리 6.48, 보조정리 6.52–6.53, 명제 6.49(다).**

정리 6.48은 작은 크기의 **16,229쌍 기저 인증**과 상하계 동시귀납을 통해 양면 추정을 만듭니다. 그런데 현재 주증명이 소비하는 것은 하계 하나이고, 필요한 범위도 제한되어 있습니다.

뒤에 이미 있는 일반 모멘트 Jensen 하계를 먼저 쓰면
\[
c_m(m-d)
\ge
\frac{\mu_1}{m}
\exp\!\left[
-\frac{\delta}{1-\delta}
\frac{\mu_2-\mu_1}{\mu_1}
\right],
\qquad \delta=\frac dm
\]
입니다. 기존 사슬 모멘트 공식에서
\[
\mu_1\ge\Psi(d),\qquad
\mu_2-\mu_1
\le d(1-\delta)^{-3/2}e^{1/(12(m+1))}
\]
를 넣으면 됩니다.

필요한 전 범위
\[
m\ge2001,\qquad 14\le d\le\frac12m^{2/3}
\]
에서 지수 손실이
\[
.663774<\log2
\]
임을 확인했으므로
\[
\boxed{
c_m(m-d)>\frac{\Psi(d)}{2m}
}
\]
가 바로 나옵니다.

따라서 이 소비처를 위해 작은 크기의 양면 추정부터 증명할 필요가 없습니다. **16,229쌍 기저 인증과 상하계 동시귀납을 주정리의 필수 입력에서 제거할 수 있습니다.**

원래 양면 정리가 거짓이라는 지적은 아닙니다. 주정리의 소비 범위에 맞추면 더 일반적인 기존 원리가 더 짧게 해결한다는 지적입니다.

### 3.2 첫 층 양성을 \(k\ge2001\)로 연결할 수 있습니다

**관련 위치: 정리 6.61, 정리 7.66의 qstar-columns, 정리 7.73.**

앞 절의 강한 대각선 비교를 Borel 무게 없이 확률질량에 직접 적용하면
\[
\boxed{
\mathcal V_k(k)
\ge
\frac{k-1}{R+1}[1-s_R(k-1)]
-(k-1)c_{2k}(k-1)
}
\]
를 얻습니다.

기존 생존 상계의 증명에서 상수 \(3\)을 \(3.2\)로 완화하고 그 증명에 필요한 끝점 조건을 다시 확인하면, 추가 범위 \(2001\le k\le3130\)을 처리할 수 있습니다. \(R=\lfloor3(k-1)/2\rfloor\)로 놓았을 때
\[
\boxed{
\mathcal V_k(k)>.0041
\qquad(2001\le k\le3130)
}
\]
가 나옵니다.

여기서 핵심값만 양수라고 해서 끝낸 것은 아닙니다. 모든 절단점으로 확장할 때 필요한 작은 결손, 앞쪽 창, 중간 영역, 먼 영역을 각각 확인했습니다. 세부 부등식은 보고서 부록 A에 있습니다.

이 결과와 제1절의 직접 SRC 하계를 결합하면, 증가하는 무게에 대한 Abel 합으로
\[
\mathrm{Left}_n\ge0
\]
이고
\[
(\star)(n)
=
(\mathrm{src}-\mathrm{inh}^{\mathrm{lin}})
+2\mathrm{Left}_n>0
\]
가 됩니다.

따라서 **\(2001\le k\le3130\)의 1130개 열을 별도로 인증하는 qstar 분기를 필수 입력에서 제거할 수 있습니다.**

정확한 대체 대상은 최종 귀납이 필요로 하는 \((\star)>0\)입니다. 원래 분기 안에 있는 더 세분된 모든 부호 명제를 새로 증명했다는 뜻은 아닙니다. 또 큰 \(k\)에서 다른 곳이 소비하는 더 강한 정량 하계는 보존해야 합니다.

## 4. 이미 계산한 G′ 인증을 직접 쓰면 자기일관 경계와 32,393,082개 위치의 별도 검사가 필요 없어집니다

**관련 위치: 장7A의 수준사슬·자기일관 경계, 정리 7.33의 G′, 정리 7.38, 부록 D 장7B.**

이 발견은 새로 복잡한 정리를 만드는 데서 나온 것이 아닙니다. **원고가 이미 계산한 더 강한 입력을 실제 증명에 연결하지 않은 부분**을 확인한 것입니다.

현재 구성에서는 \(501\le k\le840\)에 별도의 자기일관 경계와 모멘트 분기를 둡니다. 그런데 첨부된 G′ 원시 인증 결과는 실제로 \(501\le k\le2000\) 전체에 대해 존재합니다. 부록도 \(501\)–\(840\)을 계산했지만 사용하지 않았다고 설명합니다.

저는 해당 원시 결과를 읽고 다음을 확인했습니다.

- \(501\)–\(840\)의 340열에 누락·중복이 없습니다.
- 기존 인증의 필요한 플래그가 모두 참입니다.
- 이 범위의 최대 직접 적용 문턱은 \(19990\)입니다.
- \(n=20001\)에서 G′ 판정식의 최소 양의 여유는
  \[
  4.5676122546\ldots\times10^{-7}
  \]
  입니다.
- \(841\)–\(2000\)의 나머지 1160열에서도 직접 G′ 문턱이 기존 모멘트 문턱보다 모두 앞섭니다.

따라서 앞부분은 원고의 기존 \(n\le20000\) 유한행 결과로, 뒷부분은 G′로 이어집니다.

실제로 해당 모멘트 인증 분기에 필요한 위치 수는 다음과 같이 바뀝니다.

| 열 범위 | 원래 별도 검사 요구 | 직접 G′ 접합 후 |
|---|---:|---:|
| \(501\le k\le840\) | 19,840,702 | 0 |
| \(841\le k\le2000\) | 40,638,833 | 28,086,453 |
| 합계 | **60,479,535** | **28,086,453** |

차이는 **32,393,082개 위치**입니다. 이는 해당 분기의 검사 위치 수이며, 전체 실행시간을 계측한 수치는 아닙니다.

이 재연결에는 기존 G′ 인증값을 사용합니다. 원래의 모든 인증 내부 연산을 다시 실행한 것은 아니고, **저장된 상계값을 정확하게 복원해 필요한 경계 접합을 독립적으로 재확인**했습니다. 또한 G′의 근거가 제거하려는 자기일관 경계에 의존하지 않음을 확인했습니다.

수학적으로는 자기일관 경계와 이차 모멘트 충분조건을 유지하기 위해 쌓았던 상당한 분량이 주정리의 필수 환원에서 빠집니다.

## 5. EI는 별도의 현상이라기보다 이음 기준의 선택 때문에 필요해진 분기입니다

**관련 위치: 정리 5.22, 정리 5.26, 정의 5.42, 보조정리 5.65.**

EI는
\[
r\ge529,\qquad .64\le r^{3/2}/n\le.65
\]
라는 좁은 창을 별도로 인증합니다. 그 소비처는 두 군데입니다. 두 곳을 각각 해결해야 삭제가 정당합니다.

첫째 소비처인 \(P_R\Rightarrow W\)에는 이미 보조정리 5.32(가)가 주는 엄격 증가를 사용할 수 있습니다.

둘째 소비처인 작은 행의 이음 귀납에서는 기준점 자체를 옮길 수 있습니다. 기존의 \(.75\) 대신
\[
a=.82,\qquad r_a(m)=\lfloor .82m^{2/3}\rfloor
\]
를 사용하면, 필요한 크기에서
\[
.73<r_a(m)^{3/2}/m<1.2
\]
가 됩니다. 따라서 새 기준점의 엄격 증가는 **이미 다른 곳에서 필요한 A 정리**가 제공합니다.

물론 기준을 옮기면 뒤의 창 폭과 손실도 달라집니다. 이 부분은 그대로 둔 채 EI만 삭제할 수 없습니다. 바뀐 폭을 반영해 계산을 다시 수행했습니다.

| 바뀐 조건 | 확인 결과 |
|---|---|
| \(1/2\le\lambda\le2/3\)의 4000셀 | 필요한 비율 하계의 최솟값 \(1.35151670035739\ldots>1\) |
| \(\lambda>2/3\)의 무한 영역 | 최종 정규화 잔차 \(>.1477\) |
| 꼭대기 질량 | 기존 \(.9799\) 하계 유지 |
| 새 창 손실 | \(<.433\) |

이렇게 하면 **EI 전용 35개 \(r\)-칸·차수 96 Bernstein 인증과 관련 오차 조립을 제거할 수 있습니다.**

이음 귀납에서 새 기준점이 꼬리 영역 밖에 놓이는 초기 행도 확인했습니다. 그 경우 해당 경우분류가 공집합이 되므로, 새 기준점이 언제나 꼬리 안에 있어야 한다는 추가 가정은 필요하지 않습니다.

이 역시 원고의 한 분기를 더 넓은 공통 결과의 적용으로 흡수하는 사례입니다.

## 6. 공통 정리로 먼저 제시해야 할 수학적 구조들

앞의 발견들이 실제 분기를 없애는 결과라면, 다음은 원고 전체의 표현과 증명 조직을 바꿀 수 있는 일반화입니다.

### 6.1 숲·순열·용량 다중집합·표지 다항식은 임의 가중치 항등식의 특수화입니다

**관련 위치: 2.3–2.7 및 뒤의 얼린 다항식·모멘트 표현.**

가환 \(\mathbb Q\)-대수의 임의 가중치 \(w_1,w_2,\ldots\)에 대해
\[
\boxed{
\sum_{\sigma\in S_n}\prod_iw_{h_i(\sigma)}
=
\sum_{F}\prod_{v\in F}\frac{w_{t_v}}{t_v}
}
\]
가 성립합니다. 오른쪽은 뿌리 있는 라벨 숲 전체에 대한 합이고, \(t_v\)는 부분나무 크기입니다.

양쪽이 모두
\[
H_0=1,\qquad
H_n=
\sum_{j=0}^{n-1}
\binom{n-1}{j}w_{j+1}H_jH_{n-1-j}
\]
를 만족한다는 것으로 증명할 수 있습니다.

이 한 정리의 특수화는 다음과 같습니다.

| 가중치 선택 | 얻는 결과 |
|---|---|
| \(w_t=\min(t,y)\) | 누적 주차함수 수와 숲 표현 |
| \(w_t=t z_t\) | 용량 다중집합과 부분나무 크기 다중집합의 공동 생성함수 |
| 문턱을 넘으면 \(w_t\)를 고정 | 얼린 용량 다항식 |
| \(w_t\)에 문턱·무거운 크기의 표지 변수 부착 | 각종 계수와 미분 모멘트 |

이렇게 시작하면 여러 표현의 일치를 각각 증명하는 분량이 줄고, 뒤에서 새로운 표지 변수를 도입할 때도 원래 조합론을 다시 구축할 필요가 없습니다.

단, 숲 모양을 조건으로 한 국소 역전 수의 독립성은 이 항등식만으로 따라오지 않습니다. 정리 2.11의 확률구조는 별도로 남겨야 합니다.

### 6.2 여러 사슬 공식은 모든 차수의 지정 조상 사슬 공식으로 통합됩니다

\(t_0=n+1>t_1>\cdots>t_j\ge1\)에 대해 해당 크기를 갖는 지정 조상 사슬의 수를 \(C_F\)라 하면
\[
\boxed{
\mathbb E_n C_F(t_1,\ldots,t_j)
=
\frac{\operatorname{Bor}(t_j)}
{\operatorname{Bor}(n+1)}
\prod_{i=1}^{j}\operatorname{Ren}(t_{i-1}-t_i)
}
\]
입니다.

이 하나의 공식에서 다음이 나옵니다.

- \(j=1\): 부분나무 기대수.
- \(j=2\): 쌍 공식.
- 유일한 무거운 사슬 범위: 방문확률.
- 끝점 방문에 대한 조건화: 갱신 다리.

여기서 **기대수와 방문확률을 구별해야 합니다.** 무거운 사슬의 유일성이 없는 범위에서는 사슬 수가 0 또는 1이라는 보장이 없으므로 기대수를 확률로 읽으면 안 됩니다. 현재 원고의 \(\pi_n(m)\)은 먼저 기대수로 정의되어 있어, 작은 \(m\)에서 사용된다는 이유만으로 오류는 아닙니다.

### 6.3 “머묾”과 수준 방문 보존은 하나의 질량보존식입니다

크기·대각선 단조성은 누적분포 \(F_m\)에 대해
\[
F_{m+1}(\ell)\le F_m(\ell)\le F_{m+1}(\ell+1)
\]
를 줍니다. 따라서 분포 사이에 한 단계에서 0 또는 1만 움직이는 결합을 만들 수 있습니다.

이동 질량과 머묾 질량을 분리하면
\[
c_m(\ell)=I_m(\ell)+S_m(\ell),\qquad
c_{m+1}(\ell)=S_m(\ell)+I_m(\ell-1)
\]
이고, 이를 합하면
\[
\boxed{
\sum_{m=Y+1}^{K}c_m(Y)
=
1-s_K(Y)+
\sum_{m=Y+1}^{K}\varsigma_{m-1}(Y)
}
\]
가 됩니다.

수준 방문 보존은 마지막 양의 합을 버린 특수 경우입니다. 6장과 10장에서 나타나는 여러 장부와 망원합은 이 식에 서로 다른 무게를 붙인 형태로 조직할 수 있습니다.

여기서 만든 결합은 **분포 사이의 결합**입니다. 자연스러운 주차함수 성장 과정 자체가 이 결합이라는 주장까지 덧붙여서는 안 됩니다.

### 6.4 계승 모멘트의 긴 전단사 논증은 일반 Jensen으로 대체됩니다

**관련 위치: 따름정리 7.7.**

비음 정수 확률변수 \(Z\)에 대해
\[
\mathbb EZ\ge m\ge r-1
\quad\Longrightarrow\quad
\boxed{\mathbb E(Z)_r\ge(m)_r}
\]
가 일반적으로 성립합니다. 정수 격자에서 계승 다항식의 선형 보간이 비감소·볼록이라는 사실로 증명합니다.

실제 소비처에서 필요한 \(r=2\)는
\[
\mathbb E[Z(Z-1)]
=
\operatorname{Var}(Z)+(\mathbb EZ)(\mathbb EZ-1)
\ge m(m-1)
\]
이면 충분합니다.

따라서 이 결론을 위해 표시 자리 변위 치환, 새 가중치 구성, 기울인 법칙 아래 평균 하계 재적용을 따로 할 필요가 없습니다. 추가 지지 조건도 제거됩니다.

더구나 앞서 설명한 G′ 재연결을 채택하면 이 결과의 주요 소비처 자체가 주증명에서 빠집니다. **보조정리를 간단히 만드는 단계와 그 보조정리가 필요한지 다시 묻는 단계를 구별할 필요가 있습니다.**

### 6.5 양의 생성함수 꼬리에는 기하급수 분모가 필요 없습니다

**관련 위치: 보조정리 7.29.**

\(K(z)=\sum K_jz^j\), \(K_j\ge0\)이고
\[
\omega_j=\frac{K_j\rho^j}{K(\rho)},\qquad x>\rho>0
\]
라면
\[
\boxed{
\sum_{j>X}\omega_j
\le
\frac{K(x)}{K(\rho)}
\left(\frac{\rho}{x}\right)^{X+1}
}
\]
입니다.

원고는 각 계수를 따로 \(K(x)\)로 누르고 기하급수를 합하면서
\[
\frac1{1-\rho/x}
\]
를 추가합니다. 양의 합 전체에 한 번 부등식을 적용하면 이 인자는 없어집니다.

실제 선택 \(x=\rho e^{1/k}\)에서는 약 \(k\)배의 손실이 사라집니다. 절단점을 줄일 여지가 생기지만, 새 최적 절단점의 전범위 인증까지 완료했다는 주장은 하지 않았습니다. 부호가 섞인 Hermite 꼬리에는 이 논리를 그대로 적용할 수 없습니다.

### 6.6 나머지 반복도 공통 기반과 범위별 정량 내용을 분리할 수 있습니다

| 반복되는 부분 | 앞에 둘 공통 내용 | 개별적으로 남길 내용 |
|---|---|---|
| 2장의 다섯 몫과 9장의 재생 | 양의 지수 나머지 항등식 | 각 원천의 부호와 범위별 하계 |
| 7장의 흡수, 8장의 상위해, 9장의 재생, 10장의 비교 | 양의 엄격 하삼각 연산자 \(K\)의 \((I-K)^{-1}\ge0\) | 구체 커널과 경계 입력 |
| 4장의 중앙 틈과 7장의 중앙 띠 | \(n=2k+\nu\)의 공통 Hermite 계수·윤곽 계산 | \(\nu\) 범위별 오차와 부호 |
| 6장·10장의 얼린 볼록성 | 같은 함수의 공통 이차 미분 공식 | 기준 사슬에 따른 나머지 |
| 9장의 균일 증분·한 절단점·LP | 상자 제약과 총질량 제약 아래의 선형 최소화 | 채택한 수치 입력 |
| 8장의 기하격자 봉투와 닫힌 꼴 하계 | 이미 얻은 닫힌 꼴 하계와 저장표 직접 인증 | 필요한 단조성·도함수 증명 |

특히 8장은 뒤에서 얻은 닫힌 꼴 하계와 저장표의 직접 인증이 앞의 기하격자·참 봉투 우회를 이미 대체합니다. 주증명의 순서를 발견 과정대로 유지하면서 불필요한 구축 단계를 남겨 둔 사례입니다.

## 7. 9장과 10장은 공통 기반을 통합해야 하지만, 같은 증명으로 취급하면 안 됩니다

이 부분은 중복을 줄이려다 오히려 수학을 훼손할 위험이 있어 별도로 확인했습니다.

두 장은 모두 양의 재귀와 흡수를 사용하지만 **구체적인 커널이 다릅니다.** 둘째 층에서 두 원천의 차이를 직접 계산하면
\[
\mathrm{regen}_n-A_{n,k-1}(\star)(n)
=
\sum_{m=2k+1}^{n-1}L_{n,m}d_{m,k}
\]
이고,
\[
L_{n,m}=
\left[
1+(n-m-1)\left(1-\frac{k}{m+1}\right)
\right]
\binom{n-1}{m}A_{n-m-1,k-1}\ge0.
\]

따라서 앞선 \(d_{m,k}\ge0\)를 아는 귀납 아래에서는 \((\star)\ge0\)이 재생 원천의 양성보다 강한 충분조건입니다. **두 조건이 동일한 것은 아닙니다.**

9장의 쌍 구조와 10장의 얼린 사슬 상쇄는 서로 다른 정보를 사용합니다. 그러므로 두 장 중 하나를 우선 삭제하기보다, 두 장이 함께 의존하는 불필요한 기반 분기를 먼저 제거하는 것이 적절합니다.

“독립적인 두 증명”이라는 표현도 범위를 명확히 하는 편이 좋습니다. 정확한 의미는 **공유 입력 위에서 서로 다르게 닫는 두 마무리 논증**입니다. 11장의 공유 입력 표가 이미 이 점을 상당 부분 드러내므로, 이를 새로운 치명적 오류로 취급할 필요는 없습니다.

## 8. 확인된 실제 오류와, 오류로 판단하지 않은 부분

### 8.1 보조정리 5.21(나)의 가정 범위는 수선해야 합니다

보조정리 5.21은 EI의 좁은 매개변수 범위 아래 진술되어 있습니다. 그런데 그 (나)의 보편 계수 상계를 정리 5.30·5.31에서는 그 범위 밖에서 호출합니다.

**현재 문장 그대로의 정리 호출은 정당하지 않습니다.**

다만 실제 증명을 살펴보면, (나)는 양의 재귀와 공통 커널 상계만 사용하고 EI의 범위 조건을 쓰지 않습니다. 따라서 수선은 분명합니다.

- (나)를 무조건적인 커널 계수 상계로 분리합니다.
- EI 전용 부분에만 좁은 창 가정을 붙입니다.
- 후속 참조를 분리한 일반 정리로 바꿉니다.

이것은 결론의 반례가 아니라 **가정의 조직과 호출 범위의 오류**입니다. EI를 제거하는 편집에서도 이 보편 상계는 남겨야 합니다.

### 8.2 문헌의 정규화와 상수에서는 오류를 확인하지 못했습니다

Petersson의 Theorem 2.1·Corollary 2.11, Janson의 Theorem 1.12–1.14 및 식 (1.9)을 대조했습니다. 확인한 범위에서 \(m=n+1\) 대응, 최대 변위의 \(2/3\) 지수 정규화, Brownian supremum 적분의 Laplace 표현, Mellin 유효 띠와 꼬리 상수는 원고와 맞습니다.

3장의 엄격 단봉성도 로그변수의 단봉성을 원변수로 무심코 옮기는 증명은 아닙니다. 필요한 지수 기울임, 비유계 beta 밀도의 절단, 후속 합성곱의 엄격성을 실제로 처리합니다.

봉우리 점근 역시 약수렴만으로 결론을 내리는 구조가 아니라, 주정리가 제공하는 모든 크기의 행 단봉성을 함께 사용합니다. 이 부분은 단순한 중복이나 오류로 삭제할 대상이 아닙니다.

### 8.3 “정확 정수·유리수 인증”이라는 표현도 구현에 맞춰 읽어야 합니다

원고의 정확 인증은 모든 거대한 개수를 끝까지 정확값으로 저장한다는 뜻만을 갖지 않습니다. 정확한 정수 끝점으로 참값을 감싸는 구간 산술도 포함합니다. 확인한 핵심 구현의 정수 floor/ceil 연산과 누적 방식은 이 설명과 일치했습니다.

따라서 일부 보조 계산에 부동소수점이 보인다는 이유만으로 전체 인증을 비엄밀한 근삿값 계산이라고 판단할 근거는 없었습니다.

## 9. 검증의 범위와 권하는 재편집 순서

새로 제안한 항등식과 범위 확장에서는 원고의 계산 결과를 그대로 받아들이는 검사와 독립적으로 재구성하는 검사를 구별했습니다.

| 대상 | 확인 방법 |
|---|---|
| 임의 가중치 숲–순열 항등식과 사슬 모멘트 | 작은 크기의 숲·순열을 직접 전수생성해 비교 |
| 머묾 항등식과 장부 | 독립적인 마지막 차 정수 재귀로 957개·9422개 관계 확인 |
| 두 재생 커널의 차이 | 정확 정수·유리수 계산으로 464개 확인 |
| 대각선 망원과 방문 하계 | 원고 코드와 별도로 680개 확인 |
| 새 V 범위와 Jensen 상수 | 해석적 단조성·끝점 환원 후 방향 포위 계산 |
| \(.82\) 이음 | 4000셀 전부와 무한 영역의 충분조건 재계산 |
| G′의 재연결 | 1500열 원시 결과의 완전성·해시·저장 상계값과 판정식 재확인 |

작은 크기의 일치는 무한 범위 증명을 대신하지 않습니다. 그 검사는 지표, 정규화, 경계항의 실수를 찾는 데 사용했고, 무한 범위의 결론은 보고서에 쓴 일반 유도와 단조성·끝점 환원에 근거합니다. 원래의 \(n\le20000\) 전범위 인증과 모든 기존 구간 인증을 이번에 전부 재실행한 것은 아닙니다.

원고를 실제로 재편집할 때의 우선순위는 다음과 같습니다.

1. **5.21(나)의 범위 오류를 수선하고, 6.21의 대각선 정규화를 공통 도구로 앞에 둡니다.**
2. \(W_0\), 합산 손실, 임계 창 하계를 직접 증명으로 교체합니다.
3. \(1/k\) 위험률 하계와 새 V 범위를 연결해 SRC+의 먼 영역 분기와 1130열 qstar 분기를 제거합니다.
4. 기존 G′ 인증을 직접 연결해 자기일관 경계와 불필요한 모멘트 검사 범위를 줄입니다.
5. 이음 기준 \(.82\)와 재계산한 여유를 반영해 EI 전용 분기를 제거합니다.
6. 가중 숲 항등식, 사슬 공식, 질량보존, 양의 연산자, Jensen·Abel 원리를 공통 기반으로 모읍니다.
7. 그 기반 위에 9장과 10장의 고유한 마무리 논증을 남기고, 11장의 계산 목록과 의존성 지도를 갱신합니다.

**가장 먼저 손댈 곳은 문장의 길이가 아니라 정리의 연결 방식입니다.** 이번에 확인한 큰 축소는 강한 결과를 앞에 세우고, 후속 논증이 실제로 요구하는 결론에 직접 연결하는 데서 나왔습니다. 그 작업을 먼저 하면 뒤의 상당한 분량은 별도의 압축 작업 없이도 필수 증명에서 빠집니다.
