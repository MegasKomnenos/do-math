2. 「노드」: 본문에서 0건(격자 계산 지점은 「격자점」). 「생산자」 0건. 「검토」는 정정·보충 사실을 적는 네 문장(50.62, CF 비단조 예, 정리 S′ 상수 2.811, 정리 P의 ε, CF♮ 오기, 명제 U의 한 줄 보충)에만 남김.
3. 지위 표지: 대괄호 안 쌍반점 하나. 「X에 의존」 꼴로 입력 의존을 적고, 계산 보조의 층(정확 정수·유리수 / 배정밀도 평가, 인증 아님 / binary64 사전 오차 해석)은 1.4절의 이름으로 적음. 층의 설명은 진술 뒤 본문 문장에 둠(정리 FLQ-relation, 따름정리 E, 명제 T, 정리 FLQ, 정리 root-proof-2).
4. 문헌 논문 안의 정리 번호: 8장에는 해당 자리 없음(인용하는 문헌 결과는 Stirling·Robbins 부등식, Jensen 부등식, Hermite–Hadamard 꼴 비교뿐이며 번호를 적지 않음).
5. 8.7 절 제목 「조립: $Q^\star_2$에서 주 정리까지」; 본문의 「뿌리」는 나무·블록의 뿌리에만 씀. $LRP_2$를 준다거나 $\mathcal R_2$를 닫는다는 서술 없음.
6. $I_1\to\mathsf c_1$("기록은 $I_1$으로 적는다" 부기); 2.11의 라벨·기호($P^y$, $p^y(a\to c)$, $\tau_\delta(c)$, 초과 $a_i$, 시작 초과 $\delta$) 사용; h-transform 병기는 8장에서 뺌; 기록 이름 괄호에 식별자 전부 부기.
