# 재실행표

부록 D의 항목마다 그 계산을 이 묶음에서 다시 돌리는 법을 한 줄로 적은 표다. 「스크립트」는 이 글의 재계산 파일(`세션_재계산/` 아래)이 있으면 그것을, 없으면 연구 기록의 코드 사본을 가리킨다(경로는 `원고_자료/` 기준). 「실행 명령」의 대괄호는 명령을 돌릴 폴더이고(기록 코드 사본은 그 기록 폴더), 파이썬 명령은 `python -I`로 돌리되 같은 폴더의 모듈을 읽는 기록 코드 사본은 `python -E -s`로 돌린다(README 「실행 환경」). 「기대 출력」은 결과 줄 또는 출력 파일의 핵심 수치이고, 「출력 파일·SHA-256」은 README 표의 값이다. 「실행 시간」은 출력·로그에 남은 시간 기록을 읽은 것이며 기록이 없으면 「—」이다(이 기계: 4코어, 다른 계산과 공유). 「최소 여유」는 확인하는 진술의 문턱에 대한 가장 작은 여유를 결과 줄에서 옮긴 것이고, 「(계산 뒤 채움)」은 계산이 진행 중이라 아직 적지 않은 칸이다. 「재실행」은 부록 D 꺾쇠 요약의 자료 항목(기록 / 이 글 / 기록·이 글)이다. 「(진행 중)」 칸은 계산이 끝난 뒤 채운다. 「(인자 확인 필요)」는 코드가 인자를 읽지만 그 값을 자료에서 찾지 못한 경우다. 몇 분 안에 끝나는 축소판은 `빠른_확인.py`가 차례로 돌린다. 이 표는 `scripts/_gen_재실행표.py`가 부록 D와 README에서 만든다.
