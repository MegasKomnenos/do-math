# 변경 — `four_families/` → `four_families_DDLnat/` (U4, 결정 K4-14의 재인증)

원 폴더 `원고_자료/세션_재계산/four_families/`를 그대로 복사하고, `families_iv.py`의 `def DDL`(126행) **한 함수만** 바꾸었다. 다른 줄은 바꾸지 않았다. 실행 모드·범위·격자(네 $k_0$, $2\le q_0\le\epsilon_0$, 40000 셀, 단조성 표본)는 원본과 같다.

## 바꾼 줄 (126–136행 → 126–131행)

### 원문

```python
def DDL(K, j1=None, j2=None):
    if j1 is None:
        j1, j2 = J1, J2
    lk = iv.log(K)
    d = 2 * p23(K)
    eps = eps_nat(K)
    epsp = F('2.26') / K + F('0.47') / (d - 1)
    gam = F('2.6047') * (F('2.53') + lk / 2 + eps + F('1.5') / K) / K
    first = F('0.457143') * CINV * qnat(d / K) * iv.sqrt(1 + d / K) * (d + 1) ** 3 * iv.sqrt(d + 1) / K ** 3
    second = 2 * CINV / iv.sqrt(K) * (1 + epsp) * (j1 + (lk / 2 + eps) * j2 + gam)
    return first + second + F('3.9') * CINV / K
```

### 새 문

```python
def DDL(K, j1=None, j2=None):
    """DDL^natural(k) = 14 (log 3k - 1) / (5 sqrt(pi k)) + 37.6 / (5 sqrt(pi) k)   (k >= 3131; decision K4-14).
    37.6 is the upward rounding of 7(3 - log 3) + 42/sqrt(3) = 37.558..., so the value stays an upper bound.
    Every operand is an `iv` interval (outward rounding), hence the returned interval encloses the exact R(k);
    its upper end is what the (na)/(ga) margins subtract.  j1, j2 are accepted and ignored (callers unchanged)."""
    return 14 * (iv.log(3 * K) - 1) / (5 * iv.sqrt(iv.pi * K)) + F('37.6') / (5 * iv.sqrt(iv.pi) * K)
```

## 상계가 상계로 남는 까닭(방향 확인)

- 코드의 관행: 모든 양은 mpmath `iv`(바깥쪽 반올림 구간, 소수 30자리)로 계산하고, 양성 판정 `pos(m)`은 구간의 **아래 끝**으로 한다. $\mathrm{DDL}^\natural$은 $\mathfrak o_F$에 부호 $-1$, $\mathfrak R^\sharp_F$·$\mathfrak R^{\sharp\prime}_F$에 부호 $+1$로 들어가므로, 여유 구간의 아래 끝은 자동으로 $\mathrm{DDL}^\natural$ 구간의 **위 끝**을 쓴다. 따라서 따로 방향을 고를 것 없이 `iv` 연산만으로 "참 $R(k)$의 상계"가 쓰인다(원본의 `DDL`도 같은 방식이었다).
- 피연산자: `K = F(k)`(정수, 정확), `3 * K`(정확), `iv.log`(구간), `14`·`5`(정확 정수), `iv.pi`(구간), `iv.sqrt`(구간), `F('37.6')`(37.6을 감싸는 구간). 나눗셈·곱셈 모두 `iv`.
- 상수 37.6: 별도 확인(`python -I`, `iv.dps=30`)으로 $7(3-\log3)+42/\sqrt3\in[37.5584252852875142696175321226187, 37.5584252852875142696175321226314]$이고 그 위 끝이 `F('37.6')`의 아래 끝보다 작다 → 37.6은 위쪽 반올림이며 상계로 쓸 수 있다.
- 적용 범위: 식은 $k\ge3131$에서 선다. 이 스크립트가 `DDL`을 부르는 $k$는 $k_0\in\{6668,8065,9551,9705\}$와 단조성 표본 $k\in[k_0,10^7]$뿐이라 모두 범위 안이다.

## 바꾸지 않았으나 뜻이 바뀐 자리(기록)

"with the record's constants" 줄의 shift는 0이 된다(`DDL`이 `j1`, `j2`를 무시하므로). K4-14 여파대로 부록 D의 recheck_1a 대조 문장은 지워질 예정이라 이 블록은 참고용일 뿐이다.
