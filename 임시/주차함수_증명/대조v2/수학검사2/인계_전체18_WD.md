## 인계 행(파일, 자리, 전→후 제안, 까닭)

1. **세션(생성기).** `scripts/_gen_재실행표.py` 109–118행 `CONFIG["xcert-partAB"]["cmd"]`. 전: `python -I layerB.py --run --part 0 --nparts 2 --out resB_p0.jsonl`(과 `--part 1`), `python -I layerAint.py --run --part 0 --nparts 2 --idx 0 97 --out resAint_p0.jsonl`, `… --part 1 --nparts 2 --idx 97 110 --out resAint_p1.jsonl`, `python -I layerA1.py --run --part 0 --nparts 2 --out resA1_p0.jsonl`(과 `--part 1`), `python -I layerA3.py --run --out resA3.json`. 후: `layerB.py`는 `--ks 501-5000 --part 0 --nparts 2 --out resB_p0.jsonl`(과 `--part 1`)로(`--ks`가 필수라 현행 명령은 `ValueError`로 멈춘다; `--run`은 읽지 않는다), `layerA3.py`는 인자 없이, 범위 2·3은 묶음의 결과 파일(`resAint_p0/p1/p3.jsonl`, `resA1_p0/p1/p3.jsonl`)과 맞도록 부록 D 114행에 적은 여덟 명령(slot2 넷, slot1 넷)으로 — 한 프로세스 꼴 `--part 0 --nparts 1 --idx 0 110`·`--idx 0 36`로 적으면 명령은 간단하나 결과 파일 이름이 `outputs` 칸의 세 조각과 달라지므로 실제 여덟 명령이 맞다. 까닭: 재실행표 32행 「실행 명령」 칸의 원천이 이 CONFIG이고(생성기 9–10행), 부록 D 자료 줄을 사실대로 고쳤으므로 표도 같은 사실을 적어야 한다. 고친 뒤 `python -I scripts/_gen_재실행표.py`로 재생성.
2. **세션(README 산문).** `원고_자료/README.md` 753행 「범위별 실행은 `layerB.py`(범위 1 $[501,5000]$, `--part 0/1 --nparts 2`), `layerAint.py`(범위 2 $[5000,10^5]$, `--idx 0 97`·`--idx 97 110`), `layerA1.py`(범위 3), …」. 후(제안): 「… `layerAint.py`(범위 2 $[5000,10^5]$)·`layerA1.py`(범위 3)은 두 프로세스가 `--idx`의 번호 범위를 받아 구간마다 요구 파일(`_claims/`)을 먼저 만든 쪽이 맡는 방식으로 나누어 돌렸고(명령과 조각 파일의 대응은 부록 D 항목의 「자료」 줄), …」; 뒤의 「실제 실행 순서는 `run_slot2.sh`·`run_slot1_after.sh`다(프로세스 2개로 벽시계 약 9.6시간)」는 그대로(로그 16:53–02:29와 맞는다). 까닭: L13 5절 2항 — README의 재현 안내가 「실행」 줄을 따르므로 D와 같은 말을 해야 한다.
3. **세션(선택).** `scripts/_재실행표_여유.json` 3행 「$n=1000$: 위 끝 $0.06573317522$ 대 진술 $0.0658$」 → 「위 끝 $\le0.06573317522$ …」. 까닭: D 결과 줄의 새 말씨(위 끝의 상계)와 맞춤; 뜻은 같아 두어도 된다. 바꾸면 재실행표 8행이 따라 바뀐다.
4. **세션(묶음 위생; 결정 122-2로 가름).** `원고_자료/세션_재계산/xcert_iv/make_draft.py` 143–150행이 부록 D 항목의 옛 「독립 재계산」·「자료」 문구(두 조각 실행 줄 포함)를 초안으로 만든다. 부록 D 본문은 이제 그 초안과 다르다. L12 5절 1항의 `make_draft.py`들과 함께 묶음에 둘지 가른다. WD는 코드 주석도 손대지 않았다 — 묶음 파일의 SHA-256이 README 409행에 고정되어 있어 한 글자를 바꿔도 SHA 표 재생성이 따라온다.
