## 2. 고친 것(세 자리; 모두 `장v2/장7B.md` 명제 `{{7:block-exponential}}`)

### 2.1 S7a-1 — 명제 `{{7:block-exponential}}` (나)의 진술, 104행

전: `\mathcal S^{\mathrm G}(z;x)=\int_0^{T(x)}e^{z(V(\mathrm s)-V(T(x)))}(1-\mathrm s)^2\,\mathrm{Bor}^{\mathrm{tail}}_k(\mathrm s)\,d\mathrm s`
후: `\mathcal S^{\mathrm G}(z;x)=\int_0^{T(x)}e^{z(V(\mathrm w)-V(T(x)))}(1-\mathrm w)^2\,\mathrm{Bor}^{\mathrm{tail}}_k(\mathrm w)\,d\mathrm w`

까닭: 같은 명제의 (가)(7.6)가 $\mathrm s$를 $x$ 쪽 더미로 쓰고, 바로 다음 (나)의 진술이 같은 글자를 $T$-값 더미로 쓰며, (나)의 증명은 치환 $\mathrm s=\mathrm we^{-\mathrm w}$로 $T$-값 변수를 $\mathrm w$로 두고 $(1-\mathrm w)^2\mathrm{Bor}^{\mathrm{tail}}_k(\mathrm w)\,d\mathrm w$에 이른 뒤 「이것이 적분 표현이다」로 끝난다. 원문으로 확인했다(103–117행). 진술과 증명이 낸 식을 맞대 보는 독자가 $\mathrm w\leftrightarrow\mathrm s$를 스스로 바꿔 읽어야 하는 자리다. 더미라 수학은 서지만 독자가 멈추는 문면 문제이고, 증명이 이미 $\mathrm w$를 쓰므로 진술을 증명에 맞추는 쪽이 가장 적게 손대며 깔끔하다(반대로 증명을 진술에 맞추면 증명 출발식의 $x$ 쪽 더미 $\mathrm s$와 다시 부딪힌다).

### 2.2 S7a-1 — 같은 진술의 $V$ 정의 괄호, 106행

전: `이고($V(\mathrm s)=(1-\mathrm s)^2/2$), 연쇄 해` → 후: `이고($V(\mathrm w)=(1-\mathrm w)^2/2$), 연쇄 해`. 까닭: 2.1과 한 식이다. 증명 117행의 「$\mathrm{Gr}=\mathrm w-\mathrm w^2/2=\tfrac12-V(\mathrm w)$」와도 글자가 맞는다.

### 2.3 S7a-1 — (나)의 증명 끝, 117행

전: `피적분함수에 $(V(\mathrm s)-V(T))$, $(V(\mathrm s)-V(T))^2$가 곱해지므로, $z=k$에서 $\partial_z^2\mathcal G_\ast|_{z=k}=e^{T}\int_0^{T}(1-\mathrm s)^2\mathrm{Bor}^{\mathrm{tail}}_k(\mathrm s)e^{k(V(\mathrm s)-V(T))}\bigl[2(V(\mathrm s)-V(T))+k(V(\mathrm s)-V(T))^2\bigr]d\mathrm s=\Phi(T(x))$`
후: 같은 식의 $\mathrm s$ 일곱 자리를 모두 $\mathrm w$로.

까닭: 이 식의 $\mathrm s$도 $T$-값 더미(적분 상한 $T$)이고, 같은 증명 안에서 $\mathrm w$가 그 변수다. 4장 (4.1)의 $\Phi(\mathfrak Y)=e^{\mathfrak Y}\int_0^{\mathfrak Y}(1-\mathfrak Z)^2\mathrm{Bor}^{\mathrm{tail}}_k(\mathfrak Z)e^{k\mathfrak J}[2\mathfrak J+k\mathfrak J^2]d\mathfrak Z$($\mathfrak J=V(\mathfrak Z)-V(\mathfrak Y)$)와 꼴이 정확히 같음을 다시 맞추어 보았다. 7.4절은 $\mathfrak Z_n$ 등 프락투어 Z를 모멘트에 쓰므로 4장 글자 $\mathfrak Z$를 가져오지 않고 $\mathrm w$로 둔다.

고친 뒤 103–117행을 다시 읽었다. 7.4절 안에서 이제 $\mathrm s$는 $x$ 쪽 더미(97행 (가)의 둘째 합, 104행→없음, 115행 (가) 증명, 117행 (나) 증명의 출발식과 치환식, 132행 green-atom)와 $[0,1]$ 실수 더미(322행 vertical-nu 증명 $\mathrm s:=z/\sqrt k$, 338행 analytic-transfer (C1)의 $\mathrm{Wi}_j$)이고, $\mathrm w$는 $T$-값 더미(104·106·117행)와 증명 국소(220–228행 kernel-bound $\mathrm w:=s+1$, 257행 pair-criterion-sharp $\mathrm w:=1-\mathfrak s_q(k)$, 294행 hermite-nu 복소 변수, 322행 vertical-nu $\mathrm w=z^2/k$, 598행 explicit-bounds $\mathrm w:=(U+1)\mathfrak J$)다. 모두 적분 더미거나 「잠시 적는다」로 선언된 증명 국소라 서로 부딪히지 않고, 장부 395행이 $\mathrm w$를 7.4 증명 국소로 이미 등록하고 있다(장부 글귀 수정은 BL — 인계).

결정: 새 글자를 고르지 않고 **$m$**(1.1 둘째 크기 변수)으로 적는다. 7.7절 655행이 바로 그 양을 「왼쪽 자식의 크기가 $m$인 무거운 뿌리 $j=m+1$」로 적고 $w_m$·$\mathfrak p_m$($k\le m\le2k$)이 그 지표를 쓰며, 6.5절 720행의 $\mathcal V_k(m)$과 7.5절 명제 `{{7:fold-A}}`의 $\sum_{m=k}^{n-1}$도 같은 글자이므로 $L$은 처음부터 $m$과 같은 뜻의 두 번째 글자였다. 7장 여유 글자를 새로 들이는 것보다 이미 있는 글자로 모으는 쪽이 깔끔하다(원칙 10). 전→후:

- 532행 (7.20): `\sum_{L=k}^{2k}e^{\gamma_kL}\bigl(1+\mathrm{dev}_{n-1-L}\bigr)\frac{e^{-L}d_{L,k}}{L!}` → `\sum_{m=k}^{2k}e^{\gamma_km}\bigl(1+\mathrm{dev}_{n-1-m}\bigr)\frac{e^{-m}d_{m,k}}{m!}`.
- 537행 (7.21): `\mathrm{tsum}_k:=\sum_{L=k}^{2k}e^{\gamma_kL}\frac{e^{-L}d_{L,k}}{L!}\ \ge\ \sum_{L=k}^{2k}\varepsilon_k(n-1-L)\,e^{\gamma_kL}\frac{e^{-L}|d_{L,k}|}{L!}` → 같은 식의 $L$을 모두 $m$으로.
- 542행 증명: 「크기 $L\in[k,2k]$인 자식 … $j-1=L$ … $j=L+1$ … $n-j=L$ … $j=n-L$ … $\tilde{\mathfrak a}_L\mu_L(k)=e^{-L}d_{L,k}/L!$ … $\sum_{L=k}^{2k}\tilde{\mathfrak a}_{n-1-L}\,e^{-L}d_{L,k}/L!$ … $\tilde{\mathfrak a}_{n-1-L}=…e^{\gamma_kL}(1+\mathrm{dev}_{n-1-L})/(k\rho_k)$ … $\sum_L\varepsilon_k(n-1-L)e^{\gamma_kL}e^{-L}|d_{L,k}|/L!$」 → 모두 $m$.
- 544행: 「첫 층 차분 $d_{L,k}$($k\le L\le2k$) … $\tilde{\mathfrak a}_{n-1-L}$ … $1+\mathrm{dev}_{n-1-L}$」 → $m$.
- 552행: 「$e^{-L}d_{L,k}/L!$ … $e^{-L}b_{L,k}/L!$, $e^{-L}b_{L,k-1}/L!$」 → $m$.
- 657행: 「모든 $L\in[k,2k]$에서 $\mathcal V_k(L)=\sum_{m=L}^{2k}\mathfrak p_m\ge0$」 → 「모든 $m\in[k,2k]$에서 $\mathcal V_k(m)=\sum_{m'=m}^{2k}\mathfrak p_{m'}\ge0$」(6장 720행의 꼴).
- 659–663행: 「왼쪽 자식 $L=j-1\in[k,2k]$인 뿌리 $j=L+1$」 → 「왼쪽 자식의 크기가 $m=j-1\in[k,2k]$인 뿌리 $j=m+1$」; 식의 $L$ 열세 자리 → $m$, $w_L\mathfrak p_L\to w_m\mathfrak p_m$; 「오른쪽 자식 $R=n-j\in[k,2k]$인 뿌리 $j=n-R$에서도 $\mathcal P^{(k)}_n(n-R)=k\binom{n-1}RA_{R,k-1}A_{n-1-R,k-1}/A_{n,k-1}$이라 같은 양 $w_R\mathfrak p_R$」 → 「오른쪽 자식의 크기가 $m=n-j\in[k,2k]$인 뿌리 $j=n-m$에서도 $\mathcal P^{(k)}_n(n-m)=k\binom{n-1}mA_{m,k-1}A_{n-1-m,k-1}/A_{n,k-1}$이라 같은 양 $w_m\mathfrak p_m$」.
- 715행: 「왼쪽 자식 $L=j-1>2k$이면 … $n-1-L$ … $\mu_L(k)=k\binom{n-1}Lp_{n-1-L}d_{L,k}/A_{n,k-1}$. 오른쪽 자식 $R=n-j>2k$이면 $j=n-R$ … $\mu_R(k)=…d_{R,k}…=(n-R)\binom{n-1}Rp_{n-1-R}d_{R,k}/A_{n,k-1}$. 두 경우를 $m=L$, $m=R$로 모으면」 → 「왼쪽 자식의 크기가 $m=j-1>2k$이면 … 오른쪽 자식의 크기가 $m=n-j>2k$이면 $j=n-m$ … 두 경우를 자식의 크기 $m$마다 모으면」(식의 $L$·$R$은 $m$).
- 717행: 「왼쪽 자식 $L=j-1\in[k,3k-1]$ 가운데 $L\le2k$ … $w_L\mathfrak p_L$ … $L>2k$ … 오른쪽 자식 $R=3k-j\in[k,2k-1]$($k<j\le2k$)도 $w_R\mathfrak p_R$ … 오른쪽 자식은 $R=2k$이고」 → 「왼쪽 자식의 크기 $m=j-1\in[k,3k-1]$ 가운데 $m\le2k$ … $w_m\mathfrak p_m$ … $m>2k$ … 오른쪽 자식의 크기 $m=3k-j\in[k,2k-1]$($k<j\le2k$)인 것도 $w_m\mathfrak p_m$ … 오른쪽 자식은 크기가 $2k$이고」.
- 391–395행(정리 `{{7:old-6-14}}` 증명; 여기서는 $m$이 진술의 토막 크기라 지표로 쓸 수 없음): 「이 증명 안에서 $A_L:=A_{L,k-1}$로 줄여 적으면 $A_{L,k}=A_L(1+\mathrm{cl}^+_L)$, $A_{L,k-2}=A_L(1-\mathrm{cl}^-_L)$」 → 「$A_t:=A_{t,k-1}$ … $A_{t,k}=A_t(1+\mathrm{cl}^+_t)$, $A_{t,k-2}=A_t(1-\mathrm{cl}^-_t)$」($t$는 1.1 크기 변수; 7.5절 374행 토막 크기 $t_v$와 같은 쓰임); 「…을 넣어 $L=j-1$, $R=m-j$로 적으면」 → 「…을 넣고 두 자식의 크기를 $j-1$, $m-j$로 적으면」; 표시식과 395행의 $L$·$R$ 전부를 $j-1$·$m-j$로 풀어 적음($A_{j-1}A_{m-j}$, $\mathrm{cl}^\pm_{j-1}$, $\mathrm{cl}^\pm_{m-j}$, $\mu_{j-1}(k)+\mu_{m-j}(k)$ — 진술 (7.13)·$\chi_m(j)$의 첨자와 같은 꼴); 「$j=k$에서는 $L=k-1$이라 $\mathrm{cl}^-_L=0$」 → 「$j=k$에서는 왼쪽 자식의 크기가 $k-1$이라 $\mathrm{cl}^-_{k-1}=0$」; 「중괄호는 $\mu_L+\mu_R+\chi_m(j)$」 → 「$\mu_{j-1}(k)+\mu_{m-j}(k)+\chi_m(j)$」.

**(ㄴ) B6 인계 8 — 7.6절 $\mathfrak i_m$ 대 7.3절 $\mathfrak i_j$.** 확인: 보조정리 `{{7:explicit-bounds}}` 진술(584·588행)이 $\mathfrak i_m:=m\log\frac m{m+1}+1$을 정의하고 정리 `{{7:theorem-W}}` 진술 616행의 $\mathfrak G_k(n)$이 $e^{\mathfrak i_n}$으로 쓴다. 7A 673–752행 보조정리 `{{7:fourier-lemmas}}`(사)·`{{7:lemma-P-pole}}` 준비 문단의 $\mathfrak i_j=\sum_nn^j\varrho^{\mathrm{pr}}_n$(소인 분포의 모멘트)과 (바탕 글자, 글자체)가 같고 둘 다 진술문이다 — 결정 47·R1′의 꼴이 맞다. 독자에게도 7.6절에서 $\mathfrak i_n$을 보면 7.3절의 모멘트 $\mathfrak i_j$를 $j=n$으로 읽을 수 있는 자리다. 7.3 쪽은 부록 D 7A 여섯 자리($\mathfrak i^{\mathrm U}_j$ 포함)에 닿아 B6이 두었으므로 7.6 쪽을 바꾼다. 이름: 로마체 $\mathrm{sg}_m$(B7 몫 n–z의 s; Stirling형 로그 간격 $1-m\log(1+1/m)$). `\mathrm{st}`는 5A 5.4절(격자 간격)과 장부 397행 7.6 묶음의 $\mathrm{st}_N$(정리 H* 귀납의 양)에 있어 피했고, `\mathrm{sg}`는 `장v2/*.md`·`장부_v2.md`·`구조표_v2.md`·README에 0건이었다. 전→후: 584행 「$\mathfrak i_m:=m\log\frac m{m+1}+1$로 두면 $0\le\mathfrak i_m\le…$」 → $\mathrm{sg}_m$; 588행 (나)의 $e^{\mathfrak i_m}$ 두 곳 → $e^{\mathrm{sg}_m}$; 590행 증명의 $\mathfrak i_m$ 세 곳, 598행 두 곳 → $\mathrm{sg}_m$; 616행 $\mathfrak G_k(n)$의 $e^{\mathfrak i_n}$, 620행 $e^{\mathfrak i_n}$, 622행 두 곳, 626행 $e^{-\mathfrak i_n}\ge0.9999$ → $\mathrm{sg}_n$. 열네 자리 전부이며 7B에 `\mathfrak i`는 남지 않았다. 부록 D 7B·11장·부록 A·C에는 $\mathfrak i_m$이 없고, 장부 397행 등록은 BL(인계 첫머리).
