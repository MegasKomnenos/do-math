## 2. 고친 것

지적 번호, 자리(행 번호는 고친 뒤의 것), 전→후, 까닭.

**N4-1 (글자 $r$의 세 뜻) — 15자리.**
- 134행(보조정리 5-26 증명): 「$r=t-y$에 대해 $\mathrm{Ren}(r)\mathrm{Bor}(y)/\mathrm{Bor}(y+r)=r\,\mathrm{Bor}(r)\cdots\le(2\pi)^{-1/2}r^{-1/2}\cdots$」, 「$\sum_{r=1}^{\varrho_0}r^{1/2}$」 → 「나무 크기의 초과 $q=t-y$에 대해 $\mathrm{Ren}(q)\mathrm{Bor}(y)/\mathrm{Bor}(y+q)=q\,\mathrm{Bor}(q)\cdots\le(2\pi)^{-1/2}q^{-1/2}\cdots$」, 「$\sum_{q=1}^{\varrho_0}q^{1/2}$」.
- 211행(5.5.6 머리): 「곧 숲 크기 $Y+1,\dots,Y+q_{\max}(Y)$이고 폭은」 → 「곧 초과가 $1\le q\le q_{\max}(Y)$인 숲 크기 $Y+q$이고 폭은」. 착지 창의 변수 $q$를 1.5절의 낱말 「초과」로 들여 $q_{\max}$의 이름이 그 변수의 끝임을 보이게 했다.
- 213행(정리 5-31 진술): 「$1\le r\le Y+1$」 → 「$1\le q\le Y+1$」.
- 215행(정리 5-31 식): $c_{Y+r}(Y)\ge\mathrm{Lc}(Y,r)$, $\sum_{z=1}^r\sum_{D=z}^r$, $\mathrm{Bor}(Y+r+1-D)/\mathrm{Bor}(Y+r+1)$, $\pi^0_{Y+r-D}(Y)$, $z(r+1)$ → 모두 $q$.
- 218행(5-31 증명): 「$Y+r\le2Y+1$」, 「$S_0=Y+r+1$」, 「$R_j\le r$」 → $q$.
- 220행(5-31 증명 식): 「$c_{Y+r}(Y)=\sum_{\text{경로}}\cdots$」 → 「$c_{Y+q}(Y)=\cdots$」(첫 검색에서 놓쳤다가 토큰 `c_{Y+r}` 전수 검색으로 잡음).
- 222행(5-31 증명): 「$\mathrm{Bor}(Y+r+1-D)/\mathrm{Bor}(Y+r+1)$과 $\pi^0_{Y+r-D}(Y)$」, 「$S_j-Y=r+1-R_j$」, 「$\prod_j(1+(r+1-R_j)/Y)^{-1}\ge\exp(-[z(r+1)-\sum R_j]/Y)$」, 「$\mathbb E[e^{-[z(r+1)-\sum_jR_j]/Y}\mid R_z=D]\ge\exp(-(z(r+1)-D(z+1)/2)/Y)$」 → 모두 $q$.
- 224행: 「무게 $Y/(Y+r+1)$」 → 「$Y/(Y+q+1)$」.
- 226행($\Lambda_{\mathrm w}$ 정의): 「$\sum_{r=1}^{q_{\max}(Y)}\frac{Y}{Y+r+1}\mathrm{Lc}(Y,r)$」 → 「$\sum_{q=1}^{q_{\max}(Y)}\frac{Y}{Y+q+1}\mathrm{Lc}(Y,q)$」.
- 274행: 「$j:=r-D$」 → 「$j:=q-D$」.
- 286행(rig-int 증명): 「($r=j+D\le q_{\max}$, …)」 → 「($q=j+D\le q_{\max}$, …)」.
- 376행(정리 5-33 증명): 「착지 크기 $\mathfrak l=Y+r+1$($1\le r\le q_{\max}(Y)$)에 대한 합 $\sum_r\frac{Y}{Y+r+1}c_{Y+r}(Y)\ge\sum_r\frac{Y}{Y+r+1}\mathrm{Lc}(Y,r)$」 → 모두 $q$.
- 꼬리 좌표 $r=n-y$(60행, 427–439행, 5.6 표 463–465행)와 특정값 $r_0(m)$(58·451행)은 1.5절·장부 1.1의 뜻 그대로이므로 두었다. 이제 5B의 $r$은 꼬리 좌표 하나다.

**N4-2 ($F_3,F_4,F_5$의 번호) — 7자리(161·163·165·167·169·171·173행, 정리 5-28 증명).**
- 161행 식: 첫 인자의 밑줄 꼬리표 「$=e^{g(S_z)-g(m+1)}$」 → 「$F_1$」; 「$F_3$·$F_4$·$F_5$」 → 「$F_2$·$F_3$·$F_4$」.
- 163행: 「두 번 쓴 것이다.」 → 「두 번 쓴 것으로 $F_1=e^{g(S_z)-g(m+1)}$이다.」
- 165행: 「$\mathfrak H:=e^{g(S_z)-g(m+1)}\le1$」, 「$1-\mathfrak H\le$」 → 「$F_1\le1$」, 「$1-F_1\le$」.
- 167·169·171행: 「둘째로 $F_3\ge1$」·「셋째로 $F_4\ge1$」·「넷째로 $F_5$」와 171행의 $F_5$ 넷 → $F_2$·$F_3$·$F_4$.
- 173행: 「$F_3F_4\ge1$에서 $\mathcal R\ge\mathfrak HF_5$이고, $1-\mathcal R\le1-\mathfrak HF_5=(1-F_5)+F_5(1-\mathfrak H)\le(1-F_5)+(1-\mathfrak H)$」 → 「$F_2F_3\ge1$에서 $\mathcal R\ge F_1F_4$이고, $1-\mathcal R\le1-F_1F_4=(1-F_4)+F_4(1-F_1)\le(1-F_4)+(1-F_1)$」.
- 네 인자가 「첫째·둘째·셋째·넷째」와 $F_1$–$F_4$로 맞물린다. $\mathfrak H$는 5B의 165·173행에만 있던 글자라 5B에서 사라졌다(장부 1.3 380행의 등재는 YL 인계).

**N4-3 (「소구간」 대 「셀」) — 2자리(415·425행, 명제 band-inequality 증명; 낱말 넷).**
- 415행: 「$4000$개 소구간 $[\lambda_a,\lambda_b]$로 나누고, 각 소구간에서」 → 「$4000$개 셀 $[\lambda_a,\lambda_b]$로 나누고, 각 셀에서」.
- 425행: 「소구간마다 하계 인자에는」, 「첫 소구간 $\lambda\in[\frac12,\frac12+\frac1{24000}]$」 → 「셀마다」, 「첫 셀」.
- 5B에 「소구간」이 남지 않는다. 부록 D·장부·11장·README의 같은 낱말은 인계.

**N4-4 (정리 5-33 증명의 빠진 한 줄) — 1자리(372행).**
- 「… $\mathrm{Bor}(D')/\mathrm{Bor}(m+1)\ge1$이다. 걸음 수 $z$, 총 하강 $D$인 걸음 수열 전체의 질량은 $\Pr(R_z=D)$이므로 $D\le\chi_{\mathrm w}-1$에 걸쳐 더하면 …」 → 「… $\ge1$이다. 총 하강이 $D\le\chi_{\mathrm w}-1$이면 정리의 가정 $m\ge Y+q_{\max}(Y)+\chi_{\mathrm w}+1$에서 모든 걸음이 $S_j\ge S_z=m+1-D\ge Y+q_{\max}(Y)+3$을 만족하므로, 이 부류의 걸음 수열에는 착지 창 밖이라는 제약이 따로 붙지 않는다. 그러므로 걸음 수 $z$, 총 하강 $D$인 걸음 수열 전체의 질량은 $\Pr(R_z=D)$이고, $D\le\chi_{\mathrm w}-1$에 걸쳐 더하면 …」. N4의 제안 문장을 「전체의 질량」 문장 바로 앞으로 옮겨 근거가 쓰이는 자리에 서게 했다.

## 6. 확인하지 못한 것, 막힌 것, 공통 안내와 다르게 판단한 것

- **공통 안내 1절의 글자 규칙과 $q$.** 1절은 「그리스·프락투어·필기체 글자를 새로 쓰려면 상대 장 파일 … 에 없는 것만 쓴다」고 했고, 배정 메모는 「그리스·라틴은 5A … 전수 확인」을 요구했다. 확인하니 5A에 $q$가 세 가지로 있다(2절 표). 그래도 $q$를 택한 까닭은 $q$가 새 글자가 아니라 1.1 변수 표가 「초과」에 준 글자이고 1.5절이 「뒤의 장들은 이 $q$를 변수로 쓴다」고 정한 그 쓰임이며, 5A의 셋은 1.1 머리말의 예외(「그 장에 그 변수가 나오지 않을 때만」)로 빌려 쓴 임시 글자이기 때문이다. 다만 5A가 고쳐지기 전까지 5장 안에서 $q$가 두 뜻이다. 세션이 Y3에게 인계 1항을 전달해 주기를 청하고, 이번에 닿지 못하면 다음 차례의 지적이 될 것이다.
- 조립·PDF·생성기는 돌리지 않았다. 11.2절 38행(부록 D의 「소구간」을 끌어오는 생성 열)과 README 613행은 YD 수정 뒤 재생성·패치로 따라와야 한다.
- 읽기 전용 검사기 `scripts/_check_지위서식.py`는 「문제 0건」. 고친 31행의 `$` 짝은 모두 짝수임을 세었다. 라벨은 손대지 않았다.
