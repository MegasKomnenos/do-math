## 3. 지적을 받았으나 고치지 않은 것과 그 까닭

- **Petersson 학위논문 Theorem 2.1·Corollary 2.11(Q2 3절·5절; 공통 안내 4절 A2 메모).** DiVA의 전문(`diva2:173191`, 요약부 viii+20쪽)을 열어 확인했다. 1.1절: 「A hash table $T_{m,n}$ is called … almost full if $n=m-1$. A non-full hash table is said to be confined if the last cell in the table is empty」. 2.1절 Theorem 2.1: 「If $m\to\infty$, then the maximum displacement $D$ in an almost full hash table $T'_{m,m-1}$ is given by $P\bigl(\frac{m-D}{m^{2/3}}\le z\bigr)\to1-\psi(z^{3/2})$, $0<z<\infty$」, 여기서 $\psi$는 급수 $\frac1{\Gamma(2/3)}\sum_n\frac{\Gamma(n+2/3)}{\Gamma(3n/2+1)}(-\frac{3\sqrt2 s}4)^n$. 2.3절 Corollary 2.11: 「The Laplace transform of $A$ is $\psi(s)=$ (같은 급수)」, $A=\int_0^1\max_{s\le t}B(s)\,dt$. 장3 19–23행이 적은 조건(자리 $m$개, 항목 $m-1$개, 마지막 자리 비어 있음), 정규화 $m^{2/3}$, 「Theorem 2.1에서 $\psi$는 급수로 적혀 있고, 같은 학위논문의 Corollary 2.11에 따르면 그 급수가 $\mathcal B$의 Laplace 변환이다」가 모두 원문과 같다. Janson 논문의 (1.8)은 이 결과를 「[24, Theorem 5.1]」로 인용하는데 [24]는 「N. Petersson, The maximum displacement for linear probing hashing I. Tech. report 2008:8, Uppsala. In *The Maximum Displacement for Linear Probing Hashing*, Ph. D. thesis, Uppsala, 2009」, 곧 학위논문에 실린 논문 I의 번호다. 이 글은 학위논문 요약부의 번호를 적었고 그 번호가 실재하므로 고칠 것이 없다. 장11 148행도 그대로(A11에 알림).
- **장부 515행·부록 C 15·131행의 「봉우리」.** 첫 판 낱말과의 대응을 적는 열이라 Q2-2를 받아도 바꾸지 않는 것이 맞다(AL 범위; 인계에 「그대로」로 적음).
