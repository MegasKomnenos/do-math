## 7.1 명제 10.5의 부호 결론
명제 10.5는 $k\ge43$, $2k+1\le n\le3k$에서 예산 분해를 진술하고, 이어 정리 6.62의 (V)를 이용해 $\mathcal X_n\ge0$이라 한다. 정리 6.62가 보장하는 범위는 $k\ge3131$이므로 $43\le k\le3130$의 부호 결론은 현재 인용으로 정당화되지 않는다. 정확한 분해 항등식에는 적용되지 않고 부호 결론에만 해당. 가장 간단한 수정은 항등식 범위는 유지하고 부호 결론에 「$k\ge3131$에서」 또는 「(V)가 성립하면」을 붙이는 것. 주 정리가 쓰는 범위는 $k\ge6667$이라 주 정리는 무너지지 않음.

## 7.2 / 6.1 D.30 (7)(ㄱ)의 작은 기울기 처리
상계 적분의 $(e^{sh}-1)/s$를 $|s|\le10^{-14}$이면 $h$로 대신한다고 적혀 있으나 $h>0$, $s>0$이면 $(e^{sh}-1)/s=\int_0^he^{su}du>h$라 문자 그대로는 상계가 아니다. 안전한 규칙의 예: $\int_0^he^{su}du\le h\,e^{\max(s,0)h}$, 또는 $\mathrm{expm1}(sh)/(sh)$를 나머지를 포함한 구간으로. 원 기록의 합 부풀림이 이 오차를 덮었을 수 있고, 새 구간 구현은 분기를 고쳤을 수 있으며, 실제 입력에서 분기가 안 쓰였을 수 있음 — 코드 미확인. 분류: 「현재 적힌 상계 명세에 정당화가 빠진 대체가 있으므로 최종 코드·오차 예산과 대조해 고쳐야 함」.

## 6.3 보조정리 5.73의 미분·적분 교환
5.73 (다)에서 $8\varrho^{2m-2}e^{-\eta\varrho^2/2}$를 지배함수로 드는데 $m=0$에서는 원점 근처에서 적분 가능하지 않다. 결론을 흔들지는 않음: $m=0$의 적분은 직접 계산했고, 원점 근처는 (가)의 유계성, 큰 $\varrho$는 꼬리 상계로 됨. 미분도 $\eta$의 작은 근방에서 공통 지배함수를 잡는 설명을 보태면 충분. 증명 서술 문제.

## 5. D.15의 구간 덮개(가장 중요)
정리 5.39는 $k\ge10001$, $n=k+r$, $1.4\le\hat x=(r+1)k^{-2/3}\le10$의 모든 정수 위치에서 차분이 양수임을 얻는다. $u=k^{-1/3}$의 44개 상자와 $\hat x$의 43개 셀에서 Taylor 모형과 구간 산술로 양의 하계를 인증. 필요한 둘: (1) 각 모형의 구간 안에서 하계가 엄밀히 양수, (2) 구간들의 합집합이 전체 영역을 덮음. 문제는 (2)와 Taylor 반경.
- `rig_cert.py`는 셀의 폭·양 끝점·중점을 먼저 Python float로 계산한 뒤 `iv.mpf`로 바꾼다. 이 변환은 binary64 수를 정확한 한 점으로 받아들이고 십진 유리수로 넓혀 주지 않는다. 실제 폭은 $h=7205759403792793/2^{55}=0.19999999999999998\ldots$.
- 저장된 셀 경계에 앞 셀 끝 1.9999999999999998, 다음 셀 시작 2.0 같은 틈이 있고, 이런 양의 틈이 명목 경계 9곳에서 확인됨. `verify_new_certs.py`는 경계 차이가 $10^{-12}$보다 작으면 통과시켜 「빈틈없는 덮개」로 출력됨.
- 중점 1.9, 2.1(binary64)에서 반경 $h/2$를 쓰면 두 Taylor 적용 영역 사이에 $(2-7/2^{56},\,2+7/2^{56})$의 열린 틈이 남아 정확한 $\hat x=2$가 43개 구간 어디에도 들지 않음(Fraction으로 확인). 이 값은 정수 입력에서 실제로 나타남: $k=64000=40^3$, $r=3199$, $n=67199$에서 $\hat x=3200/1600=2$; $u=1/40=0.025$는 A14 상자 안.
- 반례가 아니라 인증이 놓치는 적법한 입력의 예. 저장된 최소 양의 여유 약 0.001827, 빠진 구간 폭은 극히 작아 흡수될 가능성이 높으나 실제로 증명해야 함.
- 마무리 방법: 경계를 $(7+i)/5$ 같은 정확한 공통 유리수 격자로 정하고 중점과 반경을 바깥으로 반올림해 다시 인증 / 현재 하계와 도함수 상계로 각 인증 영역을 필요한 만큼 확장할 수 있음을 정량적으로 증명 / 덮개 판독기에서 양의 틈을 허용 오차로 통과시키지 않고 정확한 포함·겹침 조건 검사.
- 정리 5.39는 W와 V를 통해 주 정리 양쪽 경로에 들어가므로 우선순위가 가장 높음.
