# dream 2026-11-06 확정 패킷 계약

이 문서는 주제군별 확정 에이전트가 따르는 계약이다. `파견-공통.md`의 3절(종합의 원리), 3.4절(현행층에는 현 상태만), 3.6절(작문 관례), 6절(평가 기준), 7절(권한)이 그대로 적용된다. 먼저 `임시/dream-20261106/파견-공통.md` 전문을 읽는다.

## 1. 목적

초안(`초안-G##.md`)은 주제군마다 50~130 KB라 메인이 전부 적재할 수 없다. 확정 에이전트는 초안과 검증(`검증-G##.md`)을 읽고, 검증 지적을 반영한 확정 패킷 `확정-G##.md`를 쓴다. 메인은 확정 패킷의 1~4절만 적재해 D 노드를 쓰고, 5절은 L 노드별 통합 에이전트가 모든 주제군에서 모아 L 노드에 반영한다.

## 2. 입력

1. `임시/dream-20261106/초안-G##.md` 전문.
2. `임시/dream-20261106/검증-G##.md` 전문.
3. 검증 지적의 처분을 정하는 데 필요한 근거 노드(`기억/layer1/M-####.md`)와 L 노드. 지적마다 근거를 직접 읽고 판정한다. 검증자의 지적도 틀릴 수 있다. 지적을 기각하면 근거를 적는다.

## 3. 지적 처분

검증의 결함마다 `수용`(검증자의 처분 제안대로), `수정 수용`(다른 문안으로 고침), `기각`(원문 근거로 반박) 중 하나로 처분한다. 주장을 낮추는 지적을 수용하면 같은 주장이 초안의 다른 절(특히 7절 L 패킷)에 남아 있는지 따로 찾아 같이 낮춘다.

## 4. 산출 `확정-G##.md`의 구조

절 번호와 제목을 바꾸지 않는다. 1~4절의 합계는 12 KB를 넘기지 않는다. 짧게 하려고 근거·조건·예외를 빼지 않되, 사건 서술은 줄이고 원리와 그 근거 노드를 남긴다.

```
# 확정 G## <주제군 이름>

## 1. 종합 확정본
D 노드 "종합" 섹션에 들어갈 이 주제군의 통찰. `###` 소제목마다 원리 한 문단과 인라인 [[M-####]] 근거. 소제목 끝에 `판정: 새 정보 | 재실증 | 반례`와 대조한 L 항목. 재실증만인 소제목은 한 줄로 줄이거나 뺀다. 마지막에 "설명하지 않는 것" 한 문단.

## 2. 제안 확정본
각 제안에 적용 대상(기억 내부 | 핵심층 | 프로젝트 소스 | 사용자 결정)과 교정 위치. 사용자 결정 사안은 선택지와 추천(있으면)을 둔다. 없으면 "없음"과 근거.

## 3. 원장 입력
가정, 강화·반증 증거, 이동. D-0010 원장 (가)(나)(다)에 대한 답 각 한 줄.

## 4. basis와 반영 판정
- basis 후보: id 목록(한 줄 이유는 필요한 것만).
- 반영 판정 표: | id | 판정 | 행을 주제군의 모든 노드에 대해 쓴다. 판정은 `반영: L-####` 또는 `불요: 진행기록 | 구현소멸 | 기존지식 | 기타(설명)`.

## 5. L 패킷 확정본
L 노드마다 `### L-####` 아래 개정·신설·삭제 제안 항목. 개정은 기존 `## 제목`을 인용하고 다시 쓴 항목 전문을 둔다. 신설은 제목과 전문. 문장마다 인라인 [[id]]. 기존 근거 id 보존. L-0020 패킷은 3.4절 구분을 지킨다.

## 6. 지적 처분표
| 지적 번호 | 처분 | 한 줄 이유 |
```

## 5. 권한과 반환

`임시/dream-20261106/확정-G##.md`만 쓴다. 다른 파일은 수정하지 않고 커밋하지 않는다. 응답 본문은 짧게 유지한다. 마지막 메시지는 다음만 담는다.

```
<DONE | PARTIAL | BLOCKED> G##
산출: 임시/dream-20261106/확정-G##.md  (1~4절 크기 KB)
지적: 수용 n, 수정 수용 n, 기각 n
L 패킷 대상: L-#### 목록
```
