## 3. 근거 id 대조(기계)

`\[\[([A-Z]-\d{4})\]\]` 패턴으로 원고와 두 산출의 id를 뽑아 비교했다.

- **집합.** 원고 174개, 분할-L-0001 103개, 분할-L-0023 112개, 합집합 177개다. 원고에 있고 산출에 없는 id는 0개다. 산출에 새로 생긴 id는 `L-0001`, `L-0023`, `D-0011` 셋이고, 모두 상호 참조와 지시받은 도입 문장이다.
- **다중집합(출현 횟수).** 원고와 두 산출의 합을 비교하면 M·D·L의 모든 기존 id의 출현 수가 같다. 차이는 더한 참조뿐이다. `L-0001` +14, `L-0023` +9, `D-0011` +1이다. `[[L-0022]]`(1회, L-0001 검증 계약), `[[L-0016]]`(1회, L-0023 판본과 완결 실행), `[[L-0005]]`, `[[D-0010]]`의 출현 수는 그대로다.
- **문장 보존.** 원고 본문을 문장 단위로 나눈 487개를 산출과 대조했다. 어느 산출에도 그대로 없는 것은 4개였다. 2개는 2절에서 바꾼 참조 문구다. 나머지 2개는 대조 스크립트의 분절 결과로, 121행의 분할 경계에서 id 묶음과 다음 문장이 한 조각으로 잘린 것이다. 이 두 문장은 각각 L-0023과 L-0001에 1회씩 그대로 있음을 따로 확인했다. 두 산출에 함께 있는 문장은 2개다. 하나는 139행 연결 문장이다. 다른 하나는 원고에서 이미 두 문단(143행, 165행)에 나오던 id 묶음 `[[M-0545]] … [[M-0549]]`다.
- **교차 참조의 해소.** `[[L-0001]]의 "…"`와 `[[L-0023]]의 "…"` 형태로 인용한 제목 18개와 "같은 노드의" 인용 2개가 모두 상대 노드의 실제 `##` 제목과 일치한다.
- **문면 점검.** U+2014 0건, `→`·`↔` 0건이다. L-0001의 frontmatter는 원고와 같다. L-0023의 frontmatter는 `id: L-0023`, `layer: 3`, `title: 시험 스위트 설계`, `convention_version: 27`이다.
