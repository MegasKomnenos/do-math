# 작업자 노드

이 폴더의 파일은 2026-09-26 시험 경량화 작업자들이 반환한 기억 노드 초안의 원문 사본이며, 작성 뒤 `git add -f`로 추적되었다. 통합된 기억 노드는 `기억/layer1/M-0350.md` 하나다. 본문에 적힌 "Git 제외"·"Git 무시 대상" 같은 지위 서술은 작성 시점의 사실이며 지금은 맞지 않는다. 원문 보존을 위해 본문은 고치지 않았다. frontmatter의 `worker_id`는 작업자 이름이다. 기억 노드 ID와 혼동하지 않도록 원래의 `id: M-0350`·`id: M-0351` 줄을 바꾼 것이며, 이 파일들은 기억 그래프의 노드가 아니다.
