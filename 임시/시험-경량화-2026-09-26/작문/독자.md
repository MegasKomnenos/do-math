# 독자 정보

문서 종류: do-math 스킬의 시험 실행과 시험 작성 지침. 스킬 개발 저장소의 `.claude/skills/do-math/scripts/tests/`에 두는 개발자용 절차 문서다.

주 독자: do-math 코드(Python, 제품 모듈 약 80개, 시험 모듈 약 140개, 시험 약 1,850개)를 고치는 AI 작업자. 혼자 일하기도 하고, 통합자(메인 세션)가 여러 작업자를 각자의 git worktree에 병렬로 파견하기도 한다. 작업자는 Python unittest, git, 셸 사용법을 안다. do-math의 제품 용어(엔진, 활성화, 실행, 게시, 템플릿)는 코드를 읽어 알 수 있다. 과거 작업에서 무엇이 잘못됐는지는 이 문서로만 안다.

부 독자: 통합자와 사용자. 통합자는 작업자를 파견할 때 이 문서를 따르게 하고 병합 뒤 검증을 수행한다. 사용자는 시험 운영 방식이 합리적인지 확인한다.

사용 상황: 작업자는 작업을 시작할 때 한 번 읽고, 시험을 돌리거나 새 시험을 쓸 때 해당 절을 다시 찾는다. 실행 환경은 Windows 11, 4코어 개발 기계이며 여러 작업자가 같은 기계를 공유한다.
