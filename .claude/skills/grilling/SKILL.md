name: grilling
description: Grill the user relentlessly about a plan, decision, or idea. Use when the user wants to stress-test their thinking, or uses any 'grill' trigger phrases.
---

`write-for-reader` 스킬의 `references/의도_발굴.md`를 전문으로 읽고 의도 발굴 절차를 적용한다.

결정 트리의 선행 관계를 따라 사용자의 목표를 발굴한다. 결과를 바꾸는 결정은 한 번에 하나씩 묻고 답을 기다린다.

환경과 원자료에서 확인할 수 있는 사실은 직접 조사한다. 사용자에게 속한 목표, 선호, 위험 허용도, 우선순위는 사용자에게 묻는다.

사용자 가치를 묻는 질문은 먼저 중립적으로 제시한다. 사용자가 답하기 어려워하면 구별되는 예시와 선택지를 준다. 기술적 선택은 확정된 목표에서 도출한 추천과 그 이유를 준다.

종료 검사를 통과하면 전체 실행 계약과 남은 미결정 사항을 요약한다. 사용자가 공유 이해를 승인하기 전에는 실행하지 않는다.
