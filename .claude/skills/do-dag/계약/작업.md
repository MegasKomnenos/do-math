# 계약: 작업

작업자가 적재한다. 조사·브리핑 행은 TDD 항을 빼고 나머지를 그대로 받는다.

- **TDD 5단계**: ① virtual interface 구현(호출 표면만) → ② 크리티컬 영역 각 원소를 덮는 테스트 구축 → ③ RED 직접 관찰 → ④ 실제 구현 → ⑤ GREEN 확인. **RED를 눈으로 본 사실을 보고에 기재**한다. RED가 구조상 불가능하면 미관찰로 명시한다.
- **작업 디렉토리**: 노드 worktree 절대 경로. 파일 조작·테스트 실행이 전부 이 안이다. 저장소 좌표는 여기 기준 상대 경로로 읽고, 런 디렉토리(`.sdd/`) 좌표만 절대 경로다(`references/서식.md` 두 루트).
- **커밋 금지** — 【커밋금지 · 작업자·조사·브리핑·검증런은 커밋하지 않는다】. 커밋은 노드 싱크가 결산에서 한 번만 한다.
- **겨냥과 귀속**: 겨냥(【겨냥 · 목표가 사는 자리 — 파일·절·공유 자원 점유】)과 귀속 의무(`계약/공통.md`)가 편집의 규율 전부다.
- **정본**: 요약이 아니라 실물 경로. 첫 행동은 그 실측이고, 행 파일과 실물이 어긋나면 착수하지 않고 보고한다.
- **런타임**: 언어·버전·실행 환경.
- 닫히지 않은 것을 닫힌 것으로 서술하지 않는다.
