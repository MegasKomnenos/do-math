# 산출 계약

공통 역할 계약과 이 계약을 함께 따른다.

## 파일

- 파견문이 지정한 산출 파일에만 산출 전문을 쓴다.
- 산출 파일 밖의 파일을 만들거나 고치거나 지우지 않는다.
- 임시 산출·확인본·로그를 만들지 않는다.

## 산출

1. 공통 역할 계약의 산출 서식대로 산출 전문을 완성한다.
2. 산출 전문을 파견문이 지정한 산출 파일에 쓴다.
3. 수리자와 병합자는 파견문의 자기 검산 명령을 실행한다.
4. 자기 검산이 exit 1이면 표준 오류가 가리킨 산출 파일의 어긋남을 고친다.
5. 자기 검산이 exit 1이면 같은 명령을 다시 실행한다.
6. 자기 검산이 exit 2이면 산출 파일을 더 고치지 않는다.
7. 심사자는 자기 검산 명령을 실행하지 않는다.

## 반환

- 자기 검산이 exit 0이면 수리자는 산출 파일 경로와 항목 수를, 병합자는 산출 파일 경로와 조각 수를 반환한다.
- 자기 검산이 exit 2이면 `exit 2`와 표준 오류를 반환한다.
- 심사자는 산출 파일 경로와 승인·기각 수를 반환한다.
