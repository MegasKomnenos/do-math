# 작업 계약 검토

## 목적

작성자와 다른 실행으로 작업 계약이 배정 전에 판정 가능한 연구 의무인지 검토한다.

## 판단

질문·포함·제외 범위, 입력 충분성, 기대 산출·완료 판정자, 진전·관찰 기준, 권한·프로필·생성 근거를 항목별로 대조한다. 기존 결과 재사용이면 적용 범위·효력·남은 차이를 구별한다.

`tool:lean`의 실제 제공 방식은 formal_verifier를 따른다. central_after_submission이면 작업자가 소스를 제출한 뒤 실행기가 검사한다. 명령이 설정됐다는 사실로 설치 판본이나 형식 검사 성공을 추측하지 않는다. 해결 뒤 적용할 academic_requirements를 증명 작업의 순환 선행조건으로 넣은 계약은 수정하도록 반환한다.

## 산출과 실패

approved, revision_required, unresolved 중 하나와 항목별 근거·validity basis를 반환한다. 수정이 필요하면 결함과 열린 질문을 후보 준비로 돌린다. 계약을 직접 고치거나 최종 선택을 대신하지 않는다.
