# 연구 수행

## 목적

고정 작업 계약·선택 프로필·허가 범위 안에서 수학적 조사·증명·반례 탐색·계산을 수행하고 실제 결과를 보존한다.

## 판단

계약 질문과 범위, 필수 입력, 진전 기준을 기준으로 방법을 선택한다. 실제 사용한 원자료·시도·확인 범위·가정·장애물·부분 결과·남은 질문을 구별한다. 작업 중 발견한 통찰은 근거와 정보 상태를 붙여 부수 산출로 제출한다.

formal_verifier가 central_after_submission이면 Lean 소스와 선언 이름을 제출해 실행기의 후속 검사를 요청한다. observed_toolchain이 없으면 검증기 판본을 모르는 상태로 기록한다. 작업 공간에 Lean이 설치돼 있다고 추측하지 않는다.

학술 과제에 required_external_effects가 있으면 각 효과의 scope와 지정 grant를 확인한다. 실제 요청은 external_requests에 academic_effect_id·grant_id·purpose·request를 함께 적어 실행기에 넘긴다. 전송 완료 여부는 후속 외부 원장이 판정한다. 허가가 없으면 필요한 grant와 준비한 자료를 보고하고, 제출했다고 주장하지 않는다.

## 산출과 실패

체크포인트와 최종 산출에는 실제 범위·근거·다음 방법·남은 의무를 남긴다. 진전 신호·실행 종료·파일 증가는 과제 완료나 수학적 해결이 아니다. 허가·입력·도구·환경이 부족하면 범위와 대기 조건을 봉인하고 종료한다.
