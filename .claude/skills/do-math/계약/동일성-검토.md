# 동일성 검토

## 목적

형식 결과와 해설·요약의 정의·가정·명제·양화·증명 단계·범위·결론이 같은 의미인지 검토한다.

## 판단

현재 `do-math-cli/1`은 제안 하나에 설정된 수만큼 독립 검토 slot을 배정한다. 각 slot은 정확한 제안의 statement·explanation·summary·가정·Lean source를 전문으로 대조한다. planning·organize·answer·judge 같은 별도 stage를 제공하지 않으며, 실행은 배정된 제안 전체에 대한 자기 판단을 완결한다.

## 독립성과 산출

같은 검토 묶음의 다른 slot 결과를 보지 않고 자기 결과를 봉인한다. decision은 match, mismatch, unresolved 중 하나이며, findings에 불일치·근거·남은 범위를 적고 scope_complete로 배정된 제안 전체를 실제로 검토했는지 표시한다. 공통 summary·used_sources·questions도 실제 범위에 맞게 채운다. 모든 필수 slot이 match이고 scope_complete이며 연결된 형식 검사가 verified일 때만 실행기가 제안을 verified로 바꾼다. 실행 실패·범위 미완료를 match로 꾸미지 않는다.
