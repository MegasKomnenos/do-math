# 행 2.7.10.55.3 예외 기록

## 현재 입력 판정

현재 입력 반환의 첫 줄은 `검증런이 완료됐습니다.`다. 이 문장은 공통 반환어휘
`DONE`·`DONE-비준`·`상신`·`예외` 밖이다. 현재 입력 반환을 `반환형식위반`으로
기록한다.

현재 입력 반환의 사용자 확인 요청은 상신이 아니다. 세 이탈은 아래와 같이 처분한다.

1. 라운드 커밋 미실행은 계약 준수다. do-dag `계약/검증런.md` 「실행 규율」은
   검증런의 커밋을 금지한다. 같은 계약은 verify-rounds §7 「라운드 커밋」을 실행하지
   않는다고 명시한다.
2. `2-보고.md`를 산출물에서 빼고 기준 원문으로 둔 판단은 verify-rounds §8 신호 4에
   닿는다. 이 판단은 하위 지급 목록을 파견문과 다르게 닫았다. 예외가 자체 판단한 결과,
   사용자에게 올리지 않는다. 오판은 `2-보고.md`의 검증 범위만 줄이며 외부 상태를
   바꾸지 않는다. 후속 검증으로 되돌릴 수 있다. `2-보고.md` 실물, 작업자 로그,
   파견문으로 판단할 수 있으므로 사용자만 가진 정보가 필요하지 않다. 이 런은
   `2-보고.md`를 기준 원문으로 읽었고, 승인 조각 2건은 모두 L04.md에만 적용됐다.
3. `수리_관점기수` 3은 허용된 동결값이다. verify-rounds §4.1은 수리자 전원이 관점을
   맡는 배분을 허용한다. §4.4는 동결문 값이 체급 값을 덮게 한다.

종료보고와 장부는 상신·자체 처리·승계가 없다고 적는다. 현재 입력 반환의 확인 요청은
이 실물과도 어긋난다.
