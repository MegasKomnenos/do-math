# 동결 — L18 재판독 검증런

## 산출물

- research/pvsnp/literature/readings/L18.md

## 목적 진술

대응 작업자가 쓴 재판독 상태와 도출 근거를 원문 확보와 내용 완료 기준에서 독립 재도출한다. 상태를 확정할 수 없으면 FAIL로 판정한다.

L18의 새 정리를 지급 원문과 독립 대조한다. 원문이 요구하지만 정리에 구현되지 않은 주장·한정·경우도 검사한다. 앞선 판독 내용은 비교 기준으로 사용하지 않는다.

「호출자에게 전달」로 확정된 발견은 do-dag 검토전개 행 하나를 생성한다.
검토전개가 타당으로 판정하면 작업자 행 하나 이상과 검증런이 추가될 수 있다.
「승인하되 고치지 않는다」와 기각 발견은 검토전개를 생성하지 않는다.

`호출자에게 전달`은 검토전개 행 하나의 비용만 뜻하지 않는다. 발견이 타당하면
전개 뒤 검증런, 작업자 행 하나 이상, 산출물 검증런, 싱크가 뒤따른다. 각 검증런은
수리자·심사자 여러 기를 다시 파견한다. 심사자는 이 전체 후속 전개의 최소 규모를
방치 손상과 비교한다.

## 불변식 목록

결정 파일 「결정」 절의 확정 문면 두 항을 불변식으로 쓴다. 승인된 일곱 내용 기준과 분량·밀도 비례를 검증한다. 기록을 원문 대체물로 만드는 과잉 전사도 검사한다.

크리티컬 영역에 대응 정리의 상태 필드, 작업자 보고의 도출 근거, 원문 확보, 내용 완료 기준을 더한다. 종료보고에는 `재판독 상태 판정: PASS|FAIL` 한 줄을 쓴다.

크리티컬 영역은 원문 좌표 실재, 읽은 범위의 정직성, 주장과 전제·한정의 분리, 인용 좌표 실재, P vs NP 접점의 원문 결속, 봉쇄 준수다. 기존 `records/` 본문과 원장의 판독 열을 열지 않는다. 구독 원문을 저장소에 편입하지 않는다.
