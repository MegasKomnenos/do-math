## 판정

반환 주장은 실물과 일치한다. 행 2.7.8의 완료 기준 중 `후행 크리덴셜 입력 0건`은 충족되지 않았다. 추적 종료보고에 크리덴셜 값이 남아 `크리덴셜 비인용`도 충족되지 않았다.

현재 파일만 수리하면 위반 값이 Git 커밋 이력에 남는다. 이력에서 값을 완전히 제거하려면 커밋 64952423b2c5451e208e888a98803008f8c56211과 후속 이력을 재작성해야 한다. 이력 재작성은 비가역 행위에 해당한다. 외부 서비스에서 해당 크리덴셜을 폐기하고 교체하는 행위도 현재 행의 권한을 넘는다.

## 1차 처분

**상신**

상신 사유는 `비가역 행위가 필요하다`다. 사용자는 다음 두 행위의 승인 범위를 결정한다.

1. 해당 학술 DB 크리덴셜을 폐기하고 교체한다.
2. 로컬 main에서 커밋 이력을 재작성해 추적 종료보고의 위반 줄과 파생 객체를 제거한다.

권고 처분은 두 행위를 모두 승인하는 방안이다. 승인 후 수리 행은 현재 종료보고 1건과 무시 로그 2건을 마스킹한다. 수리 행은 Git 이력을 재작성한 뒤 값 출현 0건을 검증한다. 그런 뒤 행 2.7.8을 `미착수`로 돌려 재파견한다.

파견표의 행 2.7.8 상태는 `예외`로 유지했다. 수리 행은 추가하지 않았다.

## 결정 후 처분

**완**

`C:\math\.sdd\dag\pvsnp-탐사-1\결정\상신-2.7.8-1.md`는 크리덴셜 잔존을 무처분으로 닫았다. 사용자는 교체·파일 값 제거·Git 이력 재작성을 하지 않도록 확정했다. 사용자 결정은 병합과 push를 막지 않는다.

행 2.7.8 보고는 비밀 검사 `FAIL`을 보존했다. 보고는 이 FAIL이 사용자 결정으로 수용됐음을 추가했다. 결정 소비 후 커밋 후보 0건과 외부 원문 목록 해시의 동일성을 다시 확인했다. 나머지 감사 항목은 전건 `PASS`다.

행 2.7.8은 수리 행 없이 완결했다. 상태 기입은 오케가 반환어휘 `DONE`을 소비해 완료한다.
