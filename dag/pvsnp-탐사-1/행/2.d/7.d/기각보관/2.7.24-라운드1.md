## R1-02

제목: R1-01 — 외부 원문 대조 명령의 필수 입력을 기록하지 않음

### 위치
`.sdd/dag/pvsnp-탐사-1/행/2.d/7.d/8-보고.md` 54행은 외부 원문 동문성 대조에 쓴 `dag_measure.py same` 명령에서 `--files` 인자를 빼고 적는다.

### 기준
`.sdd/dag/pvsnp-탐사-1/행/2.d/7.d/23.md` 9행:

```
(4) 외부 원문은 확장자·매직 바이트·NUL·원본 바이트 동문성 검사에서 0건이다.
```

`C:\Users\wogud\AppData\Local\dag-wt\pvsnp-탐사-1+2.7\.claude\skills\do-dag\scripts\dag_measure.py` 21행:

```
python dag_measure.py same   --files "행/*.d/z.md" [--raw] [--root DIR]
```

같은 파일 425~428행:

```
s = sub.add_parser("same")
s.add_argument("--files", required=True)
s.add_argument("--raw", action="store_true", help="정규화 없이 바이트 그대로")
```

### 영향
읽는 사람이 `8-보고.md` 54행의 명령 축자대로 실행하면 필수 `--files` 인자가 없다는 오류가 난다. 따라서 후보 65건과 저장소 밖 원문 1,313건을 함께 대조했다는 검사 결과를 재현할 수 없다.

### 보관 심사

최종 판정: 기각
- 심사 1: 기각 · 관문 1에서 기준 인용이 성립하지 않는다. 파견문이 준 기준 원문에는 `--files`가 필수라는 규율이 없다. 심사 대상이 인용한 `C:\Users\wogud\AppData\Local\dag-wt\pvsnp-탐사-1+2.7\.claude\skills\do-dag\scripts\dag_measure.py`는 기준 원문 목록에 없으므로 직접 대조할 수 없다. 관문 3에서도 대체 문면은 후보와 저장소 밖 원문의 경로를 어떤 `--files` 값으로 넘겼는지 적지 않는다. 따라서 영향 칸이 말한 명령 재현 가능성을 회복하지 못한다.
