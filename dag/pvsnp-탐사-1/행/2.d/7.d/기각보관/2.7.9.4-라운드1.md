### 원문

### 위치
`.claude/skills/verify-rounds/scripts/tests/test_심사집계.py` 235~240행의 `test_기각보관_파일_기재`가 기각 보관 본문에서 항목 제목·판정·근거만 검사한다.

### 기준
`C:\math\.sdd\dag\pvsnp-탐사-1\행\2.d\7.d\9.d\4.d\동결.md` 「불변식 목록」은 다음과 같다.

```
시험 목록은 실제 시험 메서드 수와 닫힌 열거를 함께 갱신한다.
```

`.claude/skills/verify-rounds/scripts/tests/test_심사집계.py` 18행의 닫힌 시험 열거는 다음과 같다.

```

```

### 영향
현재 재료에서 `R1-M1`과 `R1-M2`는 병합 항목이다. `cmd_심사집계`는 `항목.md`에서 두 병합 ID를 찾지 못하면 `(항목.md에서 찾지 못함)`을 쓴다. 현행 시험은 그 표식이 있는 보관도 통과시킨다. 따라서 기각 보관의 원문이 빠져도 열두째 시험이 성공한다.

## R1-02

### 원문
제목: 미러 검사가 삭제된 오버레이 기준 해시를 놓친다

### 위치
`.claude/skills/writing-skills/scripts/build_skill_mirrors.py` 172~195행은 현존 오버레이만 순회한다. `--check`는 `_manifest.json`에만 남은 오버레이 기준 해시를 검사하지 않는다.

### 기준
`C:\math\.claude\skills\writing-skills\references\멀티런타임_동기화.md` 「구조」는 다음과 같다.

```
_manifest.json: 오버레이별 정본 기준 해시. 생성기가 관리하며 수기 편집 금지.
```

같은 파일의 「생성기」는 다음과 같다.

```
python .claude/skills/writing-skills/scripts/build_skill_mirrors.py --check    # 무변경 드리프트·낡음 검사 (exit 0 = 정상)
```

### 영향
정본 변환 결과와 같은 오버레이를 생성한 뒤 오버레이 파일만 지우면, 생성물은 정본 변환 결과와 같아서 드리프트가 없다. 그러나 `_manifest.json`에는 지운 오버레이의 기준 해시가 남는다. 현행 `--check`는 exit 0을 반환하므로 생성기가 관리할 기준 해시의 잔존을 정상으로 보고한다.
