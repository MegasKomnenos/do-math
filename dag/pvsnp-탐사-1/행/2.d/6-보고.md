## 병행 자격 판정

단위 이름은 다음과 같다. `L=2.6.1`, `A=2.6.2`, `V1=2.6.3`, `B=2.6.4`, `G=2.6.g1`, `F=2.6.5`, `P=2.6.6`, `V2=2.6.7`, `Z=2.6.z`다. 같은 worktree는 어느 쌍에서도 순차 사유로 쓰지 않았다.

| 단위 쌍 | 쓰기 교집합 | 소비 간선 | 배타 점유 | 배치 |
|---|---|---|---|---|
| `L·A` | 없음 | A는 L의 PASS를 소비한다 | 없음 | 순차 `L→A` |
| `L·V1` | FAIL 시 파견표 편집 가능성이 있으나 동시 실행하지 않는다 | V1은 L의 PASS를 소비한다 | 없음 | 순차 `L→V1` |
| `L·B` | 없음 | B는 L의 PASS를 소비한다 | 없음 | 순차 `L→B` |
| `L·G` | 없음 | G는 L의 PASS를 소비한다 | 없음 | 순차 `L→G` |
| `L·F` | FAIL 시 파견표 편집과 F의 파견표 편집이 겹칠 수 있다 | F는 L의 PASS를 소비한다 | 없음 | 순차 `L→F` |
| `L·P` | 없음 | P는 L의 PASS를 소비한다 | 없음 | 순차 `L→P` |
| `L·V2` | FAIL 시 파견표 편집 가능성이 있으나 동시 실행하지 않는다 | V2는 L의 PASS를 소비한다 | 없음 | 순차 `L→V2` |
| `L·Z` | 없음 | Z는 L 판정 파일을 소비한다 | 메인 인덱스는 Z만 점유한다 | 순차 `L→Z` |
| `A·V1` | V1이 A의 저장소 파일을 수리할 수 있다 | V1은 A 보고와 편집 귀속 전건을 소비한다 | A만 설치 환경을 점유한다 | 순차 `A→V1` |
| `A·B` | 없음 | B는 A 기준선과 보고를 소비한다 | A만 설치 환경을 점유한다 | 순차 `A→B` |
| `A·G` | 없음 | 직접 소비 없음. G는 A를 반영한 결정 파일을 소비한다 | A만 설치 환경을 점유한다 | B를 사이에 둔 순차 |
| `A·F` | 없음 | F는 A 보고를 소비한다 | A만 설치 환경을 점유한다 | G를 사이에 둔 순차 |
| `A·P` | 저장소 기준선·코드·테스트가 겹친다 | P는 A의 코드·로그·기준선을 소비한다 | A만 설치 환경을 점유한다 | 순차 `A→P` |
| `A·V2` | V2가 A의 누적 저장소 파일을 수리할 수 있다 | V2는 A가 만든 누적 변경을 소비한다 | A만 설치 환경을 점유한다 | P를 사이에 둔 순차 |
| `A·Z` | Z가 A 변경을 병합한다 | Z는 A 보고와 diff를 소비한다 | A는 설치 환경, Z는 메인 인덱스를 서로 다른 시점에 점유한다 | 순차 `A→Z` |
| `V1·B` | 없음 | B는 V1 종료보고를 소비한다 | 없음 | 순차 `V1→B` |
| `V1·G` | 없음 | 직접 소비 없음. G는 V1을 반영한 결정 파일을 소비한다 | 없음 | B를 사이에 둔 순차 |
| `V1·F` | 검토전개가 생기면 양쪽이 파견표를 고칠 수 있다 | F는 V1 종료보고를 소비한다 | 없음 | G를 사이에 둔 순차 |
| `V1·P` | V1 수리와 P의 저장소 파일이 겹칠 수 있다 | P는 V1 종료보고를 소비한다 | 없음 | 순차 `V1→P` |
| `V1·V2` | 두 검증런이 누적 저장소 파일을 수리할 수 있다 | V2는 V1 종료보고의 잔여를 소비한다 | 검증 실행은 서로 다른 시점이다 | 순차 `V1→V2` |
| `V1·Z` | 없음 | Z는 V1 종료보고를 소비한다 | 메인 인덱스는 Z만 점유한다 | 순차 `V1→Z` |
| `B·G` | 없음 | G는 B가 쓴 결정 파일을 소비한다 | 없음 | 순차 `B→G` |

| `B·V2` | 없음 | V2는 B가 생산한 게이트 결정의 확정 문면을 소비한다 | 없음 | G·F·P를 사이에 둔 순차 |
| `B·Z` | Z가 결정 파일을 읽기만 한다 | Z는 B 보고와 결정 파일을 소비한다 | 메인 인덱스는 Z만 점유한다 | 순차 `B→Z` |
| `G·F` | G는 쓰기 없음 | F는 G에서 확정된 결정 절을 소비한다 | 없음 | 순차 `G→F` |

| `F·V2` | F가 V2 행 파일을 재작성할 수 있다 | V2는 F 보고와 `F.z`를 소비한다 | 없음 | P를 사이에 둔 순차 |
