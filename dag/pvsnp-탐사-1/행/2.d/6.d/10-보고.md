# 증거 부록

## 1. 재발 조건

저장된 로그의 `where.exe winget`은 exit code 0으로 WindowsApps 별칭을 찾았다. 그러나 별칭 probe는 exit code 127과 `실행 파일 없음: FileNotFoundError`를 냈다. 기존 코드는 이 실패를 `discovery: none`으로 축약했다. MiniSat 탐색은 성공한 `winget` 조회의 `package_id`에 의존했다.

## 2. RED

`python -m unittest experiments.pvsnp.smoke.test_toolchain_smoke.ToolchainSmokeTest.test_windowsapps_alias_probe_failure_is_preserved experiments.pvsnp.smoke.test_toolchain_smoke.ToolchainSmokeTest.test_minisat_fallback_does_not_depend_on_winget_query_success`는 exit code 1을 냈다. 첫 테스트는 기대 `PATH_probe_failed`와 실제 `none`의 차이로 실패했다. 둘째 테스트는 `_find_installed_winget_executable`이 없어 오류가 났다.

## 3. GREEN

같은 회귀 명령은 `Ran 2 tests`, `OK`, exit code 0을 냈다. `python experiments/pvsnp/smoke/test_toolchain_smoke.py`는 `Ran 20 tests`, `OK`, exit code 0을 냈다.

## 4. 최종 로그 생성

`python experiments/pvsnp/smoke/toolchain_smoke.py --evidence-dir experiments/pvsnp/smoke/evidence`를 한 번 실행했다. 명령은 `minisat: PASS`를 포함한 도구 9건의 판정을 출력하고 exit code 0을 냈다. 그 뒤 증거 로그를 다시 쓰지 않았다.

## 5. 최종 읽기 전용 대조

`sat-solvers.txt`의 `candidate_status` 값은 `PASS`다. `solvers.minisat.status`는 `PASS`다. `solvers.minisat.package_queries[0].stdout`은 `minisat PolarGoose.minisat 2.2`를 담는다. `solvers.minisat.executable`은 `%LOCALAPPDATA%\Microsoft\WinGet\Packages\PolarGoose.minisat_Microsoft.Winget.Source_8wekyb3d8bbwe\minisat.exe`다. SAT 명령은 그 실행 파일과 `%TEMP%\sat.cnf`를 호출해 exit code 10을 냈다. UNSAT 명령은 같은 실행 파일과 `%TEMP%\unsat.cnf`를 호출해 exit code 20을 냈다. 광범위 검색은 패키지 80건과 미해소 79건을 기록했다.

읽기 전용 구조 대조는 최종 로그, 저장소 기준선, 런 기준선에서 위 값을 전건 확인했다. 대조 스크립트는 `log: true`, `repo: true`, `run: true`, exit code 0을 냈다. `dag_check.py --table C:\math\.sdd\dag\pvsnp-탐사-1\파견표.md`는 `무발견`과 exit code 0을 냈다.
