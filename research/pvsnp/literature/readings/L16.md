## P vs NP 탐사와의 접점

| ID | 탐사에서 소비할 결론 | 원문 결속 |
|---|---|---|
| E1 | 이 문헌은 \(\mathrm{P}\ne\mathrm{NP}\)나 \(\mathrm{P}=\mathrm{NP}\)를 지지하는 증거가 아니다. 탐사는 후보 증명이 Definition 2.3의 대수적 오라클 치환에도 유지되는지를 따로 검사해야 한다. | PDF p. 9, Definition 2.3; PDF pp. 23–24, Theorems 5.1, 5.3 |
| E2 | 분리 증명 후보와 포함 증명 후보에는 서로 다른 반증 오라클을 적용한다. \(\mathrm{P}\ne\mathrm{NP}\) 후보에는 \(\mathrm{NP}^{\widetilde A}\subseteq\mathrm P^A\)를, \(\mathrm{P}=\mathrm{NP}\) 후보에는 \(\mathrm{NP}^A\not\subset\mathrm P^{\widetilde A}\)를 대조한다. | PDF pp. 9, 23–24, Definition 2.3, Theorems 5.1, 5.3 |
| E3 | 후보가 산술화를 쓴다는 사실만 기록하지 않는다. 산술화 뒤 저차 다항식을 임의 블랙박스로만 쓰는 단계가 있는지를 식별해야 대수화 장벽과 결속된다. | PDF pp. 4–6, §1.3; PDF p. 46, §11 |
| E4 | 산술화와 대각선화를 함께 썼다는 사실도 장벽 회피를 보장하지 않는다. 논문의 회로 하한 세 개는 두 옛 장벽을 피하지만 여전히 대수화된다. | PDF pp. 2–4, §1.1–§1.2; PDF pp. 15–16, Theorems 3.16–3.18 |
| E5 | 대수적 오라클 붕괴와 분리는 실제 복잡도 계급 포함의 증거로 쓰지 않는다. 탐사는 이 결과를 증명 기법의 안정성 검사로만 소비한다. | PDF p. 9, Definition 2.3; PDF pp. 23–29, §5 |
| E6 | 후보가 산술화된 작은 공식의 생성 구조를 이용한다면, 단순 저차 블랙박스 기법과 구별해 기록한다. 저자들이 제안한 장벽 밖 방향이 바로 그 추가 구조의 이용이다. | PDF p. 24, §5.2 첫 문단; PDF pp. 45–46, §11(2) |
| E7 | 질의 하한을 옮길 때 다중선형과 다중이차를 구분한다. OR의 직접 하한은 다중차수 2를 쓰지만, 통신 전이 하한은 유일한 다중선형 확장에도 적용된다. | PDF pp. 18–23, Theorems 4.4, 4.9, 4.11–4.12 |
| E8 | 블랙박스 탐색 주장에는 Lemma 4.5식 적대 구성을 대조한다. 질의 이력과 일치하는 확장들이 불리언 큐브에서 다른 답을 가질 수 있는지 검사하는 틀이다. | PDF pp. 19–20, Lemma 4.5; PDF pp. 23–24, Theorem 5.3 |
| E9 | 대수적 질의 하한을 직접 세우기 어렵다면 통신 복잡도 하한으로 전이할 수 있다. 다만 전이된 오라클 분리는 원래 \(\mathrm{P}\) 대 \(\mathrm{NP}\) 명제의 판정이 아니다. | PDF pp. 21–23, Theorems 4.11–4.12; PDF pp. 27–29, Theorem 5.11 |
| E10 | 회로 하한 탐사는 \(\mathrm{PromiseMA}\)에서 \(\mathrm{NP}\)로의 이동을 기술 경계로 기록한다. 당시 기법은 \(\mathrm{PromiseMA}\)의 초선형 회로 하한을 대수화해도, \(\mathrm{NP}\)의 같은 하한에는 비대수화 기법이 필요하다. | PDF pp. 3–4, §1.2; PDF pp. 15–16, Theorem 3.18; PDF p. 27, Theorem 5.6 직후 |
| E11 | 상수 번 재귀 산술화와 다항 차원 행렬 대수는 \(\mathrm{P}\ne\mathrm{NP}\) 후보의 충분한 탈출 근거가 아니다. 후보가 이 틀만 넓힌다면 Theorems 10.2와 10.5를 다시 대조한다. | PDF pp. 42–45, §10.1–§10.2, Theorems 10.2, 10.5 |
| E12 | 이 문헌이 남기는 양의 연구 방향은 완성된 비대수화 기법이 아니다. 작은 불리언 공식에서 생긴 다항식의 구조, 새로운 대수 구조, 대수적 오라클 분리의 열린 문제를 탐사 후보군으로 남긴다. | PDF pp. 45–47, §11(1)–(5) |
