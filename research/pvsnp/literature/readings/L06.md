## 읽은 범위와 좌표 규칙

이 재판독은 PDF pp.1–16 전건을 읽었다. PDF 텍스트 레이어와 같은 PDF의 전 페이지 렌더를 대조했다. 텍스트 레이어에서 깨진 수학 글꼴은 페이지 렌더로 확인했다.

- `PDF p.n`은 파일 안의 물리 쪽번호다.
- `원문 p.n`은 저널에 인쇄된 쪽번호다.

## P vs NP 탐사와의 접점

| ID | 탐사 접점 | 원문 결속 |
|---|---|---|
| E01 | `TAUT`의 결정적 다항시간 판정은 $P=NP$와 연결된다. `TAUT`의 다항 길이 증명 존재는 $\mathrm{TAUT}\in NP$와 연결된다. 탐사에서는 두 문턱을 분리해야 한다. | 원문 pp.36–38, §1의 복잡도 동기, 명제 1.1, 정의 1.3, 명제 1.4 |
| E02 | 일반 증명 시스템의 다항 제한성을 보이거나 부정하는 문제는 $NP$의 여집합 폐쇄 문제로 이어진다. 따라서 명제 증명 복잡도는 P 대 NP 탐사의 보조 축이지만, 같은 명제는 아니다. | 원문 p.38, 명제 1.4 뒤 첫 문단; 원문 p.37, 명제 1.1 |
| E03 | 증명 시스템 하한을 주장하려면 일반 증명 시스템, 통상적 증명 시스템, 특정 규칙 시스템을 구분해야 한다. 원문은 일반 시스템의 자연성을 보장하지 않으며 제한 시스템의 하한만 별도 문헌에 둔다. | 원문 pp.38–39, 명제 1.4 뒤 두 문단과 §1의 통상적 시스템 부호화; 원문 p.36, §1 둘째 문단 |
| E04 | 한 시스템의 다항 제한성을 다른 시스템으로 옮기려면 p-시뮬레이션이 필요하다. 단순한 증명 길이 비교만으로는 계산 가능한 번역 조건이 닫히지 않는다. | 원문 p.38, 정의 1.5와 명제 1.6 |
| E05 | 같은 연결사 집합 위의 Frege·자연 연역 시스템은 p-시뮬레이션 등가다. 이 범위 안에서는 공리 스키마나 자연 연역 표기의 선택만 바꿔 다항 제한성 문제를 피할 수 없다. | 원문 p.40, 따름정리 2.4; 원문 p.42, 따름정리 3.4 |
| E06 | 증명 복잡도 실험과 보조정리는 줄 수 $\lambda$, 최대 줄 길이 $\rho$, 전체 문자열 길이를 분리해야 한다. 확장 규칙은 줄 수를 크게 줄이지 않아도 수식 길이의 지수 팽창을 없앨 수 있다. | 원문 p.39, §1 마지막 길이 표기; 원문 pp.43–45, 비둘기집 예시와 명제 4.3 |
| E07 | 확장 Frege에서는 연결사 집합을 바꿔도 줄 수 상한을 옮길 수 있다. 정리 4.6은 줄 수 상한이 있으면 최대 줄 길이도 입력 수식 길이의 상수배로 정규화할 수 있음을 보인다. | 원문 p.45, 정리 4.5와 4.6 |
| E08 | 비둘기집 원리 예시는 반복 치환이 만든 표현 팽창과 증명 논리의 난도를 구별한다. 탐사에서 큰 중간 수식만 관찰한 결과를 증명 하한으로 쓰면 안 된다. | 원문 pp.43–45, §4 비둘기집 예시와 명제 4.3 뒤 문단 |
| E09 | 치환 Frege는 확장 Frege를 p-시뮬레이션한다. 역방향은 증명되지 않았으므로 두 체계를 같은 강도로 취급할 근거는 이 원문에 없다. | 원문 p.49, 정리 5.3과 직전 문단 |
| E10 | Frege 또는 자연 연역 한 체계에 대한 다항 제한성 결과는 같은 표현 조건의 다른 체계로 전달된다. 확장 Frege 한 체계의 결과는 모든 연결사 집합의 확장 Frege 체계로 전달된다. 탐사 산출은 이 전달 범위를 적어야 한다. | 원문 p.40, 따름정리 2.4; p.42, 따름정리 3.4; p.45, 따름정리 4.7 |
