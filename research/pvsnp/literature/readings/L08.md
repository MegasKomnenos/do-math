## P vs NP 탐사와의 접점

| ID | 탐사에서 소비할 접점 | 원문 결속 | 소비 제한 |
|---|---|---|---|
| E1 | \(P\ne NP\)를 가정하면 \(NP-P\)에는 다항시간 튜링 완전하지 않은 언어가 존재한다. 다대일 환원은 튜링 환원의 특수한 경우이므로 이 언어는 다항시간 다대일 완전하지도 않다. | PDF 2–3쪽/저널 156–157쪽, 환원 관계; PDF 5쪽/저널 159쪽, 따름정리 1.1 | 조건부 존재 정리다. \(P\ne NP\)의 증거로 쓰지 않는다. |
| E2 | P vs NP 가정은 정리 1의 대각화 자체가 아니라 \(B\in NP-P\)를 고르는 데 쓰인다. 정리 1은 계산 가능한 모든 \(B\notin P\)에 적용된다. | PDF 4–5쪽/저널 158–159쪽, 정리 1·따름정리 1.1 증명 | 정리 1과 따름정리 1.1의 전제를 합치지 않는다. |
| E3 | 따름정리 1.1에서 얻는 중간 언어는 \(A=B\cap D\) 꼴로 볼 수 있고 \(D\in P\)다. 완전 문제의 입력을 다항시간 판정 영역으로 잘라 중간 언어를 만드는 구조를 제공한다. | PDF 4쪽/저널 158쪽, 정리 1 증명; PDF 6쪽/저널 160쪽, 정리 2 직전 문단 | \(D\)의 존재가 \(A\)의 다항시간 판정 알고리즘을 주지는 않는다. |
| E4 | 정리 2는 하나의 어려운 언어를 다항시간 판정 집합으로 나눠 환원 비교가 불가능한 두 부분을 만든다. \(P\ne NP\)를 붙이면 \(NP\) 안의 비교 불가능 쌍과 유리수 색인 계층을 얻는다. | PDF 6–7쪽/저널 160–161쪽, 정리 2·따름정리 2.4·2.5 | 자연 언어의 실제 비교 불가능성을 판정한 결과가 아니다. |
| E5 | 정리 1–4는 다항시간 기계의 효과적 열거, 길이 단계, 유한 대각화 요구를 결합한다. 탐사에서 비슷한 구성을 쓰려면 구성 함수의 자원 상계와 결과 언어의 복잡도 소속을 따로 증명해야 한다. | PDF 3–5쪽/저널 157–159쪽, 효과적 열거·정리 1 증명; PDF 8–12쪽/저널 162–166쪽, 정리 3·4 증명 | 구성의 계산 가능성과 다항시간 계산 가능성을 같은 것으로 취급하지 않는다. |
| E6 | 조밀성은 엄격한 두 계산 가능 degree 사이에 다른 degree가 존재함을 보인다. 최소쌍과 비격자성은 환원 순서가 단일 난이도 축이나 격자로 정리되지 않음을 보인다. | PDF 7쪽/저널 161쪽, 따름정리 2.3; PDF 7–13쪽/저널 161–167쪽, 정리 3·4와 따름정리 4.1 | 이 구조 정리들은 \(P\)와 \(NP\)의 동일성 여부를 판정하지 않는다. |
| E7 | 원문이 \(NP\)에 직접 결속하는 결과는 따름정리 1.1과 2.4·2.5다. 정리 3·4의 최소쌍과 비격자성 대상을 \(NP\) 내부라고 옮기면 원문을 넘는다. | PDF 5쪽/저널 159쪽, 따름정리 1.1; PDF 7쪽/저널 161쪽, 따름정리 2.4·2.5와 정리 3; PDF 10쪽/저널 164쪽, 정리 4 | 전체 계산 가능 degree와 \(NP\) 내부 결과를 분리한다. |
| E8 | 시간·공간 일반화는 지연 대각화의 구조가 적절한 하위재귀 환원에서도 유지됨을 보여 준다. | PDF 13–17쪽/저널 167–171쪽, 6절·정리 5·보조정리 6·정리 7 | `time class`와 `space class`의 공종·합성 조건을 생략하지 않는다. |
| E9 | GRAPH ISOMORPHISM, NONPRIMES, LINEAR INEQUALITIES에 관한 문장은 1975년의 미해결 상태와 추측을 기록한다. | PDF 5–7쪽/저널 159–161쪽, 따름정리 1.1 뒤 논평·따름정리 2.4 뒤 논평 | 현재 상태의 근거로 소비하지 않는다. |
