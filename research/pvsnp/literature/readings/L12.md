## 반증 대조

앞선 `records/` 본문, `source-ledger.md`의 판독 열, 앞선 판독 보고는 열지 않았다. 따라서 이 절은 앞선 판독과 내용 비교를 하지 않는다. 아래 표는 이번 정리에서 생길 수 있는 과잉 해석을 원문에 대조한다.

| ID | 기각한 과잉 해석 | 원문 대조와 판정 | 원문 좌표 |
|---|---|---|---|
| H1 | 논문이 $P\ne NP$ 또는 ETH를 증명한다. | **기각**. 논문은 ETH를 가정하고, 준지수 알고리즘의 존재 여부를 열린 질문으로 둔다. | PDF p.1–p.2 / 인쇄 p.367–p.368 / 초록과 ETH 정의 뒤 문단 |
| H2 | $s_k<s_{k+1}$가 모든 $k$에서 성립한다. | **기각**. ETH 아래 결론은 각 $k$보다 큰 어떤 $k'$가 있고 엄격한 증가가 무한히 여러 번 나타난다는 것이다. | PDF p.3 / 인쇄 p.369 / 주결과 개요 마지막 문단 |
| H3 | 주환원이 절 너비를 낮춘다. | **기각**. 개요의 환원은 $k'\ge k$다. $k'<k$인 유용한 환원은 공개 문제다. | PDF p.3 / 인쇄 p.369 / 환원 개요; PDF p.8 / 인쇄 p.374 / Open Problems 1항 |
| H4 | 환원이 하나의 더 작은 CNF를 만든다. | **기각**. 출력은 여러 $k'$-CNF의 논리합이며, 분기 수의 지수 비용이 시간식에 들어간다. | PDF p.3 / 인쇄 p.369 / 환원 개요; PDF p.7 / 인쇄 p.373 / Theorem 2 |
| H5 | Lemma 1이 임의의 일반 $k$-CNF에 바로 적용된다. | **기각**. Lemma 1은 유일 만족식을 가정한다. 일반식에는 Lemma 2와 낮은 무게 탐색을 결합한다. | PDF p.5 / 인쇄 p.371 / Lemma 1; PDF p.7–p.8 / 인쇄 p.373–p.374 / Lemma 2·Theorem 3 |
