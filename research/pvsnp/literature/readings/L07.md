## 읽은 범위와 좌표 규칙

지급 HTML의 물리 1–408행을 전수 구조 판독했다. 내용 주장은 아래 구간을 다시 문장 단위로 읽어 결속했다.

| 구간 | 읽은 범위 | 역할 |
|---|---|---|
| S1 | HTML L1–L107, 특히 L26–L38 | 문자 인코딩, 제목, 정본 URL, 페이지 메타데이터 |
| S2 | HTML L108–L306, 특히 L252–L265 | 사이트 머리말과 밀레니엄 문제 탐색 구조. P vs NP 항목은 L261에 있다. |
| S3 | HTML L308–L353, 특히 L311과 L319–L344 | 이동 경로, 본문 제목, 두 문단, 세 항목의 순서 목록 |
| S4 | HTML L355–L408 | 바닥글, 스크립트, 문서 종료 구조 |

`HTML Lx`는 지급 HTML을 UTF-8로 읽었을 때의 1부터 시작하는 물리 행 번호다. 한 행에 여러 HTML 태그가 있어도 행 번호를 나누지 않는다. 인용문은 태그를 제거하고 `&nbsp;`를 보통 공백으로 바꾼 렌더 텍스트다.

본문 L319–L344는 제목 하나, 문단 두 개, 목록 항목 세 개로 이루어진다. 세 번째 목록 항목은 결합 조건 세 개를 한 행에 둔다. 아래 정리는 이 구조를 C1–C8, Q1–Q7, I1–I8, E1–E7로 나눈다. 항목 수는 여덟 개의 독립 명제 단위를 구별하되, 짧은 안내 페이지를 대체하지 않도록 정했다.

지급 실물은 HTML뿐이다. HTML L324가 연결하는 PDF는 읽은 범위에 포함하지 않았다. 따라서 이 기록은 PDF의 절 구성이나 세부 규칙을 설명하지 않는다.

## P vs NP 탐사와의 접점

| ID | 접점 | 원문 좌표 |
|---|---|---|
| E1 | 이 페이지는 밀레니엄 문제 전반의 상금 규칙을 다룬다. 사이트의 같은 탐색 구조는 P vs NP를 밀레니엄 문제 항목으로 열거한다. 따라서 P vs NP 해법 주장에도 이 페이지의 절차 안내가 닿는다. | HTML L252–L265, L321 |
| E2 | 탐사 산출이 제안된 해법을 주장하더라도 그 해법을 CMI에 직접 제출하는 경로는 없다. | HTML L333 |
| E3 | CMI의 고려에 앞선 원문상 관문은 적격 출판처의 출판, 출판 후 최소 2년, 세계 수학계의 일반적 수용이다. 세 관문은 `and`로 결합된다. | HTML L341 |
| E4 | 탐사 단계의 내부 문서, 계산 실험, 검증런만으로 적격 출판처 조건이나 일반적 수용 조건을 충족했다고 판정할 근거는 이 HTML에 없다. | HTML L341 |
| E5 | 세 절차 조건의 충족 여부와 P vs NP 해법의 수학적 정당성은 구분해야 한다. 이 HTML은 CMI가 “고려”하기 전의 절차만 말한다. | HTML L341 |
| E6 | 후속 작업이 적격 출판처를 판정하려면 연결된 규칙 문서의 §6 원문이 별도로 필요하다. 지급 HTML의 §6 표지는 정의가 아니라 교차 참조다. | HTML L324, L341 |
| E7 | 이 페이지는 P vs NP 공격 방향이나 증명 장벽의 근거가 아니다. 탐사에서 이 페이지를 쓰는 범위는 상금 절차와 제출 경계다. | HTML L321–L341 |
