## P vs NP 탐사와의 접점

| ID | 접점 | 원문 결속 |
|---|---|---|
| E1 | 이 문헌은 $P$, $NP$, 다항시간 many-one 환원, NP-hard, NP-complete를 한 튜링 기계 모형 안에서 정의한다. 행 2.8은 다른 문헌의 계산 모형과 환원 방향을 이 정의에 맞춰 비교할 수 있다. | C6–C8; §3.1, PDF p.368–369 |
| E2 | $P\subseteq NP$와 “NP-완전 언어 $L$이 $P$에 속함 iff. $P=NP$”가 형식화되어 있다. 따라서 이 문헌에서 P vs NP의 직접 관문은 SAT의 다항시간 결정 가능성이다. | C9; `P-subseteq-NP`, `NP-complete-imp`, PDF p.375–378 |
| E3 | 최종 정리 `NP-complete-SAT`는 SAT를 관문으로 만들지만 SAT의 다항시간 알고리즘이나 초다항 하한을 주지 않는다. NP-완전성 자체를 $P\ne NP$의 증거로 쓰면 안 된다. | C22, Q13; PDF p.873–874 |
| E4 | 환원은 인증서 검증 계산을 지역적 스냅샷 제약으로 바꾸는 구조를 상세히 분해한다. 탐사에서 새로운 부호화나 환원을 제안하면 (Y0)–(Y7), (Z0)–(Z5), $\Phi_0$–$\Phi_9$에 대응하는 완전성과 양방향 정확성을 점검할 수 있다. | C16–C19; PDF p.605–651 |
| E5 | 망각형 시뮬레이션은 머리 위치를 입력 내용에서 분리한다. 계산 이력을 CNF로 부호화할 때 주소 함수가 인증서 값에 의존하지 않게 만드는 연결 고리다. | C14–C16, Q10; PDF p.428–429, 475–476, 600–626 |
| E6 | 형식화는 모형 변화와 부호화 변화를 다항시간 안에서 닫는다. 다른 문헌의 결과를 연결할 때 “표현이 다르다”는 사실만으로 복잡도 계급이 달라진다고 결론 내리지 않도록 하는 비교 기준이 된다. | C4–C5, C11, C14, C21; PDF p.22–33, 387–390, 475–602, 811–873 |
| E7 | 이 문헌의 SAT는 비정상 문자열을 예 인스턴스로 포함한다. 다른 SAT·CNF 문헌과 환원식을 결합하기 전에 정상 부호화 집합과 비정상 입력의 처분을 대조해야 한다. | C12, Q9; `SAT`, PDF p.389–390 |
| E8 | $\Psi$·$\Psi'$의 지수 크기는 입력과 무관한 고정 검증기 상수로 흡수된다. 입력 크기에 따라 검증기나 알파벳을 바꾸는 탐사 제안에는 같은 다항시간 논증을 그대로 적용할 수 없다. | Q11; PDF p.620–622, 870–872 |
| E9 | 110테이프·60단계 환원 기계는 존재와 다항시간성을 형식적으로 닫지만 실용 SAT 변환기의 성능 근거는 아니다. 실험 결과와 최악 경우 복잡도 주장을 분리해야 한다. | C21, Q12; PDF p.811–873 |
| E10 | 장벽 용어와 회로 하한은 원문 범위 밖이다. 이 문헌은 Cook–Levin 환원의 형식 검증 근거로 쓰고, relativization·natural proofs·algebrization 회피 근거로 쓰지 않는다. | Q14; PDF p.1–875 전수 텍스트 검색 |
