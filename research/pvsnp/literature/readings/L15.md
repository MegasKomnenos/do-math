## 읽은 범위와 좌표 규칙

원문 50쪽 전부를 읽었다. PDF의 1번째 이미지에는 인쇄 쪽수 1이 있고, 이후에도 PDF 이미지 번호와 인쇄 쪽수가 50까지 일치한다. 아래 `p.`와 `pp.`는 이 1기준 원문 쪽수를 뜻한다. `§`는 원문의 절 번호를 뜻한다. `Definition`, `Theorem`, `Lemma`, `Proposition`, `Corollary` 번호는 원문 번호를 그대로 쓴다.

이 문서에서 \(A\)는 Boolean oracle을 뜻한다. \(\widetilde A\)는 주로 유한체 위 저차 확장 oracle을 뜻한다. \(\widehat A\)는 정수 위 확장 oracle을 뜻한다. 원문은 포함 \(\mathcal C\subseteq\mathcal D\)와 분리 \(\mathcal C\nsubseteq\mathcal D\)에 서로 다른 algebrization 방향을 정의하므로 두 방향을 바꾸지 않는다(§2, Definition 2.3, p.9).

## P vs NP 탐사와의 접점

| ID | 탐사에서 소비할 접점 | 원문 결속 |
|---|---|---|
| E01 | 후보 증명은 결론만 검사해서는 안 된다. 후보 증명의 핵심 단계가 모든 \(A,\widetilde A\)에서 Definition 2.3의 방향을 보존하는지도 검사한다. 보존하면 후보 증명은 이 논문의 장벽 안에 남는다. | Definition 2.3, p.9; Theorems 5.1·5.3, pp.23–24 |
| E02 | \(P\ne NP\) 방향은 \(NP^{\widetilde A}\subseteq P^A\)인 collapse oracle이 막는다. \(P=NP\) 방향은 \(NP^A\nsubseteq P^{\widetilde A}\)인 separation oracle이 막는다. 두 방향을 하나의 “oracle 반례”로 합치지 않는다. | Theorems 5.1·5.3, pp.23–24 |
| E03 | arithmetization으로 Boolean 공식을 저차 다항식으로 바꾼 뒤 저차성만 이용하는 후보는 장벽의 직접 표적이다. 탐사 기록은 공식의 작은 회로 구조나 생성 경로를 실제로 이용하는 단계를 따로 표시한다. | §1.1, p.2; §11, pp.45–46 |
| E04 | \(IP=PSPACE\)나 \(MIP=NEXP\)를 호출했다는 사실은 장벽 회피 증거가 아니다. 이 논문은 두 결과가 algebrize함을 보인다. | Theorems 3.7·3.8, pp.13–15 |
| E05 | \(MA_{EXP}\nsubseteq P/poly\)와 \(PromiseMA\nsubseteq SIZE(n^k)\) 같은 기존 하한을 NP·NEXP 하한으로 밀어붙일 때는 새 비algebrizing 단계가 어디에 있는지 요구한다. 기존 하한 자체는 algebrize한다. | Theorems 3.17–3.18, pp.15–16; Theorem 5.6, pp.26–27 |
| E06 | 비Boolean 점 질의에서 얻은 “전역 단서”가 OR witness를 드러낸다는 주장은 multiquadratic 적대 확장으로 반박될 수 있다. 유한 실험은 Lemmas 4.3·4.6의 적대 확장 조건을 구현한 반례 탐색으로만 사용한다. | §4.2, Lemmas 4.3·4.6과 Theorems 4.4·4.9, pp.18–21 |
| E07 | multilinear 확장은 multiquadratic 확장과 구별한다. 전자에서는 합이 한 번의 질의로 드러날 수 있으므로, 후자의 OR 하한을 전자에 적용하지 않는다. | §1.4, p.7; Theorem 4.4 직후, p.19 |
| E08 | 적은 수의 multilinear 대수 질의를 쓰는 후보 알고리즘은 통신 protocol로 변환해 검사할 수 있다. 알려진 통신 하한과 충돌하면 후보의 질의 상한이나 성공 보장이 잘못되었다. | Theorems 4.11–4.12, pp.21–23 |
| E09 | 유한체를 정수로 바꾸는 것만으로 장벽을 피했다고 판정하지 않는다. 통신 기반 장벽은 정수에도 옮겨가며, 직접 구성은 출력 크기 문제 때문에 일부만 옮겨간다. | §6, pp.29–35 |
| E10 | 반복 arithmetization을 상수 횟수 적용하는 후보는 \(P=NP\) 증명에 부족하다. 반복 횟수가 입력에 따라 커지는 방법은 Theorem 10.2의 직접 적용 범위 밖이므로 별도 분석한다. | §10.1, Theorem 10.2와 직후 문단, p.43 |
| E11 | 다항 차원의 행렬·quaternion·Clifford형 결합대수로 값을 올리는 것만으로는 회피가 성립하지 않는다. 후보가 비가환 대수를 쓰면 차원과 결합성·항등원 전제를 대조한다. | §10.2, pp.43–45 |
| E12 | 탐사의 유망한 회피 지점은 arithmetization이 만든 다항식의 저차성 외 구조를 이용하는 단계다. 원문은 작은 3SAT 공식에서 나온 확장으로부터 공식을 회수할 수 있는 예를 제시하지만, 일반 회피법은 열린 문제로 둔다. | §11 항목 (2)와 각주 16, p.46 |
| E13 | 이 문헌은 \(P=NP\)나 \(P\ne NP\)를 증명하지 않는다. 탐사 산출은 oracle 장벽, 조건부 함의, 실제 계급 분리를 분리해 기록한다. | Definition 2.3, p.9; §§5.1, 7.1, pp.23–24, 36–37; §11, pp.45–47 |
