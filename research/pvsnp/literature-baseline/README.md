# P vs NP 문헌조사 작업대

이 디렉터리는 실제 연구 전에 현대 수학과 이론 컴퓨터과학 전 분야의 문헌을 조사해 하나의 닫힌 집합으로 만드는 작업대다. 조사 규범은 [`../문헌-체계-명세.md`](../문헌-체계-명세.md)가 소유한다.

## 지금 할 일

현재 상태는 [`STATUS.md`](STATUS.md)에 있다. 지금 사용자에게 열린 조사 묶음은 없다.

B002는 MathSciNet에서 MSC2020의 63개 대분류별 기준 전거 후보 6,233건을 확보하고 닫혔다. AI는 이를 MR 키 기준 5,472개 고유 후보와 378개 관계 후보 묶음으로 정규화했다. 다음 단계는 분야별 실제 후보를 공개 자료원의 제목·초록·분류·venue·판본과 대조해 기준 핵심층과 누락 후보를 선별하는 일이다. 현재 사용자 행동과 인증 B003 묶음은 없다.

## 협업 순환

1. AI가 현재 조사 묶음을 작성한다.
2. 승인된 로컬 프로그램 또는 사용자가 인증 DB에서 지침을 실행하고 원시 파일을 투입한다.
3. AI가 파일을 직접 검사하고 정규화·중복 제거·누락 분석을 한다.
4. AI가 필요한 보충 묶음 하나를 열거나 조사 완료를 판정한다.

사용자는 문헌 요약, 분류, 파일명 정리, 중복 제거와 manifest 작성을 하지 않는다. 대화가 끊기면 `STATUS.md`와 현재 묶음에서 재개한다.

## 저장 경계

- `intake/`: DB가 만든 원시 export와 검색 증거. Git 비추적.
- `originals/`: 후속 선별 뒤 확보한 원문·코드·데이터. Git 비추적.
- `catalog/`, `manifests/`, `reports/`: AI가 만드는 추적 산출물.

크리덴셜, 세션 토큰과 개인 식별 정보는 어느 조사 파일에도 넣지 않는다.
