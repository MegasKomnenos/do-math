# 전 분야 검색표

## 1. 사용법

이 표는 조사 범위를 줄이지 않으면서 먼 분야의 선행 조사를 반복 가능한 검색으로 바꾼다. 수학 분야는 MSC2020 두 자리 분류 전건을 사용한다. 각 분야의 `-00`, `-01`, `-02`는 일반 참고자료·입문 해설·연구 종합을 찾는 첫 검색이고, `-04`, `-06`, `-08`, `-10`, `-11`은 소프트웨어·학회집·계산 방법·모형·자료를 찾는 후속 검색이다. 실제로 존재하는 코드만 표에 넣었다.

첫 전 분야 묶음은 `기준 핵심층 코드`를 MathSciNet과 zbMATH Open에서 검색한다. AI가 결과를 읽은 뒤 계산·구조 연결이 유효한 분야에만 `계산·모형·자료 코드` 검색을 연다. 직접·인접 분야는 그 결과에서 확인한 3자리·5자리 하위 분류로 세분한다.

정적 입력은 [MSC2020 공식 CSV](https://msc2020.org/MSC_2020.csv)이며, 2026-09-04에 회수한 파일의 SHA-256은 `f7c889354c202551fe01f89bad2ae95ccadec4c57ac1f6f9de38bbd658d3c78c`다.

## 3. 이론 컴퓨터과학 씨앗

[ACM CCS 2012](https://www.acm.org/publications/class-2012)의 `Theory of computation`과 `Mathematics of computing`을 주 축으로 사용한다. 계산 이론의 하위 주제뿐 아니라 다른 ACM CCS 분야에서 이론·하계·형식 의미가 있는 가지도 포함한다. 이 분류는 MSC `68`을 대체하지 않고 독립적으로 누락을 찾는다.

[arXiv category taxonomy](https://arxiv.org/category_taxonomy)는 다음 범주를 첫 씨앗으로 사용한다. 이 목록은 조사 범위를 닫지 않는다.

| 범주 | 조사 역할 |
|---|---|
| `cs.CC` | 계산 모형, 복잡도 계급, 상·하계, 구조 복잡도 |
| `cs.DS`, `cs.DM` | 알고리즘·자료구조, 이산수학·조합론 |
| `cs.FL`, `cs.LO` | 형식언어·오토마타, 논리·기술 복잡도 |
| `cs.CR` | 암호학, 평균 경우 난이도와 P vs NP 경계 |
| `cs.IT` | 정보·부호 이론과 복잡도 연결 |
| `cs.GT` | 알고리즘 게임이론·계산경제학 |
| `cs.PL`, `cs.PF` | 프로그램 의미·형식 방법, 계산 성능 이론 |
| `cs.SC`, `cs.NA` | 기호·대수 계산과 수치 계산의 복잡도 |
| `cs.CG`, `cs.DC` | 계산기하, 분산·병렬 계산의 이론 |
| `cs.LG`, `stat.TH`, `quant-ph` | 학습·통계·양자 계산의 고전 P vs NP와 다른 경계 |

## 4. P vs NP 직접 세분 씨앗

직접 영역은 검색 결과를 바탕으로 적어도 다음 방향을 구분한다. 이 목록은 하위 영역을 닫지 않는다.

- 계산 모형, 부호화, 시간·공간 복잡도
- P·NP·coNP, 환원, 완전성, 구조 복잡도와 계층
- 회로 복잡도와 하계, meta-complexity
- 증명 복잡도
- 무작위성·의사난수성·derandomization
- SAT·CSP, 정확·지수시간·fine-grained·매개변수 복잡도
- PCP와 근사 난이도
- 대수적 복잡도·산술 회로·geometric complexity theory
- 기술 복잡도·유한모형이론·논리적 특성화
- 통신·질의·정보 복잡도와 자료구조 하계
- 암호학·평균 경우 난이도·one-way functions
- 상대화·natural proofs·algebrization와 추가 장벽
- 양자·무작위·비균일 계산과 핵심 목표의 범위 차이
- 형식 증명·코드·계산 자료
