- 루트 확인: KUDOS 홈페이지는 `/pages/index.htm`으로 이동한다. 초기 DOM이 비어 있을 수 있다. 로그인 완료 뒤 `로그아웃` 링크를 확인했고, 보호된 bootstrap 상태를 새 context에서 재사용해 인증 유지도 확인했다.

- g08 발견·루트 독립 확인: Connes의 1994년 책에 잘못 붙은 47쪽 PDF는 Connes·van Suijlekom의 `Spectral Truncations in Noncommutative Geometry and Operator Systems`, DOI `10.1007/s00220-020-03825-x`, 2020년 온라인/2021년 권호 논문이었다. 제목 부분일치와 본문 저자 언급으로는 판본을 결박할 수 없다. 반례는 `intake/kudos-recovery/g08/VER-299d3105cede6b2302ad9759/`의 최초 `publisher.txt`, `fulltext.pdf`와 결과의 `rejected_other_work`에 보존되어 있다.
- 루트 발견·g05 수리: Lee의 올바른 15쪽 PDF도 텍스트 레이어의 초록에 OCR 오류가 있었다. 루트는 `intake/kudos-recovery/operator/lee-first-page.png`로 실제 첫 면을 대조했고 g05가 초록을 이미지 기준으로 교정했다. 원시 OCR과 교정문, 품질 표지를 함께 보존한다. PDF의 바이트·쪽수 검증은 추출 텍스트의 정확성을 대신하지 않는다.

- g05 제기·루트 대조: Sipser 1992 논문은 인쇄 첫 면에서 Significance 절로 시작하지만 Summon은 그 도입부에 기반한 완결된 서지 초록을 제공한다. 이 값은 저자 원문과 구별한 `database_indexing_abstract`로 보존할 수 있다. 제공 출처와 작성 주체는 구별한다. 단순 인용, 잘린 snippet, 다른 문헌의 내용은 필드명만으로 초록이 되지 않는다.
- g02 발견: 동적 검색 화면을 같은 파일명에 덮어쓰면 이전 evidence의 해시가 무효가 된다. 내용이 바뀌는 캡처는 해시가 포함된 새 파일명으로 보존하고, 결과 JSON의 갱신과 원자료의 보존을 구별한다. 이전 오류 자료도 회귀 테스트와 철회 근거가 쓰는 동안 유지한다.
- 루트·새 g05 확인: Atallah 논문의 실제 첫 면 인쇄 서지는 JACM38(3), July1991, pp516–533이고 Goldreich/Micali/Wigderson 논문은 같은 권호·시기 pp691–729다. 원입력의 페이지 범위와 다르므로 원입력을 보존하고 관측 서지의 차이를 기록한다. 실제 첫 면은 각 `VER-e84f6654b69722fc19148fa5`, `VER-fbb80c52fb3b9ca8caaa8e87` 폴더의 `pending-first.png`에 있다.
- 루트 발견·새 g02 수리: `VER-03d4f40f5e02f445ed375c27`의 Gradient flows DB 문구에는 단어 내부 물음표·분리된 문자와 수식 손상이 있다. DB 원시값의 정확한 보존만으로 읽을 수 있는 완전한 초록이라고 판정하지 않는다. 새 작업자는 실제 문구의 회귀를 추가하고 자동 초록 확정을 철회하여 다른 출처 검토를 열었다. 훼손 원시값은 보존한다.

- 루트 UI 준비 관측: KUDOS 학술DB에서 Scopus를 검색하여 `바로가기`를 누르자 기관 경유 `/pages/home`에서 Cloudflare Attention Required 화면이 나타났다. 이는 검색 전 한 번의 관측이며 g07 전건의 접근 불가 판정이 아니다. - 루트 공개 검색 반례: 입력 URL 없음·MR Article 비활성·Summon 0건으로 닫힌 g08 음성 표본 두 건에 공개 자료가 있었다. `VER-314684f8fca9344b61ba09da`는 `https://math.stanford.edu/~vakil/preprints.html`의 Vakil 공식 목록과 `https://ems.press/content/serial-issue-files/13716?nt=1`의 EMS89(2013) 전체호 PDF에 대응한다(목표24–30, 첫쪽의 앞 글 경계 주의). `VER-09b5e675f4d3706945f363cf`는 `https://diposit.ub.edu/items/f873c894-dad5-4b56-8e4e-3b53b03a2f1c`에 Catalan 원제, Burgos Gil,2001,16(1),61–85, Resum·published version PDF가 있으며 `https://www.icmat.es/miembros/burgos/files/introduccio_arakelov.pdf`도 관측됐다. 회수는 작업자가 Playwright로 수행한다. 이 종료 분기의 공개 검색 보완은 restart-contract에 정했다.
- 루트 Summon 고급검색 실물 확인: 시작 화면의 `button[aria-label="옵션"]`이 `[role=dialog]` 검색 옵션을 연다. 제목은 `#searchField0`의 `string:TitleCombined` 옵션과 `#searchValue0`, 저자는 `#searchField1`의 `string:AuthorCombined`와 `#searchValue1`로 설정한다. 제출은 dialog 안의 `button[data-aid="submit-search"]:visible`이다. 숨은 submit 버튼과 본 화면의 offscreen submit도 있으므로 전역 submit 또는 단순 dialog button[type=submit]은 잘못된 제어를 선택했다. 초기·ho=f 검색 응답과 dialog 초기화 후 두 필드를 선택하고 값을 채워, 제출 직전 선택값과 입력값을 다시 확인했다. 성급한 설정에서는 첫 행이 재초기화되어 제목 또는 값이 사라진 실제 실패가 있었다. 성공 응답은 `original_query=(TitleCombined:(Gradient Flows)) AND (AuthorCombined:(Ambrosio))`, `s.ho=f`, HTTP200,18문헌/18수신이었다. 증거는 `intake/kudos-recovery/operator/summon-advanced-observation.json`의 `validated=true` 기록이다. 이 관측된 질의 문법을 일반 검색 UI로 재사용할 때도 실제 응답·범위 대응을 TDD로 검사한다.

문헌 동일성은 실제 서지 구획을 기준으로 판단한다. DOI/ISBN/MR 같은 식별자, 제목, 저자, 문헌 종류, 발행·판본 정보, 권호쪽을 함께 대조한다. 필요한 필드가 실제 UI에서 접혀 있으면 펼쳐 확인한다. 표기·전사·온라인/인쇄 연도 차이는 근거로 해소하고, 문자열 차이만으로 다른 문헌이라 단정하거나 동일성의 필수 차이를 지우지 않는다. 실제로 읽지 못한 저자명이나 날짜를 원래 후보 값으로 채워 확인한 것으로 보고하지 않는다.

한 출처에서 확인한 트래픽 제한·보안 확인·CPE 오류는 해당 시도 근거로 남긴다. 다른 정상 기관 경유·출판사 경로가 작동한 사례도 있으므로, 한 화면의 실패를 다른 출처 전체에 복제하지 않는다. 개발 중 타임아웃이나 PDF viewer 처리 실패는 수리 가능한 도구 문제로 남기고 재개 때 영구 건너뛰지 않는다.
