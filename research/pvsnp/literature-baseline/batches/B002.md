# B002 — MSC2020 전 분야 기준 전거 수집

상태: **완료**

## 목적과 범위

MathSciNet에서 MSC2020의 63개 대분류별 표준 교재·종합 자료·대표적 연구 해설 후보를 인용순으로 최대 100건씩 수집한다. 이 묶음은 P vs NP에서 먼 수학 분야의 선행 조사를 시작한다.

B002는 분야별 전체 문헌을 수집하지 않는다. 첫 페이지의 기준 전거 후보만 받고, AI가 내용·중복·후속 참고문헌을 판정한다. 최신 연구 전선과 MathSciNet 누락은 zbMATH Open·arXiv·독립 색인으로 보완한다. 원문과 Review PDF는 수집하지 않는다.

## 입력과 출력

- 검색표: [`B002-queries.tsv`](B002-queries.tsv)
- 수집 프로그램: [`../scripts/mathscinet_collect.py`](../scripts/mathscinet_collect.py)
- Python 의존성: [`../scripts/requirements-mathscinet.txt`](../scripts/requirements-mathscinet.txt)
- 원시 출력: `research/pvsnp/literature-baseline/intake/B002/mathscinet/<field_code>/`
- 추적 manifest: [`../manifests/B002.json`](../manifests/B002.json)
- 검사 결과: [`../reports/B002-automation-audit.md`](../reports/B002-automation-audit.md)

## 자동 실행

저장소 루트에서 다음 명령을 실행한다.

```powershell
python -m pip install --user -r research/pvsnp/literature-baseline/scripts/requirements-mathscinet.txt
python research/pvsnp/literature-baseline/scripts/mathscinet_collect.py
```

프로그램은 다음 순서로 동작한다.

1. `.credentials/kudos.md`의 `ID`와 `PW`를 실행 중에만 읽는다.
2. 한 Chrome 컨텍스트에서 KUDOS에 로그인하고 KUDOS 프록시를 통해 MathSciNet을 연다.
3. 각 검색을 `MSC Primary or Secondary`, 100건, `Citations DESC`로 실행한다.
4. `Export`, `Select all on page`, `BibTeX`, `Get Citations` 순서로 화면을 조작한다.
5. BibTeX 엔트리 수·키 중복·100건 상한·요청 MSC 포함을 검사한다.
6. 검사를 통과한 citation text만 원자적으로 저장하고 다음 분야로 간다.

로그에는 분야 코드와 상태만 나오며 크리덴셜 값·세션 URL·citation 전문은 나오지 않는다. 브라우저 컨텍스트는 실행이 끝나거나 실패하면 폐기한다. 한 분야가 실패하면 프로그램을 멈추고 이미 완료한 분야는 다음 실행에서 건너뛴다.

일부 분야만 격리 실행하려면 별도 출력 경로를 함께 지정한다.

```powershell
python research/pvsnp/literature-baseline/scripts/mathscinet_collect.py `
  --codes 00,01,03 `
  --output-root research/pvsnp/literature-baseline/intake/B002-probe/mathscinet
```

## 수동–자동 동일성 검증

사용자가 먼저 같은 검색표로 수동 수집한 00·01·03을 프로그램이 격리 경로에서 다시 수집했다. 셋 모두 다음 조건을 통과했다.

- 수동과 자동이 각각 100건
- MR 키 집합 동일
- 인용순 MR 키 순서 동일
- LF로 정규화한 BibTeX 전체 바이트 동일

프로그램이 읽은 전체 검색 결과 수는 00이 583건, 01이 1,118건, 03이 1,749건이었다. 이 검증을 통과한 뒤 같은 프로그램으로 나머지 60개 분야를 실행했다.

## 완료 결과

63개 분야에서 6,233개 citation 레코드를 확보했다. 60개 분야는 100건씩, 결과 자체가 100건 미만인 19·85·97 분야는 각각 89·85·59건을 전부 수집했다. 재실행 계획 검사는 63개 분야를 모두 유효한 기존 결과로 인식해 `pending=0`, `skipped=63`을 반환했다.

## 이탈 처리

- **계속**: 유효한 기존 export가 있으면 그 분야를 건너뛴다.
- **중단**: 폴더에 파일이 있지만 유효한 BibTeX가 아니면 덮어쓰지 않고 중단한다.
- **중단**: 로그인·구독·검색 결과·선택·citation 모달 계약이 달라지면 부분 결과를 보존하고 중단한다.
- **중단**: 비정상 트래픽이나 기관 차단 경고가 보이면 브라우저를 닫고 더 검색하지 않는다.
