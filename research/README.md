# 연구 상태

2026-09-14 사용자 지시에 따라 연구를 빈 상태에서 다시 시작한다. 기존 탐사·수집·요약·실험의 진행 상태와 산출물은 이 작업 공간에서 제거했다. 새 연구 실행이나 자료 수집은 아직 시작하지 않았다.

아래 세 문서는 이전 연구의 입력과 배경을 보존한 자료다. 새 연구의 활성 계약이나 재개 지시로 취급하지 않는다. 새 연구에서 사용할 목표·입력·방법은 새 작업 지시를 기준으로 정한다.

- [이전 연구 주제 선호](pvsnp/연구-주제-선호.md)
- [이전 문헌 조사 명세](pvsnp/문헌-체계-명세.md)
