# 검색 범위와 새로움 판정

기준일은 2026-09-15 KST다. 최종 문제는 S1의 추측 6.5 전체이며, 이 문서는 문제를 선정할 때 확인한 문헌의 범위를 기록한다. **미해결 추측을 원문에서 확인했고, 아래 범위에서 해결 문헌을 발견하지 못했다.** 전 세계 문헌의 완전 조사나 새로움의 보증은 아니다.

## 학술 MCP 사용

서비스의 `list_sources`로 등록 자료원을 확인하고, 사용한 자료원은 `describe_source`의 문법을 읽었다. 검색 결과는 실제 반환된 artifact 참조로 `extract`한 뒤 제목·식별자를 대조했다. 원문은 서비스의 `fetch`와 PDF `extract`로 회수했다. 주요 응답은 [mcp-results.json](mcp-results.json)에 보존한다.

| 자료원·입력 | 실제 결과와 해석 |
|---|---|
| arXiv: `cat:math.CO AND (ti:"conjectures" OR ti:"open problems")`, 최신순 20건 요청 | HTTP 500. 응답 artifact 보존. 후보가 없다는 결과가 아님 |
| arXiv: `id:2507.07243`, 1건 요청 | timeout. arXiv 검색 경로의 실패이며 논문 부재가 아님 |
| Crossref: `Statistics on interval parking functions`, 5건 요청 | 5건 반환. 관련도 상위 창에 목표 논문은 없었음. 제목·저자 필드로 좁혀 추가 검색 |
| Crossref: `query.title=Statistics on interval parking functions`, `query.author=Celano`, 5건 요청 | 5건 반환했으나 상위 후보의 저자·주제가 다름. 목표 논문의 등록 또는 부재를 확정하지 않음 |
| zbMATH: `ti:parking & ti:interval`, 20건 요청 | 전체 9건 반환. S1·S2와 단위 구간·Fubini 후속 문헌을 제목·연도·식별자·서지로 선별 |
| zbMATH: `parking & unimodal`, 20건 요청 | 전체 4건 반환. ‘unimodal forests’, 총합 통계 등 제목이 비슷한 다른 문제를 구별. 라이선스 충돌 안내문을 논문의 초록으로 읽지 않음 |
| zbMATH: `parking & "maximum displacement"`, 20건 요청 | `not_found`, HTTP 404와 원 응답 보존. 이 검색식·색인의 결과에 한정 |
| Semantic Scholar: `ARXIV:2507.07243`, `kind=citations`, 100건 요청 | `received=0`, `total=null`, `has_more=false`. [응답](citation-query.json) 보존. 실제 인용 논문이 전혀 없다고 확대하지 않음 |
| author-repository: S1 저자 PDF, S4 학회 발표 PDF | 25쪽·36쪽 원문 확보. 제목과 문제 좌표 확인 |
| society-journal: S2 저널 페이지 | `/12598`에서 `/14279`로 이동. 공개 서지의 DOI가 `10.46298/dmtcs.12598`임을 대조하고 29쪽 PDF 확보 |
| society-journal: S3 저널 PDF | 8쪽 원문 확보. 비감소 주차 함수에 한정한 최대 변위 대응임을 확인 |

arXiv API 실패 뒤 저자 공개본을 고른 것은 호출자의 자료원 선택이다. 서비스가 임의로 다른 자료원에 전환했다고 기록하지 않는다. S1의 arXiv HTML과 버전 이력은 별도 웹 도구로 확인했다. 서비스의 검색·원문 확보는 성공한 범위와 실패한 범위를 함께 보고한다.

## 웹 후보 발견과 후속 대조

초기에는 조합론의 최근 open problems, independence polynomial, combinatorial proof, parking functions와 bijection을 조합해 분야 후보를 찾았다. 검색 결과의 문제 소개 사이트는 원 논문을 찾는 단서로만 사용했다. 최종 수학 주장과 미해결 표시는 S1 원문과 S4 저자 발표에 근거한다.

선정 후보를 좁힌 뒤 실제 사용한 주요 검색식은 다음과 같다.

- `"Statistics on" "interval parking functions" Foata`
- `"Foata" "Conjecture 6.3" parking`
- `"spot" "Foata" "unit interval" proof`
- `"parking functions" "maximum displacement" "unimodal"`
- `"parking" "Conjecture 6.5"`
- `"maximum displacement" "parking functions" -site:researchgate.net -site:scribd.com`
- `"maximum displacement" parking unimodality proof`
- `"2507.07243" "unimodal"`
- `"parking functions" "unimodality conjecture"`
- `"parking functions" "maximal displacement" distribution`
- `"unimodality" "interval parking" -site:researchgate.net`
- `"A note on the log-concavity of parking functions"`

[arXiv의 S1 버전 이력](https://arxiv.org/abs/2507.07243)은 조회 시 v1만 표시했다. [Jeremy Martin의 논문 목록](https://jeremymartinmath.github.io/pubs-brief.html)과 저자 공개 PDF도 확인했다. S1 §6은 여전히 추측 6.5를 미해결 질문으로 제시하며 S4 35쪽에도 같은 질문이 있다. 원문에 실린 표는 n≤9의 계산 근거이고, 그 밖의 n에 대한 증명이 아니다.

다음 근접 문헌을 구별했다.

| 문헌 | 확인 범위와 처분 |
|---|---|

## 확인하지 못한 범위와 재개 기준

모든 인용 문헌의 전문, 비영어권 문헌 전수, 학위논문 전수, 비공개 원고와 저자에게 직접 문의한 최신 상태는 확인하지 않았다. 기관 로그인이나 유료 원문 확보는 필요하지 않아 사용하지 않았다. 저자 연락·게시·투고는 수행하지 않았다.

따라서 후속 풀이를 시작할 때에는 S1 판본과 정확한 추측명·최대 변위의 동의어를 다시 검색한다. 해결 주장이 발견되면 원문의 대상·통계량·양화 범위를 P와 대조한다. 이미 해결된 문제로 확인되면 사실과 사용자 독창성 기준의 충돌을 보고하며, 이 준비 문서를 근거로 다른 문제를 자동 선택하지 않는다.
