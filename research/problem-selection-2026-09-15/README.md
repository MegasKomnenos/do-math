# 주차 함수의 최대 변위 분포 단봉성: 문제 선정과 연구 준비

**선정 문제는 Celano 외 6인(2025)의 추측 6.5, ‘주차 함수의 최대 변위 분포는 항상 단봉인가?’이다.** 차들이 선호하는 자리부터 차례로 주차할 때 가장 멀리 밀려난 거리를 기록한다. 그 거리가 정확히 0, 1, 2, …인 선호 목록의 개수가, 차의 수에 관계없이 한 번 증가한 뒤 감소하는 모양인지 묻는다. 평탄한 구간과 처음부터 감소하는 경우도 단봉에 포함한다. [원문 §6, 추측 6.5](https://arxiv.org/html/2507.07243v1#S6)

현재 상태는 **선행연구 전문 독해와 연구 준비 검토 완료, 실제 풀이 미착수**다. 논문 11편과 발표자료 1개, 총 234쪽을 읽고 시작 자료를 보완했다. 이 디렉터리는 선정 문제를 연구할 때 사용할 수학적 배경과 자료를 담는다. 기준일은 2026-09-15 KST다.

## 확보한 것과 검증한 것

최초 원문 4개는 학술 MCP로 확보했고, 추가 기초·후속 원문까지 총 12개를 전문으로 읽었다. 제가 직접 읽은 핵심 두 편과 병행 독해 담당이 읽은 자료를 [목록](evidence/fullread-index.md)에 구별했다. MCP 요청 제한·브라우저 오류 뒤 공식 공개본으로 회수한 자료도 실제 경로를 기록했다. [로컬 PDF와 추출물](originals/)은 Git에서 제외하며, URL·해시·독해 기록은 추적한다.

다른 컴퓨터에서는 목록의 URL로 원문을 다시 받아 지정된 PDF 경로에 보존한다. 최초 네 MCP 자료의 원 회수 manifest는 `evidence/source-manifests/`에 함께 보존되어 있어, 이전 MCP 데이터 저장소 없이도 아래 재현 검사를 할 수 있다.

원문 해시와 MCP manifest 해시, 논문에 실린 n=1..9의 45개 값, n=1..5의 직접 주차 전수 계산, 정의의 경계를 검사했다. **34개 검사 모두 통과**했다. 이는 가져온 자료와 해석의 검증이며 추측의 증명이 아니다. n>9 계산이나 새 증명 탐색은 수행하지 않았다.

전문 독해에서는 제한 2→1의 자리 보존 대응, 인접 역전 제거의 단조성, Fubini 하위족의 증가 구간별 분해를 발판으로 추가했다. 원문의 보조정리·식에서 발견한 오류는 구체적 반례와 함께 기록했다. [원문 주장 다섯 건의 재현](evidence/source-findings.json)은 선정 추측의 반증과 구별한다.

```powershell
python research/problem-selection-2026-09-15/verify_reference.py
```

2026-09-15 조사 범위에서 이 추측의 해결 문헌은 발견하지 못했다. ‘원문이 미해결 추측으로 제시하며, 확인한 후속 자료에서 해결을 찾지 못함’이 정확한 판정이다. 검색하지 못한 자료나 비공개 연구까지 포함한 새로움의 보증으로 해석하지 않는다.
