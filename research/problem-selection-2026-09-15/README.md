# 주차 함수의 최대 변위 분포 단봉성: 문제 선정과 연구 준비

**선정 문제는 Celano 외 6인(2025)의 추측 6.5, ‘주차 함수의 최대 변위 분포는 항상 단봉인가?’이다.** 차들이 선호하는 자리부터 차례로 주차할 때 가장 멀리 밀려난 거리를 기록한다. 그 거리가 정확히 0, 1, 2, …인 선호 목록의 개수가, 차의 수에 관계없이 한 번 증가한 뒤 감소하는 모양인지 묻는다. 평탄한 구간과 처음부터 감소하는 경우도 단봉에 포함한다. [원문 §6, 추측 6.5](https://arxiv.org/html/2507.07243v1#S6)

현재 상태는 **문제 선정·연구 준비 완료, 실제 풀이 미착수**다. 이 디렉터리는 후속 연구의 입력이며 do-math 인스턴스의 활성 헌장이나 형식 정본 K가 아니다. 기준일은 2026-09-15 KST다.

기초적인 순열·세기·귀납법으로 출발할 수 있고, 마지막 차를 기준으로 나누는 기존 점화식이 있다. 그 점화식이 거리별 개수의 모양을 어떻게 강제하는지는 별도 연구가 필요하다. 이런 이유로 **석사논문 수준의 연구 후보로 적합하다고 판단**했다. 학계의 난도 인증이나 해결 보장은 아니다. 단순 계산표 확대보다 전 범위의 증명 또는 반증과 그 구조적 설명을 목표로 삼는다.

## 확보한 것과 검증한 것

학술 MCP로 핵심 논문·선행 논문·관련 논문·저자 발표 자료의 원문 4개를 확보했다. [로컬 PDF](originals/)는 Git에서 제외되며, URL과 해시는 추적한다. 다른 컴퓨터에서는 `source-catalog.json`에 적힌 자료원과 URL로 다시 확보해야 한다.

원문 해시와 MCP manifest 해시, 논문에 실린 n=1..9의 45개 값, n=1..5의 직접 주차 전수 계산, 정의의 경계를 검사했다. **34개 검사 모두 통과**했다. 이는 가져온 자료와 해석의 검증이며 추측의 증명이 아니다. n>9 계산, 새 증명 탐색, Lean 실행, do-math 초기화는 수행하지 않았다.

2026-09-15 조사 범위에서 이 추측의 해결 문헌은 발견하지 못했다. ‘원문이 미해결 추측으로 제시하며, 확인한 후속 자료에서 해결을 찾지 못함’이 정확한 판정이다. 검색하지 못한 자료나 비공개 연구까지 포함한 새로움의 보증으로 해석하지 않는다.
