# 독립적인 새 연구의 조건

이 인스턴스는 오직 root.md에 담긴 동일한 프로젝트 목표로 새로 시작한다. 이전 연구 인스턴스, 세션, knowledge, 진행 기록, 로컬 메모리, 기존 풀이·증명·계산 코드·선행연구 요약·실패 접근을 열람하거나 가져와 사용하지 않는다. 원 문제 선정 폴더와 선정 후 연구 산출물도 열람하지 않는다. 이전 대화나 인스턴스를 resume/continue하지 않는다. 새 인스턴스에서 생산하고 검토한 지식만 세션 사이에 이어 사용할 수 있다.

일반 CLI, Python, Git 및 Lean/Mathlib 설치는 실행 환경으로 사용할 수 있으나 이전 연구 산출물은 사용할 수 없다. 공개 학술 문헌은 새로 찾아 원문에서 직접 확인하고, 현재 해결 여부·기여·가치를 독립적으로 판단한다. 문제 식별용 원 논문은 Celano 외, Statistics on ℓ-interval parking functions, arXiv:2507.07243, Conjecture 6.5이다(https://arxiv.org/abs/2507.07243).

사람이 이해할 수 있는 한국어 수학 해설을 주 산출물로 작성한다. 이전 인스턴스의 운영 이력·모델 정책·대기 상태·미완료 작업을 가져오지 않는다. 현재 인스턴스 settings.json과 현재 do-math 역할 지침을 따른다.

## 수학적 해결과 학술적 완료

**수학적 해결:** P의 모든 n에 대한 증명을 주거나, P가 거짓임을 엄밀히 입증한다. 후자의 경우 한 n에서 감소 이후 다시 증가하는 두 위치를 정확한 개수와 함께 증명하면 반증이 된다. 임의의 주차 함수 하나는 개수의 단봉성에 대한 반례가 아니다. 계산 범위를 넓혔지만 반례를 찾지 못한 상태, 특정 n의 검증, 조건을 추가한 명제는 부분 성과다.

**학술적 완료:** 수학적 해결에 더해 기존 문헌과 다른 기여를 설명하고, 결론을 낳는 구조나 장애물을 근거와 함께 제시한다. 검토자는 다음을 확인한다.

1. 결과가 어떤 기존 정리와 같거나 즉시 따라오는지 실제 가정과 결론을 대조했는가?
2. 증명이 의존하는 핵심 분해·대응·부등식이 무엇이며, 그것이 원 문제의 어떤 현상을 설명하는가?
3. 계산이나 특정 예시 밖에서도 적용 범위와 한계를 정확히 밝히는가?

새로움·흥미·가치를 점수나 증명 길이로 대신하지 않는다. 후속 독립 검토는 이 질문에 근거를 제시하고, 사용자는 해설과 진행 결과를 보며 원하는 통찰이 구현됐는지 피드백한다. 구조적 설명 없이 수치 반례만 확보하면 P의 반증과 사용자 목적 전체의 달성을 구별해 보고한다.

## 산출물과 보증 수준
사람이 이해할 수 있는 한국어 수학 해설이 주 산출물이다. 전체 P의 증명 또는 반증을 원래의 주차 과정·대상·정의·양화와 일치하는 Lean 정리로 제공한다. 현재 do-math의 형식 검증 기준에 따라 독립 검토가 별도로 컴파일하고 정확한 명제와의 일치를 확인해야 한다. 허용 공리는 propext, Classical.choice, Quot.sound이며 sorryAx는 허용하지 않는다. 새로 정의한 점화식이나 추상 수열만 다루는 경우 원래 주차 함수 개수와의 일치도 증명해야 한다. 부분 사례, 조건부 명제, 유한 범위 계산, 비형식 주장만으로 전체 달성을 선언하지 않는다. 독립 검토는 수학적 해결과 학술적 완료를 구별한다. 목표 달성 후 투고·외부 공개·외부 연락은 이번 요청 범위에 포함되지 않는다.
