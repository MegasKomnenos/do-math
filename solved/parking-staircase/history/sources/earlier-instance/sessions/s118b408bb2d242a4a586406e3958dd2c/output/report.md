Q⋆ 열 닫힘(r207f1244…, k ≤ 3130)과 비교하면 k = 3131과 표본 열들은 원 비교로서도 새 위치다. 2001 ≤ k ≤ 5000 전체를 목표로 한 배치는 사용자 결정에 따라 k = 3131에서 멈추었다(§1.4).

**구조의 관찰(§4.3).** 창의 아래 끝 띠 n = 2k + ν (|ν| ≤ 400)에서 T_n은 거의 상수다: k = 2001에서 17.5 ~ 21이고, 그 사이 E[Z_k]², Var(Z_k), kE[H_k]는 각각 두 배 가까이 움직인다. ν = 41에서 T_n은 20.2 (k = 2001) → 39.3 (k = 50000)으로 천천히 늘고, Var(Z_k)/(kE[H_k]) ≈ 0.53이 같은 범위에서 ±0.004 안에서 일정하며, 상대 여유 T/kE[H]는 0.24 → 0.066으로 k^{−0.4} 꼴로 준다. 공표 비형식 정리 B(r56698e9…: |n−2k| 유계에서 T_n ∼ 0.776·k^{1/3})와 대조하면 T_n/k^{1/3}은 1.60 → 1.07로 예측값에 k^{−1/3} 꼴로 다가간다. 곧 노드의 아래 끝 여유는 두 k^{2/3} 규모 항의 상쇄 뒤에 남는 k^{1/3} 규모의 양이고, 𝓦_M의 k-균일 증명은 정리 B를 명시적 상수로 만드는 일과 같다. 공표 합 규칙 T_n = E_k² + Δ₁ + Δ₂(r10ff8c2a… §5.7)로 옮기면 "용량 응답 −Δ₁이 E_k²을 k^{1/3} 차이로 따라간다"는 진술이다.

**부호의 지도(§4.7).** 정확 유리수(k ≤ 12)와 binary64 점 추정(k ≤ 3200)으로 보면 T_n < 0인 n은 k+1 ≤ n < n₀(k)뿐이고 n₀(k) ≈ k + 2.7√k이다(k = 3200에서 n₀ = 3354). 곧 모멘트 부등식은 노드가 묻는 2k+41보다 훨씬 아래, n ≈ k + 3√k부터 이미 성립한다. 노드의 아래 끝 2k+41은 T의 부호 경계가 아니라 관계 rel-lmcore-split의 필요에서 온 것이다.

**블록 크기 사슬(§7.4–7.5, 정리 8).** 최대 차 분해로 T_n = Σ_m N_n(m)Φ_m (크기 m인 마디의 기대 방문 수 × 한 마디의 원천)이고, n ≤ 2k+1에서는 크기 ≥ k인 마디가 한 줄의 사슬을 이루어 𝓦_M의 양은 "사슬 위 큰 자리 순서쌍의 기대 개수 × 2 − k × 문턱 마디의 기대 개수"다. 문턱 바로 위 띠 t = m − k ≪ k^{2/3}에서는 하강 법칙이 Borel(1) 분포, 문턱 확률이 k/(√(2π)t^{3/2}), 멈춤 가운데 문턱의 비가 1/(2t), 큰 자리 수가 0.67√t로 k에 무관하게 보편적이고, 이것이 모멘트 부등식이 거짓인 띠의 폭 ≍ √k와 그 위치를 설명한다. 문턱 비용의 94%가 이 띠에서 나오고 쌍의 60%가 t ≥ k^{2/3}에서 나오므로, k-균일 증명은 t ≍ k^{2/3}의 전이 윤곽을 상대 오차 o(k^{−1/3})로 적는 일로 귀착한다.

**띠의 명시적 꼴(§7, 명제 7).** n ≤ 2k에서는 갱신열의 앞부분이 나무 수로 명시적이어서(Abel 항등식 Σ_m C(l,m)(m+1)^{m−1}(l−m+1)^{l−m−1} = 2(l+2)^{l−1}), 정리 1과 공표 정리 C가 a_n E_n = Σ_{j=k+1}^{n} L_j·2(n−j+2)^{n−j−1}/(n−j)!, a_n k h_n = k a_{k−1}[a_{n−k} + kΣ_{j=k+1}^{n} κ_j·2(n−j+2)^{n−j−1}/(n−j)!]로 닫힌다. 띠의 노드는 첫 창(k < j ≤ 2k+ν)의 두 가중치 열 L_j, κ_j와 나무 핵만의 문제다. 이것이 정리 B의 명시화로 가는 출발점이라고 본다.

### 1.3 선택의 이유와 접근

판 190의 board에서 왼쪽 창의 원 비교 b_{n,k−1} ≤ b_{n,k}에 해당하는 위치는 여러 세션이 맡고 있었다. 모멘트 창 𝓦_M은 같은 창 위에서 더 강한 부등식을 묻는 서로 다른 진술이며 아무도 맡지 않았다.

도구는 **정확한 갱신열(renewal) 표현**이다. 공표 rb7effe02…/정리 C는 문턱 자리 밀도 𝔓_k(n) = kE[H_k]/n을 극 정규화 갱신열 u_l = A_{l,k−1}ρ_k^l/l!의 길이 ≈ 3k인 창 평균으로 정확히 썼다. 이 세션은 같은 꼴의 표현을 평균 E[Z_k]에 대해(정리 1), 그리고 2차 모멘트에 대해 양의 레졸번트 꼴로(정리 2) 얻었다. 그러면 노드의 두 항은 모두 "비음수 가중치 × 갱신열(또는 그 합성곱)"의 창 평균이고, 갱신열 자체는 양의 재귀 u = 1 + π ∗ u로 계산된다. 양의 재귀는 입력을 위·아래로 치우치게 주면 출력도 위·아래 한계가 되므로, 창 전체를 한 번에 **엄밀한 상·하한**으로 덮는 계산이 가능해진다(§3.5). 처음에는 공표 X′ 인증서의 평탄성을 입력으로 쓰는 조건부 정리(정리 3)와 그 귀결(n ≳ 0.6k^{3/2}부터 닫힘; §4.5)을 만들었으나, 자체 상·하한이 그 입력을 필요 없게 했다.

**이 접근이 닿지 않는 곳.** 열마다 O(k²) 계산이 필요하므로 모든 k ≥ 2001을 한 번에 닫지 못한다. k-균일 진술로 가려면 (가) 띠(2k+41 ≤ n ≲ 3k)에서 T_n > 0의 이유(k^{1/3} 규모의 나머지), (나) 평탄 영역의 상수 κ_k, 𝔓_k(∞)의 k-균일 한계와 갱신열의 k-균일 평탄성 인증이 필요하다(§5).

### 1.4 계산의 비중에 대한 사용자 결정과 이 세션의 판단

작업 중 운영자가 사용자 결정(2026-11-09, `control/inputs/1794207919341484900-…txt`)을 전달했다: 남은 범위나 큰 구멍을 계산으로 하나하나 메우는 대규모 계산은 피하고, 문제 자체를 스스로 생각하는 일에 더 큰 비중을 둔다; 꼭 필요하고 이해를 깊게 하는 계산은 해도 된다; 이미 얻은 결과의 지위는 바뀌지 않는다.

그 시점에 돌고 있던 계산은 둘이었다. (1) 2001 ≤ k ≤ 5000 열 전체 배치(3 작업자; k = 3128까지 끝남), (2) 표본 열 k = 30000. 둘 다 **범위를 메우는 계산**이다. 인증서가 주는 이해(띠에서는 분산이 꼭 필요하다는 것, Jensen 문턱이 k와 함께 오른다는 것, 가장 빠듯한 곳이 언제나 2k+41이고 그곳의 여유가 k^{1/3} 규모라는 것, 창 귀납 영역은 여유가 커서 k-균일 꼴로 닫힌다는 것)는 표본 열 2001–3131과 5000–20000에서 이미 모두 얻었고, 열을 더 보탠다고 새 이해가 생기지 않는다. 그래서 두 계산을 멈추었다. 멈추기 직전 2001–3128이 끝나 있었으므로 공표 Q⋆ 경계(k ≤ 3130)에 맞추기 위해 세 열(3129–3131, 26초)만 더 돌렸다. 끝난 열의 결과는 그대로 둔다(정리 4의 범위 = 2001 ≤ k ≤ 3131과 표본 열).

멈춘 뒤의 시간은 문제 자체에 썼다. 작은 k의 정확 부호 지도(§4.7)와 띠의 명시적 꼴(§7)이 그 결과다. 둘 다 계산은 작고(초 단위), 노드가 묻는 양이 어디서 왜 양수인지를 보는 데 쓰였다.

### 3.1 평균의 정확한 갱신 표현 (정리 1; 증명 완료, 정확 검산)

### 3.3 동률 항등식: 노드의 양을 개수로 (정리 5; 증명 완료, 전수 검산)

**정리 5.** z_{n,k,j} := #{α ∈ PF_n : M(α) = k, 변위가 k인 차가 정확히 j대}, B̃_{n,k−1} := #{(α, s) : α ∈ PF_n, M(α) ≤ k−1, 자리 s의 용량 h_s = k, 자리 s의 차의 변위가 k−1}라 하자. 모든 n ≥ 1, k ≥ 1에서

  A_{n,k−1}·E_n = k·z_{n,k,1},  A_{n,k−1}·S_n = 2k²·z_{n,k,2},  A_{n,k−1}·h_n = k·B̃_{n,k−1},

따라서 **A_{n,k−1}·T_n = k²·(2 z_{n,k,2} − B̃_{n,k−1})**이고, 노드 𝓦_M은 2 z_{n,k,2} ≥ B̃_{n,k−1}과 같다.

*증명.* 결과 순열 σ를 고정하면 자리 p의 차가 가질 수 있는 선호는 t_p < a ≤ p의 h_p개이고, 변위 p − a가 j인 선호는 h_p > j일 때 정확히 하나다. 최대 변위 ≤ k−1인 선호 목록은 자리마다 min(h_p, k)개, 그 곱이 ν_{n,k}의 가중치다. M(α) = k이고 변위 k인 차가 정확히 j대인 목록은, h_p > k인 Z_k개 자리 가운데 j개를 골라 변위 k를 주고(한 가지씩), 나머지 h_p > k인 자리에는 변위 ≤ k−1(k가지), h_p ≤ k인 자리에는 h_p가지를 주는 것이므로 z_{n,k,j} = Σ_σ ∏_{h_p≤k}h_p · C(Z_k, j)·k^{Z_k−j} = k^{−j}Σ_σ ∏_p min(h_p,k)·C(Z_k, j). j = 1, 2가 앞의 두 식이다. B̃는 h_s = k인 자리 s를 고르고 그 차의 변위를 k−1로 고정(한 가지), 나머지 자리는 min(h_p,k)가지이므로 B̃ = Σ_σ ∏_{p≠s}min(h_p,k)·#{s : h_s = k} = k^{−1}Σ_σ ∏_p min(h_p,k)·H_k. ∎

*읽기.* 오른쪽 창의 공표 노드 X(E2 비교)의 왼쪽 쌍둥이다. T_n > 0은 "새 수준 k의 최대값 차 두 대(순서쌍)"가 "수준 k−1의 최대값 차 한 대가 용량 k인 자리에 막힌 배치"보다 많다는 것이다. §4.3의 관찰 T_n ≈ 상수는 이 두 개수의 차가 A_{n,k−1}/k²의 20–36배라는 뜻이다.

### 3.4 조건부 전달 정리 (정리 3; 증명 완료) — 평탄성 하나로 환원

**정리 3.** k ≥ 2를 고정하고 (H1) 어떤 L_0 ≥ 1과 ε_0 ∈ [0,1)에 대해 모든 l ≥ L_0에서 |μu_l − 1| ≤ ε_0, (H2) J_1 ≥ k+1에 대해 ℓ̄ := Σ_{j>J_1} ℓ_j, w̄ := Σ_{j>J_1} w_j라 하자. 모든 n ≥ max(L_0, J_1 + 2L_0 − 1)에서

  E_n ≥ κ_k · (1−ε_0)²(1−ℓ̄)/(1+ε_0) · (n − J_1 − 2L_0 + 1),  k h_n ≤ (n+1)·𝔓_k(∞)·[(1+ε_0) + μ w̄]/(1−ε_0) (n+1−L_0 ≥ J_1일 때),

따라서 좌변 하계를 E^{low}, 우변 상계를 (kh)^{up}이라 할 때 E^{low} ≥ 1이고 E^{low}(E^{low} − 1) > (kh)^{up}이면 T_n ≥ J_n > 0이다.

이 정리의 입력(κ_k, 𝔓_k(∞), ℓ̄, w̄, μ)은 k만의 상수이고 유한 크기 정보는 (L_0, ε_0) 하나다. 공표 X′ 인증서(rf451d83…)의 기록 (n_0, m, R_U)에서 L_1 = n_0 − 3k(Part B) 또는 n_0(K_1) − 4K_1(구간 층), ε(L) = (R_U−1)(L_1/L)^m (L ≥ L_1)이 (H1)을 준다(R_U의 정의에서 ε(L_1) ≤ R_U − 1). 이 길로 얻은 문턱은 §4.5에 있다. §3.5의 자급식 인증은 (H1)을 공표 인증서 대신 자체 상·하한으로 대체한 것이고, 띠에서는 정리 2로 분산까지 넣는다.

### 3.5 열 전체 인증서의 수학 (명제 6; 증명 완료)

열 k를 고정하고 top := ⌈2k^{3/2}⌉ − 1, Spi := 7k(증가분 절단), Jw := 6k(가중치 절단), N2 := max(⌊0.12k^{3/2}⌋, Spi + 5k)(직접 영역의 끝), NS := min(3k, N2)(2차 모멘트 영역의 끝)라 하자. 인증서는 다음 네 층으로 되어 있다.

**(A) σ_k의 괄호.** Σ_n d_n e^{σn/k} = 1이 σ_k를 정의하고 좌변은 σ에 증가한다. d_n은 양의 재귀(§2)로 n ≤ Nd := Spi까지 계산하고, 꼬리 Σ_{n>Nd} d_n e^{un/k}는 (I-H)로 k·max_{Nd−k<n≤Nd} d_n e^{un/k}이하다(가설 Nd ≥ 2W + k는 수치로 확인). 그러면 이분법으로 σ_lo < σ_k ≤ σ_hi를 얻는다: σ_hi는 (절단합)(1−G) ≥ 1인 최소값, σ_lo는 (절단합 + 꼬리)(1+G) < 1인 최대값(G는 §2의 오차 허용). 계산에서 폭 σ_hi − σ_lo ≈ 10^{−9}(k = 2001, 5000).

**(B) 단조성으로 방향 잡기.** 다음 모든 양은 σ에 증가하는 비음 항의 합이다: π_n = d_ne^{σn/k}, ρ = e^{−1+σ/k}, u_j (j<k) = (j+1)^{j−1}ρ^j/j!, P̃_i, 그리고 재귀 (j+1)λ_{j+1} = Σ P̃_iλ_{j−i} + ρR̃_j (R̃ = π∗u_{<k}, Lw_j = kλ_j), (j+1)κ̂_{j+1} = Σ P̃_iκ̂_{j−i} + 1{j=k} (κ̂_j = κ_jρ^{j−k−1}, w_j = κ̂_j/Σκ̂, 𝔓_k(∞) = kτ_ke^{σ}Σκ̂_j)의 해. 그러므로 σ_lo로 계산한 π, Lw는 참값의 하계, σ_hi로 계산한 π, κ̂는 상계다. j > Jw의 Lw는 하계에서 버리고(비음), κ̂의 꼬리는 (I-H)로 k·max_{Jw−k<j≤Jw}κ̂_j 이하, 가설 Jw ≥ 2W + k 확인.

**(C) 직접 영역 [0, N2]: 양의 갱신 재귀의 상·하한.** 다음 다섯 수열을 같은 재귀로 계산한다.

  u = 1 + π∗u,  V = Lw + π∗V (= Lw∗u),  En = V + π∗En (= Lw∗u2, 정리 1의 분자),  W = w + π∗W (= w∗u, 정리 C의 합성곱),  u2 = u + π∗u2 (l ≤ NS).

하계(u^{lo}, V^{lo}, En^{lo}, u2^{lo})는 π^{lo} := π(σ_lo)(1−G_π)를 Spi에서 절단해 쓴다: 비음 항을 버렸으므로 정확한 산술에서 참값 이하이고, 양의 재귀는 입력에 단조이므로 반올림은 끝에 한 번의 인자 (1 − G_u) (G_u := (N2+2)REL(Spi+2), 한 단계 상대 오차 × 깊이)로 덮인다. 상계(u^{up}, W^{up})는 π^{up} := π(σ_hi)(1+G_π)에 절단 꼬리를 더한다: Σ_{s>Spi}π_s u_{l−s} ≤ (Σ_{s>Spi}π_s)·1 ≤ tail_π := k·max_{Spi−k<s≤Spi}π^{up}_s ((I-F)의 u ≤ 1과 (I-H)); W에는 또 j > Jw의 w 꼬리 w̄·1을 더한다. 그러면 모든 l ≤ N2에서

  u^{lo}_l ≤ u_l ≤ u^{up}_l,  En^{lo}_l ≤ (Lw∗u2)_l,  u2^{lo}_l ≤ u2_l,  W^{up}_{l} ≥ (w∗u)_l,

이고 E_n ≥ E^{low}_n := En^{lo}_n/u^{up}_n, k h_n ≤ kh^{up}_n := (n+1)𝔓^{up}_k(∞)W^{up}_{n+1}/u^{lo}_n. 2차 모멘트는 정리 2의 극 정규화 재귀를 하계 입력으로 풀어 S_n ≥ S^{low}_n := 2k(u2^{lo}∗ĥ^{lo})_n/u^{up}_n (n ≤ NS).

**(D) 창 귀납(샌드위치) 영역 (N2, top].** 창 [N2−Spi+1, N2]의 계산값에서 상수를 만들고 n > N2로 귀납한다.

*보조정리 A(기하 비율).* r ≥ 1을 Σ_{s≤Spi}π^{lo}_s r^s ≥ 1인 수, R ≥ 1을 Σ_{s≤Spi}π^{up}_s R^{−s} ≤ 1인 수라 하자(이분법; π^{lo}의 총질량이 1보다 약간 작으므로 r − 1 ≈ (1 − Σπ^{lo})/μ ≈ 10^{−13}). m := min_{j∈창} u^{lo}_j r^{−(N2−j)}, M := max_{j∈창} u^{up}_j R^{N2−j}라 하면 모든 n > N2에서

  u_n ≥ m·r^{−(n−N2)},  u_n ≤ (M + tail_π·(n−N2))·R^{n−N2}.

증명. 하계: 귀납 가설 u_j ≥ m r^{−(j−N2)}가 j ∈ [N2−Spi+1, n−1]에서 성립하면(창에서는 m의 정의로 성립) u_n ≥ Σ_{s≤Spi}π_s u_{n−s} ≥ m r^{−(n−N2)}Σ_s π^{lo}_s r^s ≥ m r^{−(n−N2)}. 상계: u_n ≤ Σ_{s≤Spi}π^{up}_s u_{n−s} + tail_π·1이고 가설 u_j ≤ (M + tail_π(j−N2))R^{j−N2}를 넣으면 R^{n−N2}[(M + tail_π(n−N2))Σπ^{up}_sR^{−s} − tail_π Σ s π^{up}_s R^{−s}] + tail_π ≤ (M + tail_π(n−N2))R^{n−N2} (Σ s π^{up}_s R^{−s} ≥ 1을 수치로 확인). ∎

*보조정리 B(아핀 귀납).* v_0 := (Σ_{j≤Jw}Lw^{lo}_j)·m, b := v_0/mean_r (mean_r ≥ Σ_s s π^{lo}_s r^s), a := min_{j∈창}[En^{lo}_j r^{−(N2−j)} + b(N2−j)]라 하면 모든 n > N2에서 (Lw∗u2)_n ≥ (a + b(n−N2))·r^{−(n−N2)}.

증명. En = V + π∗En이고 n > N2에서 V_n = Σ_{j≤Jw}Lw_j u_{n−j} + (비음) ≥ v_0 r^{−(n−N2)} (보조정리 A와 Jw < Spi, r ≥ 1). 귀납 가설 En_j ≥ (a + b(j−N2))r^{−(j−N2)} (창에서는 a의 정의)로 Σ_{s≤Spi}π_s En_{n−s} ≥ r^{−(n−N2)}[(a + b(n−N2))Σπ^{lo}_s r^s − bΣ s π^{lo}_s r^s] ≥ r^{−(n−N2)}[(a + b(n−N2)) − b·mean_r]. 더하면 ≥ r^{−(n−N2)}(a + b(n−N2)) + r^{−(n−N2)}(v_0 − b·mean_r) ≥ r^{−(n−N2)}(a + b(n−N2)). ∎

W에는 귀납이 필요 없다: n > N2에서 (w∗u)_{n+1} ≤ (Σ_{j≤Jw}w^{up}_j + w̄)·max_{n+1−Jw ≤ i ≤ n+1}u_i ≤ (Σw^{up} + w̄)·u^{up,ext}(n+1) (상계가 증가함수이고 창의 아래 끝 N2−Spi+1 ≤ n+1−Jw). 따라서 n > N2에서 E^{low}_n := (a + b(n−N2))·r^{−(n−N2)} / [(M + tail_π(n−N2))·R^{n−N2}], kh^{up}_n := (n+1)·𝔓^{up}_k(∞)·(Σ_{j≤Jw}w^{up}_j + w̄)·(M + tail_π(n+1−N2))R^{n+1−N2} / (m·r^{−(n−N2)})이다. 손실은 top에서 r^{−(top−N2)} ≈ 1 − 10^{−6}(하계)과 (1 + tail_π(top−N2)/M)R^{top−N2} ≈ 1.16 (k = 5000; 상계)이다.

**명제 6(인증서의 정당성).** §2의 수치 모형 아래, (A)–(D)로 계산한 E^{low}_n, kh^{up}_n (2k+41 ≤ n ≤ top), S^{low}_n (n ≤ NS)은 각각 E_n의 하계, k h_n의 상계, S_n의 하계다. 그러므로 모든 n ∈ [2k+41, top]에서 max(S^{low}_n·1{n≤NS}, E^{low}_n(E^{low}_n−1)·1{E^{low}_n≥1}) − kh^{up}_n > 0이면 열 k의 𝓦_M(과 2k+41 ≤ n < 10001의 추가 위치)이 성립한다.

*증명.* (A)의 괄호, (B)의 단조성, (C)의 양의 재귀의 단조성과 반올림 인자, (D)의 두 보조정리, 꼬리의 (I-H)·(I-F), 그리고 x(x−1)의 단조성(x ≥ 1)과 S_n ≥ E_n(E_n−1)(Var ≥ 0)을 합친다. 모든 반올림 허용(G_d, G_π, G_u, G_L, G_chain)은 §2 모형의 한 단계 한계 × 체인 깊이의 4배 이상이다(코드 머리말). ∎

## 5. 장애와 남은 어려움

1. **k-균일 진술.** 인증은 열마다 O(k²)이고 모든 k ≥ 2001을 덮을 수 없다. 균일 증명에 필요한 것은 두 가지다. (가) 띠 2k+41 ≤ n ≲ 2.9k: T_n의 양수성. §4.3의 관찰과 공표 비형식 정리 B(r56698e9…)를 합치면 T_n은 두 k^{2/3} 규모의 항(E² + Var와 kE[H])이 상쇄되고 남는 k^{1/3} 규모의 양이다. 그 증명은 정리 B를 명시적 상수로 만드는 일이고(공표 기록은 "비명시적"이라 적었다), 공표 합 규칙 T = E² + Δ₁ + Δ₂로는 "용량 응답 −Δ₁이 E²을 k^{1/3} 차이로 따라간다"는 진술이다. §7의 명제 7은 n ≤ 2k에서 두 항을 첫 창 가중치 L_j, κ_j의 두-나무 핵 평균으로 완전히 명시화하고, 정리 8은 같은 양을 블록 크기 사슬의 가법 함수로 쓴다; 두 꼴 모두에서 필요한 것은 t ≍ k^{2/3}의 전이 윤곽 F_{k+t}와 그곳의 하강 법칙을 상대 오차 o(k^{−1/3})로 적는 일이다(§7.5). 귀납·거친 부등식·단사·단조성은 모두 이 정밀도 요구에서 실패했다(§7.6). (나) 평탄 영역: κ_k의 k-균일 하계(§4.6의 항등식으로는 kσ′(k+) ≤ c), 𝔓_k(∞)√k ≤ 0.76의 증명, 그리고 갱신열의 k-균일 평탄성(공표 인증은 k^{4/3}부터, 참값은 3k부터 3%). 보조정리 A·B는 꼴이 k에 균일하므로, 이 입력들이 해석적으로 주어지면 창 귀납 영역은 k-균일하게 닫힌다.
2. **Jensen 문턱의 이동.** 1차 판정의 시작점 n/k(2.11 → 2.81)가 k와 함께 오르므로 분산이 필요한 띠의 길이(k 단위)도 는다. 이것은 갱신열의 감쇠 비(k당 4.3 → 3.5)가 느려지는 것과 같은 현상이다. 공표 기록의 둘째 영점 간격 δ*_k(rb7effe 보조정리 P′ δ ≈ 0.17; r7c079be1 refined-pole-gap)의 명시 k-의존이 여기에 닿는다.
3. **보증 수준.** 정리 4는 §2의 binary64 모형 아래의 컴퓨터 보조 결과다(구간 산술·Lean 없음). 모형의 가정은 세 가지 뿐이다(순서 무관 합의 n·u 한계, fsum의 정확 반올림, libm의 64 ulp). 독립 재구현으로 검증 가능하도록 코드와 출력(JSON lines, 열마다 σ 괄호·상수·최소 여유·위치)을 남긴다.
4. **운영상의 기록.** 공유 기계(4코어)에서 다른 세션의 많은 계산이 함께 돌아 시간 측정이 불안정했다. 이전 판 배치를 정리하면서 명령줄 패턴(`multiprocessing`)으로 프로세스를 멈추었는데, 그 가운데 다른 세션의 작업자가 섞였을 가능성을 배제할 수 없다(14:3x). 이후 정리는 PID로만 했다.

## 7. 문제 자체에 대한 고민: 띠의 명시적 꼴과 k-균일 증명으로 가는 길

§1.4의 결정 뒤에 계산 대신 생각한 것을 적는다. 목표는 창의 아래 끝 띠 2k+41 ≤ n ≲ 3k에서 T_n > 0을 k에 균일하게 보이는 일이고, 그 첫걸음은 띠에서 노드의 두 항이 정확히 무엇의 합인지 보는 것이다.

### 7.1 띠에서 갱신열은 나무 수다 (명제 7; 증명 완료)

**명제 7.** n ≤ 2k이면

  a_n·E_n = Σ_{j=k+1}^{n} L_j · 2(n−j+2)^{n−j−1}/(n−j)!,
  a_n·k h_n = k a_{k−1}·[ (n−k+1)^{n−k−1}/(n−k)! + k Σ_{j=k+1}^{n} κ_j · 2(n−j+2)^{n−j−1}/(n−j)! ],

여기서 a_{k−1} = k^{k−2}/(k−1)!이다. n = 2k+ν (1 ≤ ν ≤ k)이면 j ≤ n−k인 ν개 항에서만 2(n−j+2)^{n−j−1}/(n−j)!를 참값 (a²)_{n−j}로, (n−k+1)^{n−k−1}/(n−k)!를 a_{n−k}로 바꾸면 된다.

*검산.* `work/code/check_prop7.py`(정확 유리수, k = 3, …, 7): 두 식이 k+1 ≤ n ≤ 2k의 모든 n에서 정확히 성립하고, n = 2k+1에서는 보정한 꼴이 성립한다(`work/out/check_prop7.out`). 실은 A_{k,k−1} = (k+1)^{k−1}(길이 k에서는 변위가 k−1을 넘을 수 없다)이므로 a_k = p_k/k!이고 나무 꼴은 n = 2k+1까지 그대로 맞는다; 검산도 이를 확인했다.

*증명.* m < k에서 a_m = p_m/m! = (m+1)^{m−1}/m!(변위 제한이 걸리지 않는다). 그러므로 m < k에서 (a²)_m = Σ_{i=0}^{m} p_i p_{m−i}/(i!(m−i)!) = (1/m!)Σ_i C(m,i)(i+1)^{i−1}(m−i+1)^{m−i−1} = 2(m+2)^{m−1}/m! (Abel의 항등식 Σ_i C(m,i)(x+i)^{i−1}(y+m−i)^{m−i−1} = (1/x + 1/y)(x+y+m)^{m−1}에 x = y = 1; 같은 말로 [x^{m+2}]T(x)² = 2(m+2)^{m−1}/m!, T는 나무 함수). 정리 1(iii) e = a²L에서 a_nE_n = Σ_j L_j (a²)_{n−j}이고 j ≥ k+1, n ≤ 2k이면 n−j ≤ k−1. 공표 (I-C) η = a·a_{k−1}(x^k + k a K)에서 a_n h_n = a_{k−1}(a_{n−k} + kΣ_j κ_j (a²)_{n−j})이고 같은 이유로 n−k ≤ k−1, n−j ≤ k−1. ∎

*뜻.* 띠에서 노드의 두 항은 **첫 창 k < j ≤ n의 두 가중치 열 L_j, κ_j를 같은 두-나무 핵 2(m+2)^{m−1}/m!로 평균한 것**이다(kh에는 한-나무 항 a_{n−k} 하나가 더 붙는다). 갱신열의 골(§1.3)이니 평탄성이니 하는 유한 크기 정보가 띠에서는 모두 사라지고, 남는 것은 두 가중치 열의 모양이다. L_j/k = pz_{j,1}/j!는 길이 j의 소인 주차 함수 가운데 최대 변위가 k이고 변위 k인 차가 하나뿐인 것의 수(정리 1(vi), 로컬 용어집)이고, κ_j는 공표 핵 K = e^{Q}∫t^ke^{−Q}의 계수다. 2차 모멘트 S_n도 정리 2로 같은 꼴(두-나무 핵과 레졸번트 ĥ)로 쓰인다.

### 7.2 띠의 노드가 묻는 것

명제 7과 정리 5를 합치면, 띠에서 T_n > 0은 "첫 창의 가중치 L_{k+t}, κ_{k+t} (1 ≤ t ≤ k+ν)를 핵 2(n−k−t+2)^{n−k−t−1}/(n−k−t)!로 평균했을 때 (L로 만든 2차 모멘트) ≥ k·a_{k−1}·(κ로 만든 1차 평균 + 한-나무 항)"이다. 핵은 t에 대해 Poisson-류의 봉우리(m = n−k−t에서 (m+2)^{m−1}/m! ≈ e^{m}/(√(2π) m^{3/2})·… )를 가지므로 작은 m, 곧 j가 n에 가까운 쪽(j ≈ n − O(1))의 가중치가 가장 크게 기여한다. 그러므로 띠의 노드는 결국 **j ≈ 2k 근처에서 L_j와 κ_j가 어떤 비율로 자라는가**의 문제다. §4.3의 수치(E²−E ≈ 0.71 → 0.53 kH, Var ≈ 0.53 kH)는 이 비율이 k^{−1/3} 속도로 어떤 극한으로 가고 있음을 말한다.

이 읽기에서 k-균일 증명으로 가는 길은 둘이다.

(가) **첫 창 가중치의 점근.** L_{k+t}, κ_{k+t}의 t ≤ k 범위 점근을 명시적 오차와 함께 얻으면(두 열 모두 Q_k의 지수 적분 꼴이고, j ≤ 2k에서는 Q_k의 절단이 한 번만 끼어든다), 명제 7의 합은 명시적 적분으로 바뀌고 T_n의 k^{1/3} 주항과 오차가 나온다. 이것은 공표 정리 B(r56698e9…)의 "비명시적" 부분을 메우는 일이다. 공표 첫 층 정리(r9d97cea…)와 층 윤곽(r6b37c7e…)이 다루는 양이 바로 이 범위의 A_{n,k}·b_{n,k}이므로, 그 기록들의 방법이 L_j, κ_j에도 닿을 것이라고 본다.

(나) **개수의 단사.** 정리 5로 띠의 노드는 2z_{n,k,2} ≥ B̃_{n,k−1}이다. n ≤ 2k+ν에서 변위 k인 차 두 대는 길이 k+1인 창 두 개가 겹친 자리(두 자리의 간격 ≤ ν)에 있고, B̃의 (α, s)는 길이 k인 창 하나와 바로 앞의 더 큰 차로 이루어진다. 두 집합의 크기 비가 1 + O(k^{−1/3})로 1에 가까우므로 단순한 단사는 기대하기 어렵고, 있다면 요동 규모 k^{1/3}의 구조를 담아야 한다. 이 길은 시도하지 않았다.

### 7.3 부호 지도가 말하는 것

§4.7의 지도는 모멘트 부등식이 n ≈ k + 3√k부터 참이라고 말한다. 노드의 창 2k+41 ≤ n은 그 경계에서 k 가까이 떨어져 있으므로, 띠에서 T_n > 0을 보이는 일은 경계의 정밀한 위치와는 무관하고 오직 규모(k^{1/3})와 상수(0.776)의 문제다. 반대로 (나)의 공표 범위 n ≤ 2k+40(k ≥ 2001, n ≥ 10001)이 비형식 증명된 것과 이 지도가 보여 주는 n ≥ k + 3√k의 양수성 사이에는 아직 아무도 다루지 않은 n ∈ [k+3√k, 2k]의 구간이 있다. 그곳은 노드에 필요하지 않지만, 명제 7의 꼴(n ≤ 2k에서 완전히 명시적)이 가장 깨끗하게 적용되는 곳이므로 (가)의 방법을 먼저 시험해 볼 자리로 적어 둔다.

### 7.4 최대 차 분해: T_n은 블록 크기 사슬 위의 가법 함수다 (정리 8; 증명 완료, 정확 검산)

공표 모멘트 재귀(I-M)는 마지막(가장 큰) 차의 위치 p로 블록을 둘로 쪼갠다. 그 재귀를 T에 대해 쓰면

  T_n = Σ_{p=1}^{n} π_n(p)[T_{p−1} + T_{n−p}] + Φ_n,  π_n(p) := min(p,k)a_{p−1}a_{n−p}/(n a_n),
  Φ_n := 2Σ_p π_n(p)[E_{p−1}E_{n−p} + 1{p>k}(E_{p−1} + E_{n−p})] − k·π_n(k)

이다(S의 재귀에서 k·(H의 재귀)를 뺀 것; T_0 = 0). 양의 재귀의 해는 원천 Φ를 분해 나무를 따라 더한 것이므로:

**정리 8.** (i) N_n(m) := 1{m=n} + Σ_p π_n(p)[N_{p−1}(m) + N_{n−p}(m)] (m ≥ k; 최대 차 분해 나무에서 크기 m인 마디의 기대 개수)라 하면 모든 n에서 T_n = Σ_{m≥k} N_n(m)·Φ_m, E_n = Σ_m N_n(m)·P_big(m), h_n = Σ_m N_n(m)·π_m(k), 여기서 P_big(m) := Σ_{p>k}π_m(p). 크기 m < k인 마디는 Φ_m = 0이므로 기여하지 않는다.
 (ii) n ≤ 2k+1이면 크기 ≥ k인 마디들은 뿌리에서 내려가는 **한 줄의 사슬** M_0 = n > M_1 > ⋯ ≥ k를 이룬다. 크기 m인 마디에서 최대 차의 상대 위치 p ~ π_m(·)에 따라: p ≥ k+1이면 그 마디는 **큰 자리**(용량 p > k; B)이고 다음 크기는 p−1; p = k이면 **문턱 자리**(Θ)이고 다음 크기는 m−k (m ≥ 2k일 때; 아니면 사슬이 끝남); p ≤ k−1이면 다음 크기는 m−p (≥ k일 때; 아니면 끝). 모든 큰 자리와 문턱 자리는 사슬의 마디다. 따라서 Z_k = #{B인 마디}, H_k = #{Θ인 마디}이고 𝓦_M의 양은 **T_n = E[2·#(B 마디의 순서쌍) − k·#(Θ 마디)]**, 사슬 하나의 기대값이다.
 (iii) (진입 분해) 2k ≤ n ≤ 3k+1이면 T_n = R_n + Σ_{j=k}^{2k−1} ε_n(j)·T_j, R_n := Σ_{m∈[2k,n]} N_n(m)Φ_m, ε_n(j) := 크기 ≥ 2k인 부모에서 크기 j < 2k로 처음 들어오는 마디의 기대 개수.

*증명.* (i) 선형 재귀의 중첩: 같은 재귀를 만족하는 Σ_m N_n(m)Φ_m과 T_n은 T_j = 0 (j < k)와 Φ_m = 0 (m < k)에서 일치한다. E, h도 각각 원천 1{p>k}, 1{p=k}의 같은 재귀다. (ii) 두 조각 p−1, n−p의 합이 n−1 ≤ 2k이므로 둘 다 k 이상일 수 없다. 블록의 최대 차의 용량은 블록 안 상대 위치 p다(블록의 왼쪽 경계 바로 앞 자리에 더 큰 차가 있거나 경계가 0이므로). 용량 > k 또는 = k인 자리는 왼쪽 범위만으로 부분나무 크기가 ≥ k이므로 사슬의 마디다. (iii) m < 2k인 마디는 어느 진입 마디 j의 자손이고 그 자손들의 Φ 합의 기대는 T_j다(마르코프 성질). ∎

### 7.5 문턱 근처의 보편 구조: Borel 갱신과 √k 띠 (k = 2001 수치와 그 해석; `work/code/chain_near_k.py`)

문턱 비용 82.8 가운데 77.8이 **문턱 바로 위 띠 t = m−k < 2.7√k**에서 나온다. 그 띠의 구조는 k에 거의 무관하다.

(a) **문턱 확률.** π_{k+t}(k) = k a_{k−1}a_t/((k+t)a_{k+t})이고 t < k이면 a_t = (t+1)^{t−1}/t!, a_{k−1} = k^{k−2}/(k−1)!, a_{k+t} = (k+t+1)^{k+t−1}F_{k+t}/(k+t)! (F_j := A_{j,k−1}·j!/(j+1)^{j−1} = 균등 PF_j에서 Pr(M ≤ k−1))이므로 Stirling으로 k·π_{k+t}(k) = k/(√(2π)(t+1)^{3/2}F_{k+t})·(1 + O(1/t) + O(t/k)). 계산: t = 10에서 21.92 (식: 21.9), t = 50에서 2.40 (식 2.19; F 보정 10%).
(b) **멈춤과 문턱의 비.** 크기 k+t의 마디가 끝나는(두 조각 모두 < k) 확률 P_stop(k+t)에 대해 Pr(Θ | 멈춤) = π_{k+t}(k)/P_stop(k+t) ≈ 1/(2t) (t = 20: 0.0240 대 0.0250; 50: 0.0103 대 0.0100; 100: 0.0055 대 0.0050). 이유: 멈춤 위치 p ∈ (t, k]의 무게 min(p,k)a_{p−1}a_{m−p}는 양 끝에 몰리고 오른쪽 끝(p = k, 문턱) 쪽이 왼쪽 끝보다 k/(t+1)배 무거우며, 오른쪽 끝 근처의 합이 Σ_{s≥t}s^{−3/2} ≈ 2t^{−1/2}로 t^{−3/2}의 2t배다.
(c) **하강 법칙은 Borel 분포다.** 계속되는 마디의 크기 감소 d의 법칙 q_m(d) = (k+d)a_{d−1}a_{m−d}/(m a_m) = τ_d·((k+d)/m)(m/(m−d))^{3/2}(F_{m−d}/F_m)(1+o(1)), τ_d = d^{d−1}e^{−d}/d! (Borel(1)). m = k+400에서 d ≤ 10까지 1–3% 안에서 맞고, 큰 d에서는 F 비가 끼어든다. Borel(1)은 평균이 무한한(안정지수 1/2) 분포이므로 사슬은 거리 t를 ≍ √t 걸음에 내려가고, 그 걸음 거의 모두가 B 마디다(P_big(k+t) = 0.82 (t=20), 0.90 (100–200)). 실제로 E_{k+t} ≈ 0.67√t (t = 10, 20, 50, 100에서 1.94, 2.94, 4.86, 6.67). Borel–Tanner 갱신 밀도 u_m ≈ 1/√(2πm)의 합 √(2t/π) ≈ 0.80√t에 멈춤이 깎은 값으로 읽힌다.
(d) **Φ의 부호 전환과 n₀(k) − k ≈ 2.7√k의 이유.** 한 마디의 원천은 Φ_{k+t} ≈ 2·P_big·E_{k+t−O(1)} − kπ_{k+t}(k) ≈ 1.2√t − k/(√(2π)t^{3/2}); 0이 되는 곳은 t² ≈ k/3, 곧 t ≈ 0.58√k(k = 2001: 26; 계산에서 Φ는 t = 20과 50 사이에서 부호를 바꾼다). T_{k+t}는 거기서 더 내려간 사슬이 모으는 음의 원천까지 더하므로 더 늦게, t ≈ 2.7√k에서 양수가 된다(§4.7). 이것이 모멘트 부등식이 거짓인 띠의 폭이 √k인 이유다: **문턱 비용 k·t^{−3/2}와 쌍 생산 √t의 균형**.
(e) **조건부 법칙의 희소성.** F_{2k+41} = 0.020 (k = 500), 0.0079 (2001), 0.0027 (8000): 창에서 ν_{n,k}는 균등 주차 함수의 1% 안팎의 사건(M ≤ k−1)으로 조건부한 법칙이고, F_{k+k^{2/3}} ≈ 0.65는 k에 무관하다(첫 층의 k^{2/3} 눈금). 조건부가 큰 블록을 벌하므로 분해는 균등 순열보다 훨씬 고르게 쪼개진다(균형 분할의 확률 0.13 대 나무 수 추정 0.004).

**이 그림에서 k-균일 증명이 요구하는 것.** 정리 8(ii)로 띠의 노드는 Borel 하강 사슬의 두 기대값 비교이고, (a)–(c)의 보편 부분(F ≈ 1인 t ≪ k^{2/3})은 나무 수의 Stirling 한계로 명시적으로 쓸 수 있다. 그러나 표가 보여 주듯 쌍의 40%는 t ∈ [k^{2/3}, k/2]에서, 20%는 뿌리 영역에서 나오고 문턱 비용의 94%는 t < 2.7√k에서 나오며, 두 합은 k^{2/3} 규모에서 k^{1/3} 규모의 차만 남긴다(§4.3). 그러므로 필요한 것은 t ≍ k^{2/3}의 전이 윤곽 F_{k+t}(공표 r9d97cea…의 중심 전이 J(t), 정리 A의 명시적 양쪽 한계가 그 도구다)와 거기서의 하강 법칙을 상대 오차 o(k^{−1/3})로 적는 일이다. 공표 기록은 이 전이를 극한 꼴(O_T(k^{−1/6}) 오차항, 비명시적)로 적었고, 이 세션은 그것을 명시화하지 못했다.

### 7.6 시도했으나 닫지 못한 길

- **귀납.** T_n = Σ_p π_n(p)[T_{p−1} + T_{n−p}] + Φ_n에서 n ≥ n₀의 양수성을 작은 n부터 귀납하려면 음의 조각(크기 ∈ [k, n₀))의 기여를 막아야 한다. 균등 나무 수로는 균형 분할이 드물어 그 기여가 O(1)이지만, 실제로는 조건부의 희소성(F_{2k} ≈ 1%) 때문에 균형 분할 확률이 0.13이고 음의 기여가 −17(k = 2001)로 T 자체와 같은 크기다. 귀납 가설이 정량적이어야 하고 결국 (e)의 F 윤곽이 필요하다.
- **거친 부등식.** 뿌리 영역 R_n > 0을 E_j ≥ P_big(j) ≥ k/(ej) 같은 초등 하계로 보이려 하면 2·P_big·E ≥ 0.3 대 k·π(2k) ≈ 1.45로 실패한다; 실제 E_j ≈ 8이 필요하다.
- **개수의 단사(정리 5).** 2z_{n,k,2} ≥ B̃의 직접 대응은 비가 1 + O(k^{−1/3})이라 단순 단사로는 불가능하다(§7.2 (나)).
- **단조성.** T_n은 n에 단조가 아니다(k = 2001: ν ≈ −200에서 극소, n ≈ 2.3k에서 극대, n ≈ 2.65k에서 골). 한 점의 양수성으로 환원되지 않는다.
