## Description

The first value of the kernel $\varepsilon_m = (m-1)^{m-1}/m!$ is $\varepsilon_1 = 1$.

## Statement

$\varepsilon_1 = 1$, where $\varepsilon$ is the sequence of `Parking.eps`.

## Explanation

The value is $0^0/1!$ with the convention $0^0 = 1$. It is the only place where that convention enters the definition of $\varepsilon$.

## Proof

Unfold the definition at $m = 1$.
