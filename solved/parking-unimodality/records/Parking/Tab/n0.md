## Description

For $2\le k\le81$, $n_0(k)$ is the listed row below which the table computes the column $k$, at which it checks the suffix sums of the propagation theorem, and from which on that theorem takes over; it is given by a list of eighty numbers and satisfies $2k+3\le n_0(k)\le2k+14$.

## Explanation

**What the row is for.** For a column $2\le k\le81$ the inequality $b(n,k-1)\le b(n,k)$ has to be proved for all rows $n\ge\max(2k,17)$ (`Parking.small_columns`). The table settles the rows below $n_0(k)$ by computing them, and at the row $n_0(k)$ it checks a condition from which all later rows follow: the nonnegativity of the sums $\sum_{t=s}^{n_0}\xi_tx_k^t$ for $k\le s\le n_0$, the hypothesis of the propagation theorem `Parking.propagate` (see `Parking.Tab.small_table`). So $n_0(k)$ is the place where, in the column $k$, computation ends and the general argument begins.

**How the rows were chosen.** The library records the numbers and proves that the check passes with them; it does not say how they were found, and any row at which the check passes would serve. An exact computation made for this record, outside the library (the last-car recursion in integer arithmetic), found that for each of the eighty columns $n_0(k)$ is the least row $n\ge k$ at which all the sums $\sum_{t=s}^{n}\xi_tx_k^t$, $k\le s\le n$, are nonnegative. This is not a statement of the library.

**The Lean form.** The function is defined for every natural number $k$ as `nth n0tab (k - 2)` (`Parking.Tab.nth`). Outside the range $2\le k\le81$ its values are artefacts of that definition ($7$ for $k<2$, by the subtraction of natural numbers, and $0$ for $k>81$, beyond the end of the list) and are never used.
