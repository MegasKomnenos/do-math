## Description

The numerical inequality $e^{41/60} \le 2$.

## Statement

$\exp(41/60) \le 2$.

## Explanation

In `Parking.caseFar` the rows with offset $0.47k < r \le \frac35k$ are treated with a run of $t_0 = \lfloor\frac{41}{300}k\rfloor + 1$ positive rows. The bound `Parking.P1_le` of the near term asks for a number $E_0 \ge e^{5\sigma}$ with $\sigma = \frac{41}{300}$, and $5\sigma = \frac{41}{60}$. The value is $e^{41/60} = 1.9805\ldots$

## Proof

The library has the bound $e < 2.7182818286$ from Mathlib, hence $e \le 2.7183$. For natural numbers $p$, $q \ge 1$ and $B \ge 0$, the inequality $2.7183^p \le B^q$ implies $e^{p/q} \le B$: indeed $(e^{p/q})^q = e^p \le 2.7183^p \le B^q$, and $q$-th powers are monotone on nonnegative numbers. Here $p = 41$, $q = 60$, $B = 2$, and $2.7183^{41} \le 2^{60}$ is an inequality between rational numbers that is checked by exact arithmetic.
