# 의도 해석

## 목적

사용자 원문·문맥·현재 내부 기록을 대조해 의미 단위의 소유자와 필요한 결정·영향을 식별한다.

## 판단과 산출

현재 `do-math-cli/1`은 사용자 입력마다 의도 해석 실행 하나를 배정한다. interpretation에 원문의 의미와 현재 연구에 미치는 영향을 적고, requested_changes에는 현재 기록·후속 연구에서 바꿔야 할 사항을 적는다. 사용자만 답할 수 있는 결정이 남으면 needs_clarification을 true로 하고 공통 questions에 정확한 질문을 둔다. false이면 실행기가 interpretation을 후보 준비의 입력으로 넘긴다.

이 실행은 별도 checking 단계나 approved·revision_required 판정을 제공하지 않는다. 해석 결과는 사용자 허가 자체가 아니며, 새 효과는 필요한 결정과 현재 권한을 따로 확인한다.
