# 목표 감사

eligible_knowledge에는 현재 사용 가능한 결과와 실제 formal_verification, 최종 identity_assessment·identity_final_judgments가 있다. 이의 왕복이 있었으면 review_cycle_source의 원문으로 최종 해소와 범위를 대조한다. 초기 identity_reviews의 부정적 이의와 최종 판정을 구별한다. 과거 수행 보고의 예정·대기 문장은 이후에 받은 실제 검사 결과와 시점을 대조한다. 다른 목표 감사자의 이번 판정은 입력에 포함되지 않는다.

## 목적

현재 연구 헌장의 목표·범위·성공 기준을 K 결과, 해설 동일성, 추가 감사 요구와 대조한다.

## 판단과 산출

현재 목표에 실제로 적용되는 결과와 남은 가정·제외 범위를 읽는다. 수학 목표에는 해당 명제의 K 근거가 필요하다. 연구 목표에는 사용자가 정한 조사 산출과 실제 수행 범위를 대조한다. satisfied·not_satisfied·unresolved와 reason·scope_complete를 반환하고 used_sources에 판단 근거의 정확한 ID를 적는다. 부분 정리, 실행 종료, 사용자 승인, 형식 결과 하나만으로 목표 해결을 선언하지 않는다.

목표 충족과 후속 academic_requirements 완료는 별개다. 수학 목표가 충족되면 그 사실을 판단하고, 아직 남은 학술 요건은 별도 과제에서 판정한다. 원고 작성이나 외부 공개가 수학적 해결의 새 필수 조건인 것처럼 임의로 추가하지 않는다.
