# 파견문 템플릿

## 사용 설명

이 문서는 수리·병합·심사 파견문의 골격과 슬롯 원천을 정한다. 공통 역할 계약은 임무와 산출 서식을 정한다. 산출 계약은 파일 쓰기·산출 전달·자기 검산 방법을 정한다.

## 작성 지시

1. 아래 템플릿의 `{슬롯}`을 모두 채운다.
2. 해당하지 않는 슬롯에는 「없음」을 쓴다. 예외는 `{분량상한표}` 하나다 — 분량 상한이 없으면 그 슬롯이 선 줄을 지운다.
3. 템플릿에 문장을 더하지 않는다.
4. 채운 파견문을 SKILL.md §9의 경로에 보존한다.

## 슬롯의 값 원천

| 슬롯 | 원천 |
|---|---|
| `{런}` | 작업 디렉토리 경로 |
| `{라운드디렉토리}` | `<런>/라운드N/` |
| `{라운드번호}` | 현재 라운드 번호 N |
| `{동결문}` | `<런>/동결.md` |
| `{사본}` | 산출물이 하나면 `<런>/라운드N/사본.<확장자>`, 여럿이면 `<런>/라운드N/사본/` 한 줄 |
| `{산출물}` | 동결문 「산출물」 절의 좌표 |
| `{기준경로들}` | 동결문 「기준 원문」 절의 원문 경로 전건. 없으면 「없음」 |
| `{담당}` | 동결문 「영역 배분」 절의 그 기 몫. 행 범위는 재정박 뒤 행 번호를 쓴다 |
| `{병합지급}` | `<런>/라운드N/병합지급_<묶음ID>.md` |
| `{심사자번호}` | 1부터 `심사_기수`까지의 기 번호 |
| `{심사대상}` | `<런>/라운드N/심사대상.md` 또는 그 배치의 `심사대상_배치<K>.md` |
| `{산출파일}` | 수리 `수리_<기번호>.md`, 병합 `병합_<묶음ID>.md`, 심사 `심사_<기번호>[_배치<K>].md`의 전체 경로 |
| `{재개산출파일}` | `<런>/라운드N/심사_<기번호>[_배치<K>]_재개<R>.md` |
| `{자기검산명령}` | 수리는 `python .agents/skills/verify-rounds/scripts/vr.py 수리검산 --런 {런} --라운드 {라운드번호} --동결 {동결문} --수리 {산출파일}`. 병합은 `python .agents/skills/verify-rounds/scripts/vr.py 병합자검산 --런 {런} --라운드 {라운드번호} --지급 {병합지급} --병합 {산출파일}`. 심사는 「없음」 |
| `{분량상한표}` | 분량 상한이 있으면 파일별 상한·현재 행 수 표. 없으면 이 줄을 지운다 |
| `{앞라운드들}` | `라운드1/`부터 `라운드N-1/`까지. 라운드 1이면 「없음」 |
| `{남은항목ID들}` | `심사집계`가 낸 남은 항목 ID 전건. 줄마다 `- <항목 ID>`로 적는다 |
