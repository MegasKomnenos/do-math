# 멀티런타임 스킬 사본 동기화 (생성 방식)

이 문서는 런타임 스킬 사본의 구조·생성 절차의 정본이다. 이 파일은 축자 사본으로 미러링되므로 어느 런타임 트리에서 읽어도 같은 내용이며, 여기 적힌 경로는 런타임과 무관하게 저장소 사실이다.

## 구조

- **정본**: `.claude/skills/`. 스킬의 수기 편집은 여기서만 한다.
- **사본(생성물)**: `.agents/skills/`. 생성기가 전량 산출하며 **수기 편집 금지**다. 수기 변경은 다음 생성에서 덮인다. 사본 런타임 세션에서 스킬을 고칠 일이 생기면 정본을 고치고 재생성한다.
- **타깃 diff 디렉토리**: `.agents/diff/`. 사본이 정본과 달라지는 모든 지점의 서식지다.
  - `_rules.json`: 기계 변환 규칙. 치환(`keep`은 이후 치환에서 리터럴 보호), SKILL.md frontmatter 키의 본문 이동, 축자 사본(verbatim) 패턴.
  - `_manifest.json`: 오버레이별 정본 기준 해시. 생성기가 관리하며 수기 편집 금지.
  - `<정본 상대경로>`: **오버레이 문서**. 존재하면 그 경로의 생성물을 이 파일 전문으로 대체한다. 정본에 없는 경로면 타깃 전용 추가 문서로 포함된다.

## 생성기

`.claude/skills/writing-skills/scripts/build_skill_mirrors.py` (테스트: 같은 디렉토리 `test_build_skill_mirrors.py`)

```
python .claude/skills/writing-skills/scripts/build_skill_mirrors.py            # 타깃 재생성
python .claude/skills/writing-skills/scripts/build_skill_mirrors.py --check    # 무변경 드리프트·낡음 검사 (exit 0 = 정상)
python .claude/skills/writing-skills/scripts/build_skill_mirrors.py --bless    # 오버레이 재검토 완료 후 기준 해시 갱신
```

## 타깃 변환 정책 요지 (상세는 `.agents/diff/_rules.json`)

- **.agents** (OpenAI Codex 및 범용 에이전트 런타임): 경로 `.claude/`→`.agents/`, `CLAUDE.md`→`AGENTS.md`, `.claude/settings.json`→`.agents/hooks.json`, frontmatter `argument-hint`·`effort`를 본문 줄(`호출 인자`·`권장 추론 수준`)로 이동.
- **공통 보호**: 검증 스크립트의 게이트 상수(`'/.claude/'`)와 도구 사실 진술(`~/.claude/plugins`, `.claude/commands/` 등)은 치환에서 보호한다. 경로를 바꾸면 거동이 바뀌거나 허위가 되는 지점들이다.
- **축자 사본**: `references/원본_대조.md`(각색 시점 역사 기록), `writing-skills/examples/CLAUDE_MD_TESTING.md`(원문 예제), 이 문서, 미러 생성기와 그 테스트. 생성기 코드는 `.claude` 정본과 `.agents` 타깃을 함께 다루므로 런타임 경로 치환을 적용하지 않는다.

## 오버레이 운용

- 오버레이는 기계 치환으로 표현할 수 없는 **의미 델타**에만 쓴다. 현행 표면: 타 런타임 미실측 기계 거동의 준용 한정 문구, 도구 실명의 대응 기제 치환(SendMessage→메시지, AskUserQuestion→간이 질문 도구). 실측 수치·기계 거동은 실측한 런타임에 한정해 명기하고 타 런타임 판에는 미실측·원리 준용을 명기한다(허위 귀속 차단, M-0282 계열) — 그 문구가 사는 곳이 오버레이다.
- 신설법: 생성물(`<타깃>/skills/<경로>`)을 `<타깃>/diff/<경로>`로 복사한 뒤 의미 델타만 수정하고 재생성한다.
- **낡음 경고**: 오버레이가 있는 경로의 정본이 변경되면 생성기가 경고하고 `--check`가 실패한다. 정본 변경분을 오버레이에 반영(불요하면 반영 불요 판단)한 뒤 `--bless`로 기준 해시를 갱신한다. 확인 없는 `--bless`는 구 수동 절차의 "델타 침묵 소실"을 재현하는 길이므로 금지다.

## 절차 (정본 스킬을 고쳤을 때)

1. 정본(`.claude/skills/`)에서 수정을 완결한다.
2. 생성기를 실행하고, 오버레이 낡음 경고가 있으면 해당 오버레이를 재검토·개정 후 `--bless`한다.
3. `--check` exit 0을 확인한다.
4. 정본 변경 + diff 변경 + 재생성된 사본을 **같은 커밋**으로 커밋한다(commit-harness 절차의 스킬 게이트).

## 신규 런타임 추가

새 타깃 디렉토리에 `diff/_rules.json`을 만들고 생성기의 `DEFAULT_TARGETS`에 등재한 뒤 생성한다.
