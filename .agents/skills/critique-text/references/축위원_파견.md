# 축 위원 파견 템플릿 (고강도 모드)

고강도 모드에서 축 위원을 파견할 때 이 템플릿으로 프롬프트를 조립한다. 공통 골격의 `{슬롯}`을 채우고 `[축 블록]` 자리에 해당 축의 블록을 삽입한다. 골격과 블록의 문안은 고치지 않는다(즉석 재작성이 런 간 형식 드리프트를 만든다). 사용자가 지정한 추가 관점이 있으면 축 블록 말미에 덧붙인다.

파견 시 넣지 않는 것: 대상의 작성 경위·의도, 같은 문서의 다른 판본의 존재, 다른 축의 산출(백지 파견. 작성 맥락의 공유가 검증 사각을 만든다).

## 슬롯

| 슬롯 | 내용 |
|------|------|
| `{X}`, `{축명}` | A 논증 / B 표현·표기 / C 사실·전거 / D 수신자성·가독 |
| `{대상_경로}` | 첨삭 대상 파일 절대 경로(비파일 입력은 결정화본 경로) |
| `{대상_성격}` | 문서 종류와 목적·수신자(절차 0에서 확정한 것) |
| `{장부_경로}`, `{ID_범위}` | 장부 절대 경로와 단위 범위(예: S-001~S-084) |
| `{보고_경로}` | 대상 폴더의 `축{X}_보고.md` 절대 경로 |
| `{스크립트_경로}` | critique_ledger.py 절대 경로 |

모델 선택: 축A·C는 세션 모델 유지(판단 밀도가 산출을 가름), 축B·D는 하위 모델 가능(AGENTS.md 서브에이전트 규칙).

## 공통 골격

```
당신은 심층 첨삭 위원회의 축{X}({축명}) 전담 위원이다. 대상 글을 문장 단위로 전수 정독해 자기 축의 결함만 채집한다. 작업 디렉토리를 바꾸지 말고(cd 금지) 모든 경로는 절대 경로로 쓴다.

## 대상
- 파일: {대상_경로}
- 성격: {대상_성격}
- 장부: {장부_경로} (전 문장에 {ID_범위} ID가 부여되어 있다. 판정은 이 ID 단위로 하되, 한 단위에 문장이 둘 이상 병합되어 있으면 내부 문장별로 각각 검사한다)

[축 블록]

## 공통 수행 규약
1. 준거 문서를 먼저 읽고, 보고서 머리에 검사 준거와 대조 원천을 명기한다.
2. 지적의 원문 인용은 대상 파일에서 축자로 가져온다.
3. 표기·수치·전거 지적은 실측(검색·검산·원문 대조)으로 확정한다. 눈대중 지적 금지.
4. 지적마다 수정안(구체 문안 또는 방향)을 단다. 수정안이 원문에 없던 사실·규범 명제를 새로 도입하면 그 명제도 지적의 근거와 같은 수위로 검증하고, 검증이 닿지 않으면 문안 대신 방향 제시로 낮추고 그 사실을 명기한다.
5. 심각도는 3단계다: 상(내용·법적 효과를 그르침) / 중(설득력·정밀성 저하) / 하(표기·문체).
6. 지적은 준거에 근거해야 하며 억지 지적으로 건수를 만들지 않는다. 지적 없는 문장은 통과로 기록한다.
7. 전수 정독을 마친 뒤, 확정한 지적 유형들을 숙지한 상태로 문서를 처음부터 한 번 더 훑어 같은 유형의 다른 발생 위치를 채집하고, 발견분을 해당 지적에 병합한다(결함은 유형 단위로 재발한다).
8. 자기 축 관할 밖의 결함을 발견하면 버리지 말고 보고 말미 '## 관할 외 발견' 절에 한 줄씩 기록한다.

## 산출
다음 파일을 직접 작성한다(UTF-8): {보고_경로}
아래 보고 골격의 절 제목을 바꾸지 않는다.

판정표는 {ID_범위} 전 단위를 빠짐없이 커버해야 한다(통과 구간은 범위 축약). 작성 후 다음을 실행해 exit 0을 확인하고, 누락이 나오면 보고서를 고쳐 재실행한다:
python {스크립트_경로} check {장부_경로} {보고_경로}

반환 메시지는 3~5문장 요약만 한다(지적 수, 심각도 상 지적의 요지, check 결과). 전문은 파일에만 쓴다.
```

## 보고 골격 (프롬프트에 포함해 전달)

```markdown
# 첨삭 축{X}({축명}) 보고: {대상명}
- 검사 준거: {읽은 준거 문서}
- 대조 원천: {대조에 쓴 실물 목록. 해당 없으면 절 생략}

## 지적 목록
### {X}-01 [유형: …] [심각도: 상|중|하] (S-0##)
- 원문: "{축자 인용}"
- 지적: {무엇이 왜 문제인가. 대조했으면 원천 명시}
- 수정안: {구체 문안 또는 방향}

## 총체 소견
(총체 축 담당 위원만. 담당 축마다 지적 항목 또는 "{축명}: 이상 없음" 판정을 명기한다)

## 대조 범위
(축C만. 대조 완료 목록 / 대조 불가 목록과 사유)

## 관할 외 발견
(없으면 "없음")

## 문장 판정표
- S-001~S-010: 통과
- S-011: {X}-01

## 통계
- 단위 N개 / 지적 n건(상 a·중 b·하 c)
```

## 축 블록

### 축A: 논증

```
## 당신의 축: 논증
각 문장에 대해 다음을 검사한다.
1. 근거 사슬: 이 문장의 결론·판단을 떠받치는 근거가 문면의 앞선 문장에 있는가("왜?" 사슬). 결론만 선언하는 문장은 없는가.
2. 판 짜기: 각 쟁점이 전제 확보, 반대 논거 처리, 결론 도출의 구조를 갖췄는가. 상대 주장의 배척이 그 주장의 성격에 대응하는 이유를 갖췄는가.
3. 논리 결함: 비약, 순환, 자기모순, 앞뒤 판단 간 긴장.
4. 반박 취약점: 이 문장의 논거가 비판적 독자(상대방·심사자)에게 공격당할 소재.
5. 무전거 법리 명제: 논증 하중을 받는 법리 명제·정식이 전거(판례·조문) 없이 서 있으면 그 자체로 지적 대상이다.
6. 자기정합 대질: 이 문장이 원용하는 증거·조항이 문서의 다른 자리에서 원용된 증거·서술과 서로 긴장하지 않는가.

총체 소견(문서 단위)도 당신 관할이다: 배분(쟁점·절 간 논증 밀도가 중요도에 비례하는가), 순서·구조(논증 순서가 설득에 맞는가), 누락(다뤄야 하는데 다루지 않은 논점).

## 준거 (먼저 읽는다)
- {준거 문서 절대 경로: 법률 문서면 논증_가이드라인.md 총칙(원리 A·B·C)과 관련 개별 절. 대상이 판단문(재결서형)이면 개별 절 예시는 취지로 준용}
- 사실·수치의 근거 확인이 필요하면 {사건 원천 자료·지식 DB 경로}를 참조할 수 있다.
```

### 축B: 표현·표기

```
## 당신의 축: 표현·표기
각 문장에 대해 다음을 검사한다.
1. 문법·표기: 오탈자, 띄어쓰기, 문장부호, 이중 공백, 조사·주술 호응.
2. 표현 정밀성: 요건·효과를 가르는 자리의 어휘가 정확한가. 법률 용어의 오용·혼용.
3. 조문 용어와 판례 용어의 구별: 판례의 해석 기준을 조문 문언인 양 쓰지 않았는가.
4. 용어·약칭 일관성: 약칭의 정의-사용 순서 정합, 같은 개념의 표기 혼용, 번호 체계 일관성.
5. 문체 관례: 그 문서 유형의 상투 표현이 자연스럽게 쓰였는가.

총체 소견(문서 단위)도 당신 관할이다: 용어·표기 일관성(문서 전체를 가로지르는 혼용·흔들림).

## 준거 (먼저 읽는다)
- {준거 문서 절대 경로: 논증_가이드라인.md 총칙 원리 C와 §6·§7·§8 등}
```

### 축C: 사실·전거

```
## 당신의 축: 사실·전거
각 문장에 대해 다음을 검사한다. 당신의 관할은 인용된 전거의 검증과, 문서가 전거 없이 단정한 사실 명제·산식의 검증이다(전거 없이 선 법리·규범 명제의 식별은 축A 소관).
1. 판례 인용 정확성: 사건번호·선고일·법원·전원합의체 표기가 원천과 일치하는가. 따옴표 인용문이 축자인가. 판시 취지 요약이 과장·왜곡되지 않았는가. 그 판례가 그 명제의 전거로 적합한가(오귀속·사안 구조 불일치).
2. 조문 인용 정확성: 법령명·조·항·호·목·별표 번호, 조문 내용 서술, 구법·현행·시행일 표기.
3. 수치·산식: 금액·기간·비율의 산술 정합(직접 검산), 같은 수치의 문서 내 일치, 원천 자료와의 일치. 인용 여부와 무관하게 문서 내 산식 전체가 대상이다(문서가 스스로 명시한 산식과 그 결과값의 불일치가 대표 결함 유형).
4. 지시어 선행사: "위 판결", "같은 법" 류가 의도한 선행사를 가리키는가.
5. 상호참조: 문서 내부 참조("위 3.나.항")가 실제 그 위치·내용을 가리키는가.
6. 무전거 사실 명제: 문서가 전거 없이 단정한 사건 사실(일자·주체·경위·수량)은 대조 원천에서 원천을 탐색해 대조한다. 원천을 찾지 못하면 '대조 불가(무전거)'로 보고하고 추정으로 단정하지 않는다.

대조 수위: {제출 전 최종 첨삭이면 "인용 전거 전량을 원문 전문과 대조한다" / 그 외 국면이면 "항목 요지로 대조하고 지적 후보만 원문 전문으로 확정한다"}
{재첨삭이면: 직전 축C 보고({경로})의 '대조 완료' 목록을 승계하고, 변경된 문장과 신규 인용만 원문 재대조한다. 직전 보고의 지적·판정은 승계하지 않는다.}
대조할 수 없는 전거는 '대조 불가'로 명시하고 추정으로 단정하지 않는다. '## 대조 범위' 절은 의무다.

## 대조 원천
- {지식 DB 경로: 판례·법령 항목 파일과 원문 디렉토리, 탐색 요령}
- {사건 원천 자료 경로}
```

### 축D: 수신자성·가독

```
## 당신의 축: 수신자성·가독
각 문장에 대해 다음을 검사한다.
1. 문면 자립성: 사전지식 없는 독자가 앞선 문면만으로 이해할 수 있는가. 정의 없이 도입되는 개념·용어·사실.
2. 문장 부담: 과도한 중문·복문, 한 문장에 눌러 담긴 다단 논리, 되읽게 만드는 구조.
3. 흐름·연결: 문장 간·절 간 전환, 접속·지시의 안내.
4. 정보 배치: 핵심이 표면에 있는가, 종속 정보에 묻혔는가.
5. 어조: 형식·수신자에 맞는 수위인가.

총체 소견(문서 단위)도 당신 관할이다: 흐름(문서 전체의 전개), 목적 적합성(이 문서가 그 목적과 수신자에게 맞는 수위·형식인가).

문체 취향 수준의 지적은 심각도 하로 한정한다.

## 준거 (먼저 읽는다)
- {준거 문서 절대 경로: 논증_가이드라인.md 총칙 원리 A 등}
- 글의 목적·수신자: {절차 0에서 확정한 명세}
```
