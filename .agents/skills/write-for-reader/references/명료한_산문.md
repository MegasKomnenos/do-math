# 명료한 산문

사람이나 AI가 글의 사실, 관계, 조건을 한 가지 의미로 읽게 쓴다. 문장 길이나 문단 수는 목표가 아니다. 수신자의 해석 선택지를 줄이는 방법을 고른다.

## 낱말과 개념

- 같은 대상은 같은 낱말로 부른다. 문체를 바꾸기 위해 동의어를 쓰지 않는다.
- 한 낱말을 한 글 안에서 두 뜻으로 쓰지 않는다. 두 개념을 구분해야 하면 다른 이름을 준다.
- 수신자가 모를 수 있는 용어는 처음 쓸 때 정의한다. 정의는 현재 글에서 쓰는 뜻과 경계를 말한다.
- 비슷한 범위의 개념에 같은 이름을 주지 않는다. 물리 파일과 논리 기록처럼 수신자가 구분해야 할 단위를 이름으로 드러낸다.

## 문장

- 한 문장에 하나의 주요 주장이나 지시를 담는다. 여러 내용이 범위, 순서, 필수 여부를 흐리면 문장을 나눈다.
- 행위자, 행위, 대상을 드러낸다. 행위자가 중요하지 않거나 알 수 없을 때만 피동을 쓴다.
- 행위는 동사로 쓴다. `검토를 수행한다`보다 `검토한다`가 행위를 분명하게 말한다.
- 조건을 행위보다 먼저 쓴다. 예외는 적용할 규칙 옆에 둔다.
- 지시대명사가 두 대상 이상을 가리킬 수 있으면 명사를 다시 쓴다. 앞 문장 전체를 `이것`으로 받지 않는다.
- 은어, 관용구, 강조어가 필요한 의미 대신 해석 선택지를 늘리면 일반적인 표현으로 바꾼다.

고정된 어절 수로 문장을 판정하지 않는다. 문장이 길어도 주제와 관계가 하나로 읽히면 유지할 수 있다. 짧은 문장이 필요한 주어나 조건을 생략하면 고친다.

## 문단과 배치

- 문단 하나에 주제 하나를 담고, 첫 문장에 그 주제를 드러낸다.
- 새 주제, 판정 단계, 정보의 기능이 바뀌면 문단을 나눈다.
- 앞뒤 관계를 수신자가 추론해야 하면 원인, 결과, 대조, 예외를 드러내는 연결어를 쓴다.
- 여러 항목을 비교하거나 순서대로 수행하면 표나 수직 목록을 쓴다. 계층이 의미를 드러내면 목록 중첩을 허용한다.
- 결론, 현재 상태, 할 일 중 수신자가 먼저 알아야 할 내용을 먼저 둔다. 그 다음에 영향, 근거, 조건, 예외를 둔다.

## 수신자에게 필요한 정보

작성 전에 네 가지를 정한다. 누가 읽는가. 읽고 무엇을 판단하거나 할 것인가. 수신자는 이미 무엇을 알고 있는가. 어떤 상황에서 읽는가.

수신자가 판단·행동·검증하는 데 필요한 전제와 인과관계를 준다. 작성자가 알고 있는 양이나 작성에 들인 노력으로 분량을 정하지 않는다.

정보를 다른 정본에 두려면 수신자가 안정적으로 접근할 수 있어야 한다. 현재 글의 판단에 필수인 사실과 예외는 포인터만 남기지 않는다.

## 쓰지 않는 것

- 조사 중의 놀라움, 시행착오, 자기평가를 산출물에 옮기지 않는다. 확정된 사실, 판단 근거, 필요한 조치를 쓴다.
- 중요성을 비유, 감정, 반전, 강조어로 연출하지 않는다. 영향과 근거로 드러낸다.
- 이미 기각한 주장을 `A가 아니다`로 바꾸어 현행 글에 남기지 않는다. 수신자의 선택지에서 A를 실제로 제외해야 할 때만 금지 조건을 쓴다.
- 작성 경위가 목적인 기억 노드와 결정 기록에는 재발 방지에 필요한 경위를 남길 수 있다. 이 경우에도 정리하지 않은 사고 과정은 쓰지 않는다.

## 퇴고

1. 원문에서 행위자, 대상, 사실, 원인, 결과, 수치, 범위, 조건, 예외, 책임, 불확실성을 먼저 고정한다.
2. 뜻이 불분명하면 매끄럽게 추측하지 않는다. 원문이나 사용자에게 확인한다.
3. 새 문구만 보지 않고 문장, 문단, 절, 문서 전체의 정합성을 점검한다.
4. 사용자가 결정을 바꾸면 옛 문장을 삭제한다. 새 결정이 바꾸는 범위, 기준, 예시, 완료 조건을 함께 고친다.
5. 문장을 지웠을 때 수신자의 판단·행동·검증에서 사라지는 것이 없으면 지운다.

사용자가 퇴고 과정을 요청하지 않았으면 지운 문장과 작업 서사를 따로 보고하지 않는다. 필요한 전제, 불확실성, 검증 결과, 출처 한계는 남긴다.
