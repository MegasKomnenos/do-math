## 임무

1. 불변식 파일 4건을 먼저 읽는다.
2. 작업 디렉토리와 Python 3.11 런타임을 실측한다.
3. `pip`와 현재 설치된 로컬 패키지 관리자를 열거한다. 새 패키지 관리자는 설치하지 않는다.
4. 공식 프로젝트 문서·공식 릴리스·공식 패키지 색인에서 Python 패키지 4종, z3, 최소 SAT 후보 4종의 배포 경로를 조사한다.
5. PySAT은 import 이름 `pysat`과 공식 배포 이름을 구별해 기록한다. 이름이 다르면 둘을 한 행에서 연결한다.
6. 설치되지 않은 승인 Python 패키지는 공식 배포 경로를 사용해 설치를 시도한다.
7. SAT·SMT 실행 파일 후보는 현재 설치된 로컬 패키지 관리자 또는 공식 사전 빌드 배포 경로로 확보 가능한지 판정한다. 확보 가능이면 설치를 시도한다.
8. 설치 실패를 숨기지 않는다. 명령, exit code, 오류 요지, 대체 수단, 갱신 트리거를 기록한다.
9. WSL·컨테이너·새 패키지 관리자·소스 빌드를 사용하지 않는다.
10. Lean 4·Coq/Rocq·Isabelle/HOL을 검색·설치 명령의 대상으로 넣지 않는다.
11. Python 패키지 스모크는 실제 import와 최소 해법을 실행한다. 버전 문자열만으로 PASS하지 않는다.
12. z3 실행 파일과 SAT 실행 파일은 SAT·UNSAT 입력을 각각 실행한다. 버전 문자열만으로 PASS하지 않는다.
13. 스모크 코드와 테스트는 결과를 고정값으로 복제하지 않는다. 실제 실행 파일과 import 표면을 호출한다.
14. 원시 로그에서 크리덴셜 값과 PII를 제거한다. 제거 후에도 명령, 도구, exit code, 표준 출력·오류의 판정 근거를 보존한다.
15. Markdown 연구 문서와 보고는 한국어 산문으로 쓴다. 수식이 있으면 LaTeX로 쓴다. 소스 코드와 원시 로그에는 산문 형식 규칙을 적용하지 않는다.
