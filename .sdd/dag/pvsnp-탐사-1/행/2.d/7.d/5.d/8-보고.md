## §2 Playwright 조작 수단

Playwright MCP 서버는 이 실행 환경에 등록되어 있지 않았다. 프로젝트 `.mcp.json`은 `dag-measure` 서버 하나만 등록한다. 사용자 수준 `~/.claude.json`의 `mcpServers`는 빈 객체다. `~/.claude/plugins/installed_plugins.json`은 `ponytail` 플러그인만 설치 상태로 두고, playwright 플러그인은 마켓플레이스 캐시에만 있고 설치·활성화되어 있지 않다.

그래서 Python 패키지 `playwright`를 설치해 그 동기 API로 브라우저를 직접 조작했다.

```

python -m playwright install chromium
  → Chromium 및 winldd 1007 내려받기 완료
```
