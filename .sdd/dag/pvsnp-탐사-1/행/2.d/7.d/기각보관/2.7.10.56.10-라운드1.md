# 기각 보관

## R1-03

제목: 안전 속성 세 건이 산출물 18건 전체에 승계되지 않는다

### 위치
직후 검증런 15건의 61행은 기존 `records/` 본문과 원장의 판독 열 비열람, 구독 원문 저장소 비편입만 적고 크리덴셜 비인용을 적지 않는다. 행 60의 85행은 앞선 판독 봉쇄의 대상 좌표를 적지 않는다. 행 55의 53행은 앞선 판독 봉쇄를 `봉쇄`로만 적는다. 파견표에는 세 안전 속성 문면이 없다.

### 기준
`C:\math\.sdd\dag\pvsnp-탐사-1\행\2.d\7.d\10.d\56.d\불변식.md` 22~23행은 다음과 같이 정한다.

```
문면: 앞선 판독 봉쇄, 크리덴셜 비인용, 구독 원문 저장소 비편입을 수리 행·적용 검증런·신규 게이트 행 전건에 승계한다.
목적: 충족성 수리가 기존 안전 속성을 약화하지 않게 한다.
```

`C:\math\.sdd\dag\pvsnp-탐사-1\행\2.d\7.d\10.d\56.d\10.d\동결.md` 「불변식 목록」 4항은 다음과 같이 정한다.

```
안전 속성 세 건 — 크리덴셜 값 비인용, 구독 원문 저장소 비편입, 앞선 판독(`records/`·원장 판독 열) 비열람 봉쇄 — 를 15건 검증런과 행 `60`의 크리티컬 영역 문면이 승계한다.
```

### 영향
크리덴셜 비인용을 적지 않은 직후 검증런은 크리덴셜 값을 산출물에 넣지 않는지 검사하지 않는다. 행 60은 금지한 앞선 판독 대상을 특정하지 않는다. 행 55와 파견표는 하류 행을 여는 문서이지만 세 안전 속성을 같은 문면으로 전달하지 못한다.
