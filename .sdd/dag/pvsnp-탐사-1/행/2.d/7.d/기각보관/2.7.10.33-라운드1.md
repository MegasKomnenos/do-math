# 기각 보관

## R1-02

제목: R1-1 — 포함 장벽의 오라클 배치가 Definition 2.3과 반대다

### 위치
`research/pvsnp/literature/readings/L16.md` 54행 C11과 110행 E2. 두 행은 \(\mathrm{P}\ne\mathrm{NP}\) 포함 장벽의 반증 세계에서 확장 오라클과 불리언 오라클을 받는 계급을 서로 바꾸었다. 기준 원문은 PDF p. 9 Definition 2.3과 p. 23 Theorem 5.1이다.

### 기준
`C:\math-artifacts\pvsnp-탐사-1\2.7\originals\public\L16-L22\L16-algebrization.pdf` p. 9 Definition 2.3은 다음과 같이 정한다.

```
We say the complexity class inclusion C ⊆ D algebrizes if C^A ⊆ D^Ã is true for all oracles A and all finite field extensions Ã of A.
```

같은 PDF p. 23 Theorem 5.1은 \(A\)를 PSPACE-완전 언어로, \(\widetilde A\)를 그 유일한 다중선형 확장으로 두어 포함 장벽을 세운다. 따라서 포함 \(\mathrm{NP}\subseteq\mathrm{P}\)의 대조는 \(\mathrm{NP}^{A}\subseteq\mathrm{P}^{\widetilde A}\)여야 한다. `C:\math\.sdd\dag\pvsnp-탐사-1\행\2.d\7.d\10.d\32.md` 9~10행은 모든 내용 주장의 지급 원문 좌표 결속과 PASS 상태의 완료 기준 충족을 요구한다.

### 영향
C11과 E2의 현재 문면은 Definition 2.3이 정한 포함 장벽이 아니라 반대 오라클 배치의 명제를 독자에게 대조하게 한다. 그러면 \(\mathrm{P}\ne\mathrm{NP}\) 후보의 안정성 검사가 원문의 반례 세계를 사용하지 못한다. 이 오류가 남으면 32.md의 완료 기준 (3)이 닫히지 않으므로 재판독 상태 PASS의 근거도 없다.
