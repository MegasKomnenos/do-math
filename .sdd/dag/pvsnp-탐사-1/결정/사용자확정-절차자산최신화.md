# 절차 자산 최신화와 현행 DAG 소급 적용

## 브리핑

사용자는 `C:\general`의 최신 절차 자산 커밋을 `C:\math`에 동형으로 적용하라고 지시했다. 사용자는 새 절차가 현행 국면 `.sdd/dag/pvsnp-탐사-1`에 요구하는 변경도 탐색하고 적용하라고 지시했다.

`C:\general`의 최신 커밋은 `ce9ef67c3a0ef4f680ce12940dbef9a725254bfe`다. 이 커밋은 do-dag와 verify-rounds를 함께 바꾼다. 주요 변경은 세 가지다.

1. 발견 항목은 산출물 안의 문제와 산출물 밖의 근본 원인을 함께 가져야 한다. 산출물 파일만 고쳐 기준을 충족할 수 있으면 조각 항목으로 처리한다.
2. 검증런의 기각·무처분 항목은 worktree 소유 노드의 런 디렉토리 `기각보관/`에 보존한다. 노드 싱크 직전의 검토전개가 보관 항목을 다시 판정한다.
3. 모델 문맥 예산은 sonnet 200k, opus·fable·Codex 모델 세 종류 250k로 바뀐다.

적용 대상은 `C:\general` 커밋 `ce9ef67`이 바꾼 `.agents/skills/do-dag`, `.agents/skills/verify-rounds`, `.claude/skills/do-dag`, `.claude/skills/verify-rounds`의 diff 전문이다. 현행 DAG 소급 대상은 상태가 `완`·`비준`이 아닌 행과 아직 닫히지 않은 worktree 노드다.

## 메인 결정 (사용자 축자 아님)

1. 절차 자산은 `ce9ef67`의 절차 경로 diff를 그대로 적용한다. `C:\general`의 프로젝트 기억 노드 `M-0004`는 복사하지 않는다. 적용 뒤 전거 검사가 지목한 누락 정본 `.agents/hooks.json`을 추가한다. 이 파일은 `.claude/settings.json`의 세션 훅 등록을 `.agents` 런타임 경로로 옮긴다.
2. 상태가 `완`·`비준`인 행 파일과 불변식 슬롯은 고치지 않는다. 새 계약은 경로 참조를 통해 미착수 행에 적용한다.
3. 완료된 검증런 여섯 건의 기각·무처분 55건은 `행/2.d/7.d/기각보관/`에 소급 보존한다. 이전 종료 정리로 항목 전문과 심사 전문을 복원할 수 없으므로, 장부에서 회수한 위치·제목·정족·최종 처분과 원장 좌표를 보존한다. 검토전개는 현재 실물을 다시 측정한다.
4. 미착수 검증런 `2.7.5.9`, `2.7.5.10`, `2.7.5.13.3`, `2.7.6`은 같은 기각 보관 경로를 받는다.
5. 아직 닫히지 않은 노드 `2.7.5.12.5`, `2.7.5.12`, `2.7.5.13`, `2.7.5`, `2.7`에 기각 보관 검토전개와 무작업 싱크를 추가한다. 앞선 검토 보고를 다음 검토가 읽어 같은 항목을 다시 판정하지 않게 한다.
6. 기존 발견이 만든 완료 행과 진행 기록은 역사로 보존한다. 미착수 검토전개 `2.7.5.13`은 현행 발견 기준으로 다시 판정한다. 확인된 제품 결함은 분류 이름이 바뀌었다는 이유만으로 버리지 않는다.
7. 모델 배정은 바뀌지 않는다. 새 예산은 완화이므로 기존 분해를 합치지 않는다. 미착수 행의 예산 블록은 새 상한으로 다시 측정한다.

## 전파 (메인 기입 — 실행 중 결정만)

- 불변식 문면: 영향없음 — 프로젝트 불변식 문면을 정정하지 않는다. 절차 계약은 스킬 경로가 나른다.
- 미착수 행 파일: 영향있음 — 검증런 4건에 `기각 보관:` 슬롯을 추가한다. 기각 보관 검토전개 5건을 새로 쓴다. 미착수 파견문의 예산 블록을 새 모델 예산으로 다시 측정한다. `.agents/hooks.json`을 추가해 활성 국면 재정박과 격리 잔재 고지를 등록한다.
- 파견표 행 집합·선행: 영향있음 — 검토전개 `2.7.5.12.5.2`, `2.7.5.12.6`, `2.7.5.13.4`, `2.7.5.14`, `2.7.9`와 각 무작업 싱크를 추가한다. 각 노드 싱크의 선행을 새 무작업 싱크로 결선한다.
- 파견표 모델 열: 영향없음 — 새 행은 현행 mixed 전개 배정과 사용자 확정 fable 대체에 따라 `gpt-5.6-sol med`를 쓴다.
- 이음새 원장: 영향없음 — 제품 노드 간 계약은 바뀌지 않는다.
- 기준선 미결 · 재량 위임 조항: 영향없음 — 연구 기준선의 미결과 재량 위임을 바꾸지 않는다.
